# Nomi v0.23.0 — 逐张确认，说到做到

这一版主要改了生成前确认那一步：你点了什么就生成什么，停下来就真的停，拿不准的时候直说拿不准。

## Agent 生成前的确认卡（#947）

- **每张单独决定**。Agent 一次要生成几张时，确认卡上每张都可以选「生成这张」或「去掉这张」，也可以一键「生成剩下 N 张」。底部写「N 张 · 合计」。
- **中途点 × 就停**。停下后照实告诉你「发出了 K 张，剩下 N−K 张没发」。Agent 收到的回执，和服务商实际收到的张数一致。

## 网络出问题时不重复提交（#962）

- **请求发出去以后连接断了，不再自动重发。** 这时 Nomi 不知道服务商有没有收下，节点上会写「这一镜可能已被服务商收下，结果没法确认」，请你先去服务商后台看一眼。确认没有这一笔，再点「我核对过了，重新生成」。
- **只有确定没发出去才会自动重试**，比如连都没连上。
- **提交卡住会超时。** 服务商接了请求却一直不回话时，约 2 分钟后停下，同样标成「结果没法确认」，不会一直挂在「生成中」。
- **生成到一半关掉 Nomi，重启后会标成「结果没法确认」**，不会永远转圈，也不会自动再发一次。
- **Agent 不会自己去重试**。它读到的状态会写明「不要再生成这一镜，由用户核对后决定」。
- 任务中心里，这一笔会显示服务商、模型和提交时间，方便你去后台对照。

## 用国内地址也能传参考图（#968）

- **APIMart 改成国内接口地址后，带参考图生成时，参考图也会走你填的地址。** 以前参考图上传固定走国际域名，不翻墙就传不上去，带参考图的生成会失败。

## 生成途中切项目（#966）

- **画布上单点生成时，切到别的项目再切回来，节点还显示「生成中」。** 以前这时节点会显示成空闲，底栏还会冒出「生成全部」，点下去会再提交一次。
- **同一个节点，上一次生成还没回来时，不会再发第二次。** 再点会提示「这个节点还在生成」，这一次不会发出去。
- **打开项目时，已经出完、但还没落到画布上的结果会自动补上。** 以前要靠重启也不一定补得回来。

## 画布和制作流程不再抢同一镜（#921、#934、#940）

- **同一镜只认一个主人。** 以前画布和制作流程（分镜批次、Agent 确认卡）各自判断「这一镜归谁」，有几条路会让同一镜生成两次。现在两边都问同一处。
- **制作流程停下时，原因写的是实际发生的事。** 你放行以后会真的开拍；返工、续拍都按失败原因用大白话说明。
- **每个镜头的状态都有自己的标记。** 没点过的镜头不会显示成「排队中」。

## 画布

- **节点更清爽（#953）。**
  - 出了 2 版以上才显示「N 版」。
  - 重拍挪到了悬浮工具栏。
  - 「已保存」3 秒后自己消失。
  - 草稿标题按顺序编号。
- **节点工具栏一行放得下（#969）。** 图片节点：裁切▾（裁剪、四视图、九宫格）、抠图、变换▾、画板；视频节点：抽帧▾（首帧、尾帧）、拆解▾（按镜头拆、拆成镜头表）。去掉了「建参考卡」和「AI 编辑」（拆解元素、改字）。参考卡上的「定妆」照旧。
- **分镜所见即所发（#939）。** 每一镜发出去的，只有这一行里写着的提示词和看得见的参考图。
- **生成失败会说清楚（#938）。** 写明是哪一步、因为什么失败，以及问题出在谁那边。
- **修好「正在存到你电脑上」卡住（#924）。** 结果地址返回了不该收的内容时（比如错误页），以前会一直停在这一步，点停止也没用；现在会明确失败，告诉你原因。
- **图片连到视频节点，默认进参考模式（#918）。** 你已经手动选了首尾帧的，不会被改掉。

## Agent

- **长对话不会撞上限（#945）。** 写回画布时如果位置已经变了，会直接告诉你「没有执行」，不会把后面的写入全挡住。
- **界面上不再露出服务商的原始 JSON、分类标记和内部编号（#952）。**
- **附件、默认模型、分镜表各回各位（#937）。** 修好了几处串位。

## 模型

- **同一个模型只列一次（#926）。** 经不同渠道接进来的同一个模型，合并成一行，不再列好几次。默认用哪一家，不会被悄悄换掉。
- **Sora 2 下线（#926）。** OpenAI 已于 2026-09-24 关停 Sora 2。旧项目里的 Sora 2 节点还能打开，点生成会提示「这个模型已经下线了」，换一个模型就能接着用。

## 外部 AI 工具连 Nomi（#916）

- **修好了 Windows 上的一个问题：关掉 Nomi，过半小时左右窗口又自己弹出来。** 现在外部 AI 工具只是来看看 Nomi 在不在时，不会把 Nomi 打开。真要调用 Nomi 干活时，Nomi 在后台启动，不弹窗。

## 安全

- **带着密钥的请求不会跟着跳转走（#935）。** 防止密钥被带到别的网址。
- **只有正式安装版会注册 `nomi://` 链接（#956）。** 测试版和隔离运行的实例不会抢走它。

## 文案

- **不再说保证不了的话（#957）。** 「免费」「没有扣费」「未消耗」这类说法都去掉了：用的是你自己的服务商账号，扣没扣费只有服务商说了算。

## 已知问题

- **点 × 有时停得慢。** 主进程偶尔会卡上几秒，一批只有 3 张时，可能还没停下就发完了。不会发出你没点过的。下一版修。
- **断网恢复后点「重试」，有时提示「已经重做到上限了」。** 没发出去的那几次也被算进了重试次数。可以先用「我核对过了，重新生成」，或者新建一个节点。下一版修。
- **确认卡上 @ 参考图，和画布上还不完全一样。** 列不出本项目画布上已有的图。下一版补齐。
- 模型能不能用，仍然取决于你自己的服务商账号、权限和额度。

## What changed

Confirm each shot one by one. Stop means stop, and when Nomi is unsure it says so.

### Agent confirmation card

- **Decide per shot**: Pick "Generate this" or "Skip this" on each shot, or generate the rest in one click.
- **Closing stops it at once**: After a stop, Nomi tells you how many were sent and how many were not.

### No duplicate submits on a bad network

- **No automatic resend after a dropped connection**: Nomi cannot know whether the provider received the request, so the node says the result cannot be confirmed and asks you to check the provider first.
- **Submits time out**: A request the provider never answers stops after about two minutes and is marked the same way.
- **Restarting mid-generation**: The shot is marked unconfirmed instead of spinning forever or being sent again.

### Canvas and production

- **Switching projects mid-generation**: A node that is still generating keeps showing that, and Generate All no longer submits it twice.
- **One owner per shot**: The canvas and the production flow now ask the same place who owns a shot, so a shot is not generated twice.
- **Cleaner nodes and a one-row toolbar**: Fewer badges, retake in the floating toolbar, and a toolbar that fits on one row.
- **Failures explain themselves**: They say which step failed, why, and whose side the problem is on.

### Models, providers and security

- **Each model is listed once**: The same model reached through several providers is merged into one row.
- **Sora 2 is retired**: Old nodes still open and ask you to pick another model.
- **A Windows window that popped back up is fixed**: External AI tools merely checking on Nomi no longer open it.
- **Requests carrying a key no longer follow redirects**: The key cannot be sent to another address.
- **Installer is 18% smaller**: 333.8 MB down to 272.4 MB.
- **Wording**: Claims such as "free" or "not charged" are removed, because only your provider decides billing.

### Known issues

- **Clicking stop can be slow**: With a batch of only three, all three may be sent before it stops. Nothing you did not click is sent. Fixed next release.
- **Retry after reconnecting may say the limit is reached**: Use "I checked, regenerate" or create a new node. Fixed next release.
