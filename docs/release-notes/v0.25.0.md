# Nomi v0.25.0 — 一个账户几步接好模型，发送键先看约价，画布能拍样片和拆图层

这一版把连接模型、看花费和画布出片顺了一遍：第一次打开不再等 13 秒开屏动画，连一个 APIMart 账户就能用对话、出图和出视频，粘贴 Key 自动核对余额并回到你正在写的草稿；画布发送键旁直接显示这次大约花多少积分，视频能先出 480p 样片看动作再一键出 1080p 高清，图片能拆成独立图层进画板改。Nomi 入口从右下角悬浮球搬到了顶栏最右，窗口最窄能缩到半屏并排用；位置和行为有变化的地方，文末「升级须知」逐条写了老用户怎么过。

## 接入模型与看清花费

`![待补：整窗「连接 APIMart」页与粘贴 Key 后的四项自动检查](待补)`

- **一个 APIMart 账户几步接通全套模型**：第一次打开还没有项目和模型时，项目库首屏直接给出接入主卡；在画布生成框、分镜行或 Agent 面板遇到「未连模型」点「连接模型」，也会打开同一张整窗「连接 APIMart」页，按 Esc 返回时刚写的提示词草稿一字不丢。点「打开官网」在浏览器注册并复制 Key，回来粘贴就会自动核对 Key 有效、账户余额、这把 Key 的额度与可用模型数，四项通过后自动回到原处；账户余额为 0 时停在充值提示卡，充好切回窗口自动重查。（#1650、#1653、#1660）
- **发送键旁直接显示这次大约花多少**：在画布节点选 APIMart 模型（含 Seedance 2.5 文生视频）调参数时，发送键旁实时显示预计积分数，点旁边的小箭头可切换积分、人民币、美元三种单位；账户余额不够这次预计花费时，同一排直接提示差多少并给出「去充值」；算不出价格时只显示发送箭头，不印假的 0。（#1591、#1624、#1687）
- **设置页账户卡与单价页（待合入）**：打开「设置 › 模型」，顶部直接展示 APIMart 账户余额、这把 Key 的可用额度和近 7 天本机积分花费；点「用量与单价」可看今天、近 7 天、近 30 天的本机消耗记录与常用图片、视频模型的公开参考单价，左侧新增「AI 策略」集中管理默认模型与上传隐私开关。（#1665）
- **「自动」写明是哪个模型（待合入）**：在模型菜单和默认模型设置里选「自动」时，后面直接写出这次实际会调用的具体模型名，不再让人盲猜；默认生成模型从四行简化成图片、视频两行。（#1698）
- **填好密钥保存就能用，不再卡在「验证」**：在设置里填好 API Key（未被服务商明确拒收）且请求格式齐全的模型，保存后在设置、画布、分镜和 Agent 各处立即标为可使用，去掉了「测试连接 / 继续验证」关卡；如果以前配过 Key 只是把文本模型关了，打开 Agent 面板点一下「启用」就能当场恢复对话。（#1560、#1653）
- **开着代理或连本机、局域网服务不再被拦**：开启系统代理工具或连接本机、局域网里的自建服务（含免密钥的本地生成服务和本地 Codex 生图）时，提交生成与取回成片都能正常走通；参考文件过大撞上上传通道体积上限时，错误卡会写明文件名、体积和哪条通道装不下。（#1496、#1636、#1669）

## 画布、样片与生成框

`![待补：Seedance 2.5 样片模式节点下方的剩余有效期与「出高清」按钮](待补)`

- **样片模式（待合入）**：视频模型菜单在 Seedance 2.5 下方新增「Seedance 2.5（样片模式）」，先花少量积分出一条 480p 样片看动作和构图；72 小时内满意了，直接在原节点下方点「出高清」一键出 1080p 正片存成第 2 版，样片留作第 1 版且等待期间照常能看；同一条样片点第二次「出高清」会先弹框确认。（#1702）
- **图层分离（待合入）**：在已出图的图片节点浮条点「改图 ▾ → 图层分离」，右侧会连出一张新节点；点发送一次花钱把图片拆成底图和多层独立透明图层（发送键印「≤」上限约价，按实际拆出的层数结算），打开画板即可单独选层、按比例拖角缩放、删层或接着手绘，点「完成」存成新一版。（#1703）
- **图片浮条一键生成视频，选卡不再放大切边或假等待**：已出图的图片节点浮条最前面新增「生成视频」，点一下就在右侧建好连着首帧的视频卡并自动对齐首帧画幅，等你点发送才花钱；首次进画布不再放大到 188% 把下方生成框切出屏幕，单选靠边卡片时画布自动平滑移入视野，上游已有出图时不再误报「等上游产出后继续」。（#1668）

`![待补：图层分离派生节点与画板内独立图层编辑界面](待补)`

- **生成框底栏亮明「生成方式」与「高级设置」**：视频节点的生成方式挪到底栏模型右侧，按连进来的参考图或视频自动切换（文生视频、图生视频、首尾帧、全能参考等），切方式不丢以前填过的参数；同一模型的不同速度与质量版本直接并进模型菜单，常用参数一次摊开不再滚小窗，种子、水印、输出格式、内容审核、返回尾帧收进底栏右侧「高级设置」图标，拉宽窗口时早先收起的参数摘要会自动放回。（#1489、#1493、#1517、#1525、#1562、#1591）
- **补充新一代模型并修准画幅与参数**：模型目录新增与补齐 Seedance 2.5、Seedream 5.5 / 5.0 Pro、可灵 4.0 / 4.0 Flash、MiniMax H3 / H3-Max、GPT Image 2.6 两档、Nano Banana 2.1 系列、FLUX 3、Wan 3.0 Prime、Vidu Q4 Preview、PixVerse v6、Suno V6 系列、Lyria 3.5 及 GPT-6 系列文本模型；可灵 4.0 Flash 视频编辑和 GPT Image 改图默认选「自动」跟随原素材画幅，Seedance 2.0 与 Wan 3.0 挂了参考素材可免填提示词，分镜行选 12 秒时行上显示、约价和实际发出一致，缺必填参考图时在点发送前直接灰掉并写明缺什么。（#1436、#1443、#1510、#1526、#1531、#1567、#1605、#1609、#1621、#1669）
- **点一次只交一单，关窗或重启也能找回已受理的成片**：画布点一次生成只提交一笔，遇到网络波动不自己在后台重发；只要服务商、本地 ComfyUI 或自定义脚本已收下任务（或已返回同步图片和音频），哪怕中途关窗、断网、换默认模型或重启 Nomi，重开项目后都能顺着原单把成片拉回来，不会重复扣费；服务商明确返回余额不足时当场停下直说，不再连试三次。（#1617、#1635、#1638、#1642）
- **一次出多份全留住，删某一版不弄丢别处还在用的原图**：一次生成多张图片或多段音频时全部收进这个节点的版本历史，配音和音效也直接存进项目素材；在节点多版本宫格里删掉某一版只从这张卡上移除，原文件留在项目素材库里，分镜或时间轴还在用的画面不会裂开；去素材库删原文件在提示期内也能按 Ctrl/⌘+Z 恢复，整组节点都在生成或待取回时批量入口统一置灰说明原因，失败后点「再发一次」确认只重发那一笔。（#1437、#1442、#1454、#1457、#1559、#1564、#1568、#1575、#1576）
- **新建节点整张露全，加空间节点与移多版本卡不再点空**：在笔记本屏上新建图片和视频节点，一出来就把顶部标签、卡片、生成框和底部加节点条全部露齐；选中节点时点底部加节点条的「＋」，「导演台 / 3D 模型 / 全景图 / 画板」菜单完整浮在最上层不再点穿；视频点「提取深度」在后台下载和运行、不抢走原视频选中态，连点不建第二张空卡；鼠标移去点多版本卡顶上的「设为主图 / 下载 / 删除」或悬停紧挨着的邻卡时不再闪退或被挡住。（#1612、#1616、#1625、#1685）

## Agent、花钱确认与审片

`![待补：Agent 对话流镜头行、底部单行付费确认条与「/」技能提示词弹层](待补)`

- **付费确认拆成对话里的镜头行与输入框上方一条确认栏**：Agent 起草好一批镜头请你确认时，镜头在对话里一行一个排开（超过 4 个折成「还有 N 个镜头」），点哪一行就定位到画布那张卡、悬停高亮对应节点、行尾可单独移掉；输入框上方只留一条固定高度的确认栏显示共同参数与「取消 / 生成 N 段」，镜头再多也不会把聊天记录挤没。（#1548）
- **Agent 推理档位（待合入）**：在 Agent 输入框点开模型菜单，选中支持思考深度的对话模型时可在下方切换推理档位，按任务轻重自主选择快答还是深想，下次打开自动沿用。（#1140）
- **行首输入「/」直接挂技能与提示词芯片**：在 Agent 输入框行首敲 `/` 自动弹出「全部 / 技能 / 提示词」三栏列表，上下键选好回车就挂成输入框里的图标芯片；画布节点的「提示词预设」同步理顺为「全部 / 我的 / 内置 / 公开库」四栏。（#1623）
- **没审成的镜头如实写「未校验」，行内直接点「重审 / 照用」**：自动审片遇到当前对话模型不支持看图、抽帧失败或返回结果读不出时，不再悄悄算作「全部通过」，而是在对账卡和任务中心明确写出「N 镜没审成，不代表已通过」及白话原因，隐藏不可用的自动返修按钮，单镜与多镜行尾统一提供「重审」和「照用」。（#1630、#1659）
- **给原词不乱改，只改分镜不顺手开跑**：你给了明确提示词原文时 Agent 逐字照写不再擅自扩写；只让它改分镜参数或说了「先别生成」时改完即停，不顺手触发生成；起草缺必填参考图时当场说清缺哪一格，回执首行写明默认有声等实际参数；在 3D 导演台可直接让它改单镜运镜方向与起止秒数；在预览选中字幕发消息它真能收到，点掉选区芯片上的 `×` 就撤掉那一项；同一工具连错 3 次或回答撞上限截断时立即停下，不再空转烧请求；外部 AI 助手交完接入卡不用重启就能直接走到生成确认。（#1431、#1447、#1450、#1532、#1563、#1584、#1617、#1619、#1632、#1633、#1673）
- **打开就能打字，长对话跟随滚动和回车发送不再停顿**：按 Ctrl/⌘+J 或点顶栏打开 Agent 光标直接落进输入框，新开的空会话不再显示顶部的零用量圈；模型长回复时自动贴底滚动、往上翻看旧消息即停住并出现「回到最新」；50 轮以上的长对话按回车发送立即上屏，不再卡顿一两秒。（#1359、#1467、#1618、#1672）

## 界面、顶栏与半屏窄窗

`![待补：顶栏最右 Nomi 入口各状态与 700 宽半屏窄窗布局](待补)`

- **Nomi 入口搬到顶栏最右，右下角不再挡画布和页脚**：删掉了右下角的悬浮小球，顶栏最右常驻 Nomi 小脸入口，按空闲、有新消息、运行中、刚完成、出错变换长相，有生成等你确认时宽窗伸出「等你确认 N」胶囊（窄窗或面板开着显示数字角标）；收起面板再打开，会回到这一页上次选的浮窗或停靠摆法。（#1528、#1603）
- **窗口最窄能缩到半屏 700 宽，小窗弹窗按钮不掉出窗外**：窗口最小宽度从 1100 降到 700，方便半屏并排对着资料干活；窗口缩窄时停靠的 Nomi 面板临时收进顶栏、点开变成浮窗，拉宽窗口自动停回原宽度且不改存档；顶栏按顺序收起次要文字，预览页两侧栏自动折成窄条，切去别页改窗宽再回预览也不会错位；小窗口下设置、反馈、花钱确认等弹窗标题和底部决定按钮固定可见，只滚中间内容。（#1422、#1476、#1509、#1520、#1523、#1603）
- **空闲关窗直接退出，后台连接不抢窗口，按钮与动效更跟手**：macOS 上没有生成或导出在跑时点关窗直接退出，有任务在跑时藏入后台跑完自动退出，窗口最小化或藏起时退出会先亮窗再问；外部 AI 工具在后台连接本地 Nomi 时不再把收起的窗口强行拉到前台；拖侧栏、时间轴或导演小窗不再被图片原生拖拽打断，右键菜单贴鼠标弹出不越界，用键盘关菜单焦点回到原按钮；按下文字按钮和发送键有轻按微缩反馈，系统开启「减弱动态效果」后自动省去位移动画。（#1456、#1460、#1486、#1594、#1604、#1628、#1634、#1666）

## 创作、分镜与预览导出

`![待补：预览页竖屏首段自动匹配 9:16 舞台与导出完成提示条](待补)`

- **创作页一键把全文拆成分镜，AI 编辑不打断别处打字**：创作顶栏最右新增「拆成分镜」，写完正文不用先全选就能把整篇交给 Agent 排分镜，行内代码、分隔线和表格收进「⋯」菜单；拖选文字弹出的浮条去掉重复的加粗和标题按钮，只留「AI 编辑 / 拆成镜头 / 生成图片 / 生成视频」四颗带字按钮；「AI 编辑」运行中把光标移去别的段落继续打字不会掐断请求，结果回来也不抢焦点；项目库卡片单击标题直接进项目，改名点悬停出现的铅笔按钮。（#1484、#1611、#1672）
- **分镜页空参考直加、「+ 添加镜头」常驻底栏，切页不丢字**：新建分镜方案还没有参考卡时，同行直接露出「+ 添加参考」而不再藏在空的「全部展开」后面，参考卡生图完整保留描述框里的画风词；「+ 添加镜头」移到底部固定栏常驻，镜头满屏也不用滚到底才能续写；删掉了分镜页顶上重复的整片模型参数条，统一在每镜自己的底栏调整；写完分镜提示词切去画布再切回来，框里的字不再变空。（#1430、#1505、#1573、#1667）
- **首段画面入时间轴自动对齐竖横画幅，导出完成弹提示条不抢焦点**：还没手动选过画幅的空时间轴，第一次拖入或点入竖屏视频、方图时，预览舞台与导出画幅自动匹配成 `9:16` 或 `1:1`（手动选过画幅后不再自动改）；空时间轴时顶栏「导出 MP4」置灰并说明原因，有内容时悬停直接看导出画幅与清晰度，导出完成后在应用内弹出带「打开文件夹」的提示条，不再强行切出窗口弹系统文件夹；时间轴点「添加配乐 → 上传本地文件」选完音频立即落上配乐轨，预览左栏收起后横排显示「片库」。（#1583、#1670）
- **撤销只动当前编辑区，单条坏数据自动另存不卡整份项目**：在预览页、3D 导演台和画布按 Ctrl/⌘+Z 只撤当前正在改的那一处，200 个节点的大画布撤销依然顺滑，且绝不撤掉已经生成的图片和视频；多张 4K 大图同时落地或导出 MP4 收尾时不再卡顿；万一项目里某一条分镜字段异常，Nomi 会把那一条原样另存到项目 `.nomi/quarantine/` 文件夹并弹窗提醒，其余文稿和画布照常保存打开。（#1494、#1497、#1504、#1651、#1652、#1654）

## 升级须知

老项目、已配好的模型和密钥都不需要手动迁移，直接打开就能用。下面逐条说明升级后的行为与位置变化：

- **老项目只打开不编辑、不改写磁盘（待定）**：`0.24.1` 建好的文稿、分镜、画布节点与参考连线、时间轴片段、媒体文件及未收尾生成任务，升级后打开全部完好可用，收起或展开 Nomi 面板也不再写回项目文件；但目前只读打开老项目并浏览画布或预览页时，仍会往项目文件里补写节点展示类型与时间轴缩放值，这一处是否完全改为不改写磁盘还在等定方向（待定）。（#1512、#1693）
- **新装只留 APIMart，以前接过的连接保留并标「近期未维护」**：全新安装首屏和未连模型的空节点默认引导连接 APIMart，不再预置开启即梦会员与火山语音；老用户已经接好的别家服务商、自定义中转站、本地模型与已存密钥原样保留、照常能用，也不会弹出新手首屏主卡。「设置 › 模型」把存量非 APIMart 连接收进「以前接的 N 个连接」并标「近期未维护」随 `#1665` 待合入，旧连接行上「近期未维护」标签的逐家展示细节在对应 PR 正文里未单列核实（待核）。（#1650、#1653、#1665）

## What changed

Connect your models with one account in a few steps, see estimated cost right on the send button, and shoot low-cost video drafts or split image layers on the canvas.

This release streamlines model setup, cost visibility and everyday canvas work: the 13-second startup splash is gone, one APIMart account covers chat, image and video models, and pasting a Key checks your balance and brings you straight back to the draft you were writing. The canvas send button now shows estimated credits before you submit, video nodes can run a cheap 480p sample before making a 1080p final, and image nodes can split an image into editable layers on the whiteboard. The Nomi entry moved from the bottom-right floating bubble into the top bar, and windows can shrink down to a 700 px half-screen; see Before you update and Where things moved below for what changed for existing projects.

### Known issues

- **New UI surfaces have not yet completed a full manual pass on physical Windows machines**: The new connection flow, top-bar Nomi entry and 700 px narrow window, send-button cost unit switcher, vertical preview auto-aspect, and pending sample mode and layer split were verified primarily in real macOS windows during development; Windows title-bar button spacing, native DPAPI keychain behavior and narrow-window layouts still need a physical Windows pass. (#1520, #1603, #1660, #1670, #1702, #1703)
- **Some models do not yet show an estimated cost beside the send button**: Seedream 5.0 Pro / 5.5, FLUX 3 Klein, Kling 4.0 Flash, MiniMax H3-Max, and Seedance 2.5 with reference videos show only the send arrow without a number while their upstream billing formulas are still being confirmed; generation works normally. (#1687)
- **Picking a duration before switching to certain video models on a storyboard row can send the new model's default duration**: For example, selecting 5s on a storyboard row and then switching to Veo 3.1 (which does not support 5s) still shows 5s on the row while sending 8s; re-select a supported duration after switching models. (#1567)
- **Batch shots approved before upgrading but not yet dispatched may need to be generated again**: Because default request fields for several models were aligned with official docs, pre-approved shots whose request payload changed will stay queued rather than sending silently; cancel that batch and regenerate the shot. (#1493, #1526)
- **A few built-in labels remain in Chinese or show minor pluralization quirks in English**: Built-in expression prompt names in the Agent `/` menu and default whiteboard layer names (`背景`, `图层 1`) still appear in Chinese when the UI is set to English, and a collapsed canvas timeline bar with one clip reads `1 clips`. (#1623, #1693, #1695, #1703)
- **Undo history lasts only until you close the project**: Closing and reopening a project clears previous canvas, timeline and director-stage undo steps. (#1651, #1652, #1654)
- Whether a model works still depends on your own provider account, permissions and quota.
