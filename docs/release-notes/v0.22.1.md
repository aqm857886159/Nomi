# Nomi v0.22.1 — 会干活的 Agent，你当导演，模型随便接

**从 v0.21 升级的用户，直接装这一版。** 0.22.0 发出后，Windows 用户反馈导入、生成时整个应用卡死，我们当天撤回了它。0.22.1 修好了这些问题，并包含 0.22 的全部内容。下面讲的是**从 0.21 到 0.22.1** 你会感到的所有变化。

## Agent：说一句，它就在你的画布上干活

右侧的 Nomi 面板现在是一个能动手的 Agent，不只是聊天：

- **它能看**：读画布上的节点和连线，看图、看视频，读你写的剧本和时间轴。
- **它能做**：写剧本、拆成分镜、在画布上建节点、改提示词、发起生成、剪时间轴、导出成片。做错了可以撤销。
- **它听你的**：自主程度分三档，「每步问」「自动改」「全自动」，随时能切。要花钱的生成先在面板里出确认卡；删画布上的东西之前一定先问你。
- **拆参考片**：丢一条参考视频给它，它会自动切镜、逐镜看画面、把台词对到镜头上，方便你照着这个结构做自己的。
- **找参考**：填上你自己的 TikHub Key，它能去抖音、小红书、TikTok 广告库里找参考素材。
- **边干边聊**：它干活的时候你可以接着发消息，消息会排队；想插话、想叫停都行。一个项目可以开多条对话，各干各的。

## 技能：把好做法存下来，下次一句话复用

- 技能库内置 **15 个创作技能和 40 个效果**，每个都配了样片封面。在节点上、在 Agent 的输入框里，都能直接挑来用。
- Agent 能把你这次满意的做法**存成技能**，下次一句话就能调出来；别人分享的技能包也能装进来用。

## 你当导演，不是在抽卡

- **分镜表重做**：按场分组，图在前、字在后。用**参考卡锁住人物长相**，提示词里 @ 一下就能引用。每一镜可以先出首帧，首帧显示在「本镜首帧」格里，再拿它生成视频。可以一行一行生成，也可以一键生成全部，还能顺着播一遍看节奏。
- **3D 导演台（全新）**：画布上的一个独立节点。
  - 能导入 GLB、FBX 这类 3D 模型，也能导入 3D 高斯泼溅和全景图；也可以让 AI 帮你把场景搭起来。
  - 给人物骨骼摆姿势，设机位和运镜。
  - **手机能当虚拟摄像机**：手机和电脑连同一个 Wi-Fi，扫码之后，转手机镜头就跟着转。
  - 拍好的画面，出图、出片都直接落回画布。
- **提取深度**：选中一段视频，点「提取深度」，旁边就长出一张连好线的深度视频卡，能拖进任何视频生成节点，当动作参考用。

## 模型：随便接，上游什么价你就付什么价

- **Nomi 不在模型费里加价**：你接的是自己的供应商，钱直接付给上游，一张图几分钱就是几分钱。
- **「用 AI 帮我接入」**：让你已经在用的 AI 助手（Claude Code、Codex、WorkBuddy 等）帮你把新模型接进 Nomi，地址、参数、模型 ID 它去查。密钥在 Nomi 自己弹出的窗口里填，不经过对话。
- **本地模型**：自动检测你电脑上的 Ollama、LM Studio、LocalAI，一键连上，省额度、保隐私。
- 每个连接可以单独设代理；同一个域名下可以存多条连接，分开管理。
- 模型框里显示哪些模型、怎么排、默认用哪家，都由你定，你手选过的它会记住。
- ComfyUI：更多自定义工作流能直接导入了，包括老节点用 `[False, True]` 当开关的写法（[#861](https://github.com/aqm857886159/Nomi/issues/861)）；数字选项按数字发给 ComfyUI。

## 画布：更跟手，也更听话

画布换了新内核。我们用一个真实规模的项目测过：76 个节点，其中 32 个是 15 秒的 1080p 视频。

| 动作 | 修复前 | 这一版 |
|---|---|---|
| 空闲时挂着的视频播放器 | 32 个 | 0 个（平时只显示封面，悬停或选中才播放） |
| 空闲时显卡进程内存 | 1.7–2.0 GB | 约 0.75 GB |
| 拖时长滑杆，最卡的一帧 | 40–66 ms | 14 ms |
| 新建视频节点，点击到出现 | 75–132 ms | 37–42 ms |
| 拖节点，起手那一帧 | 69–132 ms | 22–29 ms |
| 叠放后逐个拖出，有一张「粘在鼠标上」 | 10 次里 10 次 | 0 次 |

- **画布不再自己平移、缩放**。新建、导入、Agent 落卡、付费卡出片，都落在你看得见的地方；落在屏幕外时，画布边缘会提示「N 个新节点在右侧 →」，点一下才过去。只有打开项目时会摆一次全貌。
- **框工具**：编组升级成「框」，把节点拖进去就入组，拖出来就退组。编组也有「+」拉环，可以直接往外拉出新节点。
- 可以多选节点一起拉线；Alt 拖动复制；方向键挪选中的节点；加号菜单收成 5 个常用加一个「更多」。
- 导入素材时，节点按真实进度渐显。
- 生成浮框钉在节点正下方，宽度固定；画面小窗和小地图默认收起，点开一次就记住。
- 提示词里 @ 画布上的图或视频，就是引用它当参考；把视频连到新的视频节点，默认进「全能参考」。

## 生成和花钱：说真话，不重复扣

- **进度是真的**：供应商没给进度时，Nomi 不编百分比。付费卡生成的视频出好后直接落到节点上，不会一直转圈。
- **确认只在该问的时候问**：你自己点的单个生成不再弹确认；一次跑两份以上，或者由 Agent 发起的，才先问你。确认框不显示估算价格，因为现在各家中转的计价口径不一样，Nomi 估出来的数经常不准，以你在供应商那边的实际账单为准。
- **不重复扣**：镜头在排队或正在生成时，画布上不能再对它发起一次。付费卡上写「Seedance 2.0 快速版」，就按快速版发出去。
- 分镜表「生成全部」跑完后，不会再自动调用文本模型给每一镜打分。你点的是生成，就只花生成的钱。

## Windows 上重新好用

- **导入或生成时整个应用卡死、显卡进程崩溃**：节点上「等待中」的动效在 Windows 上第一次出现时，要编译将近 100 秒的显卡程序。现在只编译用到的那一种效果，0.3 秒以内完成。
- **项目放在坚果云、OneDrive 这类同步盘里，或者正被杀毒软件扫描时，一直提示保存失败**：现在会等对方松手；真被别的程序占着时，会直接告诉你「项目正被别处占用」。
- 导入成功却提示「素材复制失败」、误报「新建项目失败」：都修好了。
- **Agent 点发送没有任何反应**：修好了；万一发不出去，会明确告诉你原因。
- Agent 用 Windows 写法（反斜杠、盘符、`%USERPROFILE%`）去读 SSH 私钥或 Nomi 设置目录时，现在和 Mac 一样直接拒绝。

## 其他

- **素材库**：可以把别的项目里的图片、视频拖进来，会自动复制一份；对勾可以多选，也能取消。
- 设置精简，去掉了 7 个重复的分区。接模型时不再做任何付费验证，接上就能用。
- 新版本会在应用里弹窗提醒；出问题时可以一键导出诊断包，也可以直接在应用里反馈。
- 项目放在同步盘里时，可以换一台电脑继续编辑。
- 可选的使用频率统计：**默认关闭**，只记次数，本机能看、能删。
- 几处小修：生成的视频下载下来不再是打不开的 `.bin`；重开窗口后，还在生成的镜头照样显示「生成中」；Agent 提议改时间轴时，会逐条写清要改什么，并在时间轴上标出范围。

## 诚实边界

- **每次启动后第一次 @，要等 0.1–0.2 秒**：显卡程序的缓存不落盘，每次启动要重新编译几个。之后就不卡了。
- **批量制作暂停期间，请不要在画布上单独生成同一个镜头，再点「继续剩余」**：这样会重复生成。下一版修。
- **Windows 上 Agent 的每条命令都要你确认**：Windows 没有可用的系统级命令沙箱，所以不自动放行任何命令。Agent 运行命令依赖 Git for Windows 自带的 bash。
- 装过 0.22.0 的少数 Windows 用户：0.22.0 写下的对话记录不会出现在列表里。文件还在项目的 `.nomi/` 目录里，旧的原始记录在 `.nomi/legacy-archive/`。
- macOS 版仍然没有签名和公证，Windows 版没有 Authenticode 签名。
- 模型能不能用，取决于你自己的供应商凭据、账号权限和上游额度。
- 非硬切的转场（`dissolve`、`fade` 等）导出方式没有变。
