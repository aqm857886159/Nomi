# Nomi v0.22.1 — Windows 上重新好用，画布跟手

v0.22.0 发出后，Windows 用户反馈「导入、生成就卡死，几乎只能看不能用」，我们当天撤回了 0.22.0。Mac 用户则反馈，节点一多，生成画布就不跟手。这一版修好了这两批问题，并包含 0.22 的全部内容。**从 v0.21 升级的用户直接装这一版即可。**

0.22 整体带来了什么，见 [v0.22.0 更新说明](v0.22.0.md)（画布与剪辑、分镜与 Agent、模型凭据与技能）。

## 画布跟手

我们用一个真实规模的项目测量：76 个节点，其中 32 个是 15 秒 1080p 视频。

| 动作 | 修复前 | 这一版 |
|---|---|---|
| 空闲时挂着的视频播放器 | 32 个 | 0 个（平时只显示封面，悬停或选中才播放） |
| 空闲时显卡进程内存 | 1.7–2.0 GB | 约 0.75 GB |
| 拖时长滑杆，最卡的一帧 | 40–66 ms | 14 ms |
| 新建视频节点，点击到出现 | 75–132 ms | 37–42 ms |
| 拖节点，起手那一帧 | 69–132 ms | 22–29 ms |
| 叠放后逐个拖出，有一张「粘在鼠标上」 | 10 次里 10 次 | 0 次 |

上表是在 100% 缩放下量的。最重的情况是打开项目时摆出全貌：76 个节点全在视野里、缩到 20%，这时拖节点起手 34 ms、时长滑杆 19 ms、新建节点 48 ms，仍在 50 ms 以内。

- 提示词里 @ 画布上的视频或图片，回到「参考」语义：不再偶尔 @ 了却没进输入框，也不再连出错的线。
- 方向键可以挪选中的节点。
- **节点的生成浮框钉在节点正下方**，宽度固定，不再忽宽忽窄、跑到节点中间。被画布边缘或停靠栏挡住时，拖一下画布就出来。
- **画布不再自己平移、缩放**：新建、导入、Agent 落卡、付费卡出片，都直接落在你看得见的地方；落在屏外时，画布边缘出现「N 个新节点在右侧 →」，点一下才过去。
- **打开项目时摆一次全貌**：冷启动打开、从项目库回去再打开，都一样。之后你怎么摆，画布就停在哪。
- **画面小窗和小地图默认收起**：在 1280×800 这类笔记本屏幕上，它们会盖住生成钮和模型钮。点开一次就记住。
- **自己点的单个生成不再弹「开始生成」确认**：一次跑两份及以上、或者由 Agent 发起的生成，仍然会先请你确认。
- **付费确认框不再显示估算价格**，生成钮旁也不再显示点数：现在的模型都经由不同的中转服务接入，各家计价口径不一样，Nomi 估出来的数经常不准。在 Nomi 自己的额度服务上线之前，以你在供应商那边的实际账单为准。

## Windows 上修好的问题

- **导入素材或生成时整个应用卡死，显卡进程崩溃**：节点上的「等待中」动效在 Windows 上第一次出现时，要花约 100 秒编译显卡程序，这期间整个窗口无响应。现在只编译用到的那一种效果，0.3 秒以内完成。
- **提示「项目保存失败，请检查本地磁盘权限」，之后一直失败**：项目文件夹在坚果云、OneDrive 这类同步盘里，或者正被杀毒软件扫描时，存盘锁会卡住放不开。现在会等对方放手再释放；实在放不开，就在后台补收，不会让后面的保存全部失败。真是被别的程序占着时，提示会直接写「项目正被别处占用」。
- **导入成功了却提示「素材复制失败」**：原因同上，同步盘或杀毒软件占着临时文件，清理时出错，就把「已经导入好」改写成了失败。现在清理失败只记日志，残留的临时文件会在下次导入时回收。
- **误报「新建项目失败」**：新建过程中如果切换了项目，已经建好的项目会被当成失败报出来。现在只在真的失败时才提示。
- **创作助手（Agent）点发送没有任何反应**：Windows 上每条对话都被认成「不存在」，消息发不出去，也没有任何提示。现在可以正常对话；万一发不出去，会明确告诉你原因。
- **读取密钥文件的命令没有被直接拒绝**：Agent 用 Windows 写法（反斜杠、盘符、`%USERPROFILE%`）读 SSH 私钥或 Nomi 设置目录时，以前只弹一张普通确认卡。现在和 Mac 一样直接拒绝。

## Agent 与制作

- **付费卡生成的视频早就出好了，节点还在一直转圈**：已修复。节点现在跟着任务的真实进度走，出片后直接落到节点上；片子地址也不会再过几分钟就打不开。
- **报价卡等你确认、或者镜头正在排队生成时，「生成全部」和节点上的生成钮还能再发一次**，会重复生成、重复扣费。现在这些镜头交给制作流程，画布上不能再重复发起。
- **付费卡上写「Seedance 2.0 快速版」，实际按标准版派发（更贵）**：已修复。卡上显示哪个版本，就按哪个版本发出去。
- **Agent 付费卡选「全部」范围后点生成，没有任何反应**：已修复。
- **重开窗口后，还在生成的镜头显示成一张空白节点**，看着像没在跑：已修复，重开后仍显示「生成中」。
- **生成的视频下载下来是 `.bin`，Windows 上双击打不开**：供应商给的文件名很长时，扩展名会被截掉。现在总是按文件实际类型保存（`.mp4`、`.png` 等）。已经存成 `.bin` 的旧文件在 Nomi 里照常能用。
- **分镜表「生成全部」跑完后，不再自动调用文本模型给每一镜打分**：你点的是「生成」，就只花生成的钱。让 Agent 做片时，审片仍是流程里的一步。
- **分镜表的两处误报**：设置了供应商的视频镜头一直显示「执行计划检查失败」，开了首帧的图生视频镜头标红「缺参考图」。两处都已修复，首帧会显示在参考列的「本镜首帧」格里。
- **Agent 回复里的代码块**：只有一层边框，自动换行，复制按钮在右上角。
- **任务面板**：不再显示内部代号；「等你处理」的任务排在最上面，可以「重新拉取」结果（只查结果，不重新生成，不花钱）；重复的条目去掉了。
- **时间轴计划卡**：Agent 提议改时间轴时，卡上重新逐条写清要改什么，并在时间轴上标出待定区间。技能 chip 显示中文名，不再是内部标识。

## 素材库

- 可以把别的项目里的图片、视频拖进当前项目，会复制一份进来。
- 项目素材的对勾可以多选、也能取消；拖出时是复制。
- 引导示例项目里的图片不再裂图；Mac 上的示例视频不再被拦。
- 素材标签在窄栏里不再叠字；剪辑页只保留顶栏一个回到 Nomi 的入口。

## ComfyUI

- 老节点用 `[False, True]` 当开关的工作流可以导入了，不再报「没见过的格式」（[#861](https://github.com/aqm857886159/Nomi/issues/861)）。
- 数字选项（比如视频位深 8 / 10）按数字发给 ComfyUI，不再被转成字符串。

## 画布小改进（0.22.0 之后）

- 缺素材的项目也能打开；多结果卡、视频卡可以正常拖出连线。
- 把视频连到新的视频节点时，默认落到「全能参考」。
- 编组也有「+」拉环：选中才出现，右出左进；折叠编组卡上失效的拉环也修好了。

## 诚实边界

- **每次启动后第一次 @，约需 0.1–0.2 秒**：显卡程序缓存不落盘，每次启动都要重新编译几个显卡程序。之后就不卡了。
- **批量制作「暂停」期间，请不要在画布上单独生成同一个镜头，然后再点「继续剩余」**：这样做会重复生成。下一版修。
- **Windows 上 Agent 的每条命令都需要你确认**：Windows 没有可用的系统级命令沙箱，所以不会自动放行任何命令。Agent 运行命令依赖 Git for Windows 自带的 bash。
- 装过 0.22.0 的少数 Windows 用户：0.22.0 在 Windows 上写下的对话记录不会出现在列表里。文件仍在项目的 `.nomi/` 目录中，旧版原始记录保存在 `.nomi/legacy-archive/`。
- macOS 版仍未签名或公证，Windows 版没有 Authenticode 签名。
- 模型能不能用，取决于你自己的供应商凭据、账号权限和上游额度。
