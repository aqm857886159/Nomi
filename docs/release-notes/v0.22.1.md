# Nomi v0.22.1 — Windows 上重新好用

v0.22.0 发出后，Windows 用户反馈「导入、生成就卡死，几乎只能看不能用」，我们当天撤回了 0.22.0。这一版修好了 Windows 上的这一批问题，并包含 0.22 的全部内容。**从 v0.21 升级的用户直接装这一版即可。**

0.22 这一版整体带来了什么，见 [v0.22.0 更新说明](v0.22.0.md)（画布与剪辑、分镜与 Agent、模型凭据与技能）。

## Windows 上修好的问题

- **导入素材或生成时整个应用卡死、显卡进程崩溃**：节点上的「等待中」动效在 Windows 上首次出现时，要花约 100 秒编译显卡程序，期间整个窗口无响应。现在只编译用到的那一种效果，0.3 秒以内完成。
- **「项目保存失败，请检查本地磁盘权限」，之后一直失败**：项目文件夹在坚果云 / OneDrive 等同步盘里，或者正被杀毒软件扫描时，存盘锁会被卡住放不开。现在会等对方放手后再释放，放不开也会在后台补收，不再卡死后续所有保存。
- **导入成功了却提示「素材复制失败」**：同样是同步盘或杀毒软件占着临时文件，清理时出错，把「已经导入好」改写成了失败。现在清理失败只记日志，残留的临时文件会在下次导入时回收。
- **误报「新建项目失败」**：新建过程中项目被切换时，已经建好的项目会被当成失败报出来。现在只在真的失败时提示。
- **创作助手（Agent）点发送没有任何反应**：Windows 上每条对话都被认成「不存在」，消息发不出去，也没有任何提示。现在可以正常对话；万一发不出去，会明确告诉你原因。
- **读取密钥文件的命令没有被直接拒绝**：Agent 用 Windows 写法（反斜杠、盘符、`%USERPROFILE%`）读 SSH 私钥或 Nomi 设置目录时，原来只弹一张普通确认卡，现在和 Mac 一样直接拒绝。

## 画布小改进（0.22.0 之后）

- 缺素材的项目也能打开；多结果卡、视频卡可以正常拖出连线。
- 把视频连到新的视频节点时，默认落到「全能参考」。
- 编组也有「+」拉环：选中才出现，右出左进；修好折叠编组卡上失效的拉环。

## 诚实边界

- **Windows 上 Agent 的每条命令都需要你确认**：Windows 没有可用的系统级命令沙箱，所以不会自动放行任何命令。Agent 运行命令依赖 Git for Windows 提供的 bash。
- 装过 0.22.0 的少数 Windows 用户：0.22.0 在 Windows 上写下的对话记录不会出现在列表里（文件仍在项目的 `.nomi/` 目录中，旧版原始记录保存在 `.nomi/legacy-archive/`）。
- macOS 版仍未签名 / 公证，Windows 版未使用 Authenticode 签名。
- 模型是否可用取决于你自己的供应商凭据、账号权限和上游额度。
