# Nomi v0.23.1 — Mac 升级与退出热修

这一版是给 Mac 用户的热修，只处理三件事：升级后项目打不开、旧项目打不开、点「退出」没反应。

适用平台：Mac

## 修了什么

- **安装更新后项目打不开**：点「安装更新」时，如果退出过程被打断，之前可能出现「项目恢复失败」，之后所有项目都进不去。现在退出时的清理会等到真正退出那一刻再做；打开项目也不再要求右侧 Agent 先连上——Agent 连不上时项目照常打开，Agent 面板里会说明原因并可以重新连接。
- **旧版 Agent 记录拖住项目**：从 0.22.5 升上来后，某些项目里的旧格式 Agent 回执以前会让整个项目打不开。现在会自动迁移旧格式；确实读不出的那一份会移到隔离位置，项目照常打开。

- **点「退出」没反应**：以前有后台任务没及时停下时，点退出（包括 Dock 和菜单栏）会被吞掉，只能强制退出。现在退出最多等几秒，超时就直接结束。

## What changed

Mac hotfix: upgrading, opening old projects, and quitting now work.

- **Projects open after an interrupted update**: If clicking “Install update” interrupted the quit sequence, older builds could show “Project restore failed” and leave every project unable to open. Cleanup now waits for the real quit, and opening a project no longer requires the Agent panel to connect first — if it cannot connect, the project still opens and the panel explains why and offers to reconnect.
- **Older Agent receipts no longer block a project**: Projects upgraded from 0.22.5 now migrate the old receipt format automatically. If one receipt is unreadable, Nomi moves that file aside and opens the rest of the project.
- **Quit no longer gets stuck**: If a background task did not stop in time, Quit (including from the Dock and menu bar) could be swallowed and only Force Quit worked. Quitting now waits at most a few seconds before finishing.
