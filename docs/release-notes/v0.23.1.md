# Nomi v0.23.1 — Mac 升级与退出热修

这一版是给 Mac 用户的热修，只处理升级后项目打不开和退出卡住这两个问题。

## 修了什么

- **安装更新后项目打不开**：点「安装更新」时，如果退出过程被打断，之前可能出现「项目恢复失败」，之后所有项目都进不去。现在不可逆的清理会等到真正退出时再做，恢复项目不再依赖 Agent lane；退出卡住时，最多几秒内会结束。
- **旧版 Agent 记录拖住项目**：从 0.22.5 升上来后，某些项目里的旧格式 Agent 回执以前会让整个项目打不开。现在会自动迁移旧格式；确实读不出的那一份会移到隔离位置，项目照常打开。

## What changed

- **Projects open after an interrupted update**: If clicking “Install update” interrupted the quit sequence, older builds could show “Project restore failed” and leave every project unable to open. Cleanup now waits for the real quit phase, project hydration no longer depends on the Agent lane, and a stuck quit is forced to finish within a few seconds.
- **Older Agent receipts no longer block a project**: Projects upgraded from 0.22.5 now migrate the old receipt format automatically. If one receipt is unreadable, Nomi moves that file aside and opens the rest of the project.
