# Nomi v0.24.1 — 生成出错不再卡死，保存、安装和卡顿一起修

这一版不改界面样子，专修 0.24.0 发出后大家撞上的问题：批量生成出错后整张表卡住、项目一直存不上、Windows 升级删掉放在安装目录里的文件、大画布缩小后图片消失，还有中转站的视频模型接不上。跟花钱有关的几处也更稳：结果不明的单只取回、不重下，再发一次之前一定先问你。

## 生成与花钱

- **批量生成出错不再锁死整张表**：一批里有几镜结果不明（报错了，或者服务商的回复在路上丢了）时，以前整张表卡在「生成中」，重启也不行。现在只有那一镜变成一张提示卡（不是红色报错），写明「可能已经扣费」，下面是「再发一次」和「查看任务」，其它镜照常能改、能生成。画布、列表、分镜和任务中心看到的是同一张卡。
- **再发一次之前一定先问**：点「再发一次」会先弹确认卡，写明再发可能会再扣一次钱；点取消就什么都不发。分镜里如果服务商那边其实已经做好了，「免费取回」排在第一个。
- **已经被服务商收下的单，只取回、不重下**：关窗、重启、或者本机一时查不了，这一笔都不会被判失败，也不会重新下单；晚到的旧结果不会盖掉你重新生成的新图。等结果的时候也不再白白占着电脑。
- **试跑模型不会下第二单**：接入模型时试跑一次、结果不明，再试会接着查原来那一单；你明确要开新单时会弹确认卡，并说明上一笔结果还不确定。
- **第一次弹付费确认卡不再慢半拍**：以前每次打开 Nomi 后第一次点生成，要停顿约 0.3 秒卡才出来，像没点上。
- **参考图的临时链接过期了，改传本机文件**：引用一张生成不久的图时，服务商给的临时链接过期或被拦，以前会报「参数不被接受，请检查比例 / 尺寸」，点重试还是一样。现在改传你电脑上的那张图。

## 中转站与模型

- **中转站的视频模型接得上**：让 Agent 照文档接入的中转视频模型，参数、需要几张图、请求发到哪，一次登记完整，不用再手动设置；服务商已经收下的视频，能直接取回成品文件。没说清怎么调用的视频模型，会在发请求之前停下，错误卡上的按钮带你去接入，不再显示一段英文报错加「重试」。
- **自配的网关不再整轮拒收**：用自己配的 OpenAI 兼容网关时，让 Agent 把文稿拆成分镜，以前可能连续三次报「Invalid request parameters」，现在能正常拆。
- **外部 AI 读到的模型清单说实话**：通过 MCP 连着 Nomi 的 AI，读模型清单时，填了 Key 但用不了的模型不再算作可用、也不再被推荐，会写明原因。

## 保存、项目与安装

- **项目不再一直存不上**：新建还没起名的人物卡、清空人物名字、把整片画幅切回「默认」，以前会让整个项目反复保存失败。现在这些都能正常保存；真的存不上时，会说清是没有权限、文件被别的程序占用、磁盘满了，还是别的原因。
- **找不到文件夹的项目不会消失**：项目文件夹被挪走或改名后，项目还留在项目库里，卡片写明「找不到这个文件夹」：可以用「打开已有文件夹」重新选它接上，也可以从项目库移除，移除后重启不会再冒出来。打开项目库时，Nomi 不会再悄悄把它们从登记里删掉。
- **Windows 升级和卸载不再删你的文件**：你放在 Nomi 安装目录里的文件，以前升级时可能被一起删掉。现在安装器只删它自己装进去的文件，你的文件原样留在原处。

## 卡顿与误操作

- **大画布缩小后不再缺图**：缩到很小、一屏几十张图时，图片不再轮流消失，编组底色也不会整块不画。
- **弹窗开着时，底下不会被误操作**：确认框、设置、看大图开着时，按 Delete、⌘Z、⌘A、⌘V 不会再动到被盖住的画布、时间轴或列表；Esc 只关最上面那一层。
- **列表视图里删东西不会删到画布**：在列表里按 Delete 或撤销，不会再碰到藏在后面的画布；在素材盒里删文件时，还被画布或时间轴用着的不会被直接删掉。
- **诊断包写明卡在哪**：「设置 › 通用 › 导出诊断包」现在会带上什么时候卡过、卡了多久、显卡型号和项目大小，方便我们查卡顿；不含文件路径和提示词。

## 导演台

- **预演量的是镜头里的人**：预演给出的景别和运镜，按镜头里记录的人物来量，不会再把背景里的楼当成主体；复制场景或导入场景后，读数和原来一致。

## 反馈

- **「反馈这个问题」发得出去**：以前勾选带上内容后，可能一直停在「正在发送…」，也带不上日志。现在发得出去、带得上日志；一时没发成的会先存在本机，之后自动重发，不用守着。

## 升级须知

- **这一版分批推送**：先推给一部分用户，确认没问题再推给所有人。暂时没收到更新提示的，可以在「设置 › 关于」里点「检查更新」，或到官网下载。
- **升级后请不要再装回 0.24.0**：这一版能保存没起名的人物卡这类草稿，存过这类草稿的项目，0.24.0 打不开。

## 已知问题

- **批量生成时，参考图会在你看到上传说明之前先传给服务商**：需要把参考图传到服务商那边的模型，单张生成会先问你；批量生成的第一批目前没先问。下一版修。
- 模型能不能用，仍然取决于你自己的服务商账号、权限和额度。

## What changed

Generation no longer locks up after errors, and saving, installing and canvas slowdowns are fixed.

This release keeps the same layout and fixes what people ran into after 0.24.0: a whole batch stuck after a few shots failed, projects that kept failing to save, Windows updates deleting files kept in the install folder, images vanishing on a zoomed-out canvas, and relay video models that would not connect. Spending is steadier too: an order the provider already accepted is only retrieved, never placed again, and Nomi always asks before sending again.

### Generation and spending

- **A failed batch no longer locks the whole table**: When a few shots end with an unknown result, only those shots turn into a neutral card that says you may already have been charged, with Send again and View task. Every other shot keeps working. Canvas, list, storyboard and the task center show the same card.
- **Send again always asks first**: Send again opens a confirmation that says it may charge you again; Cancel sends nothing. In the storyboard, a free retrieve comes first when the provider already finished the result.
- **Accepted orders are only retrieved, never re-sent**: Closing the window, restarting, or a failed local lookup no longer marks the order as failed or places it again, and a late old result never overwrites a newer one. Waiting no longer keeps your computer busy for nothing.
- **Trying a model never places a second order**: If a test run ends with an unknown result, trying again checks the original order. Asking for a new one shows a confirmation that says the last result is still unknown.
- **The first spending confirmation shows up instantly**: The first one after opening Nomi used to appear about 0.3 s late.
- **Expired reference links fall back to the local file**: When a provider's temporary link for a recent image expires or is blocked, Nomi now sends the file on your computer instead of failing with a misleading size or ratio error.

### Relays and models

- **Relay video models connect**: Video models the Agent connects from a relay's docs now register their parameters, image slots and endpoints in one go, with no manual setup, and accepted videos can be retrieved as files. A video model that does not say how it is called now stops before sending and points you to connecting it, instead of showing a raw English error with Retry.
- **Strict custom gateways accept the whole turn**: With a strict OpenAI-compatible gateway, asking the Agent to break a script into shots no longer fails with “Invalid request parameters” three times in a row.
- **External AI tools see an honest model list**: Through MCP, models that have a key but cannot be used are no longer counted as usable or recommended, and the reason is shown.

### Saving, projects and installing

- **Projects save again**: A new character card without a name, a cleared name, or the film ratio set back to Default used to make every save fail. These now save normally, and when a save really fails Nomi says whether it was permission, another app holding the file, a full disk or something else.
- **Projects with a missing folder stay in the library**: The card says the folder cannot be found. Reconnect it with Open existing folder, or remove it from the library; removed cards do not come back after a restart.
- **Windows updates and uninstalls keep your files**: Files you put in the Nomi install folder are no longer deleted; the installer only removes what it installed.

### Slowdowns and stray input

- **Zoomed-out canvases no longer drop images**: With dozens of images on screen, images no longer disappear in turns and group backgrounds no longer go blank.
- **Dialogs block input to what is behind them**: With a confirmation, Settings or an image viewer open, Delete, ⌘Z, ⌘A and ⌘V no longer touch the hidden canvas, timeline or list; Esc closes only the top layer.
- **Deleting in the list stays in the list**: Delete and undo in list view no longer reach the hidden canvas, and the asset box will not delete files the canvas or timeline still use.
- **Diagnostics show when things froze**: Settings › General › Export diagnostics now includes when and how long Nomi froze, your graphics card and project size, without file paths or prompts.

### Director stage

- **Previz measures the people in the shot**: Shot size and camera moves are measured on the recorded subject, not a building in the background, and stay the same after copying or importing a scene.

### Feedback

- **Report this problem gets through**: Reports no longer hang on “Sending…” and now include logs; a report that cannot go out right away is kept on your computer and resent automatically.

### Before you update

- **This update rolls out in stages**: Some people get it first, everyone else after a health check. To get it now, use Settings › About › Check for updates, or download it from the website.
- **Do not go back to 0.24.0 after updating**: 0.24.1 can save drafts such as unnamed character cards, and 0.24.0 cannot open projects that contain them.

### Known issues

- **Batch generation uploads reference images before showing the upload notice**: Single generations ask first; the first round of a batch does not yet. Fixed in the next release.
- Whether a model works still depends on your own provider account, permissions and quota.
