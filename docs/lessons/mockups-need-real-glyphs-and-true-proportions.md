# 样张两条硬纪律：图标用真字形、布局线框用真比例

> 📎 教训 · 首次记录 2026-09-05 · 状态：现行
> **触发场景**：出任何用户可见样张（Claude Design 画布 / HTML mockup / 方案对比小图）；用户说「图标不对劲」「比例奇奇怪怪」。

**结论**：① 样张里的图标必须是实现时同一份 `@tabler/icons-react` 的真实路径（构建脚本直接从 `node_modules/@tabler/icons-react/dist/esm/icons/Icon*.mjs` 抽 `__iconNode`），禁止手绘近似线条；② 布局对比图必须按真实屏幕比例画（1680×842 缩放，左栏 300 / Nomi 390 / 时间轴 240 之类的真实数），并且渲染成图自己 Read 过再给用户，不要用比例随手填的方块图。

**为什么会踩**：2026-09-05 剪辑面样张第一版图标是手画的，转场「入 / 出」拿剪刀和图层图标凑，用户一眼看出「不对劲」；同一天用 show_widget 画的四个布局方案方块比例随意，用户反馈「空间都奇奇怪怪」。换成真字形 + 真比例线框后两条反馈都消失。还有一条同族：属性面板「选中才冒出来」是我自创的，剪映 / Resolve / Premiere 三家属性区都常驻——形态先查四家再画。

**怎么用**：
1. mockup 构建脚本里 `icon()` 只从包里读，找不到的图标名直接报错，不要 fallback 成圆圈。
2. 方案对比先用真实尺寸的 HTML 线框 + Playwright 截图，看过再发；`show_widget` 的即时小图只用于流程图，不用于布局比例。
3. 每个控件的形态先在近邻产品（剪映 / Descript / Resolve / ChatCut / OpenCut 源码）里找到出处再画；找不到出处的形态要在样张里标「自创，待验」。
