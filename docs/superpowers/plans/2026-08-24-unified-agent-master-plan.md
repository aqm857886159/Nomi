## 0. 北极星（一句话）

**内外一个控制面**：外部 agent（Claude Code/Codex…经 MCP）和 Nomi 内嵌统一 agent，驱动**同一批语义工具、同一个确认面、同一套技能库、同一组 Workflow Pack**；用户在哪个入口都能「把故事从文本推进到可编辑初稿、再到可撤销的成片，不丢上下文、不重复扣费、不被模型差异欺骗」。

## 2. 统一 Harness 设计（Track B 核心件）

采纳依据=harness 调研（该抄 10/该避 8/已有等价物 4）：

1. **单一状态推进循环**：Electron 主进程/utility process；现役为 Vercel AI SDK，已批准通过 R0 后改用受控 pi AgentSession（BYO key，Nomi 显式模型/工具/上下文配置）。不保留双 Agent engine；非 Agent 文本任务不在本次替换范围。
2. **会话事件与生产事实分层**（与交接手册 Part 5 的已决边界一致）：会话事件支持 UI 回放与任务关联；完整模型工作上下文由运行核快照恢复。以 runId/causeId/txnId/proposalId 关联耐久 Run，不物理合并两类日志，也不用 SDK 快照代替预算、批准或作品事实。
3. **Thread→Turn→Item 事件流**（Codex App Server 形状、对齐 ACP）经 IPC 投影渲染层：每 Item 一个组件、`started→delta*→completed`；留外接 Claude Code/Gemini CLI 之门。
4. **单一审批信道**：确认=事件流上的反向请求、turn 暂停等回答；「agent 只许提案不许花钱」是策略引擎 deny 规则（harness 强制，非 prompt）。
5. **策略引擎单点化**：deny→ask→allow + 三档闸门（Block/Notify/Auto）+ 会话级信任推广。
6. **模型能力分级**（BYO 拍板）：档案声明档位——弱档收窄工具面、多走 playbook 轨道、诚实提示「此模型带不动全自动」；强档放开自由 loop；限流/失败自动 fallback；系统 prompt 走 pi 式小内核。
7. **自动压缩** + compact_boundary + 可配保留指令（分镜决策/角色身份/已拍板项）。
8. **maxTurns + 预算硬顶**在 harness 层。
9. **SKILL.md 渐进披露**：导演/编剧技能库迁 SKILL.md，内外共用。
10. **v1 不做**：subagents、独立 plan 子系统（计划=只读权限档）、per-tool 弹窗、外部 orchestration runtime。

**复用边界（2026-08-26 更新，替代旧“不引 pi”结论）**：通用模型/工具循环、流式和工作上下文复用 pi AgentSession；Nomi 保留供应商配置、Skill/项目偏好、权限、确认、预算、ProductionRun、作品编辑及 Undo。框架没有 Nomi 权限不等于不能复用其循环；权限在既有工具执行边界强制。先以固定版本通过原生 PDF、恢复、Electron/ASAR 等兼容门，再同一交付删除旧 Agent engine；不以失败 fallback 留双引擎。MCP 外部请求仍直达同一业务能力，不绕内嵌模型二次推理；外部客户端的聊天历史不冒充已自动同步。

## 4. 交互层（Rev.2 重写：主栏 · 两轴 · 词汇表 · 三宿主）

### 4.1 Agent 主栏（右栏恒在）

右栏从「聊天框」升级为**项目驾驶座**：对话流 + 状态帧（当前步骤/花费/进度）+ 上下文抽屉（本次用到的锚/素材/计划缩略）+ 模式（Pack）切换 + 可拉宽/全屏/收窄。**边界：缩略可看、编辑不入栏**——结构性编辑跳各自的家（一功能一个家）；主栏提供跳转与行内轻动作。项目库页加 agent 入口（「开个新片」一句话建项目、直入 Pack 对话）。

### 4.2 两根轴：模式强度 × 使用姿态

- **模式强度**（小云雀实证三档并存不打架）：**重管线**（固定步骤+显式闸门+状态机，如短剧 Pack）｜**对话主驾**（多轮对话唯一入口）｜**单发直出**（一句话/表单直出）。强度档是 **Pack 合同的第一字段**。
- **使用姿态**（谁领路）：**纯对话**（右栏全宽，新手全程不看舞台）｜**对话领路**（左舞台自动跟随当前步骤，可关；新手默认开）｜**舞台为主**（右栏收窄当副驾）。
- 两轴正交：同一个短剧模式可用任一姿态跑。新手体验=「重管线 Pack × 对话领路」，**对话即向导**。这不否定文稿、画布、时间轴的专业多空间；核心是同一作品、对话与任务如何连续，不能把“用了多空间”本身当问题，也不能把不同专业对象强行同步成同一种内容。

### 4.3 对话词汇表 v2（该用什么用什么，不全是卡片）

| 对话里发生什么 | 形态 | 依据 |
|---|---|---|
| agent 思考/规划 | **折叠思考条**（流式可展开） | 卡在小云雀黑箱与 MiniMax 过重之间的空位 |
| 换模式/进入新阶段 | 分隔线标记 | TapNow 阶段声明同心智、更轻 |
| 调工具干活 | 单行紧凑条「正在拆镜… ✓ 7 镜」 | 可灵/虾条同构 |
| 长任务进行 | **原位更新进度条目 + 停止按钮**（留在对话流） | 别家都要跳任务中心，我们不用 |
| 任务前后态 | **排队中(第几位)/等待中/已停止**显式态 | 虾条 8 态；视频生成排队常态 |
| 向用户反问 | 问题 + 选项 chips，**≤3 问合并** | TapNow ≤4 唯一产品化案例，我们更克制 |
| **要花钱** | **富卡片（唯一重卡）+ 对话暂停 + 明标价格与冻结项** | 反着 TapNow 藏价做；闸门三件套见 §5 |
| 产物出来 | 缩略卡 + **行内动作「改这条/重跑」** + 点开跳舞台 | 星流 Tab 编辑/LibTV 勾选重跑/小云雀悬停重做——只解决看不解决改则摩擦落后 |
| **多候选** | 折叠成组并排挑、可指定生效版本 | 小云雀抽卡记录 + 可灵并行铺 |
| **失败** | **失败条：哪一步败 + 人话原因 + 下一步动作**（重试/换模型/看日志） | LibTV 诊断闭环标杆；「别重做整张，先定位失败节点」 |
| agent 动了画布 | **写入回执**「已加 7 个节点 · 撤销」 | 配「整批一个 Cmd+Z」既有拍板 |
| 普通回复 | 纯文本 | — |

**命名纪律**：组件/状态名一律大白话自解释，不造需要背的黑话（DramaClaw「虾条虾导」被用户当场吐槽为戒）。每种形态=事件流一个 item 类型；外部客户端里同一事件长成 MCP 对应物（工具结果/elicitation），**一份语义两个投影**。

### 4.4 确认三宿主（一个语义、内容组件只写一份）

| 场景 | 确认长在哪 |
|---|---|
| 用户在 Nomi 用内部 agent | **对话流里的确认消息**（富卡内嵌，对话暂停；不弹中央窗） |
| 外部客户端支持 elicitation | 客户端内嵌表单（图先经工具结果回传） |
| 外部客户端不支持且用户不在 Nomi | 置顶小浮窗（唯一「召唤注意力」场景）+ 系统通知唤起 |

### 4.5 组件来源策略

**词汇表全抄、组件拷入重皮、协议对齐形状**：消息类型分类学采用现成生态（与 Thread/Turn/Item 一一对应）；组件从 **Vercel AI Elements**（官方、shadcn 式拷入仓库、与栈内 AI SDK 同族）按需拷入并用 Nomi token 重画皮（过 check:tokens，不引运行时依赖）；assistant-ui 作 HITL 参考；AG-UI/ACP 只对齐事件形状。UI 层的拿来主义是划算的——组件不咬合安全边界。

### 4.6 编辑的家分层（「纯对话」标准的精确定义）

小云雀实证：每个中间产物有**原位编辑的家**（剧本在内容区、资产在资料库、分镜在故事板），画布是兜底精修层，对话只是修改入口之一。Nomi 同构：**纯对话标准=主链走得完**（看、确认、单条重跑、停止、导出都行），结构性编辑（改参数细节/重排/画布操作）跳各自的家；主栏行内轻动作覆盖高频小改。

### 4.7 其余交互原则（承 Rev.1）

对话是方向盘、产物落舞台聊天只留过程（LibTV 承诺句式：「交付的是一张可继续编辑的画布」）；贵步骤一张**可编辑参数卡**（自动/手动模式可切）；**级联重跑**：改上游锚/镜→列受影响下游→勾选重跑范围（IR 字段守恒保对账）；双视图（进度 vs 细节）；点选/标注画布元素即上下文；**prompt 三层可观测**（用户写的/Agent 改写的/实发的）与**失败归因+是否计费明示**——本地优先的信任差异化。

### 4.8 「自由挡不降级」原则（2026-08-24 用户质询「太死板怎么办」后升格为铁律）

**任何自动化（批量合同、Pack 流程、agent 接管）都是在画布自由模式之上加的快路，不是替换。** 用户在任何一步都能退出到单镜/单节点手动操作，做完还能回到自动，账本连续。哪天某个自动化要求「必须整批、不能插手」，即设计错误。柔性由三机制组合保证，不靠把批次做成万能开关：

1. **镜级勾选**：批次覆盖哪几镜用户定（「先拍第 1 和第 5 镜」→ 合同只覆盖这两镜，卡上只列这两镜的价）；试拍快捷是它的一键化特例。
2. **续拍**：同一计划第二批（锚复用、已完成不重扣），分几批每批几镜随意。
3. **画布自由挡恒在**：落到画布的镜头节点=普通节点，单点生成/换模型/手动抽帧续接全部照旧；合同只管装进合同的那批。

**v1 刚性清单与逃生口**（每条刚性必须有逃生口，否则不许上）：

| v1 刚性 | 逃生口 |
|---|---|
| 一批内单 provider（一张卡一次授权一本账） | 该镜移出批次单独生成（单镜链无此限制、全供应商）；下一批可换家 |
| 无自动首尾帧续接 | 画布手动抽帧→当下一镜首帧参考（抽帧功能现有） |
| 同项目同时一个批次（第二个排队） | 画布单镜生成不排队，随时插 |
| 锚检查点停一拍 | 可配「超时自动放行」 |
| 确认卡只读 | 「返回修改」一步回计划编辑；高频小改走产物行内动作 |

## 5. Workflow Pack（L6）

- Pack=受约束声明；**合同字段（Rev.2 定稿）**：`强度档（重管线/对话主驾/单发直出）`、目标输入、可用工具与 module IDs、步骤/分支、capability、每步 propose|paid|project_write、确认点位置与**闸门冻结项**（确认框+花费预估+**明说过闸后不可再改什么**——小云雀三件套）、失败/重启下一步、产物投影位置、版本迁移。Skill 只描述方法不拥有权限；Pack 描述组合；Run 执行。
- **一套画布原则**：小云雀两套画布（短剧资产画布 vs 通用画布，菜单快捷键近复制）是并行版反面教材——Nomi 一套画布 + **模式档案声明可用节点/工具集**。
- 第一条 Pack=「小说/剧本→一集」（重管线档）：编剧段（创作区+拆镜）→ 生产段（**=P4**）→ 采纳段（=P5，08-22 统一创作运行时的剪辑区 Adopt）→ **剪辑段**（同方案 P7 窄先行）→ 导出。**P4.5 候选：分镜图先行检查点**（智能预演互证：锚与视频之间垫一层便宜的一致性确认，图比视频便宜一个量级）。
- **混合素材一等公民**：时间轴是汇合点——上传素材、AI 镜头、裁剪、字幕、音乐同轨；**AI 服务于剪辑**。
- 资产=唯一真相源、分镜只引用（小云雀「改一处全剧同步」同构）：坚持引用制，画布节点不复制资产内容。

### 5.1 AI 剪辑三步（2026-08-24 展开，执行 08-22 统一创作运行时 P5→P7 弧线，不另起炉灶）

**核心对象：剪辑计划（EditPlan）**=一组类型化时间轴操作（排列/字幕/音乐/转场/裁切），每条带影响范围；对话里渲染为**剪辑计划卡**（动几条/改哪里/可撤销）→ 批准 → **一个事务 Apply → 一步 Undo**。防重复/防过期照 08-22 已设计的 Proposal 幂等键（`runId+contractHash+artifactId+artifactVersion+baseRevision+destination`，轴变了提案自动 stale）。**操作词汇表从时间轴真实能力 derive**（现有家底：多轨/字幕文字轨/画面裁切 clipFraming/上传素材进轴 addAssetToTimeline/吸附/可见区间；确切操作集——尤其时间维裁剪语义——E2 动手前做代码盘点补录，不凭目录猜）。agent 不直接落轴（08-22 铁律：生成模块不能绕过 Proposal）。

- **E1 采纳桥**（=08-22 P5，随 P4/P5 落）：单产物批准进轴、一步撤销；批量版=「整批按分镜顺序排进时间轴」（P4 T2 的时间轴续集）。零 AI 含量，纯管道，是后面一切的唯一入口。
- **E2 结构化粗剪**（Pack v1 剪辑段）：**不烧钱的聪明——结构派生而非 AI 猜**。分镜计划里本就有每镜时长/对白/字幕字段/转场声明，因此：按计划排列+时长对齐、**对白→字幕轨**（文字轨机制现成）、音乐垫底、转场应用、实拍素材混排。产出「能看、有字幕、有音乐的粗剪」——导出门槛（字幕齐才算成片）已在代码里，正好接上。配音若拍板进 Pack：TTS 走 08-22 P6 音频 module，产物进音轨同一条采纳链。
- **E3 理解式剪辑**（=08-22 P7 窄先行，最后做）：需要看懂内容的操作——审片给节奏建议（shotVerify VLM 现成接上）、「开头收紧到 15 秒」意图剪辑、口播/访谈清理（远期）。放最后因为贵（VLM/转写按量）且依赖 E2 操作词汇表成熟。

**边界**：不做通用 NLE 竞品（剪映在那，不拼也不该拼）；只做「AI 服务于交付这一部片」的操作集。交互接 §4.3 词汇表：「给全片上字幕」→剪辑计划卡→Apply→写入回执「已加 42 条 · 撤销」；改某镜→级联列受影响字幕/位置勾选；全程 §4.8 自由挡不降级（手动拖剪后，agent 计划以新轴为基线）。配音/TTS 进否 Pack v1 待拍板。
