# 画布剪辑节点实施计划

## 目标

先交付一个可理解、可恢复的剪辑节点骨架，而不是把一个不可用的小条伪装成完整功能。

## 步骤

1. 盘点现有 generation canvas node kind、toolbar registration、timeline clip types 和导出 IPC，记录复用点。
2. 先写 schema/构建测试，再增加 `clip` 节点的序列化字段和工具栏入口。
3. 实现节点空态、添加素材、时间轴片段和预览壳；片段来源可来自本地项目素材或已生成视频节点。
4. 实现节点内关闭/折叠与画布滚轮隔离，保证节点不会遮挡下方时间轴。
5. 在导出链路可用前不展示会失败的下载按钮；用明确的“准备剪辑”状态说明未完成的合成能力。
6. 运行节点 schema 测试、项目 gates 和真实用户走查；第 2 阶段单独接入 ffmpeg/IPC。

## 验收

- 新建剪辑节点后能看到完整时间轴容器、添加素材入口和可解释空态。
- 节点可以保存/恢复来源和片段字段。
- 节点不会阻挡画布底部时间轴，关闭动作真实可用。
- 没有虚假的下载/导出按钮。
