# 画布剪辑节点设计契约

## 目标

让一个视频节点可以连到剪辑节点，剪辑节点呈现真实时间轴：可添加图片/视频素材、裁剪片段、预览结果，并把原始片段、合并视频或结果导出回画布。

## 用户流

1. 在画布工具栏添加“剪辑”节点，或将视频节点连接到剪辑节点。
2. 剪辑节点默认显示时间轴和“+ 添加素材”，不是一块空白配置表。
3. 选择素材后在时间轴上移动播放头、设置入点/出点；节点内预览当前结果。
4. 下载菜单提供“下载原始片段”“下载合并视频”“导出到画布”。导出到画布生成新的媒体节点，并保留来源关系。

## 数据契约

剪辑节点必须保存 `sourceNodeIds`、按顺序排列的 `tracks`、每个片段的 `trimStart`/`trimEnd` 和生成结果引用。状态必须可序列化、可恢复，不把临时 DOM 状态当作项目数据。

## 分阶段交付

- 第 1 阶段：节点类型、工具栏入口、空态/添加素材、时间轴片段渲染和可关闭的预览壳；复用现有 timeline types/actions。
- 第 2 阶段：入点/出点交互、片段导出和合并导出 IPC，接入真实媒体合成。
- 第 3 阶段：节点连线、结果回写和端到端任务测试。

## 本次实现边界

本次先落第 1 阶段并留下第 2/3 阶段所需的数据契约和测试夹具；不显示没有行为的“导出”按钮，避免用户误以为已经完成剪辑。
