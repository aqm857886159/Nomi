NOMI · INTERACTION MOCKUP

一个 Agent，三个工作面，
不再切换对话。

这是把 OmniBoard 的“故事到成片”路径放进 Nomi 的统一工作区后的三种交互方式。重点不是把三个页面塞在一起，而是让 Agent 永远拥有同一段上下文，用户只是在同一个工作面里查看和编辑不同层。

核心用户价值：用户只需要说一次，之后一直在同一条创作线上推进。剧本、镜头、生成参数和时间轴共享项目事实；Agent 的建议先进入“待应用”，用户可以一键应用或撤销。

用户只和谁说话？

永远是同一个“创作 Agent”。剧本、画布、时间轴是它能读写的三类工作面，不再各自维护一段对话。

用户什么时候看到复杂参数？

默认只看到 Agent 推荐的结果；点击具体镜头后，右侧才出现该模型真实支持的模式和参数，避免把 Seedance 的字段硬套给所有模型。

用户如何避免被自动改坏？

Agent 先给局部变更预览；应用、撤销、复制版本都在当前工作面完成。生成和付费仍经过明确确认，不会因为聊天而隐式执行。
