ChatCut credits pay for AI processing and media generation. Manual timeline editing, uploads, project browsing, transcription, and exporting do not consume credits. A plan can still limit access to a feature even when you have enough credits.
Action
How it is charged
ChatCut Agent messages in the web or desktop editor
Variable. The model, input and output tokens, cached context, conversation length, and project context all affect the charge.
AI video generation
By generated seconds, model, resolution, and—for Seedance 2.5—eligible video-input usage. See the table below.
AI image generation
By model, output quality, resolution, and image count.
Motion-graphics generation in the built-in Agent
Variable, based on the AI model usage required to create or revise the graphic.
AI music
0.18 credits per generated song at the current backend rate.
AI sound effects
0.12 credits per generated second.
AI voiceover
Usually 0.28–0.80 credits per 1,000 characters, or 0.08–0.12 credits per generated second, depending on the voice engine.

Agent-message charges vary with the context ChatCut must process. To avoid paying for unnecessary back-and-forth:
Put the goal, required source material, output format, and constraints in one specific request.
Use attachments or Selection Mode references instead of repeatedly describing which asset, clip, time, screen region, or transcript passage you mean.
Keep related revisions in the same conversation while the previous context is useful.
Start a new conversation for an unrelated task when the old discussion is no longer needed. Create a separate project only when the media and Timeline should also be separate.
These steps reduce unnecessary context; they do not promise a fixed charge. Verify the completed amount in
Credits history → Detail

When Codex, Claude, or another supported local agent controls ChatCut through the plugin or MCP connection, the host agent’s reasoning uses that host’s own subscription or API allowance. ChatCut credits are used only when the workflow calls a ChatCut-hosted generation service, such as video, music, sound effects, or voiceover generation.
If Codex uses its own image-generation capability, that image generation follows your ChatGPT/Codex allowance instead of creating a ChatCut image-generation charge. Check the confirmation shown by the active tool when a workflow mixes host-provided and ChatCut-provided generation.
