AI Video Generation creates clips from text, images, first and last frames, references, or a source video. Models support different inputs, editing operations, durations, and resolutions, so define the task before selecting a model.
Video generation requires Pro and uses credits. Use the estimate shown in the editor before sending; see
for current rates.
First decide whether you are generating from scratch, connecting first and last frames, using references, editing a source video, or extending a clip. That choice determines the available models and inputs.
Text-only generation needs no upload, but you should know the subject, action, setting, camera, and visual style.
To preserve a person, product, or composition, prepare clear images, first and last frames, or supported references. To edit or extend a clip, import the source video into
My Assets
first.
Decide the aspect ratio, target duration, resolution, and anything that must remain unchanged.
