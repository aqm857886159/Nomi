ChatCut may pause before Motion Graphics, Video Generation, or Image Generation and show a confirmation card in the AI conversation. Review the proposed action, references, and credit estimate before deciding.
Select
Allow
to approve this generation once.
Select the displayed
Allow all …
option to approve later matching generations within the scope written on the card.
Deny
to stop this proposed generation.
Use the adjustment field when the card offers one and the request should change before it runs.
The scope is part of the visible label. Current project-scoped options apply only to that project. A Motion Graphics option may be labeled as applying across projects; Agent Settings marks an all-project preference as
Global
.
Approving a generation does not guarantee completion. The feature still checks plan access, inputs, safety rules, and available credits before or during the request.
To change a saved approval choice, open
Agent settings → Generation Auto-Allow
. The Motion Graphics, Video Generation, and Image Generation switches are independent. See
for the setting behavior.
The card may already have been allowed or denied, cancelled when the task stopped, or expired while waiting. Check the conversation and
My Assets
before retrying so you do not submit a duplicate generation.
If no job started and you still want the generation, send the request again. If the original job is visible in
, monitor that job instead of creating another one.
The value shown before generation is an estimate. After the action completes, open
avatar → Credits history → Detail
to inspect the individual transaction and resulting balance. Failed or cancelled work should be checked from the same history rather than inferred from the confirmation card.
