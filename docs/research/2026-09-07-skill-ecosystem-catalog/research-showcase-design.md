## 12 条可抄清单（已并入 showcase 规格）

1. 首页=效果瀑布流，一格一段静音成片，文字压底 —— 不做文字货架
2. 卡片印**类型章**（技能/风格包/LoRA）+ 适用标签，一眼可扫
3. 分类=顶部主导航+二级筛；勿抄 HF 左侧长表单
4. hover 主动作=播放/一键试，点击进详情 —— 两层渐进
5. 详情顺序：全屏自动播演示 → 标题+一句效果 → 主 CTA → 规格表 → 使用提示 → 作者卡 → 授权+免责沉底
6. 演示带"产出它的输入"（样张+提示词/素材字幕）—— 输入→输出对照
7. CTA 三处（演示正下主/规格后次/页尾），动词用"套用到我的视频/接入应用"
8. 信任信号：用量上卡、作者可点、文件 Verified/安全扫描、商用许可、免责声明
9. 演示全可见，文件/参数/方法接入后才给（PromptBase 付费墙原理）
10. 冷启动用官方精选垫底避免空墙
11. 详情挂"被谁用过/Remix 墙"提升可信（HF Spaces using N）
12. **无样张的商品不上架** —— 收录门槛之一

## 落到我们的展示规格（三层渐进 = PromptBase 原理 + Civitai 详情序）

- **层 1 卡片**：演示封面/静音小样(最大) + 拟人化名字 + 一句话"装了能做什么" + 类型章 + 官方/开放区徽标 + 用量。元数据(作者/许可证/统计)一律不上卡面。
- **层 2 详情**：自动播演示 → 标题+一句 → 主 CTA("接入 Nomi") → 规格/使用提示(kind 特有：skill=装法 / effect-pack=铺画布 / lora=底座+strength) → 作者卡 → License+安全状态+免责沉底。
- **层 3 接入后**：才给 SKILL.md 全文/文件/参数。接入前不可见 = 分层披露。

## 成本与边界提醒（真话）

"每张卡都有真实成片小样"是最重成本：skill/effect-pack 可托管跑小样；**lora 托管跑不了**（须对应底座）→ 用作者样张(HF/Civitai 模式)或"本机真跑"预览。收录时 `preview` 成为结构字段：`preview: {kind: demo-video|author-gallery|local-probe, url?}`，无 preview 的条目降级/不上首屏（规则 12 的工程化）。
