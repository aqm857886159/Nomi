# 技能触发机制调研（2026-09-12）

**问题**：用户在 Agent 面板选了一个技能，产出的提示词/画幅和技能里写的对不上，感觉「技能没被用上」。

**这里有什么**：

- [`prior-art.md`](prior-art.md) —— 官方 Agent Skills 标准怎么触发技能（含 Claude Code / pi 两家实现）、
  Nomi 这一侧真实做了什么（带 `origin/main` 的 file:line）、差距表、以及给用户的十行结论。

**基线**：`origin/main` @ `a40886b63`。纯调研，无生产代码改动。

**一句话结论**：触发机制本身与标准一致（description 驱动 + `read` 正文），没坏。
问题是三件事叠在一起：① **整片默认画幅根本到不了画布**（真 bug，`prior-art.md` §2.6，与技能无关）；
② **技能正文本来也管不到画幅**（全仓无任何代码把 SKILL.md 读进生成参数，只能"劝"模型填工具参数）；
③ **「用没用上」不可观测**（模型自己加载技能时界面零痕迹；仓库里那段"不许假装加载"的提示词零生产调用者）。
详见 `prior-art.md` §3 差距表与 §4 十行结论。
