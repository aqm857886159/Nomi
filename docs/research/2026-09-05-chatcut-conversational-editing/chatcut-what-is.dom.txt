Understand ChatCut
What is ChatCut?
ChatCut is a video editor with an AI agent built into the editing workspace. Ask the agent to assemble or revise an edit in natural language, generate new media, or make precise changes yourself on a multi-track timeline. You can use ChatCut through the Desktop app, web app, or Agent Plugin.
What can I make with ChatCut?
Turn talking-head, interview, or screen-recording footage into a tighter cut.
Create short versions and alternate timelines from a longer project.
Generate video, motion graphics, images, music, captions, and narration.
Make app promos, product ads, explainers, and social videos.
Edit speech by deleting or rearranging words in the Transcript panel.
Export finished video, audio, subtitles, graphics, or XML.
How do I start?
Sign in and ChatCut opens a project for you. Add media, tell the agent what you want, review the result, and export it.
Start Your First Edit
walks through those five steps with screenshots.
Which product you use — Desktop, the web app, or the Agent Plugin — changes where the conversation happens, not the steps. See
Web, Desktop, and Agent Plugin
to choose one.
How is the editor organized?
AI
: describe edits and attach references, Skills, styles, voices, or generation models.
My Assets / Library / Transcript
: import and organize media, browse built-in assets, or edit speech as text.
Viewer
: play and inspect the frame at the current playhead.
Timeline
: arrange clips on video and audio tracks and switch between multiple timelines.
Top bar
: return to projects, rename or share, undo, manage the workspace and versions, and export.
