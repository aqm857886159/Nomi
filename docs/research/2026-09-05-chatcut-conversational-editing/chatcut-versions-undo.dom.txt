Editor and Media
Versions / Undo / Redo
Use
Undo / Redo
for recent editing actions and
Versions
for named restore points. ChatCut also syncs committed edits continuously; saving a version is an extra checkpoint, not the project’s basic save command.
Undo and redo
Select
Undo
or
Redo
in the editor header, or use the active keyboard shortcuts. A new edit after Undo clears the redo path. Restoring a saved version is itself undoable until later actions replace that history.
Save a version
Open
Versions
in the top bar. Only the project owner sees this control.
Select
Save Current Version
.
Enter an optional version name and select
Save
. Leaving it blank creates a date-based name.
The save-version shortcut creates an immediate unnamed checkpoint without opening the naming dialog.
Restore or delete a version
Open
Versions
, use search if needed, then select a version. Confirm
Restore Version?
to replace the current Timeline state. Restoring can reinsert asset records stored in the snapshot, but media missing from both the project and snapshot cannot be recovered.
Use the delete action on a version row to remove that checkpoint. Deletion has no second confirmation and only the creator can delete their version, so check the row before selecting it.
See
Keyboard Shortcuts
and
Sharing and Collaboration
.
