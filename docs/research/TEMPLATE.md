### 2.3 自媒体来源（TikHub · 必填）

> **为什么这节是必填的**：论文和英文技术博客讲的是「能做到什么」，自媒体讲的是「真做的人卡在哪」。
> 后者才是 D1（从用户真实摩擦出发）的原料，而它长期是我们调研的盲区。
> 详见 `docs/engineering/agent-orchestration-playbook.md` §15。

抓取命令（原样贴进来，含关键词和时间窗，方便别人重跑）：

```bash

  --q "<关键词>" --platform all --limit 20 --since <YYYY-MM-DD> \
  --out docs/research/<date>-<topic>/tikhub/
```
