# Nomi Research Radar — 2026-08-13

## 一句话结论

本轮最强信号：**VIPE（2607.25537）把“视觉提示”变成可自动搜索的低成本 prompt 层**，以及 **VABench（CVPR 2026）把音视频生成拆成可复用的同步/对齐指标**。前者适合先做成 Nomi 的 prompt 预处理实验，后者能把当前音频/唇形同步缺口变成可量化门槛。

**本轮最该动的 1-2 件事**：
1. 在 prompt 优化节点做一个 training-free VIPE spike：对首帧/参考图自动生成少量视觉提示变体，再让现有模型按一致性与构图得分选优；先验证是否比纯文本改写更省用户试错。
2. 把 VABench 的 audio-video alignment、lip-speech consistency、desync 三项指标接进 `evals/`，哪怕先离线跑样例，也比继续用“看起来同步”做主观判断可靠。

## 🟢 可落地

### Visual Prompt Engineering for Video Models（VIPE）

- [arXiv:2607.25537](https://arxiv.org/abs/2607.25537) · 2026-07-28 · [项目页](https://visual-prompt-engineering.github.io/)
- **洞察**：自动修改任务图像作为视觉 prompt，跨多个视频推理任务提升表现；论文报告它有时比传统文字 prompt engineering 和 test-time scaling 更有效，且计算成本低。
- **Nomi 落点**：在 prompt 优化节点增加“首帧视觉提示变体”分支（草图/构图标注/主体框等），复用现有图片编辑与 VLM judge 选择器。先做黑盒 A/B，不改模型、不引入供应商专属接口，符合 P4；待核实项目代码是否可直接复用。

### PhyPrompt — 物理常识驱动的 prompt refinement

- [arXiv:2603.03505](https://arxiv.org/abs/2603.03505) · 2026-03-03
- **洞察**：用 RL 自动补足运动、受力等物理细节，同时保持用户意图；在多个 T2V 架构上 zero-shot 提升物理合理性和语义遵循。
- **Nomi 落点**：不直接搬 7B 训练流程；把它的 reward 维度（用户意图、物理合理性）抽成 prompt 优化节点的可选检查项，并在 `shotVerifyRunner.ts` 里增加“物理违规”诊断标签。这样先得到可解释反馈，再决定是否接外部 prompt refiner。

## 🟡 架构教训

### InfinityStory — 世界一致性与角色感知转场

- [arXiv:2603.03646](https://arxiv.org/abs/2603.03646) · 2026-03-04
- **洞察**：把背景一致性、多主体 shot-to-shot 转场和长叙事扩展放进同一条生成管线，并用持久的场景/角色关系保持跨镜稳定；结果显示跨镜转场不是单独的“最后一帧接力”问题。
- **对 Nomi 的影响**：生成图节点和镜间接力应同时保存“场景关系状态”（角色相对位置、背景锚点、出入场主体），不能只传单张 tail frame。先把这些字段纳入 provenance/shot metadata，再考虑模型级实现；论文是否开源代码待核实。

### Directing the World — 组合式人物动作与相机轨迹控制

- [arXiv:2606.27964](https://arxiv.org/abs/2606.27964) · 2026-06-26
- **洞察**：将人体动作和相机轨迹解耦标注并组合控制，说明“导演意图”可以拆成相互独立、可重组的控制通道。
- **对 Nomi 的影响**：3D 导演台输出应继续保持通用的动作/相机语义槽，不把供应商字段写死在 UI；模型适配层负责把这些槽映射到具体 API。该工作依赖专用训练数据，当前更适合作为 P4 的架构依据而非直接接入。

## 🔵 对标基准

### VABench — 音视频生成综合评测

- [CVPR 2026 Open Access](https://openaccess.thecvf.com/content/CVPR2026/html/Hua_VABench_A_Comprehensive_Benchmark_for_Audio-Video_Generation_CVPR_2026_paper.html) · 2026-06
- **洞察**：同时评测 text-video、text-audio、video-audio 相似度、音视频同步、唇形-语音一致性和音视频问答，避免只看画质或单一 lip-sync 分数。
- **接入 eval**：在 `evals/` 建一个轻量映射层，先记录 `A-V alignment`、`lip-sync`、`desync` 三项；每次真实生成保留原始音频/视频与指标 JSON，作为后续音频节点的回归基线。无需一次性引入整套 benchmark。

### MSVBench — 多镜叙事连贯性基准

- [arXiv:2602.23969](https://arxiv.org/abs/2602.23969) · 2026-02-27
- **洞察**：用混合 LMM 与专家模型评估多镜视频的叙事连贯性，并报告与人类判断的相关性，补足传统单镜画质指标对“故事是否接得上”的盲区。
- **接入 eval**：把其“跨镜叙事连贯”作为 `shotVerifyRunner.ts` 的独立维度，与角色一致性、画面质量分开记录；先用固定 5 镜 smoke 集做趋势监控，不把单次分数当硬门槛。

## 上轮 vs 本轮 diff

- **新增**：VIPE（🟢 prompt 层的视觉变体搜索）、PhyPrompt（🟢 物理违规诊断维度）、InfinityStory（🟡 场景关系状态）、Directing the World（🟡 动作/相机语义解耦）、VABench（🔵 音视频同步基准）、MSVBench（🔵 多镜叙事连贯基准）。
- **状态变化**：音频/唇形方向从“缺口描述”进入可量化阶段，但本轮仍没有确认可直接复用的 training-free 开源模块；先接评测，不承诺能力已补齐。
- **本轮筛掉约 10 篇噪音**：包括超窗或重复的身份一致性论文、依赖大规模专用训练的数据集/模型、以及与 Nomi 当前 decompose-stitch 痛点无直接关系的通用视频理解工作。
