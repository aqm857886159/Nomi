## 🔵 对标基准（本补充轮净增两条）

### AgenticVBench — 可跑的「AI agent 做视频后期」基准，Assembly/Sequencing 直接对位 Nomi 编排层（**全仓 grep 0 前轮记录 · 主份漏抓 · 有码可跑 · phase-7 直接相关**）

- **证据**：[arXiv:2605.27705](https://arxiv.org/abs/2605.27705) · 2026-05-26（v1）· 官方码 [PhiloLabs/agentic-vbench](https://github.com/PhiloLabs/agentic-vbench)（**89★，Apache-2.0**）· 项目页 agenticvbench.com。任务由 **20 位平均 6 年经验的行业后期专家**从真实生产流程贡献；harness 建在 Harbor 上（负责 agent 安装 / 沙箱执行 / 并发 / 打分），CLI `./avb` 支持 Claude Code / Codex / Gemini 等多 agent + Docker/Modal/E2B 多执行器。
- **测什么（100 任务 / 4 家族）**：
  - **Assembly（18）**：从候选池选 4 个片段并放进正确 slot 顺序——**= Nomi「按 storyboard 排镜」的外部化考卷**。
  - **Sequencing（28）**：把打乱的镜头恢复成正确叙事序（考因果+时序）——**= Nomi 镜序/依赖调度的考卷**，且呼应 KathaTrace 的「镜间因果链」维度。
  - **Repair（18）**：定位并修复一处局部损坏（偏色/模糊/低清/换错物体/glitch/断内容/口误/音频瑕疵）。
  - **Repurpose（36）**：把长视频按 brief 重剪成竖屏短片（recap/trailer/teaser/social cut）。
  - **判分**：前三家族用**确定性 judge + 内置 oracle 解（得 1.0）与随机基线（得 0.0）**；Repurpose 用 **rubric-based LLM-as-judge（需 Gemini + Claude API key）**。
- **关键实测（对 phase-7 是直接输入）**：最强 agent 栈只到 **38%**，人类专家 **89%**；leaderboard 含 GPT-5.5 / Opus 4.7 / Gemini 3.1 / Sonnet 4.6 这代。**同模型只换 harness，GPT-5.5 的 Assembly 摆动 20pp**——harness/编排设计本身是一等变量。
- **怎么接（守 P3，只作诊断层不作单一放行）**：先只读 Assembly/Sequencing 的任务与 judge 定义，映射到 `runStoryboardPlanner.ts`/`storyboardPlan.ts`/`dependencyWaves.ts`，作 phase-7 编排复审的对照卷；**Repurpose 腿因需付费 key，先不进 eval 门岗**。若下轮要落进 `evals/`，作**独立诊断 lane**（区别于 `evals/journeys/` 的生成质量），别与统一 Agent 能力合同争第二套状态源。
- **限制**：是 benchmark 不是能力；任务分布来自其专家集，迁到 Nomi 前需读任务定义确认可比；Repurpose 有付费依赖。

### MBench — 视频记忆的 entity/environment/**causal** 三层评测（**全仓 grep 0 前轮记录 · 与 EntityBench 部分重叠 · 仅记**）

- **证据**：[arXiv:2606.00793](https://arxiv.org/abs/2606.00793) · 2026-05-30（v1）/ v2 2026-06-08 · 项目页 peanutup.github.io/MBench-project · **PDF 未见 code 链接**（暂不宣称可跑）。
- **测什么**：把「视频世界模型的记忆」拆成 3 大维 / 12 子维——**Entity Consistency（个体跨时追踪）、Environment Consistency（场景属性保持）、Causal Consistency（因果逻辑保持）**，在真实拍摄长视频上用「规则量化矩阵 + VLM」双路打分；命题是「视觉上像 ≠ 长时程内部状态稳定合理」。
- **为什么只记不接**：① 面向通用 video **world model**（连续单模型长时程），非多镜 decompose-stitch，跨镜记忆迁移它没显式测；② 与 08-20~08-31 已在册的 EntityBench（实体一致）高度重叠，**净增只有「causal-consistency 单列」这一角**——正好补 EntityBench 偏实体、KathaTrace 偏语义轨迹之外的「因果」维度。若 Nomi 自建多镜打分器，可借它「entity/environment/causal 三分 + 规则×VLM 双路」的**维度骨架**，别引其数据集。
- **限制**：无确认可跑码；作用域是 world model 非 Nomi 流水线；只借维度形状。
