## 方向检查（RW，承接诊断PR #1196）

授权：用户2026-10-16明确要求“跑整条链路、复现、确认根因修掉并提交PR，不停在诊断文档”。本轮沿共享宿主/既有框架修根因；未新增产品方向或另一套编辑器。

### 0. 一句话根因
节点数据合法不等于屏幕操作可达；稳定框架容器也不应随每个子节点变化重扫。可达性与DOM所有权此前没有真实回归同时约束。

### 1. 归类表

| bug | 直接原因 | 类 |
|---|---|---|
| 看不到模型/生成、浮框显示不全 | 固定下方浮框伸出裁切stage | 交互动作缺视口可达性合同 |
| 密集参考边平移/缩放卡顿 | 永久subtree observer重扫稳定容器、同边有重复透明命中层 | 容器生命周期与交互所有权没有收敛 |

### 2. 为什么反复出现
原有布局与模型测试检查“生成了DOM和字段”，没有检查用户是否能真正点到；常规规模性能夹具的边密度又没覆盖3000条参考边。⑪/⑫适用：模型动作必须可见可点，点击后恰好生成本镜。⑩本轮不是意图改写，未改任何模型/比例/时长/引用。类检查为 `composerViewportReveal.test.ts` 的几何矩阵、已有CI critical/full 的双语 dense-controls 与 signed-host生成闭环；性能类回归由密边注册场景承担。两条用户逃逸保持reviewed，PR未合入前不伪称fixed。

### 3. 不改结构的预测

| 预测 | 验证 |
|---|---|
| 手工/外部Agent、旧项目/新节点，只要靠左/下边界都会丢同一底栏 | 双语60图300边、3840字提示词、左缘/底缘检查 |
| 子树变化即重扫host、同边有两层命中，会增加无关DOM工作 | 真实Electron删除前扫描6次/命中2层，删除后扫描0次/命中1层；300图3000边保留5轮量具 |
| 每帧把浮框钳回屏幕会抢用户拖动/平移 | 从未选中卡起拖、选中后平移、重复点击不漂移 |

### 4. 靶子独立性
真实Electron帧量具和预算沿用现役脚本，红证先保存。控件回归由独立线 `/root/dense_canvas_repro` 编写/运行，已查中英截图；实现线另跑有真实stdio/磁盘回写的协议闭环。首批macOS damaged-tile截图被判为无效取证；没有拿取证伪影修产品或调预算。用户原工程未知继续标unknown。

### 5. P0
视口与连线渲染是通用能力，保留stock React Flow和官方API。Nomi只写“单选浮框打开时最小平移”的领域连接，并删自己的重复DOM工作。实验性框架几何/可见缓存未闭环预算，全部撤出，package与lock未变；不把无收益依赖补丁带入交付。

### 6. 方案对比

| 选项 | 代价与风险 | 判断 |
|---|---|---|
| 复用React Flow viewport API，删除自有重复扫描/命中层 | 领域代码少；保留真实生命周期/交互和规模回归 | 当前实现 |
| 调整浮框为翻转、跟随或另开详情页 | 改掉已定“固定下方”合同，增加用户定位成本 | 不选 |
| 隐藏参考边 | 视觉变快但引用关系不可读，改变产品行为 | 不选 |
| 自写另一套边渲染器/画布 | 重复承担成熟框架职责，后续维护大 | 不选 |

### 7. 核心权衡
保留用户对节点和引用的空间认知，在共享边界保证动作可达并删除无关DOM工作；极限规模仍有长任务，改善不等于整个卡顿已消失。

最终所有权收敛：既有`composerCanvasPlacement.test.ts`原样保留禁令，Anchor没有getRect/rAF/setViewport；它仅发意图并取消宿主返回的待执行frame。宿主拒绝active/dragging/panning及已卸载元素，同一frame测量、取消既有动画租约、duration0直写。37项focused回归通过。快速fit→选卡的旧实现临时旅程通过，故动画竞争只记所有权风险核查，不伪造红灯。独立线复审建议辅助平移guard已采纳。
