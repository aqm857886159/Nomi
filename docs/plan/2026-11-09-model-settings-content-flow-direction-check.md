# 模型设置三处内容流：方向检查与已有目录例外

## 0. 根因和本轮决定

已拍板的旧样张把次级动作和展开箭头推到右侧，但设计系统的行布局要求附属紧跟文字；两份依据冲突。用户 2026-11-09 已定：「照设计系统行布局，不照样张贴右」。本轮只删除三处 ml-auto，复用已有 flex/gap-1.5 内容流，不更改交互、接口、存储或门岗，不重画样张。

## 1. 触发与例外边界

commit-msg 在本目录近 14 天已有 5 个 fix 时拦下第 6 个。两个目标文件的路径历史仅有 bed56f45e、81e973af6 两个 feat，没有触发文件自身的重复 fix。命中的是目录，不是文件。本轮是换/删旧布局，没有新条件分支或平行实现，符合 CLAUDE.md P1 既有「仅概念/目录/自写登记命中、文件自身未命中，换或删且不新增分支」例外。协调本轮明确指派按用户决定做这项替换，本记录据此执行已授权的小范围改动，并在交付报告如实披露目录触发；不另称已完成独立复盘或新开门岗例外。

## 2. 不变量与类根因

⑩说的=摆的：三处次级控件必须紧跟各自标题/状态文字，不能通过伸展标题或等价 CSS 继续推右。⑪不适用：没有参数目录变更。⑫动作不变：刷新/管理和两行展开保留原处理器，只改变位置。根因在冲突设计依据的优先级，不在按钮功能。清单明确用户的新决定，保留候选和状态；tokens 的既有上限不变，运行时几何断言同时检查间距、垂直居中和标题/副标题左对齐。

## 3. 可验证预测

保留任一 ml-auto 会继续使 tokens 红；用 label 伸展推右会使几何间距断言红；只改浅色或中文而遗漏另一轨会由中英暗三态截图/几何收据暴露。验证路径为 tests/ux/apimart-model-surfaces.rehearsal.mjs、check:tokens、check:board-parity。

## 4. 尺子独立性

设计系统 §行布局和现有 tokens 门岗均早于本改动；用户已解决旧样张与该规则的冲突。几何/截图补证由实现线执行，不能冒充独立验收。清单仍保留账户卡和接入行尚未完成的其他内容，不把三处布局收口伪装成整项交付。
