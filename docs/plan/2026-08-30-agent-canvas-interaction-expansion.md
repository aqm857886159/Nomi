把本轮调研转成 #194 可直接实现和验收的交互合同，补齐用户如何把画布对象、附件、网页素材和生成模型带进 Agent，以及 Agent 如何把多媒体结果送回画布。

## 范围

- 画布选中对象自动进入可见上下文架；`@` 显式添加其他对象。
- 图片、视频、音频、文档、3D 与网页选区的结构化引用、发送快照和漂移提示。
- 工作方式与批准策略分成两个维度。
- Agent 文本模型与图片/视频/音频/3D 制作模型分层。
- 对话内多媒体回执、画布定位、候选接收和局部返工。
- Agent 忙时不丢输入，队列保存文字、附件、上下文与模式快照。
- 浏览器只读采集与 Connector/Skill/Workflow 的既有能力目录对齐 #226。
- 用开源近邻源码支撑主要交互决策；跨领域产品只补局部原语。

## 不动项

- 不修改生产代码、IPC、Agent loop、工具 schema 或模型 API。
- 不在 #194 复制 #226 的能力目录和权限真相源。
- 不把媒体制作模型塞进 Agent 文本模型选择器。
- 不默认授权登录、发布、删除、外部写入或任意 DOM 操作。

## 回滚

本轮都是文档和独立 HTML 样张修改，可逐文件回退；规则真相源只改 `CLAUDE.md`，`AGENTS.md` 由生成脚本同步。

## 验收门

1. 主文档对输入、执行、反馈、恢复四段都有明确状态与数据合同。
2. 样张可真实操作：选中对象、`@` 引用、附件类型、工作方式、批准策略、排队、媒体回执与画布定位。
3. 320px、390px、桌面宽度均无横向溢出；亮暗色、键盘、长文案和 reduced-motion 可用。
4. 每个关键建议至少有一个开源近邻固定提交与源码位置，并说明适用边界。
5. `pnpm run check:agents-sync`、样张走查、`git diff --check` 通过；提交前执行仓库要求的完整门禁。
