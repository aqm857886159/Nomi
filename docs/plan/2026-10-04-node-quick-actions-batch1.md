## 0. 一句话

选中一张已出图的图片节点，浮条上一点「多机位九宫格」（或它右边分体的 ▾ 里的其余效果），就**新建一个下游图片节点、连好参考、填好模板、沿用模型，到此为止（不生成、不扣费）**，用户自己在新节点上点 ↑ 才生成；改图（高清 / 扩图 / 抠图 / 裁剪 / 旋转翻转）收成一个下拉；宫格切分扩到 4 / 9 / 16 / 25 + 自定义行列；节点右侧「+」圈点一下出「用这个节点生成…」；右键多一项「复制为变体（带上游连线）」。

## 先查别人

只查一个问题：「在节点上点一下预设，是直接生成，还是只把节点准备好？」

- LibTV（协调会话转述，本线未实查）：节点上的一键预设直接开跑。我们没有照做：花钱要由用户自己点——用户控制权优先于省一次点击（用户 2026-10-05 拍板）。代价：每个预设多点一下 ↑（§3 点击数已按此重算：6 / 7 / 9 → 7 / 8 / 10）。
- 本仓库已有的同类做法：效果库挑一条应用到节点，只往提示词里追加，不生成（`src/workbench/generationCanvas/nodes/NodeGenerationComposer.tsx` 的 `applyPromptPickerItem`；`src/workbench/generationCanvas/nodes/NodeEffectChips.tsx`）——派生沿用「先准备、后生成」同一个节奏。
- ComfyUI（https://docs.comfy.org/ ，通用常识，未逐页复核）：搭好节点图后要用户点 Queue / Run 才执行，改图不触发执行。
- Photoshop 生成式填充（https://helpx.adobe.com/photoshop/using/generative-fill.html ，通用常识，未逐页复核）：先选区、写提示词，点「生成」才消耗生成额度。
- 本仓库的花钱入口：节点 ↑ 走 `src/workbench/generationCanvas/runner/generationRunController.ts:539` 的 `confirmAndRunNode`（单镜 Run，用户单点不弹卡、第一次匿名托管弹披露卡）——派生不新开第二个，只让用户走它。
- 结论：用已有的节点 ↑ 生成入口，派生只做准备；派生代码里没有任何提交 / 批准 / 派发调用（`deriveFromNode.noMoneyDoor.test.ts`）。
