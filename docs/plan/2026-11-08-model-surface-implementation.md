# 模型账户、选择器与发送前估价

以 11-07 已拍板的 ModelSurfaces 板为准。设计记录见现有 #1416 与板上 M1、M2、M4。资金显示采用批准的 D1c 决策：APIMart 积分为主，美元为辅，账户余额、Key 限额、估算、实扣各有出处。原图的数值只用于排版。

## ★0 先查别人

APIMart [Key 额度](https://docs.apimart.ai/en/api-reference/account/token-balance.md)用 unlimited_quota 区分 Key 不设上限与账户余额。[账户接口](https://docs.apimart.ai/en/api-reference/account/user-balance.md)直接给 remain_credits；未知保持空。[用量](https://docs.apimart.ai/en/api-reference/account/usage.md)用成功计费请求汇总近七天消费。已拍板板上把这三项同列，旧版普通连接行混合认证、余额与启用状态。

出口：[APIMart Key 额度](https://docs.apimart.ai/en/api-reference/account/token-balance.md) · 用户可在账户余额与 Key 剩余额度之间识别限制来源 · 确认零余额提供刷新与充值，非零差额保留已有发送和授权入口。

## ★1 创作者结果

创作者打开设置能分清账户余额、Key 限额和近七天消费；画布选择型号能看到其在当前连接的能力，调整参数时估价及时更新。量具为实际设置与画布的中英真窗、独立预置响应及出站请求计数。
★2. 主进程持有凭据；账户事实和报价由现有目录确认连接和最终出站参数，再以只读接口查询。画布和 Agent 消费同一份生效型号与参数。
★3. 复用供应商凭据探测、目录选择器、已有任务请求构造、HTTP 模板和工作台 token；更新现存入口避免出现第二份目录、报价或余额。
★4. 读取账户仅发 GET。未知、不可达、零与不设上限各自呈现；读失败仍可管理连接。只有受用户花费审批保护的原始生成入口能够创建任务。
5. 同一供应商的不同连接按实际连接身份和凭据各自读取；换 Key、换地址、停用与项目切换均不能复用前一份结果。
6. 没有持久化数据迁移。旧项目中的型号和档位保留；修改模型继续使用原有入参准入。
7. 打开设置按连接合并并发读取，短期缓存。重复渲染不会发请求；以出站次数和组件时序衡量。输入参数变更沿原报价计算成本，对失序响应只采用当前参数结果。
8. 不生成媒体。官方响应回放覆盖无 Key、零余额、无限制、部分不可读、切换连接。价格与任务实际费用分开核验。
★9. 核对 M1 账户与 Key 分离，M2 上限、标签与当前目录一致，M4 只有有来源的估价才显示数值；中英和窄窗可操作，旧连接仍可管理；拒收、取消和仅看价格的流程生成提交数为零。上线状态以实际独立收据为准。

**价格判据。** [总价目](https://api.apimart.ai/api/pricing/models/all)验证按张的计价单位，[单型号价目](https://api.apimart.ai/api/pricing/model?model=doubao-seedance-2.0-mini)验证最终出站 ID 和规格。用公开折后价，未冒充会员实扣；积分 = USD × 10（[官方用量说明](https://docs.apimart.ai/en/api-reference/account/usage.md)）。例如接口 720P 的 0.0390344 USD/秒 × 5 秒为 0.195172 USD。按 token 但明确公布固定规格的输出估价时，注明仅估输出、实扣按 token；其余按输入时长、输入额外收费或分档未明时继续显示未知；这次仅展示价格，不生成花费凭据。旧预算点的单位来自本地配置，不拿来比较账户余额。

## R0 价格与额度

设置页的美元值只能由主进程读取的 APIMart 账户积分快照换算。发送按钮的估价必须来自当前连接、最终模型 ID、输出规格及份数都匹配的 APIMart 公开价。来源缺失时保留未知。会员实际价格可能更低，普通余额低于公开估价仍可走原审批。账户或有限 Key 明确为零时给充值入口及刷新。

核对窗口请运行 `node tests/ux/apimart-model-surfaces.rehearsal.mjs`。脚本使用临时项目、合成 Key 和回环 HTTP 服务，检查同一窗口里已知、未知、零余额，切换画布型号、档位与估价。每次运行在 `.tmp/model-surface-rehearsal` 留下中英截图和 GET 收据。
