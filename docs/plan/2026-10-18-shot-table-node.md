## 问题

- 拆解前选不了模型：点「拆解 → 镜头表」立刻开拆，报价卡上只有一行生硬的 `apimart · gemini-3.5-flash`，转写模型根本不显示。#1171 加的「读图模型」只在表的底栏，表建出来时已经在跑、选择框是灰的，只对重拆有用。
- 拆解表不像我们的节点：别的节点选中后上方浮条、下方生成框；拆解表把七个控件挤在节点内部的底栏里，单元格编辑弹对话框，没有列显隐、没有行高。
- 竞品参照（2026-10-18 调研）：LibTV 脚本节点（可由参考视频拆成分镜）= 表格 + 字段可见性 + 右上「全屏」+ 首列勾选批量出分镜图 + **节点底部生成器选模型 / 比例 / 分辨率**；TapNow「拉片」= 一键拆成可编辑的分镜表 + 提示词，接下游节点。

## 第一批做什么

1. **拆解改成「先建表、再拆」**：视频浮条「拆解 ▾ → 镜头表」只建出拆解表（空、待拆）并选中它，下方拆解栏出现；点「拆解」才开始花钱。与生成节点「先建节点、再按 ↑」同一个逻辑。**报价卡（用户 10-18 拍板「短片不弹，长片才弹」）**：一共不超过 `DECONSTRUCT_ASK_ABOVE_CALLS`（30）次调用时，点「拆解」那一下就是确认、不弹卡；超过才弹报价卡。
2. **下方拆解栏**（钉在节点正下方、居中，复用生成框的画布定位锚）：源视频一行 · 读图 chip · 转写 chip · 「+ 自定义列」· 主按钮（拆解 / 重新拆解 / 取消拆解 / 改用云端重试）。
3. **勾了镜头时**下方栏只说「已选 N 镜」+「取消选择」。~~「生成 N 镜」~~ 已删（用户 10-18 画布评论：表上闷头生成看不到生成什么、用哪个模型、提示词是什么，也没确认需求——拆完要干嘛交给 Agent；拍板清单 composer.generate / image-model-chips 标 dropped 带原话）。
4. **上方浮条**（选中才出、居中）：显示列 ▾ · 行高 −/标准/+ · 复制节点。
5. **记住上次的选择**：读图 / 转写模型默认取上次拆解时选的；选的模型用不了时当场说原因，不悄悄换。
6. **三档缩放**（图 4）：远 = 卡片（标题 · 镜数 · 问题数 · 关键帧条）；中 = 镜 · 关键帧 · 景别 · 画面；近 = 全部列。

第一批**不做**：全屏与右侧详情（第二批）；导出 CSV（随全屏一起，第二批）；出分镜图时选模型 / 比例（图 2 的 chips 第二批接，现有 generate 用默认模型，本批只换入口位置并原样标注）。

## 设计卡

| 格 | 内容 |
|---|---|
| ★1 用户怎么用 | 当我拿一条参考片想拆成镜头表时，我想**在花钱之前**选好读图和转写用哪个模型，并在节点上看清、改动整张表，以便不用拆完才发现用错了模型、不用在挤成一排的小按钮里找功能。步骤：①视频浮条「拆解 ▾ → 镜头表」②拆解表出现并选中，下方栏带着上次的读图 / 转写模型 ③要换就点 chip 换 ④点「拆解 ↑」→ 报价卡确认 ⑤运行中主按钮变「取消拆解」⑥拆完勾几镜 → 下方栏「生成 N 镜」⑦用浮条调列和行高。不做：见上。已知坑：选的模型被停用（不悄悄换）；本地转写失败（改用云端是显式动作）。真实任务：①用户 10-11 那条限流参考片（读图换模型后重拆）②一条有对白的 15s 参考片（本机转写）③没有音轨的片子（转写行显示「这条视频没有声音，不转写」）。主指标：拆解前改过模型的比例；护栏：误扣费 0、选择丢失 0。 |
| ★1b 连带界面 | ①报价卡：读图 / 转写两行显示用户选的模型名（目录显示名；查不到退回 `vendor · modelKey`，不编名字；没音轨就没有转写行）；②视频浮条「镜头表」菜单说明改为「建一张拆解表，选好模型后再拆」；③分镜表顶部失败摘要不变；④Agent 不涉及（拆解入口只在浮条与表）。中英文案进 i18n。 |
| ★2 谁说了算 | 选的读图 / 转写模型 → 表上 `source.visionModel` / `source.transcribeModel`（唯一一份，重拆与单镜重试都读它）；「上次选的」→ 不另存：建表时从**这个项目**里最近一次拆解的表推（`lastDeconstructModelChoice`，读图 / 转写各取各自最近一次有值的），选择只有表上这一份；新项目没有表可推，默认「自动选择」；行高 / 列显隐 → 表上 `view`（随项目保存）。拆解运行状态仍归 `deconstructionLifecycle`。 |
| ★3 一致与复用 | 定位锚复用 `ComposerAnchor` / `composerCanvasPlacement`；浮条复用 `NodeFloatingToolbar` 的 `ToolbarIconButton` / `ToolbarActionMenu` 与 `ToolbarDuplicateVariantButton`；读图选项复用 `VisionModelPicker` 的选项来源（`useModelOptionsState('text')` + `supportsImageInput`），转写选项复用主进程同一个解析器的模型清单（audio / transcribe）；chip 样式复用生成框的模型 chip。不新写定位、不新写下拉。 |
| ★4 全状态 | 空（新建待拆）：表内「选好模型后点下方「拆解」」+ 下方栏主按钮「拆解」· 加载：既有阶段文案，主按钮「取消拆解」· 成功 · 部分成功：失败镜原话 + 单镜重拆 · 失败：顶部原话，主按钮「重新拆解」· 取消中：既有取消态 · 过期（选的模型被停用）：chip 标红 + 原因 +「先换一个」，主按钮不可点 · 能力不可用：没有能读图的模型 →「还没有能读图的模型」+「去接入」；没有音轨 → 转写行写明不转写；本机转写没装 → 转写 chip 选项里本机一行写「需要下载」。**实现对账（10-18）**：过期 = chip 上红色「用不了」+ 选项行标注 + 下方栏原因行、「拆解」不可点（`shotTableComposerStates.test.ts`）；没有能读图的模型 = 读图下拉只剩「还没有能读图的模型 · 去接入」（复用模型框的 `openModelCatalog`）；**没做、明标**：没有音轨在拆之前不可知（引擎拆时才探），只在报价卡上体现为没有转写行；本机转写是否装好清单里没有信号，「需要下载」未做，转写失败走既有「改用云端重试」。 |
| 5 中途表 | 建表后不点拆解就关窗：表留着、待拆、零花费；报价卡上取消：零花费、表回到待拆；拆解中关窗 / 重启：沿用 #846 的中断终态（可重拆，不重复扣费）；连点「拆解」：一次动作一张报价卡（既有令牌约束）；断网：读图腿失败按镜标原话。 |
