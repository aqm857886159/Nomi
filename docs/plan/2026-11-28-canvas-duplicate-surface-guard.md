## ★0 先查别人

- Nielsen Norman Group — Empty-State Interface Design（`https://www.nngroup.com/articles/empty-state-interface-design/`）· 空状态本身承担首次引导与核心创建动作时，不应在同一视口同时堆叠另一套同构常驻创建栏分散视觉焦点；一旦用户创建首个对象退出空态，常驻工具条再接管 · **改了**生成画布空态挂载规则：`nodes.length === 0` 时只显示画布中央 7 张起步创建卡（`CanvasEmptyState`）与左下缩放簇，收起正下方完全同构的底部 7 钮创建胶囊（`CanvasToolbar`）；一旦有 `≥1` 个节点，中央空态退场、底部创建胶囊立即显现。
- Nomi 项目库既有单主入口实践（`src/workbench/library/ProjectLibraryPage.tsx:212` · `tests/ux/_shell.mjs:229`）· 空项目库首屏只显示中央起始动作卡「新建空白项目」，隐藏右上角「新建项目」按钮；有 `≥1` 个项目后起始卡退场、右上角「新建项目」显现，走查外壳出口 `newProjectEntry(win)` 统一匹配当前激活的那一处 · **确认了**画布创建入口与走查出口的同构收口方式：`CanvasEmptyState` 补齐与 `CanvasToolbar` 完全一致的 `data-node-kind` 属性，`_shell.mjs` 的 `canvasAddBar(win)` 按同样模式解析当前唯一激活的画布创建入口（0 节点取空态起步格，`≥1` 节点取底部工具条）。
- Nomi 常驻 Agent 面板 v4 单一头部规范（`src/workbench/ai/v4/AgentPanelV4Panel.tsx:419` · `src/workbench/ai/v4/AgentPanelV4Empty.tsx:6` · `docs/design/boards/2026-10-27-agent-persona/AgentIdentityRow.board.json:12`）· v4 面板顶栏 `<header>` 已常驻展示唯一品牌身份 `NomiBrand`，面板内所有消息气泡（`V4AssistantMessage`）与默认空态（`V4EmptyState`）均不再重复渲染头像或身份行 · **改了** `NoTextModelRecoveryCard.tsx`：移除旧 `CreationAiPanel` 时代遗留的卡片内 `<NomiIdentityRow />`，消除面板顶栏与首张恢复/指路卡相距约 22px 出现两个 `Nomi` 徽标的双胞胎冲突。
- Playwright / Axe 视口级体验扫描（`tests/ux/_feel.mjs:11` · `tests/ux/_feel-observer.mjs:124`）· 组件级单测各测局部子树，无法发现跨组件拼装后的同屏重复身份头或重复工具条；整屏几何与语义扫描器必须在每次截图和状态落定时不依赖产品选择器自动巡检整窗 DOM · **改了** `tests/ux/_feel.mjs` 与 `tests/ux/_feel-observer.mjs`：新增纯几何/语义规则 `duplicate-nearby-header`（同容器头部与紧邻正文重复标题/徽标）与 `duplicate-action-bar`（同视口非重复数据项的同构动作条），并在棘轮旅程默认设为零容忍（`allowed: 0`）。
- 出口：不涉及：本次未新增、扩大或挪动拒绝、加锁、等待等挡人保护，仅移除未连模型卡内冗余品牌徽标并在 0 节点空画布收起底部重复创建条（中央 7 动作卡、拖入文件、右键添加与 `≥1` 节点后的底部工具条全部保留）。
