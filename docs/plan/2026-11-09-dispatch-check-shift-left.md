## 反例合同

1. 实现任务缺自验，或自验缺 ★9 / 每条反例 / 改坏红 / 还原绿 / 日志进报告任一要求，必须报反例红绿缺项；自验外同样文字不得顶替；纯测试、纯文档、纯配置明确声明可豁免，混合代码任务不可豁免。
2. 范围内存在的真实 Git 热点文件缺 `docs/engineering/direction-checks/*.md` 引用必须拦并列文件、要求先派独立方向检查；补引用通过；冷文件通过；只有目录 / 概念热点提示不拦；范围外（含范围节内明确「不在范围」段）、绝对路径、不存在文件不作为热点输入，固定 ref 后的新提交不影响结果。
3. 范围含 `src/**/*.tsx` 或正文提到界面 / 样张 / 拍板，缺 `docs/design/nomi-design-system.md` 必须拦；补文件或章节引用通过；非界面任务不误拦；流程里单纯「用户拍板」及明确排除的界面不触发，含界面样张的批准仍触发。

## 系统改进

症状是测试漏检、热点多轮修补和设计系统细节不一致到独立验收才发现；直接原因是派工检查只查基础声明；类根因是规则未汇入共享派工入口。本次为既有流程工具增加自动检查，不改生产路径，根因合同 schema-v3 不适用；不增加依赖、可选开关或另一套热点逻辑。
