## 4. 靶子独立性

事故判据来自夜跑退出码及 Git 树守卫，新增文件系统断言由实现线编写，使用真实目录和子进程。两次实测事故是反例，显式指定仓库外目录是正例，能让「全部拒绝」失败。这次改动不涉及评分。协调线报告夜跑 Node 定向检查 38/38 通过，Ubuntu/Electron 走查重跑待验证。
