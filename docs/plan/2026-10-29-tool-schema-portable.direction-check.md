# 模型工具 schema：类根因方向检查

## 0. 根因与触发

发布器没有标准支持面的合同，旧黑名单只记事故。fix-churn 命中自写登记 `mcp-protocol`（to-replace）；另命中 modelFacingTools.ts 文件近 14 天第三个 fix。本轮用户及协调已明确拍板「通用标准白名单 + 推导转换」，是本类根因的结构性方向；按这一轮明确授权实施，不引用原任务书仅目录口径的代批来冒充文件级豁免。该文件仅在现有投影末尾调用共享标准转换，以保证重算指纹与实际广播一致；移除这步会产生四个确定的漂移反例。没有再加供应商补丁。交接报告单列热点与方向依据，协调独立验收复核。

## 1. 归类

| 问题 | 直接原因 | 类 |
| --- | --- | --- |
| 文稿拆镜整轮参数拒绝 | items 数组被广播，旧判据放行 | 发布合同缺失 |
| 未知关键字可继续逃逸 | 事故黑名单、MCP 另一份白名单 | 同一发布标准有多个主人 |

## 2. 为什么反复出现

作者写的是合法 Zod，转换器输出其支持方言，但发布者没有明确自己的通用方言。铁律⑫：发送拆镜请求的实际结果必须与可见能力一致。结账挂 scripts/check-model-schema.node-test.mjs 全量矩阵及真实网关走查；未有真实证据保留 reviewed。

## 3. 可验证预测

新 tuple 可从任意工具再次出现；新关键字可绕旧黑名单；普通测试不发送整工具清单就看不见网关拒绝。验证分别为泛化 tuple/未知关键字反例、全 54 条清单和 tool-schema-real.paid.mjs。

## 4. 尺子独立性

实现线的测试只证本地边界，不能自签真模型/Windows 结果；独立验收由协调另派。免费演练与付费使用同一步骤，夹具结果不计作真模型分数。

## 5. P0：现成方案

优先接入 [JSON Schema 2020-12](https://json-schema.org/draft/2020-12/json-schema-core)、[OpenAI 官方支持范围](https://developers.openai.com/api/docs/guides/structured-outputs#supported-schemas) 和现有 Ajv 8.20.0 的 2020-12 元 schema 校验。协议标准是通用能力，Nomi 只负责从现有 Zod 派生模型提示。登记 mcp-protocol 的整套 SDK 生命周期不在本轮重写；本次删除它的独立白名单，不新增 MCP 协议分支。何时替换：登记 owner 整体迁移 SDK 时仍须通过现有租约/权限/画布业务回归和本次标准矩阵，不以 schema 修复扩大为协议重写。

## 6. 对比

| 选项 | 代价与风险 | 判断 |
| --- | --- | --- |
| 接入现成标准 + Ajv 元 schema | 共享转换和一份支持范围；原 Zod 不变 | 推荐，按本轮明确方向实施 |
| 再补 tuple 黑名单 | 省眼前改动，下一种形状仍可逃逸 | 已被新方向取代 |
| 重写 MCP | 牵动租约和授权，不能代替发布合同 | 不属本轮 |
| 删执行约束 | 模型与业务输入更宽，违背任务 | 不采用 |

## 7. 核心权衡

模型提示只表达通用标准允许的约束；无法表达的写明说明，由原 Zod 拒绝违规输入，而不是改变工具实际接受什么。

特征测试：scripts/check-model-schema.node-test.mjs、tests/agent-runtime/lane-tool-schema.test.mts、electron/shared/director/directorPlanSchema.test.ts；红测试先于产品实现保存在专用交接临时目录。

## 8. 第 3 轮补充：碰到门岗族 `gate-family`

CI 查出渲染层把 CJS 校验器带进了依赖图，靠 `vite.config.ts` 的别名才跑得起来，不读那份配置的浏览器夹具起不来。这一轮是换和删：判据搬到主进程一侧，别名和 ESM 副本删掉。

为了不让它再回来，碰了 `scripts/check-boundaries.mjs`，所以命中自写登记 `gate-family`。这一刀用的是现成的 dependency-cruiser，只加一条规则，并把手抄的规则清单改成从规则集派生，没有新增自写判据。

门岗族整体现在换不了现成工具：大部分门岗查的是 Nomi 自己的登记表和合同，没有现成工具对应；保留、合并、降级、删除的清单在 docs/audit/2026-10-01-gate-ledger.md，还没逐项拍板。哪天换：清单拍板之后（登记里的复查期限是 2026-11-30），按结论逐道删或合并。
