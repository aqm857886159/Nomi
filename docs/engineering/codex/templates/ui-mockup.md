## 用户拍板的方向（10-08，原话要点）
- AI 写的方案（Agent / 分镜方案生成的提示词）里的指代：**直接引用**（自动绑定，正式 chip）。
- 画布里用户自己写的提示词：**不直接引用**——识别到的词下面**置灰（灰虚线下划线 = 建议，还没确认）**，hover / 点击弹出按匹配策略排好的**几个候选**，用户**选一个**才绑定（变正式 chip）；继续打字 = 忽略。
- **另一种引用方式**：引用来源分「Agent」和「画布节点」——点了之后**进入点选模式，直接去画布上点**某个节点 / 素材作为引用。
- 协调会话补充（已对用户说过）：付费确认卡逐镜列出「这次实际引用了什么」，引用错了在花钱前就能发现；用户手动去掉的引用永不自动加回；AI 方案里的指代对不上（不存在 / 同名两个）时退回建议态，不瞎绑。

## 要出的样张（中文为主，关键 2–3 张出英文；亮色为主，挑 1 张暗色）
1. 画布节点提示词：一个词是正式 chip（已绑定），另一个词是灰虚线建议；
2. hover 建议词弹出候选层：3–5 个候选（缩略图 + 名字 + 为什么匹配的极简标记，如「同名 / 别名 / 本组唯一」——用图标或短标签，不写解释句），键盘可选（↑↓ Enter、Esc）；
3. 选中后变正式 chip；chip 上 × 去掉后（去掉过的不再自动建议——这条状态不需要文字解释，只要样张里能看出该词不再有下划线）；
4. 引用入口：@ 菜单里分「Agent / 画布节点」两类来源（或同等清楚的入口），选「画布节点」→ 进入点选模式：画布变暗、可引用的节点高亮、不可引用的置灰，鼠标悬停的节点有选中框；顶部一条极简的模式条（含 Esc 退出）；点中后回到原输入框、插入正式 chip；
5. 分镜列表视图的卡片 / 检查器里同一套 chip 与建议态（复用上面的组件，证明三处统一）；
6. Agent 面板：AI 方案提示词里自动绑定的 chip；有一个对不上的退回灰虚线建议；
7. 付费确认卡：每一镜下面列出本次实际引用（chip 缩略），能一眼看出引用对不对。
