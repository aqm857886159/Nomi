# 方向检查：时间轴配乐「上传本地文件」空回调（协调代批例外）

命中：提交钩子按目录口径数，src/workbench/timeline/ 近 14 天已有 2 个 fix——297ef1058（快捷键弹窗换共用外壳，TimelineShortcutsDialog.tsx）、833a93e37（分隔条手势认领，TimelineResizeHandle.tsx）。本刀改 TimelineSecondaryAddRow.tsx，这个文件 14 天内没有 fix，三刀分属三个概念（弹窗外壳、手势、上传入口），不是同一处反复修。

为什么走代批例外：CLAUDE.md P1 写明「只因概念 / 目录 / 自写登记口径命中、要改的文件本身没命中，且改法是换或删（同提交删旧、不新增分支或特例）时，由协调会话代批、事后报用户」。本刀同一提交删掉空函数 `onUpload={() => {}}`，接到素材库已有的唯一本机导入口，再沿同组件「从素材库挑一首」那一支已有的落轨规则和失败文案；没有新开关、没有特例。协调会话 2026-11-21 代批，并在当天报告用户。

症状：时间轴「+ 配乐 → 上传本地文件」选完文件什么都不发生，没有配乐、没有提示（9-28 起，主分支同样）。
直接原因：父组件交给 AssetPicker 的 onUpload 是空函数。
类根因：可点控件拿到一个什么都不做的回调，没有任何检查拦；现有空处理函数门岗只认 4 个属性名。
系统改进：复盘线的空处理函数门岗扩到全部 on* 属性，排在本修复合并之后（今天主分支上全仓生产代码只有这一处会红）。
判据：挂接测试从组件渲染入口点「上传本地文件」喂文件，断言配乐轨多 1 段；在主分支代码上因断言红，「上传后不落轨」版本也红，修复后绿；真窗口中英修前修后各一次。
