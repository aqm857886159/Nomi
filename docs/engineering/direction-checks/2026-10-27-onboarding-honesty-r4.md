## 2. 为什么这一类会一直出现

- 夜跑只挑 `tests/ux/` 顶层的 `*.walk.mjs`（`scripts/nightly-walk-selection.mjs:16`）。接入旅程在子目录里，入口叫 `run-journeys.mjs`，夜跑挑不到。
- CI 的 `test:journeys` 跑的是另一套（`scripts/eval-journey.mjs`）。`pnpm run test:model-access:journeys` 只有人手动跑。
- 结果：画布或设置页一改，旅程就过时，没有任何红灯。下一个拿它验收的人正在修别的事，只好多派一轮。
- 体验铁律：适用 ⑫「点了=以为的」。接入旅程是「接入页存下的模型，用户在节点上真用得上」的唯一端到端证据。它不跑，这条证据就是空的。
