# 设计卡（暂停点①）

> 一页纸，**动手前**写。写进任务书或 `docs/plan/<日期>-<题目>.md`，PR 正文 `## 设计卡` 一节放链接或全文。公开仓里的卡不写金额、价格和供应商的商业内容。
> 暂停点②是合并前的**独立验收**（另一条线，PR 正文 `## 独立验收`，见下）。两个暂停点都不是事后补的作文：卡在动手前定，验收时对着它再核一遍。

## 填几格

- 碰「**花钱 / 长跑 / 可打断 / 新界面**」任一类 → 9 格全填；
- 其他改动 → 只填带 ★ 的 5 格（1、2、3、4、9）；
- 每格一行：写结论，后面跟「证据命令」或写「人工」。格子空着 = 没过；确实不适用就写「不适用：理由」，理由要具体。

```
改动名：                线/负责人：            类别：[花钱][长跑][可打断][新界面][其他]
```

| 格 | 问什么 | 一行怎么写 | 证据（命令 / 文件，或「人工」） |
|---|---|---|---|
| ★1 用户怎么用 | 谁、在什么时刻、要做完哪件事 | 「当……我想……以便……」；5–8 步；**不做什么 + 已知坑**；**2–3 条真实任务**（真实素材 / 真账号形态，不是合成夹具）；同格写主指标、质量指标、护栏指标、基线 / 目标和样本来源；新界面再写一句 brief + 新手 / 老手人设，以及每步「预期 → 实际」记录方式 | 真实任务脚本路径 / 人工 / 逃逸账本 |
| ★2 谁说了算 | 这件事的状态 / 数据归谁；允许谁读 | 概念名 → 唯一 owner（`concept-owners.json` 里的概念）；允许的消费者；状态默认归主进程；碰了几个概念；同一份事实存了几份（答案应是 1，否则写理由）；有没有靠「东西不见了 / 状态变了」去猜用户意图（应是没有，意图走显式事件）。**这一格取代原来的「任务书概念占用表」** | `node scripts/door-map.mjs <符号>` 的门表 |
| ★3 一致与复用 | 同一件事别处怎么做；能不能用现成的 | 已有的同类组件 / 函数是哪个；复用还是为什么不复用（理由只认领域约束）；有没有第二份定义 | `check:self-written`；`git grep` 结果 |
| ★4 全状态 | 每个状态用户看到什么（含「取消中」） | 空 / 加载 / 成功 / 失败 / 部分成功 / **取消中** / 过期 / **能力不可用**，每个一句话；能力不可用 = 要模型或外部资源才做得了的动作，此刻没有（没装 / 上游不可用 / 本机资源下不来）：写清显示什么 + **下一步是什么**（一步可走的路，只灰掉说原因不算；PR 正文 `## 验收证据` 交 `ui-capability-unavailable`）；文案走 i18n（zh / en）；文案不写免费 / 不计费 / 没扣费这类断言（界面不谈钱，样张阶段就照这条写；`check:i18n` 会拦） | 样张路径 / 截图 / `check:i18n` |
| 5 中途表 | 每个状态下用户停 / 关窗 / 断网 / 重启 / 连点会怎样 | 表：状态 × 五种打断；每格写「看到什么 · 花费怎样（扣 / 不扣 / 退）· 回执在哪」；空格不许留 | 随机打断脚本 / 真窗口走查 / 人工 |
| 6 外部数据与失败 | 外部给的东西和我们想的不一样怎么办 | 外部来源清单（供应商 API / 文件 / 用户输入）；各自「规范链接 · 我们的偏差 · 失败时用户看到什么」；未知失败不许甩锅给用户的 key | 官方文档链接 |
| 7 性能预算 | 最大规模下多慢（只记录，不阻断） | 真规模数字（如 32 个 1080p 视频节点、1000 镜头）：首屏 ms / 内存 / 掉帧 | `pnpm run test:canvas:performance` 输出 / 人工 |
| 8 真实条件 | 在用户的样子下跑过没有 | 逐项勾：Windows / 英文界面 / 最小窗口 / 真规模 / 干净安装 / 真付费 / 键盘全程；没跑的写 `unverified`，不许 mock 绿灯顶替 | 截图路径（自己亲眼 Read 过）/ `test:core-smoke -- --fixture empty` |
| ★9 验收与回滚 | 怎么证明做到了；坏了怎么退 | 验收：谁（另一条线）用什么命令 / 页面确认；按分档写中英文链、AI 创作者任务、Agent 意图准确率或发版全套；写硬门 ⑩ / ⑪ / ⑫ 的逐项对账、逃逸项及补齐提交；回滚：revert 哪个 commit / 开关；**独立验收报告链接**（四类强制） | `## 独立验收` 一节 / 回滚命令 / `tests/ux/full-walk/escapeLedger.json` |

## 功能分类（决定必交哪些测试证据）

设计卡里加一节 `### 功能分类`（PR 正文 `## 设计卡` 之内），**可多选**，用 `- [x] 类别名` 勾：

```
### 功能分类
- [x] 新界面 / 改交互
- [x] 花钱
- [ ] 长跑 / 可打断
- [ ] Agent 行为
- [ ] 大数据量 / 画布 / 长列表
- [ ] 生成效果
- [ ] 数据格式
```

- 路由表只有一份：`docs/engineering/test-routing.json`（每类必交的证据、路径推类别的规则、哪些工具还没建都在里面；可读视图见 `experience-system.md`）。
- 扫描器按 PR 改动路径推出一组类别，这组是**下限**：卡上勾的只能比它多、不能比它少；必交证据取并集。
- PR 正文再写一节 `## 验收证据`，每项一行：`- <证据 id>：<报告链接 / 运行号 / 截图路径>`，或 `- <证据 id>：未验证：原因`；工具还没建的证据（路由表里 `tool: missing`）写「未验证：工具未建」。
- 纯文档 / 测试 / 配置改动推不出类别，不要求这两节。合并前扫描（`merge-preflight.mjs`）和 CI（`pnpm run check:pr-judgement`）调同一份判据。

## 独立验收（暂停点②）

四类改动合并前，PR 正文要有 `## 独立验收` 一节：报告链接 + 验收线编号。**验收线编号不能和实现线相同**。验收线对着这张卡逐格核，红灯用固定复现命令一字不改。其余改动不强制。

## 怎么判「四类」（合并前扫描用，字符串规则，宁可多报）

`node scripts/merge-preflight.mjs <PR 号>` 按路径判：

- **花钱**：`electron/**/spend*`、`**/pricing*`、`**/variant*`、`**/credits*`、`**/charge*`、生成调度（`generationScheduler*`）、付费确认 UI；
- **长跑**：`**/task*`、`**/queue*`、`**/production*`、`**/retriev*`、`**/export*`、`**/import*`（> 5 秒的异步链）；
- **可打断**：`**/cancel*`、`**/resume*`、`**/stop*`、`**/abort*`，或新增 `AbortController` / 可取消 Promise；
- **新界面**：新增 `src/**/*.tsx` 文件，或改 `src/design/` token。

上面是启发式，误报由协调会话人工划掉并在 PR 里写理由；这份清单自己也在 `rules.json` 的复查日期里。
