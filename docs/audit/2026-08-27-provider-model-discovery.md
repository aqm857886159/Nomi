# 模型列表发现反馈：修复与验证

## 结论与边界

本改动修复的是「读取模型列表」及其状态/选择恢复，不把列出型号、保存型号和生成适配混成一件事。Kie 当前被探测的列表路由返回 404，不代表 Key 错或生成 API 不可用；保留已接入目录并明确其不是平台全集。条目来自应用目录配置，本 PR 不新增/伪造市场型号，也不宣称已验证用户账号或所有模型的生成能力。

方案与官方文档证据见 [实施计划](../plan/2026-08-27-provider-model-discovery.md)。工作分支 `codex/provider-model-discovery-20260827`，初始基线 `7dab8ee8`，交付前快进到 `4881ccce`（主分支已合入 Wan 3.0，与本次 31 文件无交集）；不包含此前 ComfyUI PR 的改动。

## 覆盖的同类问题

| 边界 | 修复与保护 |
| --- | --- |
| Kie 式 `404 / No message available` | 分类为不支持当前列表端点，显示可行动的说明，保留目录与手动录入 |
| 鉴权/限流被后续 404 或空列表覆盖 | 对完整尝试集按错误性质取优先级；有效非空的正确候选仍可成功 |
| HTTP 200 业务失败 | 先检查错误 envelope，再解析列表；健康检查也消费同一分类 |
| 非标准列表 / 重复版本路径 | 支持标准 data、字符串数组、Replicate owner/name；已有 /v1、/api/v3 不重复拼版本 |
| 分页 | Replicate next、Anthropic after_id；最多 10 页 / 2,000 条，达到预算标 partial；不把后续页失败冒充完整成功 |
| 凭证与健康检查 | 保存的 bearer/header/query 与额外请求头保持一致；鉴权配置变更使缓存失效；错误先脱敏再截断 |
| 界面失败与竞态 | 两个入口共享请求生命周期与提示；保留候选/已选类型；返回/关闭/换连接使旧请求失效 |
| 成功刷新也丢选择 | 已选项持有模型快照，即使新列表不再包含它也能正确保存；已存在模型不重复计数/写入 |

明确限制：为避免携带任意自定义鉴权头/查询参数跨域跳转，本轮列表探测拒绝重定向响应（同源重定向也返回 invalid_response）；当前已核对的官方列表使用直接端点。错误提示要求检查最终 API 地址。不存在无声的网页抓取/凭证降级/整市场自动适配。
