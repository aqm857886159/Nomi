## 1 · 导入进度渐显（#790）

**结论：渐显本身是真的（按拷贝字节走的马赛克揭开 + 带文件大小的百分比），#790 做到了。真机上剩两个体感洞：冷启动那一趟前 3 秒没有任何进度，以及到 100% 之后还要再等 5 秒。拒收文案说错了类别，而且在英文界面下基本没翻译。**

把登记过的 1.317 GB 4K 10-bit HEVC 真视频从画布左缘导入（`input[type=file][aria-hidden][tabindex=-1]`，与真人拖进画布同一条路），每 400 ms 采一次可见进度文案。**两条 locale 各跑一趟，结果不一样，两趟都要看**：

| | zh 轨（这个包的**第一次**启动，冷） | en 轨（同一个包的第二次，热） |
|---|---|---|
| 第一次看见进度 | **3047 ms，已经 83%** | **457 ms，8%** |
| 不同的进度值 | 2 个（83% → 100%） | **9 个**（8/15/36/59/60/77/88/89/100） |
| 到 100% 的时刻 | 3549 ms | 5280 ms |
| 节点真正落地 | 8615 ms | 10228 ms |
| 100% 之后还等了 | **5.1 s** | **4.9 s** |

- **渐显机制是对的**：`c1-en-02-t00.png` 里能亲眼看到马赛克从下往上揭开的真实帧 + `Importing · 100% · 1.29 GB` 胶囊；落地后是**真首帧**不是占位图。
- **洞一：覆盖层挂载晚。** 冷启动那趟直到 3 秒才出现，而且一出来就是 83%——前三秒用户对着一个没反应的画布。

  而且从截图看，显示 100% 的那一刻画面**还没揭完**，右下角仍是马赛克块。

**情绪摩擦**：「点了半天没反应……哦动了，怎么一上来就 83%？……100% 了怎么还在转？」——三秒的空白和五秒的 100% 都比中间真正的进度更有存在感。

> 「9月12日(1).txt」这里放不下——画布节点只有图/视频两种 archetype 落点；音频与 3D 在画布上没有节点可落（它们的家是素材库 → 时间轴 / 导演台）

## 2 · 拿不到模型清单（#786）

**结论：已适配平台那条路上 #786 的承诺成立；但用户说的「接一个假中转站」这条路在这个包里根本走不到。**

### 2.1 已适配平台 + 错 key —— 成立

APIMart 连接页粘一把错 key → 点「保存验证」：

- **1040 ms** 就给了答复，抽屉**没关**，仍停在 `platformConnect` 页。
- 文案：`保存失败：密钥验证失败，请检查密钥和权限后重试。原密钥和连接已保留。`
- 小瑕疵：这是**首次**接入，并不存在「原密钥和连接」，这半句对用户是噪音；而且界面上**看不出 key 到底存没存**（按 #786 的设计这里是验证失败所以没存，但用户读不出来）。

截图：`c2-zh-A-filled.png` · `c2-zh-A-wrongkey-result.png`

### 2.2 假中转站地址 / 断网 —— 走不到

模型首页「已适配平台 + 更多已适配平台」一共列出 18 家，**全部是固定地址的预置平台**，连接页只有一个「粘贴平台 API Key」输入框，**没有可编辑的接入地址**：

```
apimart, kie, agnes, modelscope, volcengine, minimax, elevenlabs, meshy, fal,
runway, runninghub, volcengine-speech, replicate, comfyui-local,
dreamina-member, codex-local, local-text, antigravity-cli
```

「其他接入方式 / 高级与连接设置」下只有两扇自定义门：

- **「我已有调用脚本」** → `add` 页，页面自己写着「继续后只会建立一条不可生成的草稿，**不会抓文档、拉模型**、调用 AI 或发起付费验证」。填好「API 根地址 + Key + 模型 ID」点「继续填写」后，**60 秒内界面一个字都没多、页面也没换**（按钮大概是被前置校验挡住了，但没说缺什么）。
- **「高级 · 自定义普通 HTTP 请求」**。

源码里确实有一条带可编辑 base URL 的向导分支（`src/ui/onboarding/OnboardingWizard.tsx:495-530`，条件是 `selectedPreset?.custom`），但**从现在这个首页点不到它**。

所以「接一个假中转站 + 错 key，看抽屉关不关」这条用例，本轮**无法在真机上构造**——不是修没修好的问题，是这条路对用户不存在。这正好撞在用户长期反馈的「自己接模型太难」上。

截图：`c2-zh-01-home.png` · `c2-zh-B-all-platforms.png` · `c2-zh-B-custom-page.png` · `c2-zh-B-fake-relay-result.png` · `c2b-zh-01-drawer.png`

### 2.3 顺带撞到：打包版拒绝验证回环地址的供应商

给隔离实例种一个指向 `127.0.0.1` 的 loopback 供应商时，打包版返回
`暂时无法验证密钥，请检查接口地址和网络后重试。原密钥和连接已保留。`
—— 同样的种法在开发构建上是通的。这意味着**本机 / 局域网的 OpenAI 兼容网关按 key 接入，在装机版上会被挡**。这条是顺手撞到的，没有专门做对照，需要复核。

### 9.1 2026-09-17 第二轮（真实资料库 + 真模型）怎么跑的

同样住在会话 scratchpad：`w0-orient` / `w1-newproject` / `w2-canvas` / `w3-import` / `w4-decompose` /
`w5-continue` / `w6-782run`（#782）· `s1`–`s13`（T-DS-05）。共用 `_open.mjs`。

与第一轮的三点不同，复跑时必须照办：

1. **`isolate: false`** —— 直连用户真实 profile。前置是**用户亲自退出 `/Applications/Nomi.app`**
   （运行中的实例持着 leveldb `LOCK`，见教训 `profile-copy-hardlink-shares-leveldb-lock`），
   并先做 `cp -R` **深拷贝**备份（**不是 `cp -Rl`**）。开跑前 `lsof +D` 两个数据目录必须为空。
2. **锁**：`/tmp/nomi-electron-walk.lock` 用 `set -o noclobber` 原子创建，跑完删；同机另有 agent 也在跑 Electron。
3. **语言开关在设置 → 通用 → `[data-settings-locale]`**，不是 `--en` 参数（第一轮那句已过期）。
   切完**必须切回 `zh-CN`**——这是用户的真机，不能留在英文。

两个踩坑，下次别再踩：

- **`node … | tail` 会把 stdout 变成块缓冲**，跑了十分钟一个字都看不到，看起来像挂死。
  改成 `nohup node … > file 2>&1`（写文件是同步的，立刻能读）。
- **模型/画幅下拉里的选项 `role` 是 `option` 不是 `menuitem`**，
  而且选项名带换行（`MiniMax H3\nAPIMart`），`getByRole('menuitem', {name:'…'})` 恒 0 匹配、
  然后静静超时 30s。用 `locator('[role=menuitem],[role=option]').filter({hasText})` 串联过滤。
