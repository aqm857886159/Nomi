## 五个问题，一个形状

| 问题 | 当时立的规矩 | 立在哪 | 没问的那一句 |
|---|---|---|---|
| 素材库拖不出别的项目的图 | 「不许跨项目引用文件」（08-31） | 拖拽起点 + 画布 / 时间轴 / 点击追加各一份拒收 | **拒了之后怎么用？**「物化复制另开合同」写进了方案，没进 TODO、没有 owner，于是规矩等于把功能删了 |
| 项目素材拖出无反应 | 「归类拖拽用独立 MIME，免得画布误建重复卡」（07-22） | 项目 tab 的拖拽起点 | **画布那边呢？** 一个格子两种载荷，画布只认一种 |
| 引导示例图裂图 | 「示例图改走 seed 落项目资产」（07-30） | 引导这一个写入口 | **已经写进去的怎么办？** 方案里一句「重看会覆盖旧项目」没人验证（实际每次都新建项目），持久化边界也没守 |
| Mac 上第三方示例媒体全被拦 | 「为抠图多线程开跨源隔离 require-corp」（06-27） | 全局响应头 | **哪个平台才生效？** Windows 版和所有走查进程都关隔离，真正生效的 Mac 上从来没人跑过；打包版又是 file:// 页面，隔离其实没拿到 |
| 剪辑页两个叫回 Nomi 入口 | 「收起后唯一的叫回入口」（09-06，两条线各一份） | 顶栏角标 / 剪辑页竖条 | **这个概念谁持有？** 两份设计稿、两条线、同一天，各自都写着「唯一入口」 |

所以 `src/workbench` 这层的结构问题不是某个组件写得差，而是**加一条边界 / 策略时，没有一个步骤强制盘点它的影响面**：还有哪些入口在判同一件事、存量数据要不要迁、它在哪个平台 / 构建 / 进程里才真正生效。每条规矩单看都对，漏掉的那一半就变成用户手上的一次「以前能用，现在不行」。

## 这次怎么收（结构上的，不是逐个补丁）

- **src/workbench**：跨项目那条改成「一个关口」——`assetLibraryMaterialize.materializeAssetLibraryItems` 放行本项目、复制别的项目，画布 / 时间轴 / 点击追加只调它，删掉各自的拒收与 `reject-external` 状态；素材格子只剩一种拖拽载荷，文件夹也读它；选择规则收成 `nextAssetSelection` 一份；剪辑面板「收起」只留 `visibility` 一份真相（`editingPanelResizeEffect` 把面板库拖出来的收起写回）。
- **electron/workspace**：「项目数据只存稳定地址」守在所有写入口汇合的清单事务上（`buildArtifactMigration` 挂在 `localizeEmbeddedMediaUrls` 那一遍遍历），读时迁存量、写时拒新值，快照读取遇到这类地址退回加锁读——不再依赖某一个写入口自觉。
- **electron**：跨源隔离头与模式收成 `electron/shared/crossOriginIsolation.ts` 一份定义（主进程与开发服务器原来各写一份），改 credentialless；探针矩阵写进了定义文件的注释，免得下一个人凭记忆改回去。
- 七个碰到的概念当场登记进 `docs/engineering/concept-owners.json`（R33）。

## 以后加边界 / 策略时先答三句

1. **还有谁在判同一件事？** 跑 `node scripts/door-map.mjs <判据符号>`，门表里每一扇要么调新关口、要么写清为什么不受影响。规矩只立在一扇门上 = 没立。
2. **拒绝之后用户怎么办、旧数据怎么办？** 「另开合同」「以后再做」必须当场进 `docs/roadmap/TODO.md` 且有 owner；迁移写「不需要」要有测试证明（不是方案里一句推断）。
3. **它在哪个平台 / 构建 / 进程里生效，那里有没有一条走查在跑？** 只在 Mac 打包版生效的策略，Windows 开发机和 `NOMI_E2E` 走查都证明不了它。本次 COEP 那一半靠的是最小 Electron 探针，不是走查。

## 不在本次范围、已登记

- 打包版宿主页从 file:// 加载，探针显示 file 源拿不到 `crossOriginIsolated`——画板抠图的多线程在打包版大概率从没生效（已开独立任务：要不要改用特权自定义协议加载渲染层，属架构改动，先问用户）。
- 跨源隔离策略没有任何在「隔离开着」的进程里跑的测试：建议把本次探针做成 CI 上的 node-test（本地起一个不带 CORP 的跨源媒体服务，断言媒体能加载、http 宿主 `crossOriginIsolated` 为真），不依赖外网。
- 技能库 / 效果选择 / 斜杠菜单不虚拟化，打开即对几十条第三方示例媒体同时发 `preload="metadata"` 请求。
- 同一张别的项目的素材反复拖入会各复制一份（主进程按文件名去重，不按内容），与工作流库跨项目复制现状一致。
