# 模型能力表

一个模型一张表：供应商文档页里写到的每一种方式、每一类输入、每个参数和它的档位，一行一条，带文档原文。每行只有四种去处：

- **露出**：档案里声明，界面上有控件（默认就是这一种）。
- **替创作者定**：我们固定传一个值、或固定不发，不给选；写清固定成什么、为什么创作者不需要选。
- **替创作者定**：我们固定传一个值、或固定不发，不给选；写清固定成什么、为什么不给选，并带 `source:`（`产品已定·出处` 或 `出处未找到`）。
- **不露出**：原因只能是五类之一，写在 `reason:` 里：`管道`（回调、鉴权、模型名这类接口管道）、`同一件事`（和另一个已露出的参数是同一件事）、`文档废弃`（文档自己标了废弃 / 不建议）、`模型无效`（文档写明这个模型不支持、实测无效，或明写只有一个合法值）、`现在做不到`（要另一种计费、额外资质或另一个渠道；必须带 `condition:` 写清什么条件下能露出，表里单独成组）。「用不上」「先不做」「价值低」不算原因。
- **待定**：要新的控件、结果形状或任务流程才能露出；`pending:` 写清缺什么。
- **待用户判**：只剩「价值低 / 别人也不用」这类理由、没有结构性原因的行；`why:` 写理由，由协调带给用户，不自己决定。

最后一列用反引号里的记号写「落到档案哪里」，合同测试 `electron/shared/modelArchetypes/capabilityTables.contract.test.ts` 双向读：

- 表里标「露出 / 替创作者定」的记号，档案里必须真有；
- 档案里的每个方式、参数、输入槽、固定参数，表里必须有一行认领；
- 标「不露出」的 `absent:` 记号，档案里必须真没有。

记号：

| 记号 | 含义 |
| - | - |
| `mode:t2v` | 有这个方式 |
| `prompt:t2v=required` | 该方式提示词必填 / `optional` 可选 |
| `param:t2v+i2v/duration=3..20@5` | 这些方式（`*` = 全部）有这个参数；`a..b` 数值范围，`a,b,c` 选项，`bool` 开关；`@x` 默认值；不写等号只核存在 |
| `slot:ref/image_ref:10:image_urls` | 输入槽：方式 / 种类:上限[:字段名] |
| `fixed:edit/size=adaptive` | 方式钉死的固定参数 |
| `combine:first=image_with_roles` | 方式把槽合并进这个角色数组 |
| `total:ref=15` | 方式的参考总数上限 |
| `constrain:edit/output_format:background=transparent=>png` | 选了某值时另一个参数只剩这些选项 |
| `absent:key` / `absent:mode/key` | 档案里（这个方式里）没有这个参数 / 输入字段 |
| `reason:管道` | 不露出的原因（五类之一） |
| `condition:…` | 「现在做不到」什么条件下能露出 |
| `source:…` | 「替创作者定」的出处 |
| `why:…` | 「待用户判」的理由 |
| `pending:…` | 待定的原因 |

表头两行 `- archetype:` 与 `- vendor:` 决定读哪个档案、按哪家供应商分层。
