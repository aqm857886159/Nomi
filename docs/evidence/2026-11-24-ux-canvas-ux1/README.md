## 回归与性能

红阶段五个目标测试文件均失败。真窗补测发现，视频模型选中后首帧会让卡面从横形长成方形。为此补入新卡首次定形与固定屏幕高度的反例。最后一轮 15 个指定测试文件、171 项通过，覆盖单选三侧越界、拖动与多选静止、上游结果、派生和撤销、方图与竖图、自动与手选比例以及默认标题。构建、应用 TypeScript、token、拍板图和双语检查均通过。

`canvas-drag-20-nodes` 使用登记的 I150 图（150 节点、75 边；框选实际命中 24 节点）。5 次帧间隔 p95 分别为 20.8、20.9、21.0、21.1、21.2 ms，中位数 **21.0 ms**，预算 33 ms，长任务 **0**。原始 JSON 使用 bench 的独立输出文件参数写出。[五次原始样本](perf.json)

`verify-line-meter` 对基线与最终五组窗口分别计得 55、102 次常驻驱动命令；停靠面板补测另有 31 次。三组自写 Playwright 脚本均为 0 个、0 行。截图、读取、等待和关窗不计入创作者的操作数。
