# 交付截图 · 三轮拍板后的最终版（对账用）

本目录是交付时的定稿截图：同一个设计实验室屏（`storyboard-reuse`），用本分支头上的真组件渲染，中文、英文两轨各 16 张，每张实现线都亲眼看过。第一轮、第二轮、第三轮的「现在 → 改后」成对图分别在上一级的 `README.md`、`round2/`、`round3/`。

- 宽 900 = 1440 视口 + Agent 面板展开时的表格宽；窄 664 = 最小窗口 1100×690 + Agent 面板展开。
- 复现：本分支 `npx vite --port <p>`，打开 `design-lab.html?screen=storyboard-reuse&frame=1&state=<id>`；英文轨把 `localStorage['nomi:locale:v1']` 设为 `en`。
- 量法与原始数据：`measures.json`（Playwright 读每行的预览框、内容列、「生成」位置）。

## 残余（照实写，不算对上）

1. **序号角标和 × 被切掉一角。** 复用的是画布同一个 `AssetTile`：它自己 `overflow-hidden`，角标和 × 又往外偏了 5px，所以在画布上也同样被切，只是 56px 大格上不明显，36 / 28 小格上明显一些（放大看 `1`、`×` 只露四分之三）。这是共享组件的现状，改它会同时改画布的样子，需要另出样张，本轮没动。
2. **参考卡区框左缘 52，镜头表 39。** 差的 13px 来自实验室里锚区外面多包的一层 p-3 和边框；真编辑器里两个容器要统一内边距才能跨区对齐（设计卡不确定项第 4 条），没在本轮改。
3. **分镜表（`StoryboardShotTable`）还在用「出现最多的画幅」近似整片默认画幅，并且还在传已不用的 `aspectOverridden`/`aspectOptions`。** 这两处在 L-sbtable 的禁区里，等它合入后再改（协调会话通知后做）。
