# Agent 界面样张 v3.2 · 逐屏走读（给用户念的版本）

> 日期：2026-09-02 · 配套样张：`docs/design/mockups/2026-09-01-agent-ui-final-redesign.html`（桌面拷贝：`~/Desktop/Nomi-Agent界面重做样张.html`）
> **v3 是什么**：你看完 v2 给了九条整改 + 一句总纲——「这个 agent 要长得像住在对话里的 Claude Code：一切事件进对话流，常驻栏越薄越好」。v3 = 照单全改。
> **v3.1 是什么**：你看完 v3 又下了两刀——「结果卡太大了」「聊天下面放 icon 吧，太多字了」。v3.1 = 屏 D 固定结果卡默认收成一根细条 + 输入框底排全 icon 化。详见文末「v3.1 · 两条快修」一节。
> **v3.2 是什么**：你 09-02 拍板补齐布局——面板在四个面 + 浏览器打开时各住哪、缩小三档（收起/窄窗/最小窗）、面板操控三能力（拖宽/放大/拖走）。全画在新页签「屏 E · 布局」，走读见本文「屏 E」一节，规格数字见定稿 §11。
> **怎么看样张**：浏览器打开，顶上五个页签切屏；右上角「暗色」切亮暗、「标尺」给所有可点的东西描虚线框（用来数每屏有多少可点）。屏 A 里工具那几行的行尾小箭头、屏 D 顶上那根细条**真的可以点**，点了会展开；屏 E 是静态标注图（手柄/热区画出来给你看位置和数字，不用真拖）。
> **本文怎么读**：每屏一节，屏里每个东西一条，每条讲三件事——这是什么 / 为什么这样 / 你什么时候会碰它。
> **功能层验收合同**：本走读里每个元素背后的行为承诺怎么被测试系统证明，见 `2026-09-02-agent-ui-functional-conformance-testspec.md`（与设计层 conformance spec 同一验收系统的两层，实施 PR 逐条勾账）。

## 屏 A · 主对话流（平时用得最多的那个面）

### 1. 顶部一行（面板的「头」）
- **这是什么**：整个头只剩一行：左边 N 标 + 「Nomi」；旁边一颗小胶囊写「还能聊 ~40 轮」；最右边两个小图标——历史对话、收起面板。
- **为什么这样**：你点名删的两样都删了（整改⑧）：「· 雨夜追逐」项目名没了（顶栏本来就写着，这里重复）、「当前现场」标签没了（没有任何行动价值）。v2 顶部那颗常驻的「按 编剧·Kasdan」技能标记也没了（整改①②，见第 5 条）。头从三行变一行。
- **那颗胶囊**：平时只说一句人话「还能聊 ~40 轮」——告诉你这轮对话还有多少余量。鼠标放上去才展开明细：本轮用了多少、累计多少、这个对话花了多少钱。不想知道的人永远不会被这些数字打扰。
- **你什么时候碰它**：想翻旧对话点历史；想让画布占满点收起；担心「聊太久它会不会忘事」时瞟一眼胶囊。

### 2. 「前面 24 轮已折叠 · 展开」细线
- **这是什么**：聊久了，Nomi 会把很早的对话收起来省地方。这条细线告诉你收了多少，点「展开」原地翻开。
- **为什么这样**：不给这条线，收纳发生那一刻你只会觉得「它怎么突然失忆了」。
- **你什么时候碰它**：长对话里想翻旧账的时候。

### 3. 「进入 · 生产段」工序线
- **这是什么**：对话从「聊剧本」推进到「动手生成」时画的一道分隔线，带一个小图示。
- **为什么这样**：做视频有固定几道工序（写剧本→拆镜头→搭画布→出片→上时间轴），这条线让你抬眼就知道走到哪一道了。v3 里它是静态的——整个屏幕同时只有「正在干活」的那一行在动，别的都安静（动效极简）。
- **你什么时候碰它**：不用碰，扫一眼定位进度。

### 4. 你的消息（右侧黑底气泡）
- 跟所有聊天软件一样，不解释。

### 5. 「⚙ 载入 编剧·Kasdan」灰字小行
- **这是什么**：Nomi 给自己装上一套写作方法的那一刻，在对话里记一笔。灰字、小号、不是卡片。
- **为什么这样**：整改①②。v2 在顶部和输入框上方**各有一块**常驻的「技能已装载」，跟这行三处重复——现在只留对话流里这一处。这正是 Claude Code 的真实做法：装载是对话里发生的一件事，发生了、记下了、过去了，不占常驻位。
- **你什么时候碰它**：好奇「它怎么突然换了个写法」时，往回一翻就看到是从哪行开始的。

### 6. 「想了 4 秒 · 拆成 5 镜，2 镜要站位参考」
- **这是什么**：Nomi 想完之后留下的一句小结。行尾有个小箭头，点开能看它当时的思路。
- **为什么这样**：想的过程结束后不凭空消失，落成一句结果留在原地——你随时能查「它凭什么这么定」。
- **你什么时候碰它**：对它的决定有疑问的时候。

### 7. 正文回复
- Nomi 说的话，纯文字。正在生成时末尾有个小光标在闪。

### 8. 「6 步 · 读剧本 · 拆 5 镜 · 生成 2 图 ▾」工具总览行
- **这是什么**：Nomi 这一轮干的所有活，收成一行。点行尾小箭头展开每一步：「✓ 读了剧本 · 2400 字」「✓ 拆成 5 镜」「✓ 生成 2 张参考图 · 0:41」。样张里真的可以点。
- **为什么这样**：整改⑤。v2 是一块带边框底色的面板区，删了。Claude Code 的真实样子：每个工具一行、可展开、干完收拢成一行总览。活干完了就不该继续占地方。
- **你什么时候碰它**：想核对「它到底动了什么」的时候点开。

### 9. 「✓ 已加 5 个节点」+ 行尾小 ↩
- **这是什么**：Nomi 把东西写进画布后的绿色回执。右侧一个小 ↩ 图标，鼠标放上去显示「撤销这一笔」。
- **为什么这样**：整改⑦「能 icon 不用字」——撤销是随手动作，收成图标不占字。
- **你什么时候碰它**：这批不想要了，点一下整批退掉。

### 10. 黄色「撤销会丢掉你改过的东西」确认卡
- **这是什么**：只在一种情况出现：你点了撤销，而这批里有你**手动改过**的东西。它列明会丢什么（「镜 3 的提示词你改过：暖光→冷调」），再问一次「再想想 / 仍要撤销」。
- **为什么这样**：整批撤销会连你自己的修改一起退掉——这种事必须先说清再动手。平时这张卡根本不出现。
- **你什么时候碰它**：撤销撞上自己改过的东西时，仅此一种。

### 11. 「2 张参考图在「参考」分类 · 去看」小胶囊
- **这是什么**：告诉你产出落到了哪里，点了直接跳过去。
- **你什么时候碰它**：想看图落哪儿了。

### 12. 「正在重画第 4 镜参考图 0:12 ▾」进行中行
- **这是什么**：当前正在干的活。一行：转圈小图标 + 一句话 + 已用时间，行尾小箭头点开看这轮已完成的步骤。
- **为什么这样**：整改⑤。同一行会原地从「排队」变「进行中」变「完成」，不会刷出三行来。没有百分比就不画进度条（画了也是假的）。
- **你什么时候碰它**：等的时候看一眼它在干嘛、干了多久。

### 13. 输入框上沿的浅色排队行
- **这是什么**：Nomi 忙的时候你继续发的消息，一条一行、浅色、贴在输入框正上方。轮到它就自动进对话开始执行；点右边小 × 撤回。
- **为什么这样**：整改④。v2 那张带编号、带一排管理按钮的「任务队列卡」删了。Claude Code 的真实样子就是这样：排队消息是几行浅色字贴在输入框上沿，无卡片无边框。
- **你什么时候碰它**：你说得比它干得快的时候——尽管说，不用等。

### 14. 输入框（@ 是唯一的引用手势）
- **这是什么**：打 `@` 弹出选择器，素材、角色定妆、视频片段、技能都从这里选；选完变成句子里的一个小色块。样张里演示了两个：蓝色的 `@阿青定妆`，和黄色的 `@街道 02:10`——黄色的意思是「你引用之后这段素材被改过，发送时会用现在这一版」。
- **为什么这样**：整改③。v2 输入框上面常驻一排「引用架」（定妆槽、素材 chip、加号按钮），全删了。引用就一个手势：@。引的东西就长在你的句子里，看得见、删得掉。
- **你什么时候碰它**：想让 Nomi 参照某张图、某段素材、某套方法的时候。

### 15. 底部一排按钮（5 个，一个不多 · v3.1 起全是图标）
- **这是什么**：📎 附件 · ⚡ 执行方式 · 🤖 文本模型 · ✏️ 提示词模板 · ↑ 发送——五颗全是图标，一个字都不带。想知道哪颗是干嘛的，鼠标放上去半秒，它自己说：「Agent · 安全自动」「文本模型 · Kimi K2」。
- **为什么全改图标**：你 v3.1 的原话——「太多字了冗余」。这排按钮你一天点不了几次，却天天在眼前占字；含义收进悬停提示后，常驻只剩五个小方块，一眼扫过去是「一排工具」，不是「两句话」。
- **⚡ 那颗管什么**：Nomi 的权限，两件事收在同一个入口里——它能动什么（只回答 / 只改选中的 / 全能动），和它问你多少（步步问 / 安全的自动做 / 全放行）。悬停显示当前档：「Agent · 安全自动」。
- **🤖 那颗管什么**：Nomi 用哪个文本模型来理解和规划。**没选过时不再摆一句常驻文字**，改成图标右上角一颗小红点（像未读消息那样提醒你「这里缺个东西」），悬停提示「去选文本模型」；选好后红点消失，悬停显示「文本模型 · Kimi K2」。
- **你什么时候碰它**：发消息每次都碰 ↑；其余偶尔调一次就不动了——所以它们不配常驻占字。

**屏 A 的账**：常驻可点 **19 → 10**（头 4→3、排队区 5→1、输入区 10→6），v3.1 底排常驻文字 **2 句 → 0**。删掉的没有一个是失去功能——都是重复入口或换了更薄的形态。

## 屏 B · 要你做决定的卡（六张）

这些卡都出现在对话流里，决定完就随聊天滚走。v3 对这屏做的事：**所有字过一遍人话闸**（整改⑥）、卡里的设计注释小字全部挪出卡外（整改⑨）——卡里只剩你真会用到的东西。

### 1. 计划卡「拆成 5 镜 · 生成计划」
- **这是什么**：Nomi 要批量生成前先给你过目的单子。上面两颗药丸是这批的公共设置（用什么模型、什么画幅），下面每镜一行：勾选框 + 镜头名 + 一句画面描述。哪行你单独改过，行尾会标「已改 · 还原」。
- **为什么这样**：直接复用现役画布里那张计划卡（一致性，不另造）。v2 这里有个重复：「竖版」出现了两次，修掉了。按钮从「确认全部（2 镜）」改成「生成已选（2 镜）」——勾了 2 个就说 2 个，不说「全部」。
- **你什么时候碰它**：每次让 Nomi 批量生成，先看这张单子再放行。

### 2. 付费确认卡「确认生成 · 会花钱」
- **这是什么**：花真钱之前的最后一道闸。每一项单价列清、合计加粗；灰底那句写明「付费后就不能再改：镜头数、模型、时长、清晰度。提示词仍可改」；确认按钮上直接带金额「确认并生成 ¥1.26」。
- **为什么这样**：竞品连「失败扣不扣钱」都不写，我们反着做——全部明示。v2 这张卡上有个「本会话不再提示」勾选框，v3 删了：**Nomi 自动干活时花钱，每次都得问你**；那个「不再提示」的开关只在你自己亲手点生成的场合才有（因为那时你清楚自己在花钱）。「过闸后」这种内部话也改成了「付费后」。
- **你什么时候碰它**：每次要花钱，必然碰。

### 3. 有出入卡「做完了，有 2 处和你批准的不一样」
- **这是什么**：Nomi 干完后自己对账，发现结果跟你批准的计划不一致时才出现的黄边卡。每条出入说人话：「镜 2 结尾的画面没接到镜 3 开头——中间那条连线生成时丢了」「阿青的头发画成了棕色，和定妆不一样」。三个选择：让 AI 修 / 撤销这一步 / 知道了。
- **为什么这样**：这是 Nomi 独有的形态（对过的竞品全都没有）——别家做完就完了，对没对上没人管。v2 这里写着「校验分 0.62，低于阈值」，这种话删了，直接说哪里不一样。**一切正常时这张卡永远不出现。**
- **你什么时候碰它**：只在结果跑偏时。

### 4. 反问卡「开始前问你 2 件事」
- **这是什么**：Nomi 觉得信息不够时先问你。一次只显示一个问题，选项竖排成按钮（键盘按 1/2/3 也行），角落写着「1 / 2」告诉你还有一问，可以「跳过」。
- **为什么这样**：一屏一问，想一件事就好（照 Beautiful UI 的确认卡整件搬的）。最多合并 3 问，绝不连环轰炸。
- **你什么时候碰它**：你的指令有歧义时。

### 5. 多候选卡「镜 1 · 3 个候选」
- **这是什么**：同一个请求出了几版结果，并排摆开，点缩略图就是选中（不设「上一个/下一个」按钮），底下一颗「采用 A 版」。采用之前它们只是候选，不动你的画布。
- **你什么时候碰它**：一次要了多版、挑一版的时候。

### 6. 产物卡 + 失败卡
- **产物卡**：标题行 = 「镜 1 · 1024×1792 · 第 2 版」+ 右侧动作（改提示词 ✏、重新生成 ⟳ 两个图标，「去画布」文字钮）；下面是完整缩略图，**任何按钮都不压在图上**。v2 写的「v2」现在说「第 2 版」。
- **失败卡**：红边。一句人话原因（「当前模型没配置好，这一步没跑起来」）+ 绿字明说「**这次没扣钱**」+ 三条出路：换模型重试 / 改提示词 / 看详情（原来叫「看日志」，改了）。
- **你什么时候碰它**：每次生成完 / 偶尔失败时。

**屏 B 的账**：七张卡平均可见选择 **4.3 → 4.0**；卡内设计注释小字 **5 处 → 0**。

## 屏 C · 右栏换班（过渡期的临时规矩）

拆解表和 Nomi 对话现在共用右边那条栏，同一时刻只住一个。这屏演示两个方向的「换班」：

### 左半：Nomi 在栏里，拆解表去哪了
- 拆解结果收成源视频节点上的一个小浮条「拆解结果 · 5 镜」，节点头顶挂蓝色小标「✓ 已拆解 · 5 镜」。点浮条，表就回来。
- **为什么放节点上**：拆解结果本来就属于那条视频，跟着它走最好找（一个功能一个家）。
- 对话里 Nomi 调用拆解的那条记录，也是屏 A 同款的一行式（v2 里的内部话「(M 线后)」这类全删了）。

### 右半：拆解表在栏里，Nomi 去哪了
- Nomi 收成顶栏一颗小角标「● 进行中」；它有新动静（回复了、干完活了）就冒蓝点。点角标，对话回来。
- **为什么放顶栏**：顶栏是唯一在创作/生成/预览三个页面都在的地方，Nomi 收哪儿都不会丢。

### 换班的规矩
- 切换 260 毫秒滑入滑出，不闪跳。
- **收起只是收起，不清空**：你勾了一半的镜、滚到一半的位置、正在跑的任务，换班回来原样都在。

**你什么时候碰它**：拆完一条视频又想跟 Nomi 说话（或反过来）的时候。这套「换班」是临时的——等下一屏的形态落地它就消失。

## 屏 D · 终局：结果固定在上、对话在下（不再换班）

### 1. 顶部一行
- 跟屏 A 完全一样：Nomi + 用量胶囊 + 两个图标。

### 2. 固定在对话上方的「拆解结果」细条（v3.1：默认是收起的）
- **这是什么**：对话上方一根细条，一行写完它的全部近况：「📌 拆解结果 · 5 镜 · 已选 2 ▾」。它**不随聊天滚走**（📌 就是这个意思），高度只有一条工具行那么高。点它，5 镜的完整表格从细条里展开；再点，收回细条。样张里真的可以点。
- **为什么默认收着**：你 v3.1 的原话——「结果卡太大了」。v3 把整张表常驻摊开，右栏一半被它占着，聊天被挤成一条缝。改成：**常驻脚印 = 一行**，但「几镜 / 已选几」这两个你最关心的数**常驻可见**（勾选变了它跟着变）——不点开也知道进展；内容随点随开，展开也**封顶约半屏**（表格内部滚动），永远压不死下面的对话。
- **展开后有什么**：每镜一行：勾选框 + 缩略图 + 镜头名 + 时间 + 画面描述 + 这镜的字幕；镜 3 画面没读出来就红字直说「这镜没读出来 · 可单独重试」。底部：「用这套结构起稿」「已选 2/5」「加入画布 (2)」。**收起只是收起**——勾选、滚动位置都保持，点回来原样还在。
- **为什么固定（不随聊天滚走）**：拆解表是要**对着它反复操作几十分钟**的东西——勾选、对照、改——不能让它被聊天冲走。过程性的东西（问答、进度）都在下面的对话里滚。竞品手册里用户自己都说：「不想在很长的聊天记录里重新找已确认的内容」。
- **你什么时候碰它**：照着别人的片子做自己的版本时，这就是你的工作台面——要操作就点开，不操作就让它缩成一行看着数。

### 3. 下面的对话流

## 屏 E · 布局（v3.2 补全：面板住在哪、怎么缩、怎么抓）

总则一句话：**面板在哪个面都停靠窗口右缘、同一个宽度（默认 340，拖 300–600）、挤主内容而不是盖主内容**。切页面板不挪窝——位置的肌肉记忆只建一次。

### 1. 创作
- **这是什么**：面板停右缘、从顶栏下沿一直到窗底（创作没有时间轴，右缘整条归它）。写稿的居中版式在剩下的空间里照旧居中。
- **为什么**：它**取代**现在编辑器旁边那条 344px 助手栏（加新必删旧，宽度归一到 340）——你 7 月拍板的「常驻右栏」不变，变的只是从内容网格里的一列升级成全局的一条 chrome。
- **你什么时候碰它**：写稿时让 Nomi 改台词、拆镜头，不用切页。

### 2. 分镜
- **这是什么**：和创作完全同款——同宽、同位、对话不断。
- **为什么**：分镜不是独立页签（顶栏三格里它亮在「创作」上），它就是创作面把中间那栏换成分镜表。同一个壳就用同一套布局，不发明第二套规矩。
- **你什么时候碰它**：在分镜表上让 Nomi 调镜头顺序、补分镜。

### 3. 画布（生成）
- **这是什么**：面板停右缘，但**停在时间轴上沿**——时间轴永远通栏在底（你拍板过：主时间观入口在底部中间），面板不盖它；时间轴收起时面板自动落到窗底。
- **为什么**：拆解表和面板共用同一条槽、同一个宽度数——屏 C 的换班、屏 D 的同壳并存，页面骨架都不用动。
- **你什么时候碰它**：用得最多的面——生成、批准、对照都在这。

### 4. 预览
- **这是什么**：同画布规则——面板停在剪辑时间轴（222px 通栏）上沿，和播放器并排。
- **为什么**：在这儿对 Nomi 说的是剪辑话（「镜 3 换第 2 版」「字幕提前半秒」），产物直接落时间轴——播放器、时间轴、面板必须同屏三见，谁也不盖谁。
- **你什么时候碰它**：粗剪回看时让 Nomi 动时间轴。

### 5. 浏览器打开时
- **这是什么**：浏览器是**全屏接管**（mac 连顶栏都在它底下），不是压暗弹窗——它开着时面板不可见也不可用，我们不装它可用。
- **为什么**：网页画面是原生视图、浮在一切界面之上，右缘还停着 500px 宽的捕捞坞——再塞一条对话栏就没网页了；两个输入焦点抢一个屏也是认知过载。
- **素材怎么回来**：网页里悬停图/视频按 Ctrl+C 收进项目素材（现成链路）；关掉浏览器在输入框打 `@`，选择器**置顶「刚从浏览器捞的」**——捞完就能 @。Nomi 的活不中断，回来瞟一眼顶栏角标就知道它这段时间干完了什么。

### 6. 缩小三档
- **收起**：面板收成顶栏一颗角标（「浏览器」和「设置」之间那格，四个面都在同一格，win32 也一样）；有新动静冒蓝点、有未读显数字；点它原宽原状态还原。
- **窄窗**：面板宽度从不背着你自动变——窗口变窄只是「最多能拖多宽」缩水（min(600, 窗宽−760)）。
- **最小窗（1100×720）**：面板 340 照样停得下：画布还有 700；创作编辑器 ~490，紧但能写，一键收起面板就宽敞。

### 7. 拖宽（能力一）
- **这是什么**：面板左边缘一条 8px 的隐形热区，鼠标放上去变「调列宽」光标（中间有根 3×32 的小蓝粒），按住拖实时变宽：最窄 300 / 默认 340 / 最宽 600（窄窗按上面的公式缩）。拖到哪记到哪；**双击手柄一键回 340**。
- **为什么**：手柄的长相和现在生成区那根完全一样——已经有一根好手柄，不发明第二种。
- **你什么时候碰它**：看拆解全表、长计划时拉宽一点。

### 8. 放大（能力二）
- **这是什么**：面板头一颗 ⤢，点一下跳到当前允许的最大宽（宽屏即 600），再点回到放大前的宽度。
- **为什么不全屏盖画布**：你批的东西全在画布上——盖住画布等于蒙着眼批；600px 已经够把拆解全表、计划卡读完整。也不另做「分屏模式」：放大只是拖宽的快捷键，全程只有一个宽度变量，没有第二种布局要学。窗口太窄（最小窗）时这颗钮置灰。
- **你什么时候碰它**：想快速把表看全，又懒得拖。

### 9. 拖走（能力三）
- **这是什么**：抓住面板头的空白处（抓手光标）把它拖离右缘超过 40px，就变成一扇浮动小窗（380×620 起，位置尺寸记忆，全 app 只此一扇，跨页跟随）；拖回右缘 30px 内亮出停靠预览、松手吸附归位，头上也有「回停靠」一键。
- **为什么不是换到左边**：三个面的左缘全住着人（文件树 / 文稿列 / 素材源），Agent 挤过去就是一边叠两条栏；而且每个面左栏宽度不同，切页它会左右横跳，把「一个家」拆了。浮动才有真用例——大屏/双屏把对话挪开，画布全宽。
- **你什么时候碰它**：超宽屏想让画布满宽、又不想收起对话的时候。

## v3.1 · 两条快修（2026-09-02 你看完 v3 的两刀）

### 快修 1 · 屏 D 固定结果卡：默认收成一根细条
- **这是什么**：那张「拆解结果」卡不再常驻摊开。默认只剩一行：「📌 拆解结果 · 5 镜 · 已选 2 ▾」——高度跟对话里一条工具行差不多。点一下，完整表格展开（最多占约半屏，超出在表格里滚）；再点一下，收回细条。收起只是收起：勾选、滚动位置全保留。
- **为什么**：你的裁决「结果卡太大了，看怎么做到足够小又能让用户看到」。拆开是两个需求：「看到」= 状态要常在——所以细条上「几镜 / 已选几」永远挂着，勾选变了数字跟着变；「小」= 内容不该常驻——表格几十行，只有操作那几分钟需要看全貌，其余时间它摊着就是在挤对话。所以：**常驻脚印一行、状态摘要常在、内容随点随开**。展开也封顶（约视口 45%），因为「查表」不该杀死「聊天」——两件事你是同时在做的。
- **你什么时候碰它**：勾镜、对照、改的时候点开当台面；跟 Nomi 聊的时候收着，瞟一眼数字就知道进展。屏 C 的节点浮条、角标语义不变——那是过渡期互斥的规矩，这条只改终局态（屏 D）的默认姿势。

### 快修 2 · 输入框底排：全部 icon 化
- **这是什么**：📎 ⚡ 🤖 ✏️ 四颗全部去掉文字，只留图标；↑ 发送不变。悬停半秒冒出完整含义：「附件」「Agent · 安全自动」「文本模型 · Kimi K2」「提示词模板」。文本模型没选时，🤖 右上角冒一颗小红点（悬停提示「去选文本模型」）——不再用一句常驻文字提醒。
- **为什么**：你的裁决「太多字了冗余，icon hover 展示真实含义」。这排按钮是低频配置（调一次管很久），却在最高频的视线落点（输入框正下方）常驻两句话；字的信息价值在你认识它们之后就归零了，图标 + 悬停把「认识它」的成本只收一次。红点替常驻提示同理：**注意态该是一个点，不是一句话**——红点比文字更醒目，还不占地。
- **你什么时候碰它**：和 v3 一样——发送天天点，其余偶尔调一次。第一周可能悬停两次认按钮，之后纯凭位置肌肉记忆。
