## User job

A creator enters Nomi with a script, reference material, or a source video. They need to understand where to start, load a Skill, ask the Agent to help, see the script/storyboard/image/video result, and continue editing without losing the canvas context.

## This exploration must show

- a fixed left rail for project/library/workspace navigation;
- the canvas as the primary work surface;
- one resident Agent shell that can be docked, collapsed, or focused/fullscreen;
- a compact result indicator so results remain discoverable without occupying the conversation;
- the five composer controls: add material, model, Skill/context, mode, send/generate;
- a non-empty onboarding/Skill empty state with three concrete task cards;
- the canvas video path: video source → video deconstruction table → selected-shot generation;
- the two storyboard meanings remain visibly distinct: `分镜计划` and `视频拆解表`;
- icon affordances for zoom/reset/help and small hover/selected states.

## Must not show

- no generic marketing landing page;
- no second Agent product or second chat history;
- no permanent result gallery under the chat;
- no automatic pile of extracted image nodes;
- no separate subtitle node or HyperFrames motion node in this round;
- no dense spreadsheet app replacing the Nomi canvas;
- no fake provider/model names or invented capabilities;
- no visual language that requires reading a long explanation before the next action is clear.

## Success check

Within roughly three seconds, a user should understand: “I am in one Nomi project; the canvas holds my work; the Agent helps me move it forward; I can start from a concrete task.” The composition must be credible for long-form creation, not only attractive as a screenshot.
