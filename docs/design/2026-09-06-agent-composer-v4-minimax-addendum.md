## 一、照抄的形态（MiniMax 实测，截图编号见研究包）

| 元素 | MiniMax 长什么样 | Nomi v4 采纳 |
|---|---|---|
| composer 底栏 | `[+]  [◇ 模型] ｜ [◇ Skill]   ……   [自动 ▾] [↑]`：图标 + 文字标签，竖线分组，右侧「自动 ▾」是工作方式文字胶囊，发送圆钮运行中变 ■ 停止（11、13b） | 同一排布：`[+] [模型名文字 ▾] ｜ [Skill]  ……  [工作方式 ▾] [↑/■]`；删语音、删机器人图标、删分类子菜单 |
| 运行中占位 | 输入框占位「可继续输入，将排队发送…」（13b） | 采用；配合我们的排队 / 插队 / 中断三态 |
| 附件 | 「+」直接系统选择器；附件缩略图出现在输入框上方（20、17b） | 采用；拖任意文件同样落成缩略 chip |
| 任务卡（内联在对话流） | 一行状态「◌ 正在生成视频 ▾ / 生成任务 ▾」→ 提示词摘录 + Show more → 参数 chip 行 `Kling O1 · 3 · std · 16:9` → 缩略图 → 结果按钮「在画布中查看」（13b、14、21f） | 这就是形态①「一行收据 + 就地展开」：状态行 + 参数 chip + 结果链接；替换现役顶部钉死的工具条与宽框「执行细节」 |
| 附件轨迹 | 「读取了 1 个文件 ›」「在画布上定位」作为独立一行出现在任务卡前（21f） | 采用：工具调用内联为一行，可点展开 |
| 模型弹层 | 视频 / 图片 / 音频三段 tab；每行 名称 + 标签 + 规格 + ✓（允许列表多选）；有「全选」；**没有价格**（18、19） | 采用三段 tab 的骨架，但语义改为**每类一个默认预设（单选）**+ 对话模型一行；我们**必须显示预计花费**（MiniMax 全程费用未知，是它最大的短板） |
| Skill 弹层 | 搜索框 + 分类 chip（全部 / 我的 / 精选 / 短剧漫剧 / 专业影视 …）+ 列表行（名称 · /斜杠命令 · 一句描述）+ 底部「探索更多」「创建」（24b） | 采用；选中后成 chip 挂在提示词框；hover 出封面/视频（MiniMax 未验证，我们做） |
| 澄清 | 复杂动作先追问对象与范围（16），画幅先问再生成（11b） | 采用为介入槽的「反问」形态；但加对象、范围、撤销三件（MiniMax 没有） |

## 二、要赢过它的地方（MiniMax 实测短板）
- 费用：全程「未知」，追问也答不出（22b）→ Nomi 任务卡与收据必带**实际花费**，临界提醒。
- 停止：点停止后任务仍完成（14）→ Nomi 中断三态要真取消后端并保留已完成。
- 错误：「运行时连接异常，请重试」无原因无恢复（15）→ Nomi 错误行给原因 + 是否扣费 + 重试范围。
- 上下文/token：未见 → Nomi 显示真实用量。
- 删除镜头：只改文字、实体未证明删、无撤销（16）→ Nomi 走提案→应用→收据→撤销。

## 三、收货标准（v4 PR 逐项对账）
底栏排布与文字标签 · 附件 chip · 内联任务卡（状态行/参数 chip/结果链接）· 模型弹层三类默认预设 + 对话模型 + 预计花费 · Skill 弹层结构 + 引用 chip · 工作方式文字胶囊（命名 A/B 候选给用户挑）· 真实 token · 介入槽默认「这次」。

## 四、词汇表收敛：21 形态 → 8 积木 × 状态（用户 2026-09-06「状态太多，能不能简化」）

实验室的 45 个状态是测试矩阵，用户不感知；用户要认的只应有 8 种积木：

| 21 形态里的 | 收成积木 | 状态维度 |
|---|---|---|
| 用户气泡 | 用户气泡 | — |
| 普通回复 / 超长回复 / 思考中 | 助手文本 | 生成中 · 完成 · 已中断（超长 = 折叠是样式不是形态） |
| 工具调用行 / 工具条总览 / 技能载入行 / 附件读取 / 布局改动收据 | 一行收据 | 进行中 · 完成 · 失败；有内容才可展开 |
| 生成中 / 产物卡 / 产物失败 / 写入回执 / 多候选 | 任务卡 | 排队 · 进行中 · 完成 · 失败 · 已停止；多候选 = 结果区多张 |
| 计划卡 / 付费确认 / 有出入 / 反问 / 缺凭证 / 缺参数 | 介入槽（#511 已是单组件） | kind 维度 |
| 排队行 / 插队 / 中断 | 队列行 | 三态 |
| 收起坞 / 结果全屏 | 收起坞 | — |
| composer + 上传 / 模型 / Skill / 工作方式弹层 | composer | 空闲 · 运行中（发送→停止、占位「可继续输入，将排队发送」） |

实施含义：`docs/design/2026-09-01-agent-ui-final-redesign.md` 的 21 形态表改成 8 积木 × 状态；实验室注册表按「积木 × 状态」重编（数量可以不变，但 id 与分组要反映积木）；六张决定卡的接线从 29 条路收成介入槽与任务卡两条。
