2. 交互路径

所有动作都使用现有 Nomi 组件
选择多个节点虚线只表示本次临时选择，工具条显示清晰的文字动作。
创建编组写入 group owner，显示框外组名、成员数和中性灰边界。
进入组区域空白区域拖整组；节点卡片拖单节点，互不抢手势。
执行或解组整组生成使用每个节点已有的模型和参数；解组回到临时多选。

3. 组内拖动判定

同一个组内，两种指针目标，两种 owner
按下位置拥有手势的组件拖动中松手时
组框内空白GroupFrame 的 blank surface只更新视觉 shell，组框和成员卡片一起移动；React Flow 节点 wrapper 保持稳定，避免边层重建。一次性提交 group 与成员位置，保留一次撤销记录。
节点卡片React Flow node drag只移动被抓住的节点；组框实时跟随边界，其他成员不跟手。一次性提交节点位置；跨组时才提交成员归属变化。
连线待连接状态组框成为落点，不再是拖动把手保持连接反馈，不触发整组移动。点击/松手提交连接，避免“想连线却把组拖走”。

4. 工具条文字合同

避免依赖猜图标
状态动作呈现验收
临时多选创建编组文件夹图标 + 文字可见用户不需要猜图标
临时多选生成总览图多张卡片图标 + “生成总览图（N 张）”可见动作目的和数量同时可读
临时多选保存工作流路径图标 + “保存为流程”可见与导出/下载区分
已编组生成整组 / 进时间轴 / 解组图标 + 文字，按主次排列可见动作不会被误认成节点生成
任意选择清除选择关闭图标 + title / aria-label保留图标这是标准撤销选择动作
