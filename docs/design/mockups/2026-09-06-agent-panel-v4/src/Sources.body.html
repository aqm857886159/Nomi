用户气泡 / 助手文本Message
Message + Response：role 决定对齐；助手侧无气泡、纯排版；Actions（复制/重试）在文本下方，hover 才显。Message / MessageContent / MessageActions
Streaming Text：末尾光标块；Thinking：shimmer 文字不转圈。
用户气泡用 ink 深底（我们 token 里的对话强调色），不是 shadcn 的 primary 蓝。助手文本走现有 NomiMarkdown compact 档。
一行收据Tool
Tool：collapsible，ToolHeader（icon + 名 + 状态 badge + chevron）→ ToolContent（ToolInput JSON 块 + ToolOutput）。状态枚举 input-streaming / input-available / output-available / output-error / output-denied。
Tool Chips：单行、icon 在左、状态点在右、hover 展开。
状态 badge 从「文字 pill」改成「行尾 ✓/spinner/⚠ + 用时」——省 60px 宽。icon 按动作家族不按工具名（见过程板）。output-denied 对应我们的「不要」。
任务卡Task
Task：TaskTrigger（标题 + 进度）→ TaskContent（TaskItem 行，TaskItemFile 文件 chip）。
Task Rows：一行一任务，左状态 icon、中标题、右元信息；带细进度条。
TaskItem 换成缩略图格（生成物是图不是文件）；加「已花 / 预计」两个钱数（MiniMax 没有，我们要）；卡尾「撤销」直连 undo_timeline_edit。
介入槽Confirmation + Plan
Confirmation：ConfirmationRequest（一句话）+ ConfirmationActions（接受 / 拒绝）+ Accepted / Rejected 回显态。Plan：可勾选步骤清单。
Approval Card：标题 + 参数 chips + 「Approve / Deny」+ 「Always allow」勾。
按钮只剩「确认 / 不要」，Claude Code 的 Yes-don't-ask-again 变成槽头「不再问 →」，本质是抬权限档，概念只有一个。四种内容体（计划 / 付费 / 改动 / 反问）共用一个槽，位置固定在 composer 上方——用户永远知道去哪按。
队列行Queue
Queue：QueueItem + QueueItemIndicator（状态点）+ QueueItemActions（插队 / 删）。
—（无对应件）
只在「运行中还继续输入」时出现在 composer 顶上；空队列不渲染。

上下文环Context
Context：ContextTrigger（环形 % ）→ hover ContextContent：ContextInputUsage / OutputUsage / ReasoningUsage / CacheUsage + ContextContentFooter 费用。
—
环放头部；展开体把 token 拆成「输入 / 输出 / 缓存」+ 本会话花费；到 80% 提示「压缩一下」。思路来自 Claude Code 的 /context。
不抄的：AI Elements 的 Reasoning（折叠「思考过程」正文——用户看不懂也不需要，只留思考行的秒数）、Checkpoint（我们撤销走收据）、Suggestion 芯片（下一步建议由介入槽的选项承担）、Web Preview / Code Block 行号；Beautiful UI 的 Loading State 骨架屏（任务卡缩略图用条纹占位即可）。
