段落 / 粗体 / 行内代码 ✓
沿用。行内 code 用于参数值（时长、尺寸、模型名），mono 让数字对齐。
标题 △ 降级
h1/h2/h3 在 390 宽里一律渲成「粗体行」（13px/600），不放大字号——聊天里没有文档层级，放大只会像广告。
有序 / 无序列表 ✓
沿用。缩进 20px；列表项内不再套第二层（LLM 爱套三层，第三层起拍平）。
任务清单 △
GFM 的 disabled checkbox 改成只读的 13px 方块，勾 = accent 底。它是「Nomi 汇报进度」不是「让用户点」——可点的进度在计划卡里。
表格 ✓ + 横向滚动
沿用现有 overflow-x 容器。超 4 列时表头第一列 sticky（改动小，收益大：镜号不滚丢）。
代码块 △
加右上角「复制」；语言标签不显示（用户不关心 json/yaml）。超 12 行折叠，尾行「还有 N 行」。提示词是最常见的代码块内容。
链接 △
内部链接（素材库 / 节点 / 时间点）不带 icon，点了在 Nomi 内跳；外部链接尾巴带 ↗ 小 icon 且走系统浏览器。禁止裸 URL 全文显示，超长自动截中间。
引用块 ✓
沿用；主要用于回引用户文稿原句。
图片 ✕ 不在文本里渲
助手文本里的 ![]() 不渲成内联大图——所有生成结果走任务卡的缩略图 + 画布。文本里出现图片 markdown 只渲成一个可点的 chip。
删除线 / 分隔线 ✓
沿用；分隔线在 compact 档 margin 减半。
HTML 原文 ✕
react-markdown 默认不渲 raw HTML，保持。
超长回复 △ 折叠
超过面板高度 60% 的单条助手文本默认折到 60% 高，尾部「还有 N 行 · 展开」。流式时不折（正在读），流完才折。
流式时的渲染 ✓
边流边 parse（已 memo 历史气泡）。未闭合的 ``` 和表格在流式中先当纯文本显示，闭合后重排——不闪烁的关键是不预测。
数学 / mermaid ✕
不做。出现 $$ 或 mermaid 围栏按普通代码块显示。
