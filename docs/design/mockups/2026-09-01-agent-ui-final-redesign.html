3从头部空白区抓着拖（grab 光标），拖离右缘 >40px 出槽变浮动窗；拖回右缘 30px 热区亮出停靠预览、松手归位；头部「⇥ 回停靠」钮一键回家。浮窗只此一个、默认落右下、跨页跟随，位置尺寸记忆；收起角标对浮动态同样生效。
✕为什么不做左右换边（考虑过，否决）：三个面的左缘全被占着——生成是探索栏(60/300)、创作是文稿列(240)、预览是素材源(268)，Agent 靠左 = 一边叠两条栏，而且各页左栏宽度不同，切页面板会左右横跳，把「一个家」拆了。浮动才有真用例（超宽屏/双屏把对话挪开、画布全宽），机构也是现成的（捕捞坞同款 useResizableFloatingWindow）。浮窗盖到节点是用户自己拖的选择，不属于「系统把动作压在内容上」。
