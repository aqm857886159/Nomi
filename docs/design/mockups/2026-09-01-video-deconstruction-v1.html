拆解视频 v1 · 面板样张

一条参考视频 → 结构化分镜表 → 勾选镜头逐个落成画布节点并自动编组 → 用这套结构起稿。真实外壳复刻（NomiAppBar 创作/生成/预览 · 生成区左侧 镜头/素材 · 画布网格 · 底部时间轴 · 右侧 AI 栏）+ 拆解面板画在真实位置（视频节点浮条唤起、右侧就近停靠）。所有颜色取自 Nomi 设计 token，光/暗双模式。

右槽互斥（本轮补的窟窿）：右侧同一时刻只住一个住户 —— 今天是「生成」AI 栏、M 线后是完整 Agent 面板。从视频节点点「拆解」时 Agent/AI 栏收成顶栏角标（有新动静在角标上示意，见 06）；反向打开 Agent 时拆解收成节点上的「拆解结果」浮条随时点回（见 07）。互斥不丢状态、两边都是收起不是销毁；面板宽度沿用现役右栏宽度真相源（--nomi-assistant-width = assistantWidth 默认 340px），不自立第二个数字。

布局 A · 推荐 右侧就近停靠面板 · 结果态（镜头结构表）——源视频节点仍在画布左侧可见，拆出的结构表在右侧就近展开，两者同屏。这一版是主推。
