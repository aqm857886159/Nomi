要点 1 · 调模型的媒体不进这里。 要写实的图、Motion / Hyperframe 的动态影像、文生/图生 3D 照旧走生成节点（model3d 已在库）——本节点是给"AI 不调模型、直接做出来的表达物"一个画布上的家：SVG、会动的 HTML、表格梳理、Markdown 要点、3D 摆位。
要点 2 · HTML 要动、要能交互（用户明确），所以在"沙箱"里 允许脚本 但隔离执行：碰不到宿主、读不了你的文件，只能演自己的动画。
要点 3 · 类型列表开放、且能喂给下游。 SVG 栅格化、3D 截当前视角 → 固化成参考图（PNG）：节点即作为 image 参考被连线 / 拖进镜头 / 另存素材库（见下方"固化为参考图"场景）。分发内核按"一行类型 + 一个渲染器"生长，未来加图表/思维导图/PDF 同理。

手艺选择尺子 先判断"要媒体本身"还是"把话说清楚"

诉求是「媒体本身」？
照片级画面 / 动态影像 / 声音
→ 调模型 · 走现有生成节点
诉求是「把话说清楚」？
示意/结构 → SVG
讲解/演示、要动 → 动态 HTML
梳理/分镜/对比 → 表格
空间/立体概念 → 3D（.glb）
要点/脚本 → Markdown
→ 不调模型 · 落 agent-artifact
要点 3 · 尺子住哪？ 这条判断住进 Agent 的技能与工具描述（"这个诉求不用调模型，画个 SVG / 做段 HTML 就好"），不是给用户做选择题——Agent 交付 HTML 讲解卡、分镜草表时，画布上就有了一个好看、会动、可回看的产物，不用在对话里翻。
