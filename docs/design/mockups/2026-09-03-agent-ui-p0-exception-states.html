族1 统一折叠策略（所有 10 个「超长/超多」缺口一致应用）

在哪折：气泡/回复/反问内容超过 3 行文字，或列表超过 N_max 条（各形态的 N_max 见下），触发折叠。

折后显示什么：首 3 行（或首 N_max 条）保持可见 + 下方「⌄ 还有 M 行」文字链（无遮罩，链子本身已传达信息）。若是列表，改为「还有 M 条 ▾」折叠行。

怎么展开：点文字链/折叠行 → 遮罩和折叠行消失，全文/全列表展开，无动画（instant，避免焦点跳动）。已展开则文字链变「收起 ▴」。

封顶高度（含列表的卡片用）：卡片内列表最大高度 max-height: 220px；超出则卡内滚动（overflow-y:auto），卡底仍显「另有 M 条 ▾」摘要行。排队/候选/@ 等独立滚动区同理。

  • 气泡超长（形态3）：首 3 行 + 气泡外下方「⌄ 还有 N 行」链（链在面板底色上，无遮罩）
  • 工具条超多步（形态6）：折叠头改 20+ 步 · …，展开列表封顶 220px 卡内滚
  • 普通回复超长（形态7）：首 3 行 + 渐变遮罩 + 展开链
  • 计划卡 >10 镜（形态8）：列表封顶 220px 卡内滚 + 脚部摘要行「共 N 镜 · 已选 M」
  • 排队行 >3 条（形态11/18）：只显前 3 条 + 「还有 N 条」折叠行（无撤回按钮），点展开显全部
  • 多候选 >3 版（形态14）：显 3 张缩略图 + 「+N」小盒；悬停 +N 展开全候选（最多 6 列；列数 >6 则改两行×3）
  • 有出入 >5 处（形态16）：显前 5 条 + 「还有 M 处 ▾」折叠行；点展开显全部，列表封顶 220px 卡内滚
  • 反问卡超长/超多选项（形态17）：问题文字超 3 行折叠同回复策略；选项超 5 个则前 4 个 + 「+N 更多」；点「+N 更多」全部展开
  • @ 选择器素材 >50（形态19）：分组 + 搜索框常驻 + 滚动区封顶 280px，不折叠（搜索替代折叠）

偏离该策略的形态：@选择器（形态19）用搜索而非折叠——因为「找到特定素材」是目标，折叠后仍需滚动；搜索更直接。

族2 统一错误态策略（形态 8·计划失败 / 9·价格算不出 / 10·写入失败 / 13·产物失败）

统一三要素：① 说人话的原因——一句用户能看懂的话，禁止错误码或技术栈信息；② 是否花钱明示——「这次没扣钱」或「已扣 ¥X.XX」，绿字/红字分别；③ 能重试的就给重试——主按钮是「重试」或「换模型重试」，次按钮是「知道了」或「改提示词」。

视觉处理：错误态用 --workbench-danger 边框，不用红色背景块（红底造成视觉压迫感，边框足够传递警示）。不用 toast——错误发生在对话流里，就在对话流里就地展示，不浮出。

何时显重试入口：所有错误默认显重试，除非已知「重试也没用」（如余额不足），此时主按钮换成「充值」或「换模型」。

族3 统一加载中策略（形态 8·计划生成中 / 形态 13·图像生成中）

原则：极简披露，不做进度剧场。显示「正在做」的事实（骨架 shimmer），不模拟假进度条，不编造步骤动画。

骨架态：卡片用骨架线（shimmer 动效，与设计系统 --nomi-motion-sweep 同频）填充「还不知道内容」的位置。已知的内容（标题行、按钮区）可以先出现，但处于禁用态。

何时切出骨架态：骨架是一个瞬间——AI 开始处理时进入骨架，内容确定（哪怕第一个字段）就开始替换骨架。不允许骨架态常驻超过 30 秒——超时显示错误提示（不是无限骨架）。

族4 空状态策略（仅 @ 选择器 × 无素材）

选择：主动引导，不留白。「@ 选择器打开却空着」发生在用户第一次用 Nomi 或刚建新项目时，此刻不知道下一步该做什么。不选「纯留白」——那会让用户怀疑「是不是哪里出了问题」。

三层结构：① 大 icon（告知这是什么地方）；② 一句话说明（没有素材可以引用）；③ 一个行动入口（「去上传素材」）——只给一个，避免选择困难。

为什么不引导「创建技能」：@ 选择器支持素材和技能两类，但空状态下用户最先缺的是素材（技能是高阶用法）。只给最直接的引导，不堆两个按钮。
