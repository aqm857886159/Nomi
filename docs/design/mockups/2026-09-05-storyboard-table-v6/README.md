## 修订 2（2026-09-05）：画幅改成「项目级默认 + 行级覆盖」

用户在外部近邻调研（LTX Studio / Boords / Higgsfield / Kling，出处见设计合同 §⑩）后拍板：**画幅是项目级设置，行级可覆盖，只有覆盖了的行才在底栏显示画幅胶囊**（设计合同 §2.4.1）。`Main.html` 按此重画：

| 位置 | 改成什么 |
|---|---|
| 批量条「画幅」胶囊 | 从"按每镜"改成整片默认值 `9:16`，挂 `data-storyboard-aspect-default`；右侧提示补一句"已覆盖画幅的 2 镜不跟着变" |
| 行 01 / 03 / 05（用默认 9:16） | 底栏**删掉**画幅胶囊——不是置灰、不是显示"继承"，是不存在 |
| 行 02（16:9）/ 行 04（1:1） | 保留胶囊，改成蓝色 `.pill.ovr` 并加「· 覆盖」小字，挂 `data-storyboard-aspect-override` |

**为什么画了两行覆盖态而不是一行**：设计合同 §9.1 有一条对账项要求"9:16 / 16:9 / 1:1 三种画幅混排时画面格左边缘仍对齐"。只留一行覆盖就只剩两种画幅，样张证明不了这条几何规则。两行覆盖同样完整示范了覆盖态与默认态的对比，不影响规则表达。

修订 2 的另外 7 条拍板（拆分镜自动绑锚、历史变体抽屉、本次跳过、产出 @tag、槽的三段声明、底栏 derive、单表 vs 多视图取舍）**只落在设计合同的文字里，本次未画进样张**——它们要么是交互时序（抽屉、跳过后的计数变化），要么是数据形态（槽携带描述与忽略项），静态样张表达不动，留给实现阶段的真机走查（设计合同 §9.2 的 J6–J9）验收。
