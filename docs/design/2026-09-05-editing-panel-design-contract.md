## ① 背后逻辑：解决哪个真实摩擦

用户剪一支生成片时的动作按频率：看片（预览 + 时间轴，全程）> 调节奏（拖 / 切 / 修剪）> 换镜头（从左栏挑变体或重生成的镜头拖上轨，Nomi 特有高频）> 改一两个值（音量 / 淡出 / 画面 / 转场，短促偶发）> 跟 Nomi 说话做以上事 > 导出。

现役（PR #500 之后）的三个摩擦：转场能渲染但零入口（还画了个点不动的 12f）；片段级能力（属性、右键、音频）没有 L2 情境层，全挤进 11 个无标签图标；文字轨默认被裁、空轨占整行。审计原文与截图见简报 §A/§B。

## ② 信息架构（C′）

### 2.1 五块面板与默认尺寸（1680×842 基准；全部可拖，尺寸持久化在 `workbenchStore`）

| 面板 | 默认 | 最小 | 可收起 | 说明 |
|---|---|---|---|---|
| 镜头 / 素材（左） | 300 | 240 | ✅（现役「‹ 收起」） | tab：镜头 / 素材；资源库 tab 本轮留位不画内容 |
| 预览（中） | 剩余 | 480 | ❌ | 舞台尺寸只随面板拖动变化，**不随选中变化** |
| 属性（预览右侧） | 240 | 200 | ✅ → 右侧图标条 | 常驻；无选中 = 整片；选中 = 这一段 |
| Nomi（最右） | 390 | 320 | ✅（⌘\）→ 右侧图标条 | 整列通到底；收起时输入框落到预览下方（§2.6） |
| 时间轴（底） | 260（装四轨） | 140 | ❌ | 只铺左三块；现役 `TIMELINE_PANEL_DEFAULT` 188 → 260，上限 300 保留 |

收起后的右侧图标条：32px 宽，属性 / Nomi 各一个图标，点击展开；顶栏「布局」菜单列五块面板开关 + 预设（默认 / 专注剪辑 / 结果全屏 / 竖屏预览）+ 恢复默认。Agent「布局」读写口：`layout.read` / `layout.write`（面板开关、尺寸、预设），effectClass = reversible_local，收据一行可撤销。

### 2.2 预览区与 transport（依据 `docs/research/2026-09-05-editing-surface-alignment.md` §A/§E/§G）

- 预览面板用中性底（`--nomi-ink-05`），画面在面板内居中；面板底部一条 40px transport 贴时间轴上沿：播放 / 上一帧 / 下一帧 · 当前 / 总时码（mono）· 右侧「叠加」可见开关（`IconSubtitles`）· 监听音量（`IconVolume`，只影响本机预览）· 全屏（`IconMaximize`）。
- 撤出 transport：「整片画幅」→ 属性面板整片态；「这一段」显示 / 缩放 → 属性面板片段态「显示」组；「导出 MP4」→ 顶栏右上固定按钮（CapCut / ChatCut / OpenCut 一致），属性面板只放导出参数不放执行按钮。
- 时间轴上沿只放编辑动作（§2.7），不重复播放控件。

### 2.3 属性面板（一个面板，组随选中 derive，组序固定：显示 → 时间 → 声音 → 转场 / 文字）

头部形态（手册 §C）：标题「属性」（`IconAdjustments`）+ 折起钮；对象行 = 4px 类型色条（accent / video / text 现役色相）+ 16px 类型图标（`IconPhoto` / `IconMovie` / `IconLetterCase`）+ 对象名 + 类型·时长；**不做大面积彩色标题**。组标题 32px 可折叠；行内 label 左、控件右对齐，行高 32；音量 = 滑杆 + dB 数值框 + 静音开关；起点 / 时长 / 淡入 / 淡出 = 数值框（帧，可步进可拖）；画面 = 分段控件 + 缩放滑杆 / 数值框 + 重置。

| 选中对象 | 出现的组 | 取值域（现成契约） |
|---|---|---|
| 无（整片） | 画幅（16:9 …）· 导出（分辨率 720p/1080p · 质量）· 配乐音量 | `exportApi.ts:21-22`；配乐音量 = 音频轨 clip.audio |
| 视频片段 | 显示（适应/填充 · 缩放 · 重置）· 时间（起点 · 时长 · 源窗口只读）· 声音（音量 −60…0 dB · 静音 · 淡入 · 淡出，帧）· 转场（入 / 出各一行，点开 = §2.4 选择器） | `timelineTypes.ts:24-30`、`clipAudio.ts:3-4`、`timelineKernel.ts:195-212` |
| 图片片段 | 同上去掉「声音」（`clip_audio_unsupported`），组不出现不画灰 | — |
| 字幕 | 文字（样式 字幕/标题卡 · 字体 · 字号）· 时间（起点 · 时长）· 「对齐到所在镜头」 | `TextClipStyleControls.tsx`；位置 / 大小仍在舞台里拖 |

「起点」的 ± 就是原「前 / 后微调」的新家（值 → 面板）；「重新生成这个镜头」进右键与面板头部。

### 2.4 转场入口（挂在剪切点上的对象）

- 接缝悬停（±8px）出虚线「+」把手；点一下直接落默认转场（叠化 · 15 帧，`timelineTransition.ts:3`），不弹表单。
- 已有转场的标记 `⧉ 12f` 改成 `<button>`（现役是 `<span role="img">`，`TimelineTransitionMarker.tsx:54-67`），hover 描边；点开选择器：5 种类型照 i18n 词表（`timelineEditor.ts:54-60`），叠化 / 淡入淡出可渲染，匹配剪辑 / 甩镜明标「预览与导出暂不支持，将保持硬切」；时长 stepper（帧，上限随两端片段 derive）；删除。
- 放不了的接缝把手灰显，title 给 9 条理由之一（`timelineVisualFeedback.ts:119-186`）。
- 标记四态：已连接（accent）/ hover / 类型不支持（`--nomi-warning`）/ 空接缝「+」。

### 2.5 右键菜单（只放动词，形态照 `CategoryTree.tsx:352-399`）

- 片段 8 项：在播放头处分割 S · 复制 ⌘D · 重新生成这个镜头 · 静音 ｜ 删除 ⌫ · 涟漪删除 ⇧⌫ · 删除播放头左侧 Q · 删除播放头右侧 W。
- 字幕 4 项：改文字 ↩ · 复制 · 对齐到所在镜头 ｜ 删除。
- 转场标记 3 项：换转场… · 套用到所有接缝 ｜ 删除转场。空轨 2 项：AI 拼片 · 从素材库添加…。
- 自检句：「点下去会弹一个让我填数字的东西吗？」会 → 不进右键，进属性面板。

### 2.6 Agent 在剪辑面

- 选中片段 / 字幕自动成为输入框 chip（数据通路已有：`ProjectAgentResidentShell.tsx:158,512`），带轨道 / 起止帧 / revision，过期提示重选。
- 编辑计划先在时间轴高亮（虚线 = 将被裁掉，虚框 = 将移到这里；`propose_edit_plan validateOnly`），介入槽在输入框上方：应用这次 / 本会话 / 总是 / 拒绝（可附一句）。
- 应用后收据 = 现役「AI 拼片」toast（`已按计划…` + 撤销），同一个 ⌘Z 栈（`timelineUndoHistory.ts`）。
- Nomi 收起（结果全屏）时：输入框落到预览下方，介入槽仍在其上；右上角「叫回 Nomi」/ ⌘\ 恢复。
- 不做 ChatCut 的多版本时间轴 tab（单一真相，P1）。

### 2.7 时间轴

- 工具条三簇用现役「带 legend 分组框」+ 竖线分隔：「这一段」分割 `IconScissors` · 复制 `IconCopy` · 删除 `IconTrash`｜「整片」AI 拼片 `IconWand` · 撤销 `IconArrowBackUp` · 重做 `IconArrowForwardUp`（恒渲染，无历史置灰）｜视图：吸附 `IconMagnet`（激活有底色）· 缩小 `IconZoomOut` · 适配 `IconViewportWide` · 放大 `IconZoomIn`。「重新生成」「微调」撤出常驻。图标唯一词典见手册 §F（Tabler，不混用）。
- 轨道头：视频轨、配乐轨各一个静音钮；眼睛不加（三轨固定）。
- 空轨一律收成窄条（图片轨与配乐行一致）；默认高度 260 装四轨；打开按内容 fit（#500 已做）。
- 快捷键：所有 tooltip 带键位；顶栏「?」/ 按 ? 弹快捷键面板（现役 8 组 + Q / W / ⇧Z / ⌘\）。


### 2.8 图标与认知负荷自查（用户 2026-09-05 指示：有 icon 尽可能用 icon；从用户角度简化认知）

| 位置 | 现在 | 裁决 |
|---|---|---|
| 左栏 tab | 纯文字「镜头 / 素材」 | 加 `IconMovie` / `IconPhoto`，剪映左栏同款「图标 + 文字」 |
| 叠加行 chip | 「+ 配乐」「+ 字幕」 | 改成 `IconMusic` 加配乐 / `IconSubtitles` 加字幕，类型图标比加号更可识别 |
| 属性 · 声音 | 组标题上一个开关（含义不清） | 改成显式「静音」一行 + 开关 |
| 属性 · 时间 | 起点 / 时长 / 淡入淡出全用帧 | 起点用时码 `0:03.00`、时长与淡入淡出用秒，与 transport 读数一致；帧只在 tooltip 与 Agent 契约里 |
| 属性 · 转场 | 入 / 出用剪刀 / 图层图标 | `IconTransitionLeft` / `IconTransitionRight`，类型只写字 |
| 组标题 | 纯文字 | 保持纯文字（OpenCut 用 tab 图标、CapCut 用文字，两种都有；组只有四个，加图标是噪音） |
| 右键菜单 | 每项带图标 + 键位 | 保持 |
| composer「模型」钮 | 插头图标 | 建议改成短模型名文字 pill（ChatCut 做法「GPT-5.6-Sol High ▾」），归 Agent UI 轨定 |
| 所有图标 | 必须是真实 Tabler 字形，与实现同一份 `@tabler/icons-react` | 样张构建脚本已直接从包里抽路径，禁止手绘近似 |

认知负荷原则：一屏只出现用户此刻能动的东西（属性随选中 derive、接缝把手悬停才出）；数值优先用用户口语单位（秒、时码），帧是工程单位；同一动作全站一个图标一个词。
