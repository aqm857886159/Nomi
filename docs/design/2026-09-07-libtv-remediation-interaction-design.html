LibTV 补齐功能 · 交互设计说明书

2026-09-07 · 每项功能：入口住哪一层（§1.5 判定）→ 用户逐步路径（每步看到什么）→ 爽点 → 原则审计。

五层机制缺一层就不爽（判定标准见对话内图表）。路径步数 = 从「起意」到「拿到结果」的用户动作数，不含等待。

扩图（outpaint）

P0入口 L2 · 图片节点编辑工具条路径 3 步
真实任务：「这张 3:4 角色图要当 16:9 视频首帧，把画面补全。」
起点
选中图片节点
编辑工具条已在（零新位置，与裁剪/抠图同家）
步 1
点「扩图」
弹出画幅 chips：16:9 / 21:9 / 1:1 …，底图实时合成预览（原图居中、四周镜像羽化）
步 2
选目标画幅 + 补充描述（可选）
预览随选择即时刷新；不改画幅直接点生成也行
结果
生成
新图进结果堆叠（原图保留可对比切换）
爽点
即时有反应（选画幅即见合成效果，不是盲选）＋ 反悔免费（堆叠并排，不满意再点一次）
审计
§1.5：图像编辑家族内的 L2 项，不进常驻条 ✓　一功能一个家：与裁剪同条 ✓　产物自动落节点 ✓

重绘 / 擦除（inpaint）

P0入口 L2 · 编辑工具条「涂抹」路径 3 步
真实任务：「角色手部崩了，涂一下那只手，说『改成握剑』，别的地方别动。」
起点
点工具条「涂抹」
画布进入沉浸模式，复用画板 Leafer 笔刷（不自研涂抹组件）
步 1
涂抹要改的区域
高亮半透明覆盖；顶部常驻一句承诺：「只修改高亮区域，其余像素保持不变」
步 2
就近输入一句话指令
高亮区旁浮出输入框；「擦除」= 预填指令「移除该区域并自然补背景」，同一链路
结果
生成
新图与原图并排堆叠；mask 保留，改指令重跑零成本
爽点
不挪窝（涂、写、生成全在图上）＋ 反悔免费（mask 和指令都留着，改一个词重跑）
审计
C1：未涂抹时「生成」禁用 + title「先涂抹要修改的区域」✓　R17：mask 走临时文件不进 store ✓　无并行版：擦除是重绘特例 ✓

智能续写

P0入口 L2 · 视频节点浮条「续写」路径 3 步
真实任务：「8 秒视频第 5 秒后的走向不满意，从 5 秒接着拍，人物场景别变。」
起点
视频节点浮条「续写」
节点底部展开一条起点游标
步 1
拖动起点游标
预览帧随游标实时刷新（本地抽帧，100ms 级），松手即定
步 2
确认，写续写描述
确认后关键帧 + i2v 节点自动建好并连好线，prompt 预填上游描述，用户只补「接下来发生什么」
结果
生成
续写段落为独立节点挂在旁边，可再续（成链）、可删、可直进时间轴
爽点
即时有反应（帧随游标刷）＋ 产物有着落（连线都替用户连好了，只写一句话）
审计
§1.5：不新增常驻控件 ✓　P4：按钮只对档案声明 supportsContinue 的模型亮起（C4 禁用有理由）✓　新节点可删 = 全程可反悔 ✓

音频三件套（截取 / 变速 / 切分）

P0入口 L2 · 音频节点浮条三钮路径 2 步
真实任务：「BGM 只要副歌 15 秒，加速 1.2 倍卡视频节奏。」
起点
选中音频节点
浮条出现：截取 ｜ 变速 ｜ 切分（三钮一组，一个心智：修这段音频）
步 1
截取：拉选区（←→ 移动 / ↑↓ 伸缩 / I·O 打点）
与时间轴同一套键盘习惯，零学习成本
步 2
变速：拉滑杆
原速 / 新速 A/B 试听即时切换；两档：节奏变速（保音高，默认）/ 磁带变速（变音高）
结果
应用 / 切分确认
结果为新的音频节点排在源节点旁；源永远不动
爽点
即时有反应（变速试听零等待，本地 ffmpeg 秒出）＋ 反悔免费（源节点不动，产物另立）
审计
§1.5：三钮是一个功能簇算 1 ✓　键盘习惯与时间轴一致（一致性）✓　切分结果多节点自动整齐排列 ✓

分离音视频 / 人声 / 背景音

P0入口 L3 · 视频节点「音频▾」路径 1 步
真实任务：「参考视频的口播不错，抽出人声当配音参考，BGM 也留着。」
起点
视频节点「音频▾」
四项：分离人声 ｜ 分离背景音 ｜ 仅画面 ｜ 仅声音（一个菜单说清四种拆法）
结果
点完即走
后台任务（任务中心可见进度）；完成后源视频 + 拆出节点自动并排摆好，零下载零上传
爽点
路径最短（1 步）＋ 产物有着落（落画布并排，接线都省了）
审计
§1.5：中低频 → L3 一键二级 ✓　C1：纯音乐无人声时明确报「未检测到人声」而非静默空文件 ✓　云/本地档走同一入口（档案声明）✓

片段重拍

P1入口 L2 · 视频节点浮条「重拍」路径 4 步（复杂度花在决定上）
真实任务：「30 秒片子里 12–15s 和 22–24s 动作不对，只重拍这两段。」
起点
浮条「重拍」
底部弹出选段时间轨（复用时间轴组件）
步 1
拉出若干段 + 每段写一句改法
每段一个输入框浮在段上方；段可增删改
步 2
「生成重拍」
每段进队列（成本前置明示）；完成段落亮起，原段 vs 新段并排预览
结果
逐段「采纳」
采纳才替换时间轴区间（可撤销）；不采纳的段留着或删掉——拍十次都不伤原片
爽点
反悔免费是主爽点（采纳制 + 撤销栈）＋ 即时有反应（逐段完成逐段亮，不用全等）
审计
§1.5：复用时间轴组件不造第二套选段 UI ✓　C3：选段层作用域写明「这一段 · 12.0–15.0s」✓　衔接提示：采纳时提示可对相邻段续写（复用续写链路）✓

视频高清 / 超分

P1入口 L3 · 视频节点「高清▾」路径 2 步
真实任务：「720p 生成片段要进 4K 成片，放大别糊。」
起点
「高清▾」
三项：2× ｜ 4× ｜ 提帧率（60fps）；每项旁标预估耗时与花费（点之前就知道）
结果
选中即入队
任务中心进度；完成后原/新结果堆叠切换；>10min 明确告知需分轨并给切分入口
爽点
反悔免费/零焦虑（成本耗时前置，点了不心疼）＋ 产物落节点
审计
No fake progress：队列真实进度 ✓　模型三档（快/高质/本地）同槽声明，用户只看到「速度/质量」选项（P4 声明翻译成人话）✓

音色克隆

P1入口 L3 · TTS 音色下拉「我的音色」首期 4 步 · 之后 0 步
真实任务：「录一段我自己的声音，以后旁白都用我的音色。」
起点
TTS 模式 → 音色下拉 → 我的音色
与 LibTV 同路径，用户跨产品零学习
步 1
录音或上传（10s–5min）
录音面板带电平表；强制朗读屏幕上的随机校验句（合规硬门：证明是本人）
步 2
试听 + 命名入库
生成一句试听，四个维度自查：像不像 / 糊不糊 / 稳不稳 / 自然不自然（对齐 LibTV 心智）
结果
下拉即可选
之后所有 TTS = 0 额外步骤；国内版音色标有效期提示（7 天），解锁费走消费确认前置提示
爽点
一次投入终身 0 步（爽的复利）＋ 合规校验嵌在流程内不做事后拦截（不打断）
审计
三供应商克隆参数收敛为一个音色来源声明，UI 一套（P4）✓　C4：失效音色报因明确 ✓

提示词预设大礼包

P1入口 零新控件 · 提示词库新分组路径 1 步
真实任务：「这张图出一组多机位」「把 AI 味去掉」「这个人改成愤怒。」
起点
生成器 prompt 编辑区 → 提示词库
新分组「分镜预演 / 质感修复 / 表情 / 构图」，老入口老交互
结果
点预设 = 注入 prompt
可编辑草稿形态，不静默追加、不直接生成——AI 建议不盖过用户决定
爽点
零学习（一次点选，词进框还能改）＋ 一个动作覆盖 10 项能力
审计
预设是数据不是代码（可热更）✓　未达标预设不上线（宁缺毋滥，R2）✓

全局生成历史

P2入口 L1 · 左侧栏「历史」tab路径 2 步
真实任务：「上周生成过一张角度特别好的图，找出来用到新项目。」
起点
左侧栏「历史」
时间线缩略图墙 + 按类型/时间过滤（虚拟滚动扛万级）
结果
悬浮 → 「发送到画布」
支持多选批量；数据来自节点 runs[]，不建独立持久层（无双真相源）
爽点
不挪窝（找历史和用历史同一处完成）
审计
§1.5.2：左侧栏 +1 簇——历史为高频刚需，预算判定通过；上线时实测簇数 ✓

AutoLink 实时引用

P2入口 零新控件 · 输入时自动浮现0 新交互
真实任务：「prompt 里写了女主，画布里正好有女主定妆图，自动帮我挂上。」
起点
正常打字
命中画布素材名/别名时，光标处浮出建议 chip（最近使用加权）
结果
Tab 单收 / Shift+Tab 全收
继续打字 = 忽略；chip 与手动 @ 同一体系（一个家）；设置里可一键关
爽点
被猜中心思的爽——但选择权永远在用户（chip 可收可无视）
审计
不打断输入流（浮层不抢焦点）✓　误匹配有逃生口 ✓

逐帧拉片 → 多参考

P2入口 L2 · 拉片结果行内按钮路径 2 步
真实任务：「拉片拆出的这个运镜很妙，下条视频照这个拍。」
起点
拉片结果面板
每个镜头行加「用作参考」
结果
选目标（或新建）视频节点
首帧落关键帧节点自动连线；运镜/画面描述以可编辑草稿注入 prompt，不静默追加
爽点
产物有着落（拆解结果直接变成下一条片子的输入，分析-创作闭环）
审计
注入内容可见可改（Creator control explicit）✓　原子能力全复用，只新增一条动线 ✓
设计原则符合性总审：12 项中 7 项入口在 L2 情境层（贴目标就近浮现，不占常驻预算）、3 项 L3 一键二级、2 项零新控件、1 项 L1 侧栏（有预算判定）；全部复用既有交互模式（结果堆叠 / 时间轴选区 / 提示词库 / @chip / 任务队列），零套新交互范式、零学习成本增量。每项的禁用态、成本提示、失败报错均按 C1–C4 契约设计。
