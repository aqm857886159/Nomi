# 跨设备继续编辑：设计方向

## Design thesis

- **Audience and job**：单人创作者在另一台电脑继续同一个项目；他要确认“项目放在哪里、换机时是否安全”，不想学习新的同步系统。
- **First-glance message**：在“文件与保存”里，一眼看到项目目录已经指向同步文件夹；Nomi 不上传文件。
- **Primary action**：选择/更改项目目录。
- **Content rhythm**：现有设置外壳 → 项目文件位置 → 路径状态与检查 → 现有自动另存设置 → 一行行为说明。
- **Visual direction**：沿用真实 SettingsDialog 的深色/浅色 token、左侧 tab、右侧纵向表单；信息密度高但不堆卡片，状态使用一条语义行。
- **Anti-patterns**：不新增同步中心、不做营销式 hero、不把 VerySync/坚果云做成两个产品配置、不在项目库常驻教学卡。

## 交互边界

1. 设置负责选择本地项目目录；同步客户端负责传输。
2. 项目库只在外部项目上显示轻量状态；异常详情由状态点击或“继续创作”前置检查触发。
3. 配置成功不等于同步成功，文案使用“路径已设置”，不伪称“已同步”。
4. 第一阶段只保证“关闭一台电脑，另一台继续”，不实现实时协作。
