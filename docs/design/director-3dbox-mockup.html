卡点表（主路径：一句话 → 预演 → 改一镜 → 出成片）

问题回答证据 / 状态
① 他怎么知道有这个功能？画布镜头节点上的「3D 预演」；Agent 在拆镜头时主动建议；导演台空态给 3 个示例句（同 LibTV 首页三句）未做：空态示例句；现有入口 stage_shot 已在 Agent 工具面
② 动手前知不知道代价？搭预演 = 本地渲染、不花钱（结果里写明）；出成片走 generate 的价格卡，用户确认才花付费边界已有：generate = user_sees_spend_card；stage_shot 永不花钱
③ 空了 / 错了他看到什么？计划不合法 → 保留上一版可播放预演 + 对话里说清哪里不行；测量问题挂在对应镜头块上（如「已修：出画 → 拉近」）原子应用已有（PR #960 那块迁入）；问题清单 = 第一棒测量模块
④ 凭什么信结果？错了怎么回头？镜头条显示实测景别/运镜/时长（不是计划里写的）；每次 AI 修改 = 一步撤销实测值来自第一棒测量模块；撤销扩展现有 undo（设计正本 §7 标为未做）

这条路几步：说一句（1）→ 看预演（0，自动播）→ 点一镜 + 说一句（2）→ 出成片（1）+ 价格确认（1）= 5 步。能砍：「点一镜」可省——直接说「第二镜慢一点」也能定位，点选只是加速器。
