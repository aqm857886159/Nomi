它在答什么问题。免费自检只能证明三件事：地址通、key 被收下、模型 id 在对方清单里。 它证不了这个模型能出片——本仓记着两个实测反例（有的供应商对合法 key 恒回 401，有的回 200 却跑不通）。 以前我们的做法是「验不过就不让它出现」，代价是一次失败的验证会让一个本来能用的模型从画布上消失。

所以改成两态，而不是「显示/不显示」。「未试跑」不是警告，是一句实话： 我们还没拿它出过片。它必须说得出自己未试跑到什么程度——上面那四行就是 unverified[] 与自检五段式的直接投影，不是另写的文案。

用户的下一步只有一个。「试跑一次」按钮由用户自己点，先显示价格再花钱 （09-09 拍板：钱的闸 = 每次提交看报价确认）。Agent 没有试跑这个动作—— 它调不到，也不该替用户决定花这笔钱。

三条待拍板。① 角标文案「未试跑 / 已试跑」对不对（备选：「未验证 / 可用」——但「可用」是我们 证不了的话）；② 角标该不该带颜色（现在借警示色，可能过重，因为这不是错误）； ③ 悬停卡要不要默认展开——不展开用户看不懂「未试跑」，展开又多一层。
