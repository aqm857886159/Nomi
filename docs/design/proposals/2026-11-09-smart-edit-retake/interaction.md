## 1. 图片：定位、表达、修改范围

| 操作先例 | 原文/真实观察 | 对Nomi决定的影响 |
|---|---|---|
| [Lovart Advanced AI Editing](https://www.lovart.ai/docs/edit-your-design/advanced-ai-editing) | Mark可由工具栏/M/修饰键点击进入；标记立即进输入框；Quick Edit可用Tab进入 | **确认**标完即可写，不必“完成→返回→再找输入框”。只借鉴就地引用，不借用它的自动物体识别承诺 |
| [Canva Magic Edit](https://www.canva.com/help/using-magic-edit/) | 提供整图/点对象/刷选；笔刷大小可调；刷选有重置/继续。帮助页指出特定刷选模式的缩放/撤销限制及细笔迹可能无结果 | **确认**位置、范围和整图应显式区分；**改变**默认刷满对象的选择：首轮用细线圈选，涂抹后续。保留平移、撤销，不能套用其模式限制 |
| [Dreamina Smart edit真实入口](https://dreamina.capcut.com/ai-tool/home?lang=en) | 从首页Smart edit进入，说明为标主体、加注释、描述变化；提供本机上传/素材选择 | **确认**标记＋意见是同一任务；Nomi已有图片时直接绑定当前版本，省去重新选素材。未据此推导其默认画笔、撤销或输出位置 |
| Nomi旧M4与本机工作区 | 旧图“圈一下→画完→回到线程”；真实工作区已有改图、画板、全屏、生成记录和版本入口 | **改变**多步返回，改为选区会话和意见输入同时可见；不增加第二套画板入口 |

### 三种手势的比较

| 方式 | 用户需要做什么 | 适用/代价 | 推荐 |
|---|---|---|---|
| 点一下 | 点对象并说要改什么 | 最快，但只给位置，模型认错对象时需要修正；不能冒充精确范围 | 复用普通位置评论，别默认启用额外语义分割 |
| 自由圈选/框选 | 画一圈或拖一个框，马上写意见 | 比刷满更轻；空间关系可见；不必沿像素描边 | **首轮智能编辑默认自由圈选，框选作替代** |
| 涂抹范围 | 调笔头、刷满、修正边界 | 适合精细mask，鼠标多画几笔；不必让每次改色都承担这份工作 | 后续精细模式 |

“圆不圆”不是强制几何：圈选保留自由轮廓；涂抹才用圆笔头。首轮圈选不是承诺像素mask，只表达“这里”。

### 推荐微交互（待原型验证）

1. 进入时不改图片像素，标题显示对象和版本，已有意见自动带入。
2. 拖动只画圈；松开后就可以写，输入不要盖住选区。点一下仍是位置标记。多区域属于同一句意见，不先做评论批处理。
3. 明确的闭合轮廓才形成范围；开放长线显示待闭合预览。不要用大跨度直线补边后悄悄确定。
4. 媒体区域聚焦时，撤销回退最后笔迹、空格临时平移；意见输入框聚焦时，空格正常输入、撤销先撤文字，沿用现有shortcut/modal owner，不全局抢键。清除只清范围不清文字；退出保存草稿。重新进入恢复原版本，不能贴到新版相同比例位置。
5. 生成期间原图可看，笔迹和意见保留；回来仍是这张图的新版本，主动作是对比/继续改/回到上一版。
6. 对比使用同一缩放和位置；按住看原版，松开回新版。两者身份、范围和意见始终可追溯；不让用户靠视觉记住修改前长什么样。

不新增一堆常驻开关：入口、范围工具和一个生成主动作够用；高级输入、模型与原参考在需要时展开。

## 2. 视频：选时间，检查完整接回的结果

| 操作先例 | 原文/真实观察 | 对Nomi决定的影响 |
|---|---|---|
| [Dreamina Edit segment真实入口](https://dreamina.capcut.com/ai-tool/home?lang=en) | 可点击进入“选择一段并定向修改”的上传空态；引导图亲眼看到视频胶片条、两端手柄与主体笔迹 | **确认**时间选段和画面标记是两个维度。引导图不是操作收据；真实编辑手柄/预览/回退在本轮未试用 |
| [Frame.io区间评论](https://help.frame.io/en/articles/9105251-commenting-on-your-media) | 在发送前拖评论时间括号，把单帧评论扩成时间范围 | **确认**意见应直接绑定区间，不能只绑定当前播放头。它是反馈，不是生成能力证据 |
| [Frame.io版本比较](https://help.frame.io/en/articles/9952618-comparison-viewer) | 版本可并排比较并联动播放/缩放 | **确认**同一时间位置对比旧新结果，不能各播各的让用户凭记忆；Nomi默认单播放器切换，首轮不必同时解码两条大视频 |
| Nomi现有VideoTrimFilmstrip源码 | 两端原生range，step=0.1；中部点击/拖动是seek且夹在选区内，键盘也可seek | **否定**新稿若把中部拖动改成移动整段的想当然设计；继续保留seek，改范围只用两端。现有“剪出片段”不改语义 |

### 推荐微交互（待原型验证）

1. 进入区间编辑先暂停；有旧选区则保留，没有就请用户拉左右手柄，不凭播放头自动定一个任意2秒范围。
2. 左右手柄分别改入/出点；拖动时预览相应边界帧，数值同步。胶片条中部仍seek，不把同一手势改成拖动整段。
3. 起止时间可直接输入，精度与实际一致。键盘聚焦手柄可微调；窄条不好选时打开同一大预览，不另造第二套时间轴。
4. 选区完成后一句话描述；来源、实际替换范围和APIMart上下文窗口同屏可核对，技术详情折叠。用户不必配置“多截几秒”。
5. 生成前循环“选中段”；结果后默认循环“前面原片→修改段→后面原片”。首轮暂以两侧各1秒为观察窗口，遇到原片首尾自动缩短；这是待测默认，不是已有用户结论。
6. 原版/新版切换保留播放位置、缩放和音轨策略；提供全片播放。不要只给2秒产物让人手动想象接回去。
7. 回退在原素材发生；时间轴发起则额外显示“替换当前片段”，不把整个项目中所有引用都换掉。

视频画面圈选属于关键帧意见：只代表这一帧指的东西，不假装已跟踪到整段。首轮有需要才展开关键帧，不强迫每次先编辑图片。

## 3. 从真实创作者任务倒推的风险

下面是任务推演，不是已访谈用户：

| 任务 | 最可能卡住哪里 | 原型里必须观察 |
|---|---|---|
| 给人物换杯子 | 以为圈外完全锁死；新物体超出圈 | 能否在生成前说清范围含义；是否会扩大范围/看原版 |
| 商品标签改一个字 | 手画不准；尺寸小；误改其它字 | 能否框选、放大、撤销；普通标注差异是否看得见 |
| 视频2–4秒手部变形 | 滑错入出点；只看新段不看接缝 | 是否会边界微调；能否发现回填跳帧/姿态变化 |
| 片头/片尾重拍 | 需要上下文时以为替换范围也变了 | 能否区分替换范围与编辑输入；首尾是否可操作 |
| 时间轴有两个相同素材 | 不知道改了哪个实例 | 能否在执行与回填时认出目标；撤销能否恢复 |

进入设计拍板前仍需：Claude Design关键图→现有组件原型→5名真实创作者任务。依次记“预期→动作→反馈→实际”，同时测操作反馈与拖动性能；不能用流程图或模型生成成功抵掉这一步。

## 4. 本轮结论与未验证

可据资料和现状选定的方向：默认自由圈选、松手即可写、意见和范围不分离、少一个返回步骤；视频复用现有两端选段和中部seek、区分生成窗口/替换窗口、默认看接缝而不是孤立片段。

尚不能定为已验证：自由圈选是否比点标更省力、开放路径的闭合阈值、笔头初值、接缝观察1秒是否足够、真实模型是否理解标记、用户是否会主动回退。官方说明、真实入口观察、设计推演和用户试验各自保留边界。
