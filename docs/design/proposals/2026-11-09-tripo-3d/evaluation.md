# 如何证明做得更好

所有数字都是**拟议验收目标**，不是本轮实测成绩。“最优”只对限定任务、质量和设备预算成立；没有真实对照数据，不宣布哪家胜出。

## 两阶段评测

第一阶段是资产质量筛选：固定 12 个有权使用的参考图，同图比较 Tripo H3.1 与 Meshy 7.1 标准模式。12 是发现明显失败的探索集，不足以证明总体可靠率。每个模型每图先一次生成；人工重试单独记为追加尝试，失败不从分母删除。没有凭据时不跑，空白表保持空白。

`evaluation-cases.csv` 是12个素材的空白占位。实际采集时每个 `(case_id, provider, attempt)` 单独留一行，或每家/每次尝试单独文件；两家首轮至少24条任务记录，失败与追加尝试不得覆盖。可用资产率按预先固定的输入任务分母汇总，全部尝试的费用和时间另行累计，不能用追加尝试冲淡首轮失败。

建议分层：硬表面道具 4（交通工具、椅、灯、商品外壳）；软/有机 4（背包、布艺、植物、食物）；风格角色/雕像 4（只看静态资产，不验动画）。素材清单登记来源、许可、哈希、遮挡和视角；本轮没有收集这些用户素材，不能把仓库示意模型当这 12 个输入已齐备。

第二阶段是 Nomi 创作任务：使用通过筛选的资产完成三件真实任务——商品两机位取景、道具跨镜复用、同一布景的预演。保持两家相同的场景、输入、面数档与设备；人工评审隐藏供应商名。第一轮先 5 位实际创作者，记录误点、返回、求助和 SEQ，AI 不代填真人评分。可靠性评估需另积累至少 60 个真实任务、跨平台分报；60 次全成功时，一侧 95% 二项下界约 95.1%，也不等于所有模型/网络/账户组合都已覆盖。

## “可用资产”的逐项判据

| 维度 | 量具 | 首轮建议门槛 |
|---|---|---|
| 文件可用 | 真实 GLB 校验、落盘、离线重开 | 全部进入本地文件的结果通过校验；损坏不进成功状态 |
| 轮廓与结构 | 盲评 1–5；正侧后视固定截图 | 轮廓/几何各≥4，无改变任务用途的结构错误 |
| 材质 | 相同光照/尺度检查 PBR 与纹理 | 纹理≥4，无关键部件大面积错贴 |
| 创作完成 | 入素材→场景→两机位截图/预演 | 指定任务完成；原资产身份不漂移 |
| 可直接使用 | 上述全过且清理≤5分钟 | 探索集建议≥80%，按 n/d 报；12例至少10例才达标 |
| 实际清理时间 | 计时+操作录屏，含失败排查 | 记中位数和最差例，不能只记录生成等待 |

不把无纹理成功和带纹理成功混为同一质量条件。不把 2D 轮廓相似度当完整 3D 几何质量；尤其背面和遮挡处要人工检查。

## 性能方案（下一轮实施前登记）

建议先测当前设备和 Windows 候选设备的既有 GLB 基线，再试每个候选模型的真实产物。最坏规模起点为画布 100 节点、10 个可见 3D 资产（每个约 30k 面、真实材质），并单独记录素材大小和纹理尺寸；超出时声明规模上限，不外推。

- 点击/切状态反馈建议 p95≤150ms；不出现>50ms 主线程长任务。
- 单资产已在本地时，从打开到可见预览建议 p95≤2s；这是包含模型加载的暂定预算，不等于通用界面可操作≤1s预算被取消。
- 旋转与导演台交互建议帧时间 p95≤33ms；记分辨率、DPR、硬件、主题、语言和样本数。
- 用 `pnpm run perf:scenarios -- --id <实施时登记的真实ID>`，没有场景/数据不能写达标。本轮不为未实现能力伪造 perf 场景或基线。

## 决策方法

先过安全、用户控制、文件有效性与任务完成硬门，再看每个可用资产总成本、总耗时和真人完成率的 Pareto 前沿。若一家只在质量更差时更快，不能称整体更优；若差异小于首轮样本的不确定性，保留可切换选择，继续固定样本比较。

默认候选 H3.1 只是“文档与系统适配值得先试”，不因联盟机会宣称质量最佳。P2/T2.5 只有在真实返工减少或场景更流畅时进入第二轮；不同时铺开所有模型。

## 实施验收清单与反例（在动手前使用）

1. 本地 PNG/JPEG、显式公有 URL、文生分别走通；WebP 未核实则显示有出口的限制，不能偷偷转图床。
2. 切 key、换 vendor、改输入、改参数、过期 token 不能复用错误授权；旧 URL 供应商与旧项目保持可读。
3. 非零业务 code、401/403/429、退役版本、内容拒绝、全部终态与 unknown 都有真实出口。
4. create 响应丢失、重复点击、断网/重启、停止等待不产生自动新任务；已有 task_id 只查询。
5. success 缺 URL、HTML 冒充 GLB、损坏/外链资源/超限 GLB 都不入成功；保留上一版本。
6. 正常 GLB 下载落盘、离线重开、节点历史、素材引用、导演台添加、双机位截图/预演形成闭环；Canvas 与 ProductionRun 分别走。
7. Agent、任务列表、通知、模型设置、节点、导演台六处状态一致；中英、明暗、最小窗口、键盘、干净安装和老数据分别核查。
8. 真付费验证按现有门岗：同构建免费演练、构建标记、专用树，协调线仅最小一次；记录请求、实际回执、模型与产物，不用 mock 通过代替。
9. 密钥/私有令牌/签名产物地址不进入公开日志或报告；外部授权范围与真实账户所属地区已确认。
