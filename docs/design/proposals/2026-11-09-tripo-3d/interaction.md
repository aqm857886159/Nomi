# 交互设计：把 3D 放回它的工作区

状态：建议稿，未批准、未实现。探索页见 [exploration.html](exploration.html)。

## 设计主张

对象是已经有脚本、参考图和镜头任务的视频创作者。第一眼应知道“这张参考图将变成可保存的 3D 道具”，主要动作只有当前节点的生成或结果检查。接入凭据住模型设置，输入/参数/结果住 3D 节点，场景摆放住导演台，Agent 只指向它们。

视觉沿用 Nomi 暖中性色、低装饰密度和语义 token，采用现役节点与面板，不增加商业横幅、注册编辑器或第二份模型预览。取舍是少一个“万能 3D 平台”，换取创作者更短的资产使用路径。

## 先例与对决定的影响

| 出处 | 已观察的做法/问题 | 本方案的影响 |
|---|---|---|
| [Tripo 文件 API](https://developers.tripo3d.ai/en/docs/files) | 上传取得私有文件引用 | 确认本地输入应有可见上传阶段，不能要求创作者自己部署图床 |
| [Meshy 图生 API](https://docs.meshy.ai/en/api/image-to-3d) | 模型、拓扑和纹理有独立字段及兼容范围 | 确认先固定一个受控预设，避免把所有高级选项堆给新人 |
| [Tripo 任务生命周期](https://developers.tripo3d.ai/en/docs/task-lifecycle) | 异步任务可查询，前台等待有界 | 改为“停止等待+恢复查询”，不把关窗当取消上游 |
| [Nomi 设计系统 §1.0](../../nomi-design-system.md) | 一个东西一个家，聊天只指路 | 确认不在聊天放完整 3D 编辑器或参数表 |

## 主流程（七步）

1. **准备任务**：从镜头需要出发，选择参考图节点创建/连接 3D 节点。现有“3D 模型”入口保留，Agent 可帮建节点和连参考，但不自动生成。
2. **确认输入**：显示实际参考图和来源节点；本地 PNG/JPEG，主体清楚。无图时可以明确切到文生模式，不能静默换模式。图生不展示不会发送的补充 prompt。
3. **选择能力**：在现有模型选择器中选择 Tripo H3.1；显示单图模式、面数、纹理/PBR 预设。影响本次请求的项可见，不藏在设置里。未接入时跳到既有供应商连接页，返回保留输入。
4. **用户批准生成**：逐项批准，使用已有生成授权/确认入口；批准什么才提交什么。连接成功不自动跑样张，换模型或参数使既有批准失效。
5. **等待与恢复**：上传→排队→生成→取回/验证。只有真实上游阶段才显示；停止等待、关窗和重启后仍能找到同一任务并继续查询。
6. **检查并保存**：节点内旋转检查轮廓、背面和纹理；校验并落盘后才成功。保留已有版本历史。结果检查不是单张缩略图验收。
7. **用于镜头**：通过现有资产节点连接导演台，在“已连接”素材列表添加到场景，调整尺度/位置并取景。后续同一 GLB 复用，不重新生成。3D 产物不是 MP4，成片仍走场景截图/预演与既有视频流程。

## 现有功能普查与归宿

以下为源码只读普查，未证明真实 App 中这些动作已通过本轮走查。当前代码基线见设计卡。

| 现有能力 | 代码 owner | 本提案归宿 |
|---|---|---|
| 3D 节点创建、文生/图生任务 | `nodes/registry.ts`、`runner/model3dActions.ts` | 保留节点，补声明，不新增节点种类 |
| 模型/模式、参考图槽、参数 | `electron/shared/modelArchetypes/`、节点共用参数组件 | Tripo 作为数据进入现有控件 |
| 供应商连接、凭据、认证 | `src/config/knownVendors.ts`、既有接入流程 | 保留已有凭据用户；不要求重新注册 |
| 停止/任务恢复/错误 | 现有任务 owner | 补准确的阶段和动作，不做另一个任务中心 |
| GLB 节点预览 | `nodes/model3d/Model3DViewer.tsx` | 保留旋转和打开检查能力 |
| 结果历史、保存为素材 | 节点结果与项目素材路径 | 保留旧结果；失败不覆盖 |
| 导演台入连素材 | `director/DirectorNode.tsx`、`panels/side/AssetsTab.tsx` | 通过 `asset` 模型引用进入；不假装 model3d 直连已支持 |
| 3D 场景摆放和尺寸 | `scene/entities/ModelEntity.tsx`、导演台 store | 保留实量包围盒与用户尺度控制 |
| 中文/英文、光/暗、键盘 | 现有 i18n/主题/控件 | 新文案双轨；继承生产组件焦点与快捷键边界 |
| 其他 3D 供应商与旧项目 | 现有 catalog/历史数据 | 保留；不替用户删模型或迁移数据 |

## 状态与可执行出口

| 状态 | 中文建议 | English | 下一步 |
|---|---|---|---|
| 无输入 | 连接或添加参考图 | Connect or add a reference image | 图槽或明确切文生 |
| 缺凭据 | 连接 Tripo | Connect Tripo | 现有凭据入口；返回保留任务 |
| 未确认能力 | 尚未验证这项能力 | This capability is not verified yet | 现有验证流程或选择已可用模型 |
| 上传中 | 正在上传参考图 | Uploading reference image | 可停止本地准备；不得 create |
| 排队 | 等待生成 | Queued for generation | 停止等待，保留任务 |
| 生成中 | 正在生成 3D | Generating 3D | 停止等待，保留任务 |
| 验证中 | 正在检查并保存模型 | Checking and saving model | 未落盘不设成功 |
| 成功 | 模型已保存 | Model saved | 旋转检查、保存/引用为素材 |
| 停止中 | 正在停止等待 | Stopping wait | 保留 task_id；不能说上游已取消 |
| 已停止等待 | 已停止等待，可稍后查询 | Waiting stopped. Check again later | 查询原任务 |
| 查询超时 | 暂时未拿到结果 | Result is not available yet | 继续查询，不自动新建 |
| 上传失败 | 参考图上传失败 | Reference image upload failed | 核对格式/网络，再上传同一输入 |
| 生成失败 | 生成未完成 | Generation did not complete | 看具体原因，用户明确决定是否重试 |
| 结果无效 | 模型无法打开 | Model cannot be opened | 重取原任务结果；保留上一版 |
| 模型/服务不可用 | 当前无法使用此模型 | This model is currently unavailable | 选择现有可用模型，输入保留 |
| 输入或版本过期 | 输入已变化，请重新确认 | Input changed. Review again | 重新核对参考与参数，不沿用旧授权 |

以上是语义文案候选；不新增“免费/未扣费”式未经验证的断言。

## 断网、关窗、重启、连点

| 时刻 | 停止 | 关窗/重启 | 断网 | 连点 |
|---|---|---|---|---|
| 尚未授权 | 保持草稿 | 草稿重开 | 可编辑，暂不提交 | 只准备同一草稿 |
| 上传中，未 create | 停止准备 | 重新核相同输入后准备 | 失败可重试上传 | 单个准备动作，不多次 create |
| create 已发，响应未知 | 标待确认 | 恢复待确认记录 | 不自动重复 POST | 拒绝重复提交 |
| 已有 task_id | 停止本地等待 | 查询原任务 | 恢复网络继续查 | 同一任务查询 |
| 下载/校验中 | 不提交半文件 | 恢复取回原结果 | 保留任务和上一版 | 不重复生成 |
| 本地成功 | 保留产物 | 离线仍可打开 | 本地预览可用 | 查看/使用同一版本 |

本表只描述本地动作和任务身份；上游执行结果与账户状态以实际回执为准，不能从“停止”等本地事件推断。

## 连带界面合同

模型设置区显示“已保存凭据/能力待验证/可用”的真实级别；不能存 key 就打已认证勾。3D 节点持有参数和结果；Agent 只说“已准备 3D 节点，确认后生成 / 3D node is ready. Review it before generating”，附节点指向。任务列表显示同一 task 的真实阶段；通知只在可用结果落盘后说“模型已保存 / Model saved”。导演台只能在素材已成功添加后说“已添加到场景 / Added to scene”。

推广或外部账户链接是独立、可选的外跳；它不修改凭据、默认模型、授权项或节点参数，也不成为使用已有账户的前置步骤。具体合作字段不进公开设计。

用户已确定使用 Tripo 并设计自然推广。[引导合同](tripo-guidance.md)将连接账户、结果来源和教程分别归到现有界面，规定 API 与 Studio 的目的地、中英文披露和停用条件；本轮不把新入口拼入 HTML 或生产组件，后续样张须按该合同评审。

## 视觉探索的边界

探索页采用仓库既有 Kenney taxi GLB 示意道具使用，不是 Tripo 生成结果。页面上的状态是评审者切换的假设情景，没有后台提交。连接、生成和保存均只展示下一步设计，不调用 API、读取凭据或写项目。

真实 Claude Design 稿和生产组件对账尚待下一阶段；本轮截图仅证明 exploration 自己能读、能切状态与旋转模型，不证明产品已具备这些新流程。
