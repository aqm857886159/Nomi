# Tripo 3D：在 Nomi 完成创作，并自然了解 Tripo

日期：2026-11-09 · 状态：**调研与产品设计，待用户拍板**。

本轮不实现接入。用户已确定使用 Tripo，并要求围绕实际使用设计推广引导；具体界面仍待拍板。没有供应商认证、付费调用、质量胜出结论或 API 内嵌授权。公开材料覆盖产品与技术；账户合作证据和商业研究由用户授权单独交付到私有 `aqm857886159/nomi-radar`。

## 两个目标

1. 创作者在 Nomi 内完成「已有参考图 → 生成 3D → 本地保存与检查 → 放入导演台 → 取景或预演」。3D 服务跨镜复用与机位控制，不以模型目录数量作为进展。
2. 外部账户引导可以支持独立的合作路径，但不能改变模型质量排序、迫使用户购买不适用的产品，或把接入成功当合作资格已成立。合作设计和收益测算放私有附录。

## 推荐的产品边界

首期建议 **Tripo H3.1 单图生 3D + 文生 3D**。图生为主路径，文生用于缺少参考素材时的概念道具；两者都落现有 `model3d` 节点和 GLB 素材链。图生上传的引用传输缺口必须先解决，不能只交文生而宣称首期完成。

Tripo 是本轮已确定的供应商方向。**Meshy 7.1 标准几何 + 支持 PBR 的纹理模型**仅作为评测参照，不新增竞品接入或联盟申请；现有 Nomi 种子仍是 Meshy 7，不能把其存在当新版本已接通。Tripo P2 可在返工时间、可用率或预览性能证明有必要时再评估。[现行模型来源](sources.md)

| 模型/能力 | 首期角色 | 取舍依据 | 当前证据 |
|---|---|---|---|
| Tripo H3.1 单图 | 主路径候选 | 从现有参考形象得到可复用资产 | 官方v3契约；未实测 |
| Tripo H3.1 文本 | 同一模型的补充模式 | 无参考时做概念道具；不能保证既有商品外观 | 官方文生契约；未实测 |
| Meshy 7.1 + PBR纹理 | 同图质量对照 | 几何/纹理版本分开固定 | 当前官方文档；Nomi尚未升级该种子 |
| Tripo P2 | 第二轮轻量资产候选 | 原生拓扑控制可能减少返工，需数据支持 | 官方定位；Nomi无接入 |
| Meshy T2.5 | 第二轮轻量资产候选 | 与标准模型不同的拓扑/面数条件 | 官方定位；Nomi无接入 |
| 现存 RunningHub Hunyuan/HiTem/Meshy 路径 | 保留已有用户能力 | 不为新增一家删旧入口；不是本轮新模型扩张 | 本地catalog代码，当前真实上游可用性未验证 |

多视图、纹理重做、网格处理、绑定和动画虽有官方端点，均不是一个单图任务的参数别名。图片生成沿用用户已有的生图供应商，不为这次3D目标再引入一组上游生图模型。

不纳入首期：自动绑定和角色表演、复杂物理、3D 编辑器、8K 与高精几何、部件拆分、重新纹理、多视图生成、自动跨供应商重试。它们都有额外参数、产物或授权链，不能借同一个“生成”暗中执行。

| 可选路线 | 创作者结果 | 主要代价 | 判断 |
|---|---|---|---|
| 只整理现有 3D 接入 | 少增系统，但没有 Tripo 能力 | 不能检验这次目标供应商 | 保留为基线 |
| 在现有任务与资产链补 Tripo | 图生资产能继续用于场景 | 必须补 provider 文件引用与 Run 授权边界 | **推荐提案** |
| 重做 3D 工作台或托管生成平台 | 更大范围的编辑与账户服务 | 偏离视频创作主线、增加运维与用户学习 | 本期不做 |

用户已批准 Tripo 方向及围绕使用做推广的目标；具体模型预设、界面和生产接入仍按设计流程验收，不把方向确认当作全部样张获批。

## 下一轮实施的完成定义

新增供应商和模型目录只是准备。真正完成需同时满足：本地 PNG/JPEG 的同一素材身份贯穿授权和上传；创建次数与用户批准项一致；任务重启后继续查询；真实 GLB 经校验落本地；离线重开可预览；能通过现有资产节点进入导演台；中英文、最小窗口和 Windows/macOS 的实际证据分别记录。缺任一项就不称完整接入。
