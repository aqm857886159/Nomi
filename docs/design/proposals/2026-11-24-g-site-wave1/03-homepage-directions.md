### 💡 推荐决策：**以「方向 A」为主骨架，吸收「方向 B」的顶部/副标题高密度 GEO 实体定义与样片省废片对比器，以及「方向 C」的 11 月模型规格矩阵表**
- **一句话点破核心取舍**：创作者来官网最怕两件事——“看着像套壳 PPT 不知道真软件长啥样”和“怕又是充值骗积分的黑盒”。**方向 A** 用可点击的真实工作台复刻直接打消第一层顾虑，再把 **方向 B** 的「原价直连 + 480p 样片省废片」对比块放在第二屏打消第二层顾虑，同时首屏正文严格嵌入 **GEO 实体锚点**（开源 AGPL-3.0、本地优先、BYOK、Seedance 2.5 / Seedream 5.5 / ComfyUI / MCP），兼顾人类转化率与大模型引用吸收率。

## 三、视觉与工程自查清单（对照 `#7108139807` 六条硬门槛逐项核验）

- [x] **1. 先看别人的真样子**：已亲眼 `read_file` 核对 Qoder、LibTV、TapNow 真实 1440 截图并提炼取舍表（见上表）。
- [x] **2. 极限视口与明暗双模零溢出**：Playwright 实测 12 组视图（`dir-a / dir-b / dir-c` × `1440×900 / 375×812` × `Light / Dark`），`scrollWidth - clientWidth` 全部等于 **`0`**，`brokenImgs` 全部等于 **`0`**。
- [x] **3. GitHub 精选区无外部盗图且等高克制**：`dir-a` 精选区采用分类色胶囊 + 等高卡片 +「它是做什么的 → **在 Nomi 里怎么配合用** → 星数/许可证/核对日期」三层结构，不搬任何第三方图标或视频。
- [x] **4. 严格遵循 Nomi Design System v2**：
  - 色彩 100% 取自 `src/theme/nomi-tokens.css`（暖灰纸墨 OKLCH 阶梯 + `hue 250` 冷蓝强调色 + 独立四档 `-soft / -edge / -ink` 状态色，**零廉价 AI 紫粉渐变**）；
  - 字标与图形标 100% 复用 `src/design/identity.tsx` 几何（`28×28` `rx="7"` 圆角方底 + Fraunces 中间字母 `m` 强调色）；
  - 选中态对勾 `✓` 全部在右侧（`--nomi-accent`）；
  - 工作台复刻内的常驻 Agent 严格遵守 `§1.0 一个东西一个家 / Agent 只指路`（只放定位芯片 + `取消 · 生成 4 段` 决定栏，绝不在聊天流画小编辑器）；
  - 中文正文行宽严格控制在 `36–38em`（约 36–38 字/行），标题无单字孤行（首次截图发现方向 B 标题断出单字「排」及方向 C 375px 顶栏双行挤压后，已当场修正并重跑截图复验通过）。
- [x] **5. 性能与无障碍底线**：纯静态语义 HTML + 按需轻脚本，支持 `@media (prefers-reduced-motion: reduce)`，全部图片带真实描述性 `alt`。
