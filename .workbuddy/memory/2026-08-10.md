# 2026-08-10

## 修复 Electron 主进程 "write EIO" 崩溃循环
- 现象：运行 `Nomi-agentic-production-ux` 时弹 "Uncaught Exception: Error: write EIO"，关不掉。根因：主进程 stdout/stderr 是坏管道（启动终端关闭/输出被管道接管后断开），WebContents handler 里的 `console.error` 写坏管道抛 EIO，Electron 默认 uncaughtException 弹对话框，渲染层事件反复触发 → 循环弹窗卡死。
- 修复：在 `electron/main.ts` 模块加载最顶部（installMainProcessLifecycle 之前）加 `installSafeStdio()`，包一层 `process.stdout/stderr.write` try/catch，坏管道静默丢弃（返回 false），从根因层杜绝日志把进程搞崩。落盘诊断仍走 crashLog（文件）。
- 改动文件：`Nomi/electron/main.ts` 与 `Nomi-agentic-production-ux/electron/main.ts`（两仓同改，用户实际跑的是 -ux）。已 typecheck 通过（-ux）。
- 用户需重新 build（dist-electron）才能让已运行的进程生效；卡死的旧进程用 Force Quit / `pkill -9 -f Nomi` 退出。
