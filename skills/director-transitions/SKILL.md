# 创意转场：AI 视频跨镜缝合方法论

Nomi 里一段成片由多个 shot 拼成，每个 shot 由 Seedance / 可灵等模型**独立生成一小段视频**。相邻两镜怎么接得自然，是每对相邻镜头都要想的常规决策——这份方法论就是它的知识库。

## 为什么必须用创意转场（这是硬约束，不是可选优化）

AI 视频生成的现实约束，**不是模型进步就能解决的，而是逐条生成的本质**：

- 单条只生成几秒，成片需要多条拼接。
- **尾帧对不齐**：上一条结尾常有运动模糊，下一条从头生成，接缝处画面/运动不连续。
- **首帧惯性断裂**：即便用上一条的稳定帧当下一条首帧，上条的运动惯性在新条里消失，观众会感知「顿了一下」。
- 帧级严丝合缝的对齐在 AI 生成流程里**不可靠**。

结论：**跨片段缝合不能指望帧对齐，唯一可靠的手段是创意转场**——在接缝处安排一个「视觉中断」（遮挡/甩镜/过曝/匹配图形），让两条可以完全独立生成，观众也感知不到剪辑点。

创意转场的三层价值：

1. **技术层**：不依赖帧对齐，从根源解决剪辑点问题。
2. **叙事层**：每次转场都能顺手完成场景切换、时间跳转、角色替换、情绪转折。
3. **视觉层**：观众感受「一气呵成」，视觉冲击力远超硬切。

**转场不是技术补丁，而是创作工具**。好的转场本身就是叙事的一部分。

## 在 Nomi 里怎么落地：写进相邻两镜的提示词

一个创意转场 = **上一镜提示词的结尾**（转场前半段：遮挡物入画 / 推入特写 / 动作起势）+ **下一镜提示词的开头**（转场后半段：遮挡物移开揭示 / 从特写拉出 / 动作完成）。

- 两条**完全独立生成**——这正是创意转场的核心：不依赖帧对齐。
- 若两镜走「图片+视频」（先首帧图再生成视频），把转场后半段写进**下一镜的视频提示词开头**（不是首帧图提示词——首帧图只写静态画面）；接缝的连续感由「视觉中断 + 首帧图承接」共同保证。
- 遮挡类转场对首尾帧最宽容：接缝那一帧本就是黑/模糊/纯色，两条几乎可以随便接。

## 遮挡转场 · 最可靠的首选手段

原理：上一镜结尾安排某物**完全遮挡镜头**，画面被 100% 遮挡的那一帧就是切点；下一镜从遮挡后揭示新画面。观众视觉被自然中断、大脑「眨眼」，对接缝的感知最低。

为什么遮挡最可靠：

- **不需要任何帧对齐**——遮挡帧本身就是黑/模糊/纯色，两条可以完全独立生成。
- 遮挡物的运动方向天然引导视线，切换后观众注意力已被重新定位。
- 通吃所有衔接类型：同场景、跨场景、时间跳转、角色替换。

### 遮挡物创意库

| 遮挡类型 | 具体手法 | 适用情境 | 叙事潜力 |
|---------|---------|---------|---------|
| **角色身体** | 人物从镜头前走过 / 转身背影填满画面 | 跟拍、人群、走廊 | 角色替换、视角切换 |
| **手 / 物体** | 手掌遮镜头、举起物品挡住画面 | 主观视角、特写 | 情绪转折（握拳→松开是新世界）|
| **门 / 舱门** | 门关闭 → 重新打开是新空间 | 室内空间转换 | 场景切换最自然的方式 |
| **建筑结构** | 柱子 / 墙角 / 隔板遮挡 + 镜头横移 | 横移跟拍 | 同一横移中切换场景 / 时间 |
| **黑暗 / 阴影** | 走进黑暗区域 / 灯灭 | 光线变化的场景 | 情绪沉降、悬念 |
| **烟雾 / 粒子** | 蒸汽、尘土、雾气、干扰粒子扑向镜头 | 街市、工地、深空、爆破 | 柔和过渡，兼顾氛围 |
| **快速甩镜** | 急速横摇产生运动模糊 | 快节奏、惊吓、转头 | 情绪加速、视角急转 |
| **光线过曝** | 强光直射镜头 → 全白 | 开门、窗户、爆炸 | 希望、顿悟、场景跳转 |
| **后脑 / 肩膀** | 摄影机推向角色后脑 / 肩膀 → 移开后是新画面 | 对话、回忆、情感 | 时间跳转（如《功夫》成年→童年）|

### 遮挡转场提示词写法

**上一镜结尾**（安排遮挡入画）：

```
…角色A转身，他的后脑和肩膀逐渐填满整个画面，直到镜头被完全遮住。
```

**下一镜开头**（从遮挡后揭示新画面）：

```
镜头从角色A肩膀后方缓缓移开，露出[新场景 / 新时空的画面]。
```

关键规则：

- 遮挡要做到**至少 2-3 帧 100% 被遮挡**，切点就落在这里。
- 遮挡物运动方向与镜头运动方向协调（同向最自然）。
- 遮挡前后画面亮度尽量接近（亮度差大时接缝加 1-2 帧交叉溶解）。

## 其他经典转场手法（除遮挡外同样适用于 AI 视频）

### 匹配剪辑（Match Cut）

前后两画面在构图、形状或动作上高度相似，视觉惯性带动场景切换。

- **形状匹配**：圆形井盖→满月、眼睛→窗户、车轮→时钟。
- **动作匹配**：伸手触控→手掌按上另一处、转身→旋转、抛物→落下。
- **色彩匹配**：橙色路灯→橙色夕阳、蓝色泳池→蓝色夜空。

Nomi 实现：**上一镜结尾构图**与**下一镜起始构图**设计成匹配图形，两条独立生成后硬切即可；无遮挡，靠图形相似度骗过眼睛。
案例：《2001太空漫游》骨头抛向天空 → 匹配切为太空站。

### 推进 / 后退揭示（Push-in / Pull-out Reveal）

镜头极速推向细节（眼睛、按钮、纹理）→ 从新场景的同类细节拉出。

- 推入手机屏幕微距 → 拉出时已是另一空间的同类屏幕。
- 推入角色瞳孔 → 拉出时角色在不同环境。

Nomi 实现：上一镜以极端特写**结束**，下一镜以极端特写**开始**，中间靠画面相似度衔接。

### 视线引导转场

角色看向画面外某个方向 → 下一镜从该方向展开新画面。

- 角色抬头望天 → 下一镜是天空 / 远景。
- 角色低头看手 → 下一镜是手中物品特写。

利用观众的视线跟随习惯，转场感知极低。

### 动势贯穿（Momentum Carry）

一个运动动作跨越剪辑点，观众被运动本身吸引而忽略场景变化。

- 镜头跟着飞行的物体（球、工具、纸张）→ 物体落地时已是新场景。
- 角色快步行走、镜头跟拍 → 走过门框后空间已变。

可与遮挡组合：**动势 + 建筑遮挡 = 最自然的空间转换**。

## 转场作为叙事工具（选哪种，先看叙事需求）

选转场时**优先看叙事价值，其次才是视觉效果**。同一个接缝，用不同转场讲的是不同的事：

- **场景切换**：门 / 舱门开合、建筑结构遮挡 + 横移、走进烟雾。
- **时间跳转**：后脑 / 肩膀遮挡后揭示、走过拐角后光线由昼变夜、匹配剪辑（旧物→新物）。
- **角色替换**：身体遮挡（一人走过、镜头后是另一人）、视角切换。
- **情绪转折**：手遮镜头（握拳→松开）、走进黑暗 / 灯灭、过曝全白后进入新心境。

跨段落（大场次之间）的转场比同场景内相邻镜头的转场更重要，值得多花创意。

## 设计原则与注意事项

1. **遮挡是默认首选**——不确定用什么时先想遮挡，因为最不容易出错、对首尾帧最宽容。
2. **转场服务叙事**——先问「这个接缝要完成什么叙事」（时间跳转？情绪转折？空间切换？），再选手法。
3. **每个接缝都想一想，但不是都要花式转场**——简单场景硬切无罪，别为炫技而转场；有意识地做决策即可。
4. **标注要具体**——不要只写「遮挡转场」，要写清遮挡物是什么、运动方向、揭示什么。
5. **找不到自然遮挡**时，退而求其次用匹配剪辑或视线引导；实在没有好创意就硬切。

## 单条时长与拼接的关系

单条越短画面越稳、越好接。多条短镜 + 创意转场拼成长段落，比硬拉一条长镜更可控：

| 时长 | 画面一致性 | 建议 |
|------|-----------|------|
| 4-8 秒 | 高 | 安全区，优先 |
| 8-10 秒 | 中高 | 简单运镜可用 |
| 10-12 秒 | 中 | 谨慎，避免复杂运镜 |
| 12-15 秒 | 中低 | 风险区，可能漂移 |

建议单条 8-10 秒，多条 + 创意转场缝成一气呵成的长段落。
