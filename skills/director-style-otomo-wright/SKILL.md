# 大友启史 × 埃德加·赖特 · 融合风格招式（时尚动作怪盗 DNA）

一套可以「套」到一段戏上的**导演运镜 + 剪辑节奏**招式。合成一句话：**「有重量感的华丽动作，踩着节拍剪出来，时髦幽默又走心。」** 适合都市动作、侠盗怪盗、动作轻喜——你想要这种质感时，按下面「情节类型」查表，把运镜词汇写进该镜头的 `prompt`，把卡点节奏当作 Nomi 时间轴上的剪辑参考。

**怎么在 Nomi 用**：
- **运镜** → 写进镜头 `prompt`（推/拉/摇/跟 + 动作演进 + 节奏感），经应用内 Seedance / 可灵等视频模型生成。
- **剪辑节奏 / 声画卡点** → 属**后期剪辑**，是你在 Nomi 时间轴上排片、卡切点的参考。⚠️ 视频模型的 `prompt` **不含音频**，别把 BPM / 音乐 / 声效写进画面提示词——那些只在你剪辑时用。

## 一 · 两位导演的核武器（先认武器，才会融合）

### 大友启史（动作骨架 + 温情内核）

| 武器 | 是什么 | 写进 prompt 的关键 |
|---|---|---|
| 长镜动作流 | 长镜头贴身跟拍展现完整招式与空间，不靠快切堆 | 连贯处用长镜、贴身 handheld / steadicam 随动 |
| 重量感 · 真实物理 | 每一击有重量、有受力、有后果，不飘不花架子 | 写清受力反馈（踉跄 / 格挡 / 被压制） |
| Speed Ramp 变速 | 慢-快-慢，在拔刀 / 命中 / 腾跃瞬间变速强调 | 写「慢动作强调…随即恢复常速」 |
| 凌厉但看得懂 | 高速凌厉，但招式落点清晰、观众跟得上 | 关键命中切到中近景 / 特写交代落点 |
| 敏捷优雅 · 身法如水 | 流畅、无多余动作、零代价（贴猫系夜行） | 「流畅如水 · 无声着地 · 无多余动作」 |
| 温情内核 · 人物深挖 | 动作之外深挖关系、内心，留白克制 | 文戏放慢、微表情、潜台词、短句台词 |
| 双重时空 | 夜战凌厉 vs 日常温情，冷暖自由切换 | 配冷夜 / 暖日双色调 |

### 埃德加·赖特（节奏剪辑 + 时髦幽默）

| 武器 | 是什么 | 落地关键 |
|---|---|---|
| Everything on the beat | 动作 / 剪辑 / 转场全部踩在节拍上 | 关键动作设计成清晰节奏点，剪辑时卡拍 |
| 音乐驱动剪辑 | 先有节奏 / 歌，画面踩着它走 | 后期剪辑参考：选一首明确拍子的曲，切点踩重拍 |
| Whip Pan / Snap Zoom | 快速横摇、急推急拉做转场与强调 | prompt 里写 whip pan / snap zoom，别滥用 |
| 对称构图 · 居中海报感 | 风格化、整齐、有平面设计感 | 登场 / 换装 / 物件用对称居中 |
| Quick Cuts / Reaction 快切 | 信息高密度，反应镜头（手 / 眼 / 脚）踩点快切 | 反应镜头短、踩拍、递进（剪辑时排） |
| 视觉笑点 · 韵律幽默 | 动作里藏幽默节拍，时髦轻盈不端着 | 贫嘴搭档 / 反差 / 意外做幽默 beat |
| 章节 / 标题卡 | 风格化分段、出字 | 后期叠字，不写进视频 prompt |

## 二 · 融合公式（谁给骨、谁给皮、谁给魂）

- **动作骨架 = 大友**（真实重量 + 连贯流畅 + 招式清晰）——地基，先立住「看得懂、有分量、够漂亮」。
- **节奏剪辑 = 赖特**（卡点 + 音乐驱动 + whip/snap + reaction 快切）——把大友拍好的动作剪出韵律。
- **情绪内核 = 大友**（温情 + 人物 + 留白）——动作再炫，落点是人。
- **整体调性 = 赖特**（时髦 + 幽默 + 轻盈）——怪盗是来潇洒的，不是来苦大仇深的。

### ★ 黄金法则：赖特剂量按情节配（这套招式的真正智慧）

赖特的「卡节拍 / 音乐驱动」很强、很风格化，**全程拉满会发腻、显 MV**。按场景给剂量：

| 情节 | 赖特剂量 | 大友剂量 | 主导 |
|---|---|---|---|
| 飙车 | ●●●● 满 | ●● | 赖特 |
| 时尚换装 / 登场 | ●●●● 满 | ●● | 赖特 |
| 盗窃潜入（盲区卡点） | ●●● 高 | ●●● | 合 |
| 跑酷 | ●● 中 | ●●●● | 大友 |
| 打斗 / 制服 | ● 低（仅命中卡点） | ●●●● 满 | 大友 |
| 文戏 / 温情 / 暧昧 | ○ 撤掉 | ●●●● 满 | 大友 |

### ★ 文戏调味（暧昧 / 暗恋线 · 第三味 · 只调不主）

大友 × 赖特是「动作 + 节奏」引擎；**暧昧惆怅 / 暗恋张力**两位都不是最强项。文戏段可借**一层**调味（不是第三个完整风格，只在文戏段加一点）：

- **王家卫味**：霓虹暧昧、框中框、欲言又止的都市惆怅 → 用于暗恋 / 夜里独处 / 未说出口。
- **是枝裕和味**：生活质感、温润日常、克制的暖 → 用于温情 / 家人感 / 不煽。

用法：文戏镜头 prompt 里点一句「借王家卫暧昧 / 是枝温情」，运镜放慢、留白，剪辑时把赖特节拍撤掉。

## 三 · ★情节类型战术手册（核心 · 按戏查表）

每类给：**主导 · 运镜词汇（写进 prompt） · 剪辑节奏（后期时间轴） · 声画卡点（后期，不进 prompt） · 落地要点 · 适配提示**。

### ① 飙车戏 Car Chase（赖特主导 ●●●●）
- **运镜**：车内 POV / 方向盘 + 档把特写、贴车侧跟 low-angle、引擎盖机位、后视镜 reaction、whip pan 切对向车流、漂移甩镜。
- **剪辑节奏**：每个换挡 / 漂移 / 擦身踩重拍；反应（手紧握 / 脚踩油门 / 眼神）快切踩拍；直道松、弯道险情密。
- **声画卡点（后期）**：引擎轰鸣 / 轮胎尖啸 / 转向灯「嗒嗒」= 节奏元素；选一首明确 4/4 拍的曲子，漂移落重拍，BPM 建议 120–140。
- **落地要点**：拆成一组镜头（漂移 / 换挡 / 擦身各成段奇观运动）；用具体物理（甩尾 / 擦护栏 / 钻车缝 / 急刹）；速度感靠**运动模糊 + 低机位 + 前景飞掠**。
- **适配提示**：没有真追车时，接应 / 逃逸的车内戏 + 搭档贫嘴卡点也是天然赖特段。

### ② 打斗 / 制服戏 Fight（大友主导 ●●●● · 赖特仅命中卡点 ●）
- **运镜**：长镜头一镜流贴身跟拍、手持随动、speed ramp 慢-快、招式落点中近景、关键命中切特写。
- **剪辑节奏**：尽量少切、用长镜展现连贯；切点放动作中间（动作遮剪）；仅关键命中 / 拔刀踩拍。
- **物理**：硬桥硬马有重量，每击有后果（踉跄 / 格挡 / 受力）；不飘不花架子。
- **落地要点**：长连贯动作拆成一组镜头，每镜按事件顺序演一个招式节拍（格挡 → 反手 → 压制）；speed ramp 处慢放动量凝固的瞬间；猫系敏捷 = 流畅如水无多余动作。
- **适配提示**：零暴力侠盗题材，「打斗」= 制服 / 擒拿 / 闪避（抢先按死控制台、躲摄像头、擒住手腕），不血腥；取大友的**优雅敏捷 > 暴力**。

### ③ 跑酷戏 Parkour（大友身法 ●●●● × 赖特落点卡拍 ●●）
- **运镜**：FPV 贴身跟、wall-run 侧跟、纵跃 crane up、落地膝盖一沉的低机位、城市夜霓虹掠过的速度前景。
- **剪辑节奏**：每个落点 / 翻越 / 蹬墙踩一个节奏点；连贯处用长镜，跨大障碍处 snap。
- **物理**：猫系——无声着地、零代价、流畅如水。
- **落地要点**：连贯跑酷拆成一组镜头，每镜按事件顺序走路径节点（蹬墙 → 借力 → 翻越 → 落定）；速度靠 crane 跟随 + 前景飞掠 + 衣摆翻飞。
- **适配提示**：序场贴墙上滑、屋顶纵跃落对面楼顶即跑酷戏；潜入盲区读秒「三二一」可当卡拍锚。

### ④ 盗窃潜入戏 Heist / Stealth（赖特倒计时卡点 ●●● × 大友静-动张力 ●●●）
- **运镜**：多搭档视角 whip 切（望风 / 黑客 / 潜入三视角）、静止悬置长镜 vs 突发 snap、手部精密动作特写。
- **剪辑节奏**：盲区倒计时做节奏锚（读秒「三二一」踩拍）；静（潜伏）松、动（窗口期）密；搭档贫嘴做幽默 beat 缓冲。
- **声画卡点（后期）**：心跳 / 秒针 / 低频脉冲作「盲区」听觉签名，倒计时归零落重拍。
- **落地要点**：多空间各自成镜；倒计时压力靠交叉剪辑（后期）+ 读秒台词；精密动作（压窗缝 / 解锁 / 避摄像头）走特写。
- **适配提示**：盲区倒计时（如六秒 / 九秒）= 天生的赖特卡点结构——剪辑时把读秒、冻摄像头、潜行动作排在同一节奏骨架上。

### ⑤ 文戏 / 温情 / 暧昧戏 Drama（大友主导 ●●●● · 赖特撤掉 ○ · 加文戏调味）
- **运镜**：稳定、缓、克制；中近景 / 特写承载微表情；少运镜，给表演空间。
- **剪辑节奏**：放慢、长镜、留白；情绪不切（积累未到峰值不切、关键反应未完成不切）。
- **内核**：关系深挖、潜台词、短句台词；**借王家卫暧昧 / 是枝温情**调味。
- **落地要点**：微表情物理化（垂眼 / 停手 / 喉结滚 / 眼眶泛水）；不炫技、不卡点。
- **适配提示**：对白戏、不煽的温情戏、一件小道具承载情绪——都是大友温情戏；暗恋 / 猎与被猎的张力那条可借王家卫的欲言又止。

### ⑥ 时尚换装 / 登场戏 Transformation / Reveal（赖特主导 ●●●● · 风格化）
- **运镜**：快切换装蒙太奇（每件装备一个**对称特写**）、snap zoom 强调、踩拍、登场逆光定格。
- **剪辑节奏**：换装每件踩一拍（手套 → 靴 → 面罩 → 收拳），节奏递进到登场定格。
- **声画卡点（后期）**：每件装备一记金属 / 皮革质感音踩拍，收拳落重拍。
- **落地要点**：每件装备一条短特写镜头（由细节运动到锋利）；登场用**逆光轮廓光**定格气场。
- **适配提示**：换装蒙太奇「快切 · 每格一物件由下往上」= 正是赖特换装蒙太奇，可在序场 / 出手前插一段，配登场逆光剪影。

## 四 · 落地自检（把招式套到一段戏时）

1. **先定剂量**：这段戏是哪类？查表拿到赖特 / 大友剂量——文戏给 ○ 别卡点，飙车 / 换装给 ●●●● 拉满。
2. **运镜进 prompt**：把该类的运镜词汇（whip pan / 长镜跟拍 / speed ramp / 对称特写…）写进这一镜的 `prompt`，加动作演进与节奏感。
3. **变速标清**：大友 speed ramp 处在 prompt 里写「慢动作强调 X，随即恢复常速」。
4. **卡点留给剪辑**：BPM / 音乐 / 声效 / 切点**不进 prompt**，记在剪辑备忘里，在 Nomi 时间轴排片时把命中 / 切点踩到拍子上。
5. **落点是人**：动作再炫，情绪内核（大友）别丢——高潮后给一记温情落点。

**画面质感（可选）**：想让参考图也带这股凌厉活力时，可在**图片提示词**里加：写实电影质感、锋利胶片颗粒、贴身手持能量混对称海报式构图、高级时髦都市气质、霓虹夜 + 暖日双色调、略提饱和与对比，避免卡通 / 动画 / 3D 渲染 / 塑料皮肤 / 文字水印。温情戏不必叠这层。

## 一句话记忆

**大友给骨与魂（真实重量的华丽动作 + 走心），赖特给皮与韵（踩拍的剪辑 + 时髦幽默），剂量按情节配（飙车换装拉满、文戏撤掉），暧昧线加一味王家卫 / 是枝。**
