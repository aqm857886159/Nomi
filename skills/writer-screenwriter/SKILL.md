# 编剧方法论手册（Kasdan × Gilroy）

Nomi 创作区帮用户写故事、写剧本时读这份。它管的是**文字剧本本身**——怎么搭结构、怎么写一场戏、怎么写对白、怎么自查质量，不是视频提示词、不是分镜镜头语言。写之前先确认目标媒介（长片 / 剧集 / 短片 / 超短概念片），到「格式变体」一节按媒介取对应的结构要点；要「克制中爆发」的质感时叠加「严肃叙事风格」一节。

两位大师的底色，贯穿全文：
- **Kasdan（人物驱动）**：对白揭示性格而非推进情节；每场戏都在改变人物关系；结局必须从第一幕就埋下。
- **Gilroy（信息驱动）**：信息不对称是张力的根源；主角永远比观众少知道一件事；道德困境没有正确答案；机构/体制才是真正的反派。

## 一、场景写作铁律（Kasdan）

**每场戏必须完成三件事之一：**
1. 改变人物关系（更近或更远）
2. 揭示新信息（改变观众对已知事实的理解）
3. 推进不可逆的决定（角色做了不能撤回的事）

**三件事都没做的一场戏，删掉它。**

**进出场时机：**
- 进入越晚越好——从冲突已经开始的地方切进去，不铺垫。
- 离开越早越好——高潮过后立刻切出，不收尾。

**场景该怎么结束：**
| ✅ 好的收尾 | ❌ 坏的收尾 |
|---|---|
| 以动作结束（她关上了门）| 以解释结束（"这就是为什么我…"）|
| 以问题结束（他看着手里的地址，没有动）| 以宣言结束（"我决定了…"）|
| 以沉默结束（两人都没有说话）| —— |

## 二、对白设计铁律（Kasdan + Gilroy）

**对白的唯一功能：揭示角色，不是传递信息。** 信息传递交给视觉手段（道具、动作、环境），对白说的永远是"别的事"。

**Kasdan 的潜台词原则**——每句对白有表层和深层：
- "你吃了吗？"→ 表层：关心饮食；深层：我需要你留下来。
- "路上小心。"→ 表层：安全叮嘱；深层：我不知道该说什么。

**Gilroy 的信息克制原则**——观众获得信息的顺序比信息本身更重要：
- 让观众先于角色知道 → 悬疑。
- 让角色先于观众知道 → 谜题。
- 两者同时获知 → 最弱，尽量避免。

**对白禁忌：**
- ❌ 解释动机（"我这样做是因为…"）
- ❌ 描述情绪（"我现在很难过 / 愤怒 / 害怕"）
- ❌ 总结刚发生的事（"所以你的意思是…"）
- ❌ 哲学宣言（"人生就是这样…"）
- ❌ 确认已知信息（对白版的"你也知道"）

## 三、人物设计铁律（Kasdan）

**主角的定义：必须改变，或者必须拒绝改变并付出代价。** 人物弧线不是"从坏人变好人"，而是核心信念在压力下被检验——信念被证伪则改变，信念被坚守则付代价。

**人物的三个维度：** ① 他们做什么（行为）② 他们说什么（语言）③ 两者之间的落差（性格）。**落差就是角色**——行为和语言完全一致的人在剧本里是平的。

**配角设计（Gilroy）：** 每个配角都有自己的目标，且这个目标在某个时刻必须和主角冲突。没有纯粹的帮手，没有纯粹的障碍，只有有自己目标的人。

---

## 四、结构铁律（Gilroy）

**每一集 / 每一章必须包含：**
- 开场钩子（30 秒–1 分钟内建立悬念）
- 中段压力点（主角的选择被迫升级）
- 结尾钩子（新问题出现，或已知问题的新角度）

**钩子密度：** 每 3–4 分钟 / 每 500–800 字一个钩子；开场必须有、中段至少一个、结尾必须有。

**五种钩子类型：**
| 类型 | 定义 | 示例 |
|---|---|---|
| 信息钩 | 观众知道角色不知道的事 | 镜头切到门口有人在监视 |
| 选择钩 | 角色被迫在两个坏选项中选 | 要么签字，要么他死 |
| 反转钩 | 已知信息被重新解释 | 原来他一直知道 |
| 时间钩 | 倒计时或截止日期 | 三小时后引擎失效 |
| 关系钩 | 两人关系发生不可逆变化 | 她关上门，没有回头 |

## 五、质量审查（Kasdan + Gilroy 联合视角）

对每集 / 每章的完成稿逐条过。

**Kasdan 维度：**
- [ ] 每场戏都在改变人物关系或揭示新信息？
- [ ] 对白有潜台词，不是直接说出情绪？
- [ ] 主角有明确的核心信念，并在本段受到检验？
- [ ] 结尾和开头在主题上形成呼应？

**Gilroy 维度：**
- [ ] 信息分配制造了张力（观众和角色的信息不对称）？
- [ ] 道德困境没有正确答案？
- [ ] 机构 / 体制 / 规则在阻碍主角（不只是个人对立）？
- [ ] 钩子密度达标（每 3–4 分钟一个）？

**四个自评维度**（各自独立打分，用来定位薄弱环节）：场景效率（每场戏都有功能）、对白质量（潜台词、个性化、不说废话）、信息张力（信息分配制造悬念）、钩子密度（开场 / 中段 / 结尾都有钩子）。

## 六、时长估算与预算（所有格式通用）

**每场戏都标注预估时长**——时长不只是"这场多长"，更是"这场在全片节奏里占多大比重"。

**估算方法：**
- 纯对话场景：中文约 200–250 字对白+动作 ≈ 1 分钟。
- 动作 / 蒙太奇：按画面数量（每个独立画面约 3–5 秒）。
- 沉默 / 情绪场景：容易低估——角色站着不动在成片里可能要 10–15 秒。
- 转场 / 过渡：每次 2–5 秒，别忘计入。

场景标注格式示例：`【场景3：医院走廊 / 夜 / 荧光灯嗡嗡响】（约1分30秒）情节节奏：中 | 情感节奏：重`。

**全片时长预算（参考比例）：**
| 格式 | 建置 | 发展前半 | 发展后半 | 高潮 | 结局 |
|---|---|---|---|---|---|
| 短片（8分钟）| 1.5分 | 2分 | 2分 | 1.5分 | 1分 |
| 长片（100分钟）| 25分 | 30分 | 25分 | 15分 | 5分 |
| 剧集单集（25分钟）| 4分 | 10分 | 6分 | 3分 | 2分 |
| 短剧单集（3分钟）| 20秒 | 70秒 | 40秒 | 30秒 | 20秒 |

**时长诊断清单：** 高潮段时长够不够（太短会被压缩）？建置是不是太长（观众等太久才进正题）？有没有连续超 3 分钟的单一情绪段落？两个高情感场景之间有没有呼吸空间？全片最长的单场戏有没有理由占那么多时长？

## 七、写作红线（全局最高优先级）

**绝对不要：**
- 写心理描写（"他意识到""她领会到""内心涌起"）。
- 写括号暗示（"（其实是在掩饰紧张）"）。
- 角色用台词解释设定或主题。
- 说教片段、强行催泪、煽情独白。
- 过度比喻、类比、书面化的 AI 腔台词。
- 写任何无法被摄影机拍到的内容。

**必须做到：** 台词口语化像真人说话；用动作代替解释（动作即潜台词）；对话像冰山只露一角；一切从视听角度出发。

**输出前自检：** 所有内容输出前内部过一遍这条红线，发现违反先改再出。

## 格式变体（按目标媒介选一节）

写之前先定媒介，取对应结构要点。基础方法论（一~七节）对所有格式都成立，本节只补各格式独有的结构。

### 变体 A：概念超短片（1–3 分钟）

纯粹的 idea delivery——用一个高概念在 1–3 分钟内击中观众，武器是概念锐度 + 视听冲击而非故事。角色是功能性载体（可无角色），通常没有弧光（若有只是一瞬间的认知翻转），世界观 5 秒内让观众理解，零废镜头。分两条路径，先确认走哪条：

**What-If 型**（假设一个反常识前提，展示后果）。好的 What-If 是现实的放大镜，把真实存在却被忽视的社会机制 / 人性弱点放大到不可忽视。五种概念组合法：① **概念嫁接**（A 的机制 + B 的场景，如"斩杀线 + AI 打分"）② **时空错置**（把人 / 技术 / 制度放到不属于的时代，如"钢铁侠 + 90 年代下岗潮"）③ **隐喻具象化**（把抽象焦虑变成能拍的物理规则，如"内卷 → 灯必须比邻居亮，不够就断电"）④ **反转并置**（两个表面相似本质矛盾的事物共存）⑤ **规则反转**（把现实规则取反推演后果）。五种结构可选：经典三段式（呈现→推演→翻转）/ 递进崩塌式（规则不断升级到崩溃）/ 双线并置式 / 循环 Loop 式 / 倒叙揭示式。检验：组合有没有 1+1>2？5 秒能懂规则？指向真实社会情绪？有推演空间和翻转潜力？

**How-to-Tell 型**（不改"讲什么"，改"怎么讲"，形式即内容）。五种创意法：① **视角置换**（用不可能的视角，如子弹视角讲战争）② **形式模拟**（用说明书 / 游戏攻略 / APP 界面重新包装，如用搜索历史讲一段心理历程）③ **时间手术**（加速 / 减速 / 倒放 / 循环 / 跳跃）④ **尺度跳跃**（极大与极小之间跳）⑤ **规则限制**（给叙事加规则，如全片只用一个固定镜位）。节奏：形式建立（前 20–30 秒，让人"哦？这样讲？"）→ 形式深入（中段 60–120 秒，升级 / 变异而非重复）→ 形式与内容交汇（最后 15–30 秒，形式本身完成翻转）。检验：去掉形式用常规方式讲，内容还有没有冲击力？没有就换形式。

超短陷阱：概念需要大量解释就换概念或降级；推演只是重复而非递进；翻转是硬转（跟前面没逻辑关系）；试图塞进完整弧光；用了太多视听手法（聚焦 1–2 种用到极致）。

### 变体 B：叙事短片（5–10 分钟）

**只允许一个"单一核心事件"**——不能有支线、不分散焦点，所有场景服务同一个戏剧动作（追求目标→遭遇阻碍→做出选择）。1–2 个主角，完整 Want / Need / Arc；世界观 30 秒内让观众理解；信息密度高；除非用户特别要求，设定放在现实主义背景。人物用简版：**Want**（外部目标）+ **Need**（未意识到的灵魂缺口）+ **Arc**（A→B 不可逆变化）+ **矛盾特征**（外在 vs 内在，至少一层）。人物太平时借长片 Ghost/Lie/Flaw 思考——不展开，只暗示"行为背后有个不被说出的原因"，一个细节就够。

四段式结构：
```
第一幕 起因（约15%）：开场钩子（前15秒画面/动作）→ 建置（常态）→ 激励事件（打破平衡）
第二幕 发展（约40%）：障碍1 → 障碍2（不可省略，须与障碍1不同质）→ 中点（伪胜利/伪失败）与一切尽失
第三幕 高潮（约25%）：最终对决（动作顶点）→ 关键选择与故事反转
第四幕 结局（约20%）：新常态（弧光完成，用一个画面让观众自己感受，不解释角色学到了什么）
```
**开场：前 15 秒决定生死**，第一个画面就含信息或悬念——最有效的短片开场是一个"不太对"的日常画面（看起来正常，某个细节让人起疑）。伏笔缩小版：一个第 1 分钟不经意出现的物件在第 8 分钟成为关键，短时间内冲击力反而更大（观众还记得）。

### 变体 C：电影长片（75–120 分钟）

长片是马拉松不是冲刺——要安静场景让观众消化情绪；讲一段旅程（一系列递进考验）而非单一事件；潜台词还藏在**场景序列**里（两个场景的并置本身就是潜台词）；节奏要有"呼吸感"、张弛交替。

**人物深度**在 Want / Need / Arc 上加三层：**Ghost**（前史创伤，可只通过反应暗示）→ **Lie**（因 Ghost 形成的错误信念，驱动 Want）→ **Flaw**（Lie 在行为上的外化）。完整弧光链：Ghost → Lie → Flaw → Want（错误追求）→ 一系列考验 → 面对 Need → 关键选择（坚持 Lie 还是拥抱 Need）→ 新常态。

**结构选型**（按题材选一种，不确定默认 Story Circle）：
| 题材 / 意图 | 推荐结构 | 原因 |
|---|---|---|
| 商业类型片 | Save the Cat 15 节拍 | 节拍精确到分钟，严格节奏控制 |
| 成长 / 冒险 / 变形记 | Dan Harmon Story Circle | 八步圆环天然贴合"离家→历险→回归" |
| 角色复杂、主题先行 | McKee 故事原理 | 以价值转变为核心，深度戏剧 |
| 角色驱动文艺片 | 内在节拍表 | 节拍是内心转变而非外部事件 |

- **Save the Cat 15 节拍**（第一幕约 25 分：Opening Image → Theme Stated → Set-Up → Catalyst → Debate；二幕前半：Break into Two → B Story → Fun and Games → Midpoint；二幕后半：Bad Guys Close In → All Is Lost → Dark Night of the Soul；三幕：Break into Three → Finale → Final Image 与开场对照）。
- **Story Circle 八步**：YOU（舒适区）→ NEED（欲望）→ GO（进入不熟悉处境·不可逆）→ SEARCH（挣扎）→ FIND（得到想要的）→ TAKE（付出代价·圆环底部）→ RETURN（回到熟悉处境）→ CHANGE（已改变）。前四步与后四步互为镜像。
- **McKee 故事原理**：控制性理念（全片一句话主题：[价值]+[原因]）→ 每场景价值必须翻转 → 鸿沟（期望 vs 实际，层层加深）→ 激励事件 → 进展纠葛 → 危机选择（不可逆两难）→ 高潮（选择的行动化）→ 结局（控制性理念被证实或证伪）。
- **内在节拍表**（角色驱动、不靠强情节）：常态与裂缝 → 扰动 → 游走与回避 → 对峙 → 选择或接受 → 余震（结局不是答案是新问题）。可叠"质感"变体：是枝裕和式（日常流·极慢建置）/ 王家卫式（情绪流·因果让位情绪）/ 小津式（静物流·固定低机位·枕镜头）/ Linklater 式（对话流·对话即故事）/ 奉俊昊式（类型杂交·商业骨架 + 社会批判，前后半可换类型）。

**Subplot 交织**：A Plot（主角外在旅程）/ B Plot（一段关系，承载主题论点）/ C Plot（可选，节奏调剂）。A/B 在 Midpoint 交汇，B 线进展映照 A 线，所有线最终服务主角弧光。**伏笔系统**：道具 / 台词 / 行为 / 结构四类伏笔，长片至少 3–5 对，埋下不刻意（首次出现有合理表面理由），每个必须回扣。**暗线**：先定终点再反推暗示密度，每个暗示都有表面含义（第一遍看是表面，第二遍是暗线），长片 1–2 条。**世界观分层**：表层规则（前 30 分展示）→ 运行逻辑（二幕）→ 底层真相（高潮揭示），全靠角色行动和发现，不靠旁白字幕。**次要角色**每个有台词的都要有功能（镜像 / 催化 / 主题 / 节奏），没功能的合并或删。

长片陷阱：二幕松垮（Midpoint 要够强）/ 弧光太线性（至少一次伪变化后回退）/ B Story 脱节 / 高潮只是"更大的打斗"（应是内心选择的外化）/ 世界观一次性倾倒 / 伏笔太刻意 / 全片节奏单调 / 情节情感始终同步（制造错位）。

### 变体 D：多集剧集（连续性 + 预算管理）

单集本身仍用短片 / 长片的结构方法；本变体补**长线管理**——连续性、弧光预算、信息释放、集间节奏。

**连续性四张追踪表**（每写完一集立即更新，开写新集前先查阅；发现冲突优先改新集不改定稿）：① 角色状态（本集结束状态 / 关键变化 / 下集需延续的点）② 暗线进度（当前进度 / 本集推进 / 下次推进在哪集；暗线不能每集都推，否则不"暗"，整季 1–3 条有明确起终点）③ 埋种 / 回调登记（种子 / 埋入集 / 计划回调集 / 已回调？）④ 已公开信息清单（信息 / 公开集 / 谁知道 / 谁不知道）。伏笔密度：每集至少 1 个集内伏笔，每 3 集至少 1 个短程回扣，整季 2–3 个长程伏笔 + 至少 1 个季度伏笔（首两集埋、季终回扣）。

**弧光预算**（规划每集的"变化额度"，防前面变太大后面无处可去）：前 25% 集数累计进度 ≤15%；40%–60% 位置至少 1 次伪变化后回退；65%–85% 是加速区变化量最大；不是每集都要有弧光事件。

**世界观信息释放时间表**：表层规则（前 10–15%，直接展示）→ 表层细节（15–30%）→ 运行逻辑（40–55%，角色调查/发现）→ 逻辑延伸（55–75%，对话中泄露）→ 底层真相（最后 20%，高潮揭示）→ 伏笔回扣（最后 1–2 集）。每层释放前铺垫 1–2 集，同集最多释放一个新层，释放时必须改变观众对已知信息的理解。

**集间节奏**：每集选一个主导情绪（建置 / 轻快 / 紧张 / 呼吸 / 转折 / 压力 / 崩塌 / 至暗 / 反击 / 高潮）。波浪原则：不连续 3 集以上同一基调；紧张 / 压力集后至少 1 集呼吸或轻快；崩塌与至暗可连续（构成低谷）但前后要有对比；呼吸集不是废集，用来深化关系、推进 B Plot。参考模板：前 10% 建置 → 20–30% 第一次紧张 → 30–40% 呼吸 → 40–50% 转折（中段大事件）→ 60–70% 压力 → 75–85% 崩塌 / 至暗 → 85–95% 反击 → 最后 5–10% 高潮 + 落幕。

剧集陷阱：跳过分集大纲直接写单集（必须先拉通全季）/ 为季度弧线牺牲单集精彩度（每集拆出来都要好看）/ 弧光预算失控 / 连续性错误（开写前查表）/ 集末钩子过于强行 / 同时运行的 Subplot 超过 3 条 / 伏笔埋了忘回扣（用登记表逐条审计）。

## 严肃叙事风格（要「克制中爆发」时叠加）

适用于科幻剧、现实主义戏剧、历史题材等需要"克制中的爆发"质感的剧本。核心哲学：**"观众比角色先感受到。"** 不告诉观众角色的情绪，让观众自己先于角色感受到——角色还在压抑时，观众已经替他难过了。这就是张力来源。

**六条铁律：**
1. **永远不写内心活动**——写她做了什么，不写她想了什么。（❌"她想到了母亲。" ✅"她的手在'退伍'两个字上停了一下。"）
2. **永远不解释动作的含义**——动作自己会说话。（❌"她没有回头，因为她知道回头就会留下来。" ✅"她没有回头。"）
3. **用物体代替情感词**——找到情绪的物理载体。（❌"他很愤怒但在压抑。" ✅"他把文件放下。没有摔。"）
4. **让沉默做功**——不解释沉默包含什么。（❌"这段沉默里包含了很多说不出口的话。" ✅"沉默。"）
5. **细节必须具体**——有材质 / 颜色 / 声音 / 气味。（❌"一种食物" ✅"军用压缩营养块，灰色，方形，化学蛋白质的味道"）
6. **结尾必须开放**——不给情绪一个出口。（❌"他意识到，一切都结束了。" ✅"他把灯关了。"）

**对白：** 极简，每句话都在负重；少说，没说出来的比说出来的更重；除非闲聊本身是掩盖，否则不写闲聊；沉默比台词多。拒绝"剧本腔"（❌"我们必须团结，只有在一起才能对抗这一切。" ✅"第一波不是赢。是让他们把主力投进来。"）。信息分层：角色说 A，其实在说 B。

**节奏——情绪延迟（本风格的招牌手法）：** 不在情绪的发生时刻写情绪，写情绪的**后果**。（❌"她听到消息，悲痛欲绝。"｜✅"三天后，她还是把那个联系方式留在手机里，没有删。"）严肃叙事的高潮不是爆炸，是一个细节——最重要的时刻节奏应变慢：用更多空间描写一个动作，让时间在那一刻拉伸，观众此刻才意识到这件事有多重。

**环境：** 每个空间都说明角色的处境或心理，拒绝装饰性描写（美丽的星空、壮观的战场），一个具体的声音 / 气味 / 光线胜过一段全景描写。（❌"战场一片废墟" ✅"有一艘驱逐舰的舰桥还没有完全沉下去，灯还亮着。"）
