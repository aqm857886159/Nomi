# 参考图 Go/No-Go 审图清单

在 Nomi 里，**参考图 = 画布上 visual anchor 节点生成出来的图**（角色定妆图 / 场景设定图 / 关键道具图）。它是后续生成的一致性锚：审核通过就用它当锚生成视频；不合格就调这个 anchor 的生图 prompt 重新生成。

本清单就是这个「审图 Go/No-Go」节点：每张参考图生成出来后，对照清单逐项审查，判定 **Go（锁定为锚）** 还是 **No-Go（调 prompt 重抽）**。用不着追求玄学，逐项打勾即可。

```
画布上的 visual anchor 生成参考图
        │
        ▼
    对照清单逐项审查 · Go / No-Go
        │
    ┌───┴───┐
    ▼       ▼
   Go      No-Go
    │       │
  锁定为    改这个 anchor 的生图 prompt
  锚·用它   （见 §5 反馈模板）→ 重新生成
  生成视频      │
        └───────┘（回到本清单重审）
```

## §1 通用审图清单（每张参考图都过）

> 对照基准：这个 anchor 自己的定妆/定景描述（它的生图 prompt），以及本片统一的色调/光源/画风约定。

### 1.1 角色一致性（identity）— 角色锚

- [ ] **面部特征**：五官比例、眼睛颜色、发色发型、肤色是否符合角色设定？
- [ ] **服装**：主要服装（款式、颜色、材质）是否符合设定？
- [ ] **体型**：身高、肩宽、比例是否符合角色年龄/性别设定？
- [ ] **标志性特征**（如有）：疤痕、纹身、配饰、特殊标记等位置是否正确？
- [ ] **年龄段**：儿童/青年/中年/老年区分是否准确？

**致命问题**（直接 No-Go）：
- 面部明显跑偏（成了别人的脸）
- 年龄段错（把中年画成青年等）

### 1.2 构图 · 景别 · 朝向

- [ ] **景别**：全景/中景/近景/特写与 prompt 一致？（定妆图通常要求全身或半身，能看清整体）
- [ ] **角色朝向 / 姿态**：正面 / 侧脸 3/4 / 中性站姿等与 prompt 一致？（角色锚建议中性站姿，不带剧情动作，便于当锚复用）
- [ ] **画幅 / 分辨率**：符合本片统一规格？
- [ ] **角色占画面比例 / 位置**：与 prompt 描述一致，主体清晰可辨？

### 1.3 光影（按本片统一的光源/配色约定）

- [ ] **主光源方向**：从左/右/顶/底/逆光射入，与 prompt / 本片约定一致？
- [ ] **光色色温**：冷蓝 / 暖橙 / 中性，与本片该场景约定一致？
- [ ] **对比度**：与本片整体风格一致（不过硬也不过平）？
- [ ] **阴影方向**：与主光源方向物理一致（光从左来，右脸就该偏暗）？
- [ ] **光位不过强 / 不穿帮**：定妆图光影不宜过强压过主体；若本片约定单光源，核对无多灯穿帮；若本片本就是多光源/高调布光，则以本片约定为准，**不强加单光源**。

**常见翻车**：
- 光位与本片约定不符（左右脸都是高光、光位不明）
- 光色与 prompt 不符（写了冷蓝却出暖调）
- 阴影方向违背物理（光从左来但右脸也暗）

### 1.4 道具 · 环境 — 场景锚 / 道具锚

- [ ] **空间结构**：场景的主要结构、布局与 prompt 一致？（场景锚建议空场景，不带人物，便于当锚复用）
- [ ] **陈设 / 关键道具**：关键陈设、道具的位置与状态（如屏幕暗屏/亮屏、指示灯颜色）与 prompt 一致？
- [ ] **时间感**：白天/夜晚/黄昏等时间氛围与 prompt 一致？
- [ ] **背景干净**：无多余杂物、无喧宾夺主的元素干扰主体？

### 1.5 跨镜一致性（多张参考图属同一段 / 同一场景时）

对照已锁定的上一张参考图：

- [ ] **场景延续**：同一场景内，墙面/地板/陈设/道具位置是否一致？
- [ ] **光影延续**：主光源色温/位置是否保持？
- [ ] **角色状态延续**：同一时间线内角色服装/状态是否一致？
- [ ] **色调延续**：整体色彩基调是否统一？

### 1.6 AI 常见画崩

- [ ] **手部解剖**：5 指正确？没有多指/少指/畸形/错位？手腕比例正常？
- [ ] **脚部解剖**：5 趾正确（如裸足出镜）？
- [ ] **面部左右对称**：眼睛大小、眉毛位置、嘴角对称（除非 prompt 要求非对称表情）？
- [ ] **眼睛**：瞳孔清晰、眼白不呆滞、反光正常？（特殊瞳孔要求别被误画成恐怖效果）
- [ ] **肢体穿模**：手臂穿过身体 / 腿部交叉异常？
- [ ] **头发物理**：静态图里发型自然，不飘起异常？
- [ ] **文字 / Logo / UI 漏出**：画面是否混入可读文字、品牌 Logo、界面 overlay？

**致命问题**（直接 No-Go）：
- 手指数量不对
- 画面混入可读文字 / 品牌 Logo

## §2 注意事项（必检）

- [ ] 无真人脸识别风险（"神似某真人"）
- [ ] 无品牌 Logo
- [ ] 无真实政治符号 / 敏感宗教符号
- [ ] 画面无可读文字（中文 / 英文 / 符号都算）；屏幕等内容是抽象图形，不是可读数据

---

## §3 Go / No-Go 判定规则

### Go（通过 · 锁定为锚）

同时满足：
- §1 通用清单全部打勾（致命问题零容忍）
- §2 注意事项全部打勾

**Go 之后**：这张参考图就是可用的锚——保留它，后续引用这个 anchor 的镜头直接用它生成视频；它也可作为图生视频的首帧 / 尾帧使用。

### No-Go（不通过 · 调 prompt 重抽）

任一致命问题命中，或累积 3+ 个非致命问题。

**No-Go 之后**：
1. 记录失败的 check 项（哪些没打勾 + 具体描述）。
2. **调这个 anchor 的生图 prompt**（改写描述 / 加负面约束 / 换参考），见 §5。
3. 用新 prompt 重新生成这张参考图。
4. 回到本清单重审。

**重抽技巧**（改 anchor 的生图 prompt，不必大动方案）：
- 手部问题 → 追加 `avoid hand deformation, avoid extra finger count, anatomy correct hands`
- 文字漏出 → 追加 `avoid text, no English, no Chinese, avoid any readable words`
- 多光源（本片本应单光源时）→ 追加 `avoid multi-light studio, single light source only`
- identity 跑偏 → 强化角色描述权重 / 重新给定妆参考 / 换 seed 多抽 1-2 次
- 单个 seed 不行 → 多试几个 seed（连试 1-2 次仍失败，回头改描述本身）

## §5 反馈模板（No-Go 时用）

不合格时，按这个模板把问题讲清楚，据此去改 anchor 的生图 prompt：

```
## 〈参考图·对象名〉No-Go 反馈

**失败的 check 项**：
- §1.1 角色一致性：角色 A 被画成年轻女性，需要中年男性比例
- §1.6 手部解剖：右手 6 指
- §2 注意事项：屏幕上漏出可读英文 "WARNING"

**建议调整方向（改这个 anchor 的生图 prompt）**：
- 加负面约束：avoid female proportions, male character, avoid extra finger count, avoid readable text, no English
- 加强 identity：把角色 A 的外貌关键词写具体、提高权重

**重抽方式**：
- 只改这张图的描述 / 负面词，其余锚与镜头保持不动
- 用新 prompt 在同一个 anchor 上重新生成
```
