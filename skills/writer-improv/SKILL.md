# 即兴生台词

## 这是干嘛的

编剧坐在桌前憋台词，容易憋出「都很客气、不制造冲突、剧情平推」的假对白。**即兴**换一条路：先让角色在设定好的世界里**各揣心事地即兴对戏**，长出真实口语、生活账、错位反应——编剧硬写不出来的活句；再把这堆原料**消化**成可拍的戏。一句话定位：**即兴负责「长出活句」，消化负责「把活句变成戏」**——只即兴不消化＝一堆散戏没法拍；只消化没即兴＝又退回编剧硬憋。

**在 Nomi 创作区**：要写对白、找真实语感、给一场戏注入真实关系张力时用这套。**注意不是让你起多个 agent**——即兴是**创作 AI 自己在一段推演里同时模拟多个角色**，每个角色只知道自己那张卡、看着别人已说的话接戏，谁都不许提前知道剧情该怎么走。**产物分两段**：先即兴出一段**原始转录**（对白矿，约八成是水、两成是金），再把它消化成**可拍的场**——别跳过原料直接写成稿。

---

## 什么场值得跑

不是每场戏都值得即兴。**只挑最吃「群口真实感 / 多角色交锋」的场**：群戏、来访、分工、讨价还价、揭短、讨债这类。独角戏、纯动作、纯抒情场不跑——即兴给不出增量，直接写更快。

---

## 第一段：即兴出原料

**放养即兴会跑偏**（太客气、不制造冲突、剧情平推、世界观漂移）。要的是**引导即兴**——给角色自由演的空间，但有一个「导演 / 世界」层兜着。下面六个要素缺一即退回放养、就会飘。

### 一 · 世界状态（防穿帮）

开跑前先写一份**本场世界状态**，这是所有角色共享的「客观事实底」：

```
时间 / 季节 / 天气：
地点：（谁此刻在哪）
在场角色：
各人持物 / 状态：（老赵夹着酒坛、拖拉机停在地头…）
已发生的硬事实：（会随剧情更新，如「拖拉机被人卸了零件，只剩四个轮胎」）
物理与世界观因果约束：（设定一致性——谁是什么底细、能做什么不能做什么、专有名词白名单）
```

推进时**随时更新这份状态**（拖拉机被卸了零件后，「拖拉机」就从在场物里改成「四个孤零零的轮胎」）。每次让角色接话前以它为准，**防止多轮对戏里穿帮**（人凭空移动、被卸零件的拖拉机又开走了、底细前后不一致）。

### 二 · 人设卡 + 秘密目标（驱动戏剧）

给每个角色**一张卡，且不告诉他剧情走向**：

```
角色：
语言指纹：（口头禅 / 句长 / 方言 / 忌讳——这个人怎么说话）
性格与防御机制：（外向/内敛、遇事是硬刚还是回避、护着什么怕什么）
与在场各人的关系：
🔑 秘密目标（本场他「想要」的、且与他人冲突的一件事）：
   例：老赵＝赊到化肥但别让媳妇知道贷款没还完；老周＝该帮帮但不让对方欠人情心理负担
当前情境（开场那一刻的处境）：
```

**秘密目标是戏剧的引擎**——每人揣着一个互相打架的「想要」，冲突自然从交锋里长出来，而不是靠编剧硬写节拍。设计秘密目标时刻意让它们**价值对立**（谁想要的正好戳到谁的痛处），戏才有张力。

### 三 · 导演视角轮替（替代排死台词）

别预先排死「第几拍谁说」。而是**站在导演视角**看着已滚出来的对话，**逐拍决定下一个该谁说话 / 谁插嘴 / 谁沉默**。判据：

- 谁的秘密目标此刻最受刺激、最想开口；
- 谁被点名 / 被冒犯 / 利益被动；
- 何时该让一个角色**沉默**（沉默也是戏）；
- 何时一拍**多人抢话 / 起哄**（群戏的真实感）。

导演视角只管「轮到谁、给什么刺激」，**不替角色硬塞台词**——轮到谁，就完全站进那个人的秘密目标和语感里让他自己说。

**导演视角还持收口权**（防止多角色循环停不下来）：开跑前定一个**目标拍数**（缺省约 **24 拍**，体量大的群戏可上调到 40 左右）。看着滚动对话，下列任一即收口——

- 到达目标拍数；
- 秘密目标的冲突已交锋出胜负 / 僵局，戏走到自然落点（早于目标拍数也停，不为凑数硬续）；
- 连续 3 拍只在平推闲聊、注入事件也带不起新张力（判定「散场」，止损收口）。

**这是硬约束：必须收口，没有「无人喊停」的开放循环。** 拍数只是缺省上限，**落点优先**。

### 四 · 思考层（出声前先盘算）

每个角色**说出台词前**，先私下过一小段**意图 / 策略 / 潜台词**：

```
〔内心〕我现在想要的是… / 我怕的是… / 这句话我表面说 X、实际是想 Y
```

台词是冰山一角，**水下的动机决定它怎么说**。这一层只用来驱动「这一拍这句话怎么讲」，**它是过程不是产物——收割转录时丢弃，不进最终剧本**。

### 五 · 事件 / 冲突注入（保持张力）

按节点向世界**投放障碍与突发**，逼出反应、防止平推闲聊：物理事件（拖拉机被卸零件、村民群涌、三轮车爆胎）、关系事件（有人揭短、耍赖、来讨债）。注入后**立即回去更新世界状态（要素一）**，让后续对戏在新事实上长。

### 六 · 跨场记忆（写系列才需要）

写连续剧集时，角色要记得上一场发生过什么，否则关系会断片。做法：给每个角色留一小份滚动记忆（谁欠了谁人情、谁的秘密被谁知道了）——开跑新一场时若这个角色有历史记忆，**先并进他的人设卡**（「你上次……」）；跑完把本场对他重要的事实**追加**回去。**单场 / 单集不需要**，只有做系列、要角色跨场连续时才启用。

> 铁律：**只发人设、不发剧情走向**。一旦把「剧情该怎么走」告诉角色，即兴就退化成「念你写好的戏」，失去发生器的价值。

**即兴出的原料存成一段原始转录**：逐拍记 `〔拍 N · 角色〕台词 / 动作`（〔内心〕思考层不入存档）；头部记一句本场世界状态初值 + 在场角色 + 注入的事件清单。这段转录是下一段消化的输入。

---

## 第二段：把原料消化成可拍剧本

即兴转录是**对白矿**，不是剧本——约八成是水、两成是金。按下面五步把「原料变剧本」。

### 第一步 · 剪水

通读转录，删掉不能用的：

- 冷场、跑题、寒暄客套；
- 重复绕圈、信息零增量的拍；
- 角色「出戏」或违背世界观 / 术语的句子；
- 把谁演成了话痨的超长台词（尤其沉稳寡言型角色）。

剪完心里有数：这场转录里**真正的金在哪几拍**。

### 第二步 · 留金

识别并标出**高密度活句 / 神来之笔**——即兴相对编剧硬写的增量全在这里。判据：

- 编剧坐在桌前**憋不出**的真实口语（方言、生活账、错位反应）；
- 把已有梗**接成生活细节**的句子（如「那帮野狗半宿在地里嗷嗷叫唤，把我刚泡的苗踩趴下一片」——把已有梗接成农活账）；
- 一句话**立住人物 / 关系**的（如阿珍「你媳妇看不出来」回扣老赵怕媳妇知道）；
- 温情**用动作 / 玩笑兑现、不抒情**的（「情分换情分，掺钱就生分了」）。

每条金句记下：它**好在哪**、**接哪个已有梗 / 关系**、**适合放本场哪个位置**。

### 第三步 · 上结构

把散金句嵌进戏剧形状——即兴给的是闲聊流，要补：

- **钩子 / 价值转变 / 弧光**：这场的价值从什么转到什么？金句放在转变的哪一拍？
- **节奏**：单峰还是多峰？把金句排进「上升—顶点—收束」，别平铺；
- **保骨换皮**：用即兴的活句**替换**原稿里对应位置的台词皮，**戏的骨架 / 进出场 / 因果链照旧**；
- ⚠️ **不动骨铁律**：招牌梗、回旋镖 / 首尾闭环钩子、已锁原句——**一字不动**。即兴里若跑出「更好」的版本但会打断已锁钩子结构（比如即兴的毒舌版正好撞掉后面的回旋镖），**弃用即兴版、保留已锁原句**。换皮不伤骨；
- **线索归位**：若某金句涉及的剧情线已挪到别处，金句**织到它现在所在的场**，不退回原场。

### 第四步 · 转场景

把择优后的对白改写成**可拍格式**：

- 加画面、动作、镜头提示，台词配动作落地；
- 沉稳角色的语感守住（少话、不话痨）；
- 口语规范但**保留方言味**；标点按成稿规范统一。

### 第五步 · 查术语

收口核对：

- 专有名词对**白名单**，零臆造（专有术语、人名、地名、设定一律不许即兴时新造）；
- 世界观一致性（状态 / 物理因果，对照即兴时那份世界状态）；
- 若冒出**必须先跟用户确认的新词**（新角色名 / 新世界观 / 新专有名词）→ **停下问用户**，不自己拍板。

---

## 织回硬纪律（骨不动、皮才换）

这几条是即兴消化最容易翻车的地方，逐条守住：

- **保结构、换台词皮**：招牌梗、毒舌首发 + 回旋镖钩子、温情纯动作、关键设定——一字不动；
- **即兴更好但打架就弃**：即兴版若与已锁钩子 / 结构冲突，保留已锁原句、弃用即兴版（别为一句活句拆了首尾闭环）；
- **沉稳角色压语感**：即兴偏长的台词压到该角色语感，**不让他变话痨**；
- **线索按现状归位**：金句织到该线索当前所在的场，不退回旧场；
- **多场一起织**：若同时跑了多场即兴，可一次性织回、再一次通读，避免来回多轮。

---

## 边界

- **即兴不出成品**：第一段只产对白矿，结构化织回是第二段的活，别拿转录当剧本交；
- **不臆造**：新角色名 / 世界观 / 专有名词一律不许即兴时新造，命中就停下问用户；
- **不动已锁招牌梗与钩子**：即兴可以重演一场，但招牌梗、回旋镖结构、已锁原句的去留由消化阶段裁决；
- **沉稳寡言型角色**：人设卡里写明语感约束（少话、不话痨），否则即兴容易把谁都演成话痨。
