# 行为心理学编剧工具

在 Nomi 创作区写故事、写剧本、设计角色时用这套方法论。核心一句话：**把心理学理论当工具箱，不当教科书**——每一条都落在「这个角色此刻会怎么做」「观众此刻会怎么想」上，写进故事和剧本，而不是拿来解释角色。角色可信不可信，不看你怎么形容他，看他在压力下的选择是否符合一套稳定的内在逻辑；这套工具就是给角色装上那套逻辑。

---

## 一、角色动机引擎

### 马斯洛需求下坠法

给每个主角定三个需求层次定位点，连起来就是角色弧线：**故事开始时**在哪一层（生理 / 安全 / 归属 / 尊重 / 自我实现）、**最低跌到**哪一层、**故事结束时**回到哪一层。三点走向即弧线类型：上升 / 下降 / V 形 / 倒 V 形。

| 需求层 | 角色状态 | 故事功能 |
|-------|---------|---------|
| 生理 | 活着就好 | 生存故事的底层 |
| 安全 | 需要稳定 | 威胁和危机的根源 |
| 归属 | 需要被接纳 | 关系线的驱动力 |
| 尊重 | 需要被认可 | 权力和地位冲突 |
| 自我实现 | 寻找意义 | 主题层面的追求 |

### 需求 / 欲望对（Truby）

- **欲望**（Desire）= 角色自己知道的外部目标。
- **需求**（Need）= 角色不知道的深层缺陷的解药。
  - 心理需求：克服某个正在伤害自己的弱点。
  - 道德需求：停止伤害他人。

**故事 = 角色追逐欲望的过程中，被迫面对需求。** 欲望推动情节，需求推动弧线——把两者拧成一股，角色越接近欲望越躲不开需求。

## 二、角色心理设计

### 1. 大五人格（OCEAN）

给每个角色在五维上定一个高 / 低倾向，它决定角色在压力下的默认反应：

| 维度 | 高 | 低 |
|------|-----|-----|
| O 开放性 | 好奇、爱创新 | 保守、固执 |
| C 尽责性 | 有序、可靠 | 随性、冲动 |
| E 外向性 | 话多、主动 | 沉默、内向 |
| A 宜人性 | 合作、温和 | 对抗、强硬 |
| N 神经质 | 情绪波动大 | 冷静、稳定 |

定完五维先问一句：**这个角色面对危机时会怎样？** 答案要能从五个倾向推出来。**冲突设计**：把维度相反的角色放一起（高宜人 vs 低宜人、高神经质 vs 低神经质），冲突自己会长出来。

### 2. 依恋类型配对

给角色定一个依恋类型（安全 / 焦虑 / 回避 / 混乱），再定他**被拒绝时的第一反应**（焦虑→追赶、回避→撤退、混乱→崩溃且不可预测）——这个反应模式贯穿全篇。两个角色的依恋类型一配对，关系的戏剧张力就定了调：

| 配对 | 戏剧效果 |
|------|---------|
| 焦虑 + 回避 | 最强推拉张力：一追一逃 |
| 安全 + 焦虑 | 治愈叙事 |
| 回避 + 回避 | 冰冷对峙 |
| 混乱 + 任何 | 高度不可预测 |

### 3. 防御机制

给每个角色指定 1-2 个主要防御机制——受威胁时本能用来自保的心理动作，也是台词底下真正在发生的事。

**不成熟防御**
- 否认：假装没发生。
- 投射：把自己的问题归咎于他人。
- 退行：退回到更幼稚的行为。

**神经质防御**
- 合理化：编造合理理由（话多、逻辑严密，但在回避情感）。
- 反向形成：做与真实感受相反的事。
- 置换：把对 A 的怒气发泄到 B 身上。

**成熟防御**
- 升华：把痛苦转化为创作 / 工作。
- 幽默：用笑化解痛苦。
- 利他：通过帮助他人来处理自己的痛苦。

**用防御机制定义角色弧线**：
- 成长型 = 不成熟防御 → 成熟防御。
- 堕落型 = 成熟防御 → 不成熟防御。

## 三、情境行为设计

这一节不设计「角色是谁」，而是设计「情境怎么逼角色动」。

### 认知失调 — 角色内心撕裂引擎

当角色的信念与行为矛盾时，有三条分叉，各通向不同的故事：

1. **改变信念** = 角色成长。
2. **否认行为** = 悲剧种子 / 自欺。
3. **合理化** = 道德滑坡的开始。

先写清「角色相信什么」和「他做了什么违背这信念的事」，再挑一条解决路径——挑哪条，故事就往哪个方向走。

### 习得性无助 — 角色困境设计

构建一个「笼子」：让角色在**三次独立事件**中失败 → 第四次机会出现时角色不行动 → 需要外部刺激才能打破无助。这套节奏让「他为什么不反抗」变得可信，而非显得角色愚蠢。

### 情境腐蚀 — 环境改变人

**权力 + 消除问责 + 群体压力 = 行为堕落。** 不需要角色「本性邪恶」，好人也会一步步滑下去。分三步写：

1. **小恶**，被忽视或被奖励。
2. **稍大的恶**，理由看似合理。
3. **更大的恶**，已经找不到「停下来」的界线。

每一步都只比上一步大一点——观众跟着角色，不知不觉走到再也回不去的地方。

### 操作性条件反射 — 行为塑形

角色过去被奖励过什么行为，压力下就本能重复什么：

- 因撒谎获益 → 压力下本能撒谎。
- 因暴力解决问题 → 压力下本能暴力。
- **间歇性强化**（时灵时不灵的奖励）= 成瘾叙事的引擎（赌徒、情感依赖者）。

给角色的过去埋一个「他曾经靠什么尝到甜头」，这个甜头会在高压时刻自己冒出来。

## 四、观众心理操控

前三节写角色，这一节写观众——同一批心理机制，掉个方向用在读者身上。

### 认知偏差利用表

| 认知偏差 | 编剧应用 |
|---------|---------|
| **确认偏误** | 角色只看到支持自己判断的证据——观众急得喊「你怎么看不到！」 |
| **沉没成本** | 角色因「已经付出太多」而拒绝放弃错误路线——悲剧的核心机制 |
| **锚定效应** | 先给观众一个初始印象（锚点），后续判断被锚点扭曲——误导 / 反转工具 |
| **基本归因错误** | 角色把别人的行为归因于「品性」而非「情境」——人际冲突的主要来源 |

### 共情建立三步法

想让观众站在某个角色一边，按顺序做三件小事：

1. 让角色做一件观众认同的小事（对服务员说谢谢）。
2. 让角色露一次脆弱（独处时的疲惫）。
3. 给角色一个不公正的遭遇——观众会自动站队。

### 鸿沟驱动（McKee）

每个场景遵循同一个引擎：**角色期望 X → 得到 non-X → 被迫升级行动。** 让这个鸿沟一幕比一幕大：

- 第一幕：「不方便」。
- 第二幕：「危险」。
- 第三幕：「生死攸关」。

鸿沟越拉越大，代价越来越高，张力就这么攒起来。

## 五、非言语信号设计（Paul Ekman）

写到具体场景、台词时，用这一节把「情绪」翻译成能写进剧本的**可观察动作**。原则：不写角色「感觉到什么」，写观众「看到什么」。

### 七种基本情绪的身体信号

| 情绪 | 面部 | 身体 |
|------|------|------|
| **愤怒** | 眉头下压聚拢，嘴唇紧抿 | 身体前倾，拳头握紧 |
| **恐惧** | 眉毛上扬并聚拢，嘴唇水平拉伸 | 身体后缩，肩膀上提 |
| **悲伤** | 眉头内侧上扬，嘴角下拉 | 肩膀下沉，动作变慢 |
| **厌恶** | 上唇上提，鼻子皱起 | 身体后仰，头微侧 |
| **惊讶** | 眉毛全面上扬，下巴下落 | 手部定格在半空 |
| **快乐** | 嘴角上扬，眼角起鱼尾纹 | 身体放松打开 |
| **蔑视** | 单侧嘴角上扬（不对称） | 头后仰，目光从上往下 |

### 微表情泄露写法

角色掩饰时，真实情绪会以微表情闪过。别写「他在说谎」，写观众能看见的那一瞬：

- ❌「他在说谎。」 → ✅「他说『我没事』的时候，嘴角有一瞬间向下抽了一下。」
- ❌「她假装不介意。」 → ✅「她笑着说『当然不介意』，但笑意没有到达眼角。」
- ❌「他讨厌这个人。」 → ✅「他听到这个名字时，鼻翼微微抽动了一下，然后若无其事地继续喝咖啡。」

### 身体语言矛盾法

角色说谎或掩饰时，让**言语和身体互相矛盾**，观众自己就读出了真相：

- 言语说「没事」 + 手在桌下攥紧纸巾 = 观众读出真相。
- 言语说「当然」 + 身体后仰拉开距离 = 观众读出抗拒。
- 言语说「我不在乎」 + 手指无意识触碰那个物件 = 观众读出在乎。

## 什么时候用哪一节

在 Nomi 创作区推进故事 / 剧本，按这个顺序取用：

- **搭角色**（写人物小传 / 角色设定）→ 第一、二节：需求弧线 + OCEAN + 依恋类型 + 防御机制。
- **搭故事骨架 / 设计转折**（写大纲 / 关键情节）→ 第三节：认知失调、情境腐蚀、习得性无助。
- **写具体场景 / 台词**（落到分镜 / 剧本文本）→ 第四、五节：认知偏差、共情三步、微表情与身体语言。
- **回头检查**：任一角色的行为，是否都能从他这套心理档案（OCEAN / 依恋 / 防御）推出来——推不出来的，要么改行为，要么补档案。
