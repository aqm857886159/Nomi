# 镜头语言与摄影技法

这是一份**手艺知识库**：把「导演想让观众感受到什么」翻译成具体的镜头选择，再落成 shot 的 prompt。Nomi 里每个视频 shot 都有一个 `prompt` 字段，在应用内经 Seedance / 可灵等模型直接生成——所以本文所有「翻译成提示词」指的都是**这段 prompt 该怎么写**，不是导出到别处。拆镜头 / 写 prompt 时通读一遍，要某块细节（打光表、运镜情绪表）时回来查对应小节。

## 两条铁律（先记这个）

- **镜头只为叙事和情绪服务，不为炫技。** 运镜只有两个合法理由：叙事（交代空间 / 引导视线 / 传信息）和表达情绪（把角色心理外化）。想不出这个镜头在讲什么、传什么情绪，就说明它错了。
- **不动也是选择。** 运镜的第一招是固定镜头——它让观众关注表演本身，也不破坏精心设计的构图。大部分叙事用「中景 + 平视 + 固定 / 慢推」就够了；特殊镜头是稀缺资源，用在最需要的地方。

## 景别 = 心理距离

景别不是「拍多大」，而是**导演替观众选择的心理距离**：越近＝越亲密 / 越紧张，越远＝越客观 / 越疏离。切换景别＝改变观众与角色的关系。对话默认中景，情绪峰值才上近景 / 特写。

| 景别 | 画面 | 信息功能 | 情绪 | 典型时机 |
|---|---|---|---|---|
| 极远景 | 人几乎不可见，环境主导 | 交代世界观 / 规模 | 敬畏·孤独·史诗 | 开场 / 结尾 / 段落过渡 |
| 远景 | 人可见但环境主导 | 交代空间关系 | 客观·旁观 | 新场景首镜 / 动作交代 |
| 全景 | 人从头到脚完整 | 展示形象 + 肢体语言 | 中性·靠站姿走姿显性格 | 角色出场 / 环境互动 |
| 中景 | 腰部以上 | 对话 / 日常互动 | 亲切但保持距离 | **对话默认景别** |
| 中近景 | 胸部以上 | 表情 + 部分身体 | 开始亲密·关注内心 | 情绪升温 |
| 近景 | 面部充满画面 | 读细微表情 | 亲密·紧张·暴露内心 | 情绪峰值 / 重要台词 |
| 极特写 | 眼 / 唇 / 手指等细节 | 强调关键细节 | 压迫·窥探·不安 | 关键物件 / 决定瞬间 |

**切换节奏**：相邻镜头景别至少跳一级（中景→近景 OK；中景→中近景太近会「跳」）；跳得越大冲击越强（远景→极特写用在高潮）。**景别逐渐收紧＝情绪升温**（把观众拉进内心），**逐渐放开＝情绪释放 / 疏离**（把观众推出喘息）。

## 构图规则

- **三分法**：主体放横纵三等分的交叉点，别放正中——正中构图＝对称 / 庄重 / 仪式感，或压迫（角色直视镜头）。
- **视线空间**：角色朝哪就在哪一侧留空；不留空＝压迫 / 无路可走（可作叙事选择）。
- **头部空间**：头顶留白太多＝渺小孤独，太少＝压迫局促，无＝被「压住」。
- **深度层次**：前 / 中 / 背景三层构纵深。前后都虚＝主体突出（浅景深）；全清晰＝环境重要（深景深）；前景遮挡＝窥探感。
- **对角线**：主体或运动沿对角排列，制造动感与不稳定，武打 / 追逐 / 紧张常用。
- **框中框**：用门框 / 窗 / 柱框住主体，强调孤立 / 被困 / 窥探。

## 运镜的情绪语言

每种运动都有天然情绪倾向。**为某个情绪选运镜，别为运镜找情绪。**

| 运镜 | 情绪 | 速度 / 方向的差别 |
|---|---|---|
| 推（Push In） | 聚焦·紧张升温·进入内心 | 慢推＝渐渐关注；快推＝突然发现 / 震惊 |
| 拉（Pull Out） | 揭示·疏离·结束感·孤独 | 慢拉＝渐渐离开；快拉＝震撼揭示 |
| 横摇（Pan） | 跟随·环顾·交代空间 | 慢摇＝探索；甩镜＝紧急 / 转移注意 |
| 纵摇（Tilt） | — | 上摇＝揭示高度 / 敬畏；下摇＝压迫 / 审视 |
| 环绕（Orbit） | 强调·戏剧化·对峙张力 | 对话高潮 / 做决定 / 英雄时刻 |
| 跟拍（Tracking） | 伴随·沉浸·和角色同行 | 背后跟＝进入未知；侧面跟＝并肩 |
| 升降（Crane） | — | 上升＝希望 / 超越；下降＝压迫 / 沉重 |
| 手持（Handheld） | 真实·紧张·纪录片感·不安 | 追逐 / 恐慌 / 私密时刻 |
| 固定（Static） | 冷静·客观·庄重·压抑 | 审讯 / 对峙 / 被「钉住」 |

**手持三句口诀**：呼吸贴心跳、摇晃随情绪轻重、变焦跟肾上腺素。真正好的运镜让人忘掉运镜——观众沉在故事里，不会想「这运镜好炫」。

## 视觉叙事（机位即立场）

- **机位角度＝谁在讲**：平视＝平等客观；仰拍＝角色有权力（观众仰望）；俯拍＝角色弱小 / 被审视；主观视角＝观众就是角色（最强沉浸）。
- **景别＝权力**：画面里谁大谁主导；权力转移就让景别比例转移（A 变小、B 变大）。
- **运动＝决定**：角色做重大决定时镜头要有反应——推近＝决定的重量，拉远＝决定的后果，定住＝让观众消化。最忌角色做了大决定镜头毫无反应。
- **切入物件＝这东西重要**：切物件特写用来埋伏笔 / 传信息；**切入后必须在后续回收，否则是无效镜头**。

## 走位 → 机位 → 焦点：一条因果链

三者不是独立选择，而是**由叙事意图驱动**的因果链：剧本节拍 → 情绪意图 → 走位（角色怎么动）→ 机位 + 焦点（什么镜头让观众感受到这个情绪）→ 切到下一镜。好编排＝三层同步响应意图；差编排＝三层各自为战，观众不知道该看谁。常见触发：

| 走位事件 | 机位响应 | 焦点响应 | 情绪 |
|---|---|---|---|
| 角色起身 | tilt up 跟随上升 | 锁定面部 | 权力提升·决心 |
| 角色坐下 / 蹲下 | tilt down 跟随 | 锁定面部 | 退让·疲惫·放弃 |
| 角色走近镜头 | 不动让其「入侵」画面 | 景深收浅·背景更虚 | 压迫·威胁 |
| 角色远离镜头 | 不动让其变小 | 景深加深·背景渐清 | 疏远·孤独 |
| 角色转身离开 | 跟走 or 留原地（叙事决策） | 跟＝焦点跟人；留＝焦点转到被留下的人 | 跟＝陪伴；留＝被抛弃 |
| 权力转移 | 仰拍↔俯拍互换 | rack focus 到新主导者 | 形势逆转 |
| 沉默降临 | 定住或极慢推 | 锁定反应者面部 | 张力·等待 |
| 角色做出决定 | 推近 | 锁定瞳孔 | 庄重·不可逆 |

## 摄影技法（提示词里的「摄影师语言」）

AI 不懂 f/1.4、ISO、开尔文值——**必须翻译成视觉效果描述**写进 prompt。

### 打光：一盏主光的九种情绪

以面部为圆心，主光从逆光到顺光再到顶底，形成九种基础光位，各有情绪「人设」：

| 光位 | 面部效果 | 情绪 | prompt 写法 |
|---|---|---|---|
| 纯逆光（正后） | 剪影 + 边缘发光 | 神秘·英雄·高人 / 大反派 | 「逆光勾勒出人物轮廓光边，面部陷入剪影」 |
| 纯侧光（90°） | 明暗各半·阴阳脸 | 对立·双面性·显瘦 | 「侧光将面部劈成明暗两半，鼻梁是分界线」 |
| 伦勃朗光（侧前偏上） | 暗面颧骨下倒三角亮斑 | 质感·古典·戏剧·肖像 | 「光从左上方照来，右脸颊阴影中透出三角形光斑」 |
| 45°侧光（前 45°） | 一侧亮一侧渐变阴影 | 立体·自然·**最常用** | 「光从左前方 45° 照来，面部右侧柔和阴影」 |
| 蝴蝶光（正前微高） | 鼻下蝴蝶形阴影 | 美·优雅·好莱坞黄金年代 | 「光从正前微高照来，鼻下投蝴蝶形阴影，颧骨高光」 |
| 大顺光（正前） | 均匀明亮·几乎无影 | 平淡·安全·梦境入口 | 「正面光均匀照亮面部，阴影极淡」 |
| 顶光（正上） | 眼窝 / 鼻下 / 下巴深影 | 压迫·审讯·教父 | 「顶光垂直照下，眼窝下刻深影，鼻子投长影」 |
| 底光（正下） | 阴影上翻·轮廓扭曲 | 诡异·恐怖·不自然 | 「光从下方照上，阴影向上投射，面部轮廓扭曲」 |

**经典组合光**（主光 + 辅光）：逆光 + 伦勃朗＝有质感的立体感（日常叙事最常用）；侧光 + 顶光＝极度紧张双重压迫（审讯 / 心理崩溃）；逆光 + 移动光＝神秘性感戏剧性（情绪独白）。**光质**：硬光（阴影锐利高对比）＝紧张 / 残酷；柔光（阴影柔和低对比）＝温暖 / 梦幻。**选光逻辑不是「哪个好看」，是「这个场景的情绪需要什么光」。**

场景速配：温馨对话＝柔光 + 暖色 + 45°侧光；审讯对峙＝硬光 + 顶光 + 冷色；英雄时刻＝逆光 + 低角度补光；回忆 / 梦境＝过曝柔光 + 暖色；悬疑恐惧＝单一硬光 + 大面积暗部。

### 景深控制

prompt 里不写光圈，写效果：
- **浅景深**：「浅景深，背景柔和虚化为色块，仅主体面部清晰锐利」——聚焦 / 亲密 / 隔离主体（近景 / 特写 / 情感时刻）。
- **深景深**：「深景深，从前景到背景全部清晰可见」——客观 / 信息量大（建立镜头 / 展示空间）。
- **焦点转移（rack focus）**：「焦点从前景的手（清晰）缓缓转移到背景的人脸（从模糊变清晰）」——注意力引导 / 揭示；写明起止对象和方向（模型可靠度中等）。
- **前景虚化**：「前景铁栏杆虚化为模糊竖条纹，透过间隙看到远处清晰的角色」——窥探 / 层次感。

### 色温与光源

不写开尔文值，写具体光源和颜色：烛光 / 壁炉＝极暖私密；钨丝灯泡＝暖黄怀旧；黄昏阳光＝金色温暖珍贵；正午阳光＝中性白无处躲藏；阴天散射＝冷白灰沉闷；日光灯管＝冷白偏绿制度化 / 廉价；月光＝冷蓝银孤独；霓虹＝城市赛博；屏幕光＝冷蓝深夜孤独。**混合色温＝冲突感**：如「左侧窗外冷蓝月光 + 右侧桌上暖黄台灯同时照脸，一冷一暖」＝内外两个世界。

### 焦距的叙事

不同焦距改变空间感与心理距离：广角（24–35mm 效果）＝空间夸大、前景变大、纵深拉长（开阔 / 近距离时压迫）；标准（50mm）＝接近人眼、自然真实；中长焦（85mm）＝轻压缩、浅景深、人像柔美（亲密 / 电影感）；长焦（200mm+）＝空间严重压缩、前后景挤扁（窥探 / 疏离 / 窒息）；鱼眼＝极度畸变（不安 / 超现实 / 监控）；微距＝极近放大细节（聚焦 / 不寻常视角）。**同样大小的近景，长焦让角色被环境「夹住」有窒息感，广角让角色突出、鼻子夸大有攻击性。**

### 曝光

欠曝 / 低调＝神秘 / 压抑 / 危险（「大面积阴影中只有少量光线」）；过曝 / 高调＝梦幻 / 回忆 / 纯净（「亮部溢出，一切笼罩白色柔光」）；剪影＝匿名 / 史诗 / 象征（「逆光将人物变为纯黑剪影，仅边缘一圈光边」）。

## 给运镜注入灵魂（三个控制器）

这三样不是某种运镜类型，而是给**任何**运镜加戏的维度：

- **加速度曲线**：匀速＝冷静观察；ease-in（缓起）＝渐渐关注 / 进入回忆；ease-out（缓停）＝观察后的定格；爆发-骤停＝震惊 / 觉醒。写法：「以 ease-out 推近面部——起始迅速，最后 0.5 秒缓缓停在瞳孔收缩的瞬间」。
- **镜头 × 角色动作的对位**：同步（镜头跟着角色）最安全也最平庸；**对位**（角色前进、镜头后退）＝揭示性；**错位**（角色先动、镜头延迟 0.3s）＝真实的反应时间；**反向**（角色转左、镜头转右）＝失衡 / 命运反向。
- **呼吸感收束**：真实手持不是持续抖——「开头 2 秒强震颤，中段稳定在动态平衡，最后 3 秒余震平稳收束」。

## 经典复合镜头（速查）

每种都是走位 + 机位 + 焦点的固定组合；理解「三层为什么这样配」比记名字重要：

- **过肩（OTS）**：前景 A 肩 / 后脑虚焦占 20–30%，焦点在面向镜头的 B。A 肩占比越大越压迫（审讯用「紧迫 OTS」占 35–40%）。
- **正反打**：不是单镜是**剪辑模式**——两个 OTS 交替。守 180° 轴线（A 始终在画面同一侧）。切换越快越紧张（争吵每条 1.5–3s）。Nomi 里正 / 反各出一个 shot，靠一致性要点保住位置与光线。
- **希区柯克变焦（dolly zoom）**：机位后退同时焦距拉近，主体大小不变而背景急剧膨胀＝眩晕 / 恐惧。模型很难直接做，退而拆两条（正常近景 + 同角度但背景空间感不同）后期过渡。
- **鸟瞰 / 虫瞰**：正上方垂直向下＝命运 / 渺小 / 上帝视角；贴地向上仰＝权力 / 威压 / 敬畏。写明「top-down aerial view / 俯拍鸟瞰」「low angle from ground level looking up」，可靠度高。
- **建场镜头**：新场景第一镜，远景 + 深景深交代「我们在哪」。**联动规则**：建场后下一镜必须收紧至少两级景别。可靠度最高。
- **插入镜头**：切到细节物件 / 局部动作特写（关键道具 / 颤抖的手 / 走动的钟）。极浅景深聚焦、周围全虚。可靠度最高（静物 / 局部是模型强项）。切入必回收。
- **反应镜头**：不拍事件、拍看到事件的脸——「不拍爆炸，拍看到爆炸的脸」更有力。微表情模型偏弱，**必须配一个明显辅助动作**（咽口水 / 眨眼 / 深吸气）。
- **倒影 / 镜面**：通过镜 / 水 / 玻璃拍角色映像＝自我审视 / 双面性；破碎倒影＝身份崩塌。简单镜面可靠，破碎 / 多重易翻车。
- **分屏**：不在单条里做，分别生成各区内容后期合成。

## 沉浸式：FPV / POV 要点

FPV 写好＝最强沉浸，写不好＝晕眩无意义素材。关键几条：
- **开头第一句就锁定绑定位置**（眼睛 / 头顶 / 胸前 / 侧颈 / 脚边 / 武器），别让模型猜。「FPV 贴身视角，镜头绑定在角色侧颈，耳廓与肩甲持续占画面左上角」＞「第一人称追着角色跑」（后者会给第三人称跟拍）。
- **近距碎片构图**：主体**不要完整展示**，只给近距碎片（手肘 / 发梢 / 爪尖 / 车轮边缘）贴镜头边缘占 10–30%——快速运动中的完整主体最易变形断肢。
- **抖动必须绑节奏源**（脚步 / 心跳 / 呼吸 / 撞击），别只写「手持抖动」（会得到像 bug 的高频随机抖）。
- **motion parallax**：近物高速放大掠过、中距中速滑动、远景几乎不动＝真实速度感。
- **速度节奏切换**：单条内 1–2 次（超高速推进 → 爆点 → 120fps 慢动作看清细节 → 恢复）。
- **德式斜角**：整个机位倾斜、地平线不平（3–8° 不安 / 10–20° 失控 / 25°+ 崩溃），写明「向右倾斜约 15 度」。

## 转场（后期为主，但要在 prompt 层预埋）

转场是叙事工具不是酷炫效果——**没有好坏，只有合不合适**。Nomi 每条素材独立生成，转场基本在后期完成，但**相似 / 遮挡**两类高级转场要在两条 shot 的首尾帧预埋对应元素：
- **硬切**＝默认，对话正反打 / 高潮碎切都用它。
- **叠化**＝时间流逝 / 意象叠加（新老角色叠化＝传承）。
- **淡入淡出**＝段落开合；闪白＝回忆 / 梦境入口，闪黑＝突发 / 喘息。
- **相似转场**（后一镜与前一镜有相似动作 / 形状 / 运镜 / 色彩）：在两条 shot 里设计对应的首尾帧元素匹配，让切换自然。
- **遮挡转场**（角色 / 甩镜 / 门框遮断视线瞬间换场）：前一条尾帧贴近遮挡物、后一条首帧从遮挡中展开——伪装「一镜到底」的关键。
- **声音先行 / 延迟（J-Cut / L-Cut）**：下一场声音提前进 / 上一场声音延续，后期做，极大提升流畅度。

## 别点模型做不到的事（能力边界）

写 prompt 前先知道边界——**点它做不到的会让成片更差**：

- **擅长（放心写）**：匀速推 / 拉、横摇 / 纵摇（最稳）；跟拍、FPV 贴地推进、指定节奏源的手持震颤、德式斜角、Whip Pan（可靠）。
- **容易翻车（改结构绕过，别指望重抽）**：360° 完整环绕（背面时身份漂移→用 180° 半环绕 + 切镜）；垂直螺旋（拆成推 + 升两段）；推 + 摇 + 环绕三连（单条内 ≤2 种运镜）；「镜头穿门进入另一空间」（穿越瞬间易闪烁→改用门框遮挡缝合）；跨 180° 轴线（插中性镜头过渡）。
- **单条 15s 运镜变化上限**：对话 / 独白 ≤1 次；一般场景 ≤2 次；动作 / 武打 3–5 次（每段 2–3s）；>5 次拆多条。
- **精确文字必乱码**（招牌字 / UI / 书法）：字幕片名一律后期叠，**prompt 不写要渲染的文字**。口型对白同步弱：用侧脸 / 画外 / 不露正脸 + 后期配音。

> 这些边界随模型迭代会变——写「XX 做不到」前，先确认当前接入的模型是不是真做不到。

## 落进 shot 的 prompt 时

- **图片 shot / 首帧图**：只写静态画面——构图 / 景别 / 光线 / 姿态表情 / 环境氛围；**别写运镜、动作演进、转场、台词字幕**（图片模型不认还污染画面）。
- **视频 shot**：写运镜 → 动作演进 → 节奏 / 时长感；不复述锚（角色 / 场景）的静态外貌（那由参考图 / 文本锚负责）。
- **物理化情绪，别写抽象词**：AI 演不出「愤怒地 / 深情地」，翻成可拍的身体信号——眉 / 颌 / 喉 / 手 / 肩 / 呼吸 / 视线焦点 + 具体动作。「望向 / 背对」写成身体朝向 + 头部方向 + 眼睛焦点。
- **忠于剧本，不发明**：天气 / 光线 / 服装 / 陈设剧本写了才写；可用景别 / 运镜 / 构图增强画面，但别新增剧情性的视觉事实。
- **守时空连续性**：闪回 / 今昔 / 转行别串身份（三年前医院里是医生、现在便利店里就不是了，别把白大褂错带过来）。跨镜别换脸 / 换景——同角色 / 场景 ≥2 镜靠一致性锚承接，prompt 里不重描外貌；场内状态延续（一旦出现血 / 伤 / 湿身，后续同场镜头继承直到剧本清除）。
