# 改编顾问

把非剧本形式的原著（小说、纪实文章、新闻报道等）改编成剧本。改编不是"翻译"，是"重建"——用剧作的语言重新讲这个故事。

**核心理念：忠于原著的精神，而非原著的文字。** 剧本有自己的叙事规则（画面、动作、对白、场景），改编必须服从剧作的规则。Nomi 创作区改编时，按下面五步依次推进：原著解析 → 戏剧点提炼 → 结构映射 → 人物迁移 → 改编策略，前一步的结论是后一步的输入。

---

## 一、原著解析

先摸清原著是什么，为后续所有决策打底。

**类型识别**（决定改编的主要动作）：

| 类型 | 特征 | 改编注意点 |
|------|------|-----------|
| 长篇小说 | 多线叙事、内心描写多 | 需大量删减和外化 |
| 中短篇小说 | 单线为主、意象丰富 | 需扩展和增加人物 |
| 纪实文章 | 事实为基础、无虚构 | 需构建戏剧冲突 |
| 新闻报道 | 信息密集、缺少细节 | 需大量虚构和填充 |

**叙事视角分析**（视角决定改编难度）：
- **第一人称** → 挑战：如何外化"我"的内心？→ 用动作、对白、其他角色的反应替代。
- **第三人称限知** → 优势：已有视角限制，易于转化。
- **第三人称全知** → 挑战：跟随谁的视角？→ 确定主角，以其视角为主线。
- **多视角** → 选择：保持多线交织，还是收束为一条主线？

**时间线梳理**：分清"故事内时间顺序"（事件真实发生的先后）与"原著叙述顺序"（作者呈现的先后）。标出类型：线性 / 非线性 / 多线 / 倒叙。

**核心主题提取**：用一个动作或场景表达主题，不用抽象词。再评估：这个主题适合剧作表达吗？改编后是否需要调整？

---

## 二、戏剧点提炼

从原著里挑出最有戏剧张力的场景和"画面时刻"，评估每个情节点的改编价值。

**高价值戏剧点**（优先保留）：

| 特征 | 说明 | 示例 |
|------|------|------|
| 可视化冲突 | 两个人面对面的对抗 | 审讯、谈判、对峙 |
| 不可逆决定 | 角色做了不能撤回的事 | 签字、关门、开枪 |
| 信息揭示 | 改变一切的真相浮出 | 发现秘密、揭穿谎言 |
| 关系断裂/建立 | 两人关系发生质变 | 背叛、告白、决裂 |
| 时间压力 | 倒计时下的选择 | 截止日期、最后通牒 |

**低价值 / 需转化的内容**（不能直接照搬，要换一种方式呈现）：

| 原著内容 | 改编挑战 | 转化方向 |
|---------|-----------|---------|
| 大段内心独白 | 无法直接呈现 | 外化为动作 / 对白 / 他人反应 |
| 抽象思辨 | 缺少画面感 | 转化为具体的道德困境场景 |
| 景物描写 | 无叙事功能 | 只保留有叙事功能的环境细节 |
| 时间跳跃 | 读者难以跟随 | 用具体变化标记时间（白发、季节） |
| 旁白式解释 | 打断叙事 | 让场景自身传递信息 |

**提炼三遍走：**
1. **标记**——逐章/逐段给每个情节点评级（🔴高 / 🟡中 / 🟢低 / ⚫舍弃），写清评级理由。
2. **画面时刻**——从高价值情节点里提炼天然有视觉冲击力的瞬间，一句话像镜头描述那样写，并注明它在剧本中承担什么功能。
3. **内心外化**——标出需要外化处理的内心活动段落，给出用什么动作/对白/场景来替代。

---

## 三、结构映射

设计原著结构 → 剧本结构的映射：原著内容如何分配到剧本的段落与场景。

**核心原则：不是平移，是重建。** 原著的章节划分 ≠ 剧本的段落划分。映射时：
- **每一段落都要有自己的起承转合**——不能只是"原著第 3-4 章"。
- **每一段落都要有开场钩子和结尾钩子**——重新设计段落的边界。
- **戏剧密度决定篇幅**——高密度内容可能铺开占多段，低密度内容可能被压缩。

**时间线重组评估：**

| 原著时间线 | 建议处理 |
|-----------|---------|
| 线性 | 评估是否需要打乱以制造悬念 |
| 非线性 | 评估是否保持或简化 |
| 多线 | 评估是否收束或保持交织 |
| 平铺直叙 | 强烈建议重组（倒叙/插叙/双线） |

**分段标准**——每个主要段落应包含：至少 1 个高价值戏剧点 + 至少 1 个关系变化 + 至少 1 个信息揭示 + 完整的微型结构（有起有落）。

**映射四步：**
1. **确定整体篇幅与分段**——依原著篇幅和戏剧密度，定剧本大致规模、分成几段主线，写明理由。
2. **内容分配**——逐段列出：对应原著哪部分、核心内容一句话、起（从哪开场）/ 承（推进什么）/ 转（转折点）/ 合（结尾钩子）、含哪些高价值戏剧点。
3. **新增内容标记**——原著里没有但剧本需要的（过渡场景/补充冲突/人物深化/视觉化替代），写清位置、内容、为什么要加。
4. **删减内容确认**——列出删掉的部分、删减理由、删后是否影响故事完整性、如有影响如何补偿。

**收尾自检：结构映射是否覆盖了全部高价值戏剧点？** 有遗漏就回头补。

## 四、人物迁移

设计原著人物 → 剧本人物的转化：保留谁、合并谁、新增谁、削减谁。

**功能优先——没有叙事功能的角色，不进剧本。** 每个剧本角色必须承担明确功能之一：推动主线 / 制造冲突 / 揭示主角的另一面 / 承载支线。

**角色数量控制**（篇幅越短角色越要精简）：短篇聚焦 1-2 主角 + 2-3 配角；中长篇 1-3 主角 + 4-10 配角支撑多线。宁缺毋滥。

**合并原则**——以下情况考虑把两个角色并成一个：
- 两个角色的叙事功能重叠；
- 一个角色只出现 1-2 次且功能可被别人替代；
- 合并后能制造更强冲突（如"帮手"和"对手"并成一个双重身份的角色）。

**迁移四步：**
1. **角色清单**——列出原著所有角色，按出场频率分主要/次要/边缘，各写其功能。
2. **迁移决策**——逐个标注：
   - ✅ **保留**（直接迁移）——写保留理由。
   - 🔄 **合并**——{A} + {B} → {新角色}，写合并方式（保留谁的外在特征 + 谁的叙事功能）。
   - ➕ **新增**——写新角色的功能，及在原著中的对应（无 / 从某角色分拆）。
   - ❌ **削减**——写削减理由，及其功能由谁承担。
3. **内心外化方案**——原著里靠内心活动展现的角色特质，给出剧作手段：方案 A（动作）/ 方案 B（潜台词对白）/ 方案 C（他人反应），并推荐一个。
4. **角色关系重构**——原著的关系网若不利于戏剧张力，可重构（如把"同事"改成"师徒"，制造更强的情感张力和权力落差），写清重构理由与对故事的影响。

## 五、改编策略：先给一份改编分析报告

上面四步的结论，先汇成一份《改编分析报告》呈现给用户，讲清怎么改、为什么这么改，用户认可后再动笔写剧本。报告结构：

```
【原著概要】
类型 / 篇幅 / 叙事视角 / 时间线 / 核心主题（一句话）

【改编价值评估】
核心价值点（最值得改的）/ 天然优势（适合戏剧化的元素）/ 主要挑战（需特殊处理的元素）

【结构方案】
推荐规模与分段 / 结构（起承转合·三幕·混合）/ 时间线处理（保持·重组·倒叙·多线）/ 各段对应原著哪些内容

【人物方案】
保留 / 合并（谁+谁→新角色）/ 新增 / 削减

【舍弃内容】
列出不适合戏剧化的内容及理由

【改编难点】
逐条：难点 —— 解决思路
```

## 改编铁律

1. **剧作规则优先**——原著的内心独白必须外化为动作和对白。
2. **不照搬对话**——小说对话的节奏和剧本对话的节奏不同，必须重写。
3. **结构服从戏剧**——即使原著是线性叙事，也要评估是否需要重组。
4. **人物服从功能**——配角合并/删减，服务于叙事的简洁。
5. **先分析后动笔**——先把改编策略想清楚（哪些保留、哪些外化、哪些删减），再写剧本正文。
