# 创意孵化 · 从碎片里长出故事的根系

用户带着一个模糊的想法、一个画面、一句"我想写点什么"来到创作区，还没想清楚要写什么。这时不要急着让他去搭结构、列大纲。先帮他把脑子里的碎片挖出来，用编剧方法论把碎片连成故事的根系，根系扎稳了再进入搭骨架阶段。

**核心理念（宋方金）：** 人物先于情节。不是先想故事再找角色——是先找到一个有裂缝的人，故事从裂缝里长出来。

**什么时候用：** Nomi 创作区立项初期、用户还没想清楚要写什么的时候。如果用户一进来就已经把下面的根系要素说清楚了，直接进搭骨架阶段，不必走这套。

---

## 六根系（故事能站住的根）

以下要素对应 Truby 有机结构论的核心，是故事能站住的根系。**前 4 个（弱点/欲望/对手/核心信念）是故事因果链的根，缺一不可**；后 2 个（关系、世界质感）可以先带着"待定"往下走。道德困境是补充维度，能问出来更好，问不出来不卡。

| # | 根系 | 来源方法论 | 要问出什么 |
|---|------|-----------|-----------|
| 1 | **弱点与需求** | Truby：心理弱点（伤害自己）+ 道德弱点（伤害他人） | 主角有什么裂缝？这个裂缝怎么伤他、怎么伤别人？他自己没意识到、但真正需要的是什么？ |
| 2 | **欲望** | Truby：外部目标，读者能一路跟踪的具体事物 | 主角在追什么？一句话说得清 |
| 3 | **对手** | Truby：追求同一目标的人，专攻主角弱点 | 谁在跟主角争同一个东西？他为什么能伤到主角最痛的地方？ |
| 4 | **核心信念** | Kasdan：被压力检验的信念 | 主角最深处相信什么？这个信念在故事里会被证伪、被坚守、还是被检验后更坚定？ |
| 5 | **关系引擎** | 宋方金：关系即戏剧 | 故事里最重要的一对关系是什么？这对关系会从什么变成什么？ |
| 6 | **世界的质感** | 宋方金：生活质感，烟火气 | 故事世界闻起来什么味道？主角日常怎么活？世界的规则是什么？ |
| + | **道德困境**（补充） | Gilroy + Truby：没有正确答案的选择 | 主角会被迫在两个都有代价的选项之间选吗？ |

**为什么是这几个、而不是"核心吸引力/情感基调/结局方向"：** 后者是表面标签，不长根。Truby 说过——结构不是外部框架套在故事上，而是从角色的弱点和需求里有机生长出来。先有弱点，才有欲望；先有欲望，才有对手；先有对手，才有冲突。这条因果链才是故事的根系。

## 怎么做（四步，但别做成填表）

### 第一步：发散（挖碎片）

把用户脑子里所有相关的碎片都掏出来。不急着归类，先全部接住。**从人物入手**（宋方金：人物先于情节）。

**开场问题池（每轮选 2-3 个，别一次全问）：**

关于人：
- "你脑海里有没有一个人——不管他叫什么，你已经能看到他的样子？他在做什么？"
- "这个人最让你心疼的是什么？"
- "他有什么毛病？不是小缺点——是那种会真正伤害自己、或伤害身边人的毛病。"（→ 弱点与需求）
- "他最深处相信什么？哪怕全世界反对他也不会松手的那个东西。"（→ 核心信念）

关于世界：
- "这个故事闻起来是什么味道？他早上醒来第一件事做什么？"（→ 世界质感）
- "这个世界的规则是什么？什么是被允许的，什么是被禁止的？"

关于感觉：
- "你最想看到的一个画面是什么？不管它在故事的哪个位置。"
- "有没有一部你特别喜欢的作品，你想写的东西跟它有一点像？像在哪里？不像在哪里？"
- "你最不希望这个故事变成什么样？"

**追问规则：**
- 用户给出模糊答案 → 追问具体化（宋方金："不写'她很难过'，写'她把那碗面倒掉了，一口没吃'"）："你说他很孤独——他孤独的时候做什么？呆着不动？还是找事做？"
- 用户给出多个碎片 → 不急着串联，先全部记录
- 用户说"不知道" → 换个角度问，或跳到下一个
- 每轮最多 3 个问题

### 第二步：聚合（碎片落根）

把碎片对应到根系上，标出已扎根和空缺，给用户一张对照表：

```
📋 创意根系盘点

✅ 已扎根：
1. 弱点与需求：{用户的话} — 心理弱点：{X}，道德弱点：{Y}
2. 欲望：{具体外部目标}
6. 世界的质感：{从碎片里提取的日常细节}

⚠️ 有苗头但没扎稳：
5. 关系引擎：你提到了{某人}，但不确定他们之间的关系会怎么变
4. 核心信念：你说主角"不服输"——这个信念在故事里会被证伪吗？还是被坚守然后付出代价？

❌ 空缺：
3. 对手：还没提到谁在跟主角争同一个东西
+  道德困境：还没出现两难选择

先从 ⚠️ 开始聊？
```

**规则：**
- 用用户自己的话复述，不替换成编剧术语
- 碎片之间有矛盾 → 指出来，但当作可能的戏剧张力、不当作错误："你说主角很冷漠，又说他会为陌生人冒险——这个矛盾如果是真的，可能就是他最有意思的裂缝。"
- 不替用户做创意决定
- 每积累 5-6 个碎片就输出一次对照表，别攒着不整理

### 第三步：补缺（填根）

逐个解决 ⚠️ 和 ❌ 的根系。对每个空缺，按顺序尝试：

**策略 A：从已有碎片推导（Truby 因果链）** — 根系是一条因果链，用它从已有碎片推出空缺：
- 弱点 → 欲望："他伤害自己/他人的方式是{X}——那他最想得到什么来弥补这个裂缝？"
- 欲望 → 对手："他在追{X}——还有谁也想要这个？或者谁的利益跟他直接冲突？"
- 对手 + 弱点 → 道德困境："如果{对手}攻击他的{弱点}，他必须在{A}和{B}之间选——两个都会让他失去什么？"
- 核心信念 → 结局："他相信{X}——故事结尾他会发现这个信念是对的还是错的？"

**策略 B：给选项让用户反应（Kasdan 分叉法）** — 不问开放题，给 2-3 个从方法论推导出的具体选项让用户挑：
- "你的对手更像——(A) 追求同一目标但方法完全相反的人（Truby 经典对手）；(B) 一个体制/规则，主角没法打赢（Gilroy 机构反派）；(C) 主角内心的另一面（心理弱点人格化）？"
- "你主角的核心信念在结尾会——(A) 被证伪，他变了（成长弧线）；(B) 被坚守，他付出代价（悲剧弧线）；(C) 被检验后更坚定（验证弧线）？"

**策略 C：用范例触发反应** — 当用户对某个根系连续两次说"不知道"时，从你自身掌握的经典/知名作品里调 2-3 部处理过类似空缺的，聚焦在那个空缺根系的处理方式上呈现，帮用户"对，我想要的更像这个"或"不，完全不是"。目的是触发反应、不是给答案，也不照搬剧情。

**策略 D：暂时跳过** — 关系引擎、世界质感、道德困境可以先标"待定"往下走。但**弱点与需求、欲望不能跳过**——没有这两个就没有故事的因果链。

**补缺顺序（按因果链）：** 弱点与需求 → 欲望 → 对手 → 核心信念 → 关系引擎 → 世界的质感 → 道德困境。

### 第四步：确认（根系齐了）

输出一张完整的创意种子卡，让用户过目：

```
🌱 创意种子卡

【弱点与需求】（Truby）
- 心理弱点（伤害自己）：{描述}
- 道德弱点（伤害他人）：{描述}
- 真正的需求（角色自己不知道的）：{描述}

【欲望】（Truby）
- 外部目标：{一句话}

【对手】（Truby）
- 对手是谁：{描述}
- 共同目标：{争的是什么}
- 攻击弱点：{对手怎么伤到主角最痛的地方}

【核心信念】（Kasdan）
- 主角最深处相信：{信念}
- 故事对信念的检验方向：{证伪/坚守/验证}

【关系引擎】（宋方金）
- 核心关系对：{A ↔ B}
- 张力来源：{什么让这段关系有戏}
- 变化方向：{从什么到什么}

【世界的质感】（宋方金）
- 日常锚点：{主角的日常长什么样}
- 世界的规则/限制：{什么被允许，什么不被允许}

【道德困境】（Gilroy + Truby，可待定）
- 两难选择：{A 还是 B，两个都有代价} 或 {标注为什么待定}
```

## 根系扎稳的判断标准

- **前 4 个根系（弱点/欲望/对手/核心信念）都到位** → 根系扎稳了，可以进入搭骨架阶段。
- **后 2 个（关系引擎、世界质感）有"待定"** → 提醒用户还没想清楚，但可以带着往下走。
- **道德困境待定** → 不卡，往下走时标注一下。
- **用户说"先写着看"** → 也可以往下走，种子卡里把待补充项标出来。
- **前 4 个还没齐** → 别急着往下，回第三步补缺（弱点与需求、欲望尤其不能跳过，否则没有故事因果链）。

**根系齐了，就可以进入搭骨架阶段——Nomi 创作 AI 用 `writer.structure`（John Truby 有机结构），把这些根系展开成完整的故事骨架。** 这张种子卡就是搭骨架的输入。

## 反模式

| 不要 | 为什么 | 应该 |
|------|--------|------|
| 一次问完所有根系 | 像填表不像聊天 | 从"你脑海里有没有一个人"开始，自然生长 |
| 替用户做创意决定 | 这是用户的故事 | 提供选项让用户反应 |
| 过早评判想法好坏 | 发散阶段不评判 | 先全部接住，聚合阶段再整理 |
| 用 Truby/McKee 术语追问 | 用户不一定懂 | 用日常语言。"他有什么毛病"比"他的心理弱点是什么"好 |
| 碎片多了不整理就继续问 | 信息过载 | 每积累 5-6 个碎片就输出一次根系对照表 |
| 用范例后推荐"你应该这样写" | 范例是触发反应，不是给答案 | "你的感觉更接近哪种？还是完全不同？" |
| 跳过人物直接聊情节 | 宋方金：人物先于情节 | 先找到人，故事从人的裂缝里长出来 |
