接入 Claude Code、Codex、Cursor

接入是一次性的：在 Nomi 里点一下，Nomi 把自己那一条写进助手的 MCP 配置，重启助手后生效。开始之前确认 Nomi 正开着，并且助手已经装在这台电脑上。

先找到入口

Section titled “先找到入口”

  1. 点 Nomi 顶栏右上的齿轮打开设置，选「自动化与权限」。

  2. 在「AI 助手连接（MCP）」那一行点「管理连接」。

  3. 卡片顶部的切换条里，只会出现这台电脑上检测到的助手。点你要接的那个。

注意

卡片里一个助手都没有时，说明 Nomi 没在这台电脑上检测到 Claude Code、Claude Desktop、Codex、Cursor 或 WorkBuddy。装好其中一个再回来，或者直接用最下面的「其他客户端」通用配置。

Claude Code

Section titled “Claude Code”
  1. 在切换条里选 Claude Code，点「一键接入 Claude Code」。
  2. Nomi 会把 nomi 这一条合并进 ~/.claude.json，其他 MCP 服务器保持原样，改写之前留一份备份。
  3. 看到「已写入 Claude Code 配置」后，重启 Claude Code。
  4. 重启后对它说一句话，比如卡片上给的那句示例。

Codex

Section titled “Codex”
  1. 在切换条里选 Codex，点「一键接入 Codex」。
  2. Nomi 会把 nomi 这一条写进 ~/.codex/config.toml，其他配置不动。
  3. 重启 Codex。

Cursor

Section titled “Cursor”
  1. 在切换条里选 Cursor，点「一键接入 Cursor」。Nomi 写的是 ~/.cursor/mcp.json。
  2. 重启 Cursor。Cursor 第一次调用 Nomi 时，可能会再向你确认一次，这是 Cursor 自己的审批，Nomi 不会代你批准。
  3. Cursor 默认不是「可信发起方」：卡片里「允许 Cursor 自动发起制作」是关着的，所以它先只能发起草稿、查看状态。想让它直接发起制作，再自己打开这个开关。

注意

Claude Desktop 和 WorkBuddy 在同一张卡里，步骤和上面一样：选它、点「一键接入」、重启它。

想撤销

Section titled “想撤销”

在同一张卡里，选中那个助手，点「撤销接入」。

警告

改配置之后一定要重启助手，没重启之前它读到的还是旧配置。
