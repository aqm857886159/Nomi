认识 Nomi：它做什么，从哪开始

你手上通常已经有点东西：一段故事，一份脚本，或者几张想参考的画面。Nomi 要做的，是把它们一路带到一条排好时间轴、能导出 MP4 的视频，每一步的东西都留在你电脑上的一个文件夹里。

上图是「生成」页，带编号的位置是：

  1. 顶栏的三步：创作、生成、预览。
  2. 左栏：文稿、目录、素材、流程。
  3. 画布底部的工具条：加图片、视频、声音、文字、剪辑，或导入文件。
  4. 右下角的 Agent 小球，点一下展开对话面板。
  5. 底部的时间轴条，展开后就是预览页里那条时间轴。

三步各做什么

Section titled “三步各做什么”
步骤 你在这里做什么 做完你会得到什么
创作 写故事、脚本、文案；也可以让 Agent 帮你写、改、拆成分镜 一份文稿
生成 在画布上放图片、视频节点，用连线把参考接到下一个节点，生成 画布上一个个有画面的节点
预览 把出好的镜头排到时间轴上，检查节奏，加字幕和配乐，导出 一个 MP4 文件

谁负责什么

Section titled “谁负责什么”
你 Agent 画布
想法和取舍 决定拍什么、留哪一版 帮你把想法拆成镜头、改文稿
动手做 随时可以自己改任何节点 在每一步旁边的面板里替你操作：创作页读你的文稿，生成页看画布、排生成，预览页读时间轴 把结果摆出来，看得见，也随时能改
花钱的生成 你来点头 三档都一样：提交之前停下来，让你确认

Agent 面板右下角有三档，决定它多久来问你一次改动（花钱的生成三档都会先问）：

档位 它怎么做
每步问 改动、生成、计划都先问
自动改 文稿和时间轴的改动直接做（回执可以撤销），生成之前仍然会问
全自动 可撤销的改动直接做，不再逐次问；不可逆的操作仍然每次问；花钱之前也会停下来问你

新手建议先用默认的「自动改」。

东西存在哪

Section titled “东西存在哪”

一个项目就是你硬盘上的一个文件夹：画布、分镜、时间轴在里面的 .nomi/project.json，生成的图和视频在 assets/ 下，导出的成片在 exports/ 下。

你需要先准备什么

Section titled “你需要先准备什么”

Nomi 本身不带模型。第一次用时，项目库顶部会提示「创作助手尚未连接模型」，点「连接模型」，按下一页的步骤接一个模型供应商，才能生成。

做完这一页你应该知道

顶栏三步各是什么；Agent 面板的三档里，默认那一档会在哪一刻停下来问你；项目文件夹里哪里放成片。
