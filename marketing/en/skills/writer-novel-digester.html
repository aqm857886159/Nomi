Novel analysis

Analyze source structure, dialogue and scenes for adaptation.

Nomi 创作区要改编一本原著、或想从某本小说取养分喂给正在写的故事时，用这套方法把原文拆成可直接引用的技术分析——不是读后感，是按编剧方法论标准拆出来的结构 / 对白 / 场景 / 叙事技法素材。

核心理念： 读原著不为复述剧情，为偷技法。每读一段都问「这一步作者是怎么做到的、我能怎么用」。产出五类分析，写故事/剧本时对着它偷。

分层读取原则： 长篇不必一次读完。先骨架扫描全书（每块只提一句话 + 结构功能），标出值得精读的段落；再回头只精读那些段落。省注意力、也省 token。

一、四位方法论坐标（拆解时用哪把尺）

四家各管一个维度，拆一段原文时叠着用：

方法论 管什么 拆解时问的问题
Truby（22 步） 结构骨架 这一步对应 22 步的哪一步？弱点/需求/欲望/对手怎么咬合？
McKee（价值转变） 场景的情感力学 进入时是什么价值状态 → 离开时变成什么？转变的层级（矛盾/相反/否定之否定）？
Mamet（台词即动作） 对白 每句台词的「动作」是什么？角色想得到什么？策略怎么升级？
Gilroy / Kasdan（潜台词与克制） 叙事与对白的深层 表层说什么 vs 深层说什么？作者藏了什么信息、什么时候揭？

二、消化流程（三层，由粗到精）

第一层：骨架扫描（覆盖全书）

按章节/段落逐块读，每块只提一行，掌握全书结构、标出精读点：

章节/段落号 | 一句话概括 | 结构功能 | 值得精读？ | 原因

结构功能从这里选：

  • 开场锚定 / 日常世界建置
  • 激励事件 / 第一转折
  • 上升动作 / 冲突升级
  • 中点反转
  • 危机 / 至暗时刻
  • 高潮
  • 新常态 / 尾声
  • 支线（B/C Plot）
  • 呼吸段落

标「值得精读」的标准：

  • 对白密度高且质量好的段落
  • 沉默 / 无对白却承载重情感的段落
  • 结构关键转折（激励事件、中点、高潮）
  • 与手头这个故事某个场景有直接对标价值的段落
  • 叙事手法特别的段落（时间跳切、视角切换、物件叙事等）

这一层的产出只是内部骨架表，用来指导第二层，不必落成正式输出。

第二层：定向精读（只读标记段落）

回到标记的段落逐个精读，按四个维度提取素材：

A. 结构素材

  • 这段对应 Truby 22 步的哪一步？
  • McKee 价值转变：进入什么价值状态 → 离开什么状态？层级？
  • 鸿沟：角色行动的期望结果 vs 实际结果？
  • 这个转折怎么准备的（伏笔/铺垫埋在哪里）？

B. 对白素材

  • 完整引用原文对白（保留上下文动作描写）
  • Mamet 动作链：每句台词的「动作」是什么 → 策略怎么升级
  • Kasdan 潜台词：表层含义 vs 深层含义，潜台词是什么
  • 语言指纹：遮住名字能猜出谁说的吗？靠什么猜
  • 沉默分析：段落里若有关键沉默，它承载了什么

C. 场景素材

  • 判定场景类型（对照下面 7 类）：
    • confrontation 对峙 / silence_breakdown 沉默崩溃 / silent 无言场景 / death 死亡 / reunion 重逢 / ghost_flashback 幽灵闪回 / ensemble_unseen 群像暗场
  • 若现有 7 类不覆盖，单独标注为新类型
  • 按类型抽结构：confrontation 按「对峙双方 / 价值观 A vs B / 反转结构」；silence/death 等按「情感承载与节奏」

D. 叙事技法素材

  • 物件叙事：哪些物件承载了情感/主题？怎么做到的？
  • 节奏控制：这段快慢节奏怎么设计的？
  • 视角选择：为什么用这个视角？换一个会怎样？
  • 信息控制：作者在这段藏了什么？什么时候揭示的？
  • 时间处理：有没有时间跳切、闪回、压缩/膨胀？

第三层：合成输出

把第二层素材合成为下面五类标准化分析。

三、输出模板（五类）

结构拆解

  • 抬头：作者 / 类型 / 篇幅 + 一句话核心（这本书用一句话说是什么）。
  • Truby 22 步映射表：步骤 | 书中对应 | 位置（章节） | 执行质量评注。
  • McKee 价值主轴：全书核心价值转变，从 {A} → {B}（层级：矛盾 / 相反 / 否定之否定）。
  • 关键转折清单表：转折点 | 位置 | 价值转变 | 鸿沟（期望 vs 实际）——至少列激励事件 / 中点反转 / 高潮。
  • 伏笔 / 回扣登记表：伏笔 | 埋入位置 | 回扣位置 | 回扣方式。

对白范例

每段一个条目，按质量排序、最好的在前：

  • 位置：第 X 章 / 上下文一句话。对白类型：对峙 / 试探 / 告别 / 沉默交锋 / 信息博弈…
  • 原文：完整引用，保留上下文动作描写。
  • 分析四点：Mamet 动作链（每句的动作 → 策略怎么升级）｜ Kasdan 潜台词（表层 → 深层）｜ 语言指纹（遮住名字怎么猜出谁说的）｜ 沉默（若有，承载了什么）。
  • 取材启示：这段技法能用在手头故事的哪里、怎么用。

场景范例

按上方 7 个场景类型归类，新类型单列。每个场景抽：

  • 位置 / 对峙双方 / 价值观 A vs B（非对峙类改抽情感承载与节奏）。
  • 结构：开场状态 → 中段反转 → 收场。
  • 学什么：3 条可迁移的做法。

叙事技法

五个维度各一节，每节先给全书模式、再给最好的一处范例：

  • 物件叙事表：物件 | 出现位置 | 承载的情感/主题 | 手法。
  • 节奏控制：全书节奏模式 + 最好的快慢切换段落。
  • 视角策略：全书视角选择 + 视角切换的关键时刻。
  • 信息控制：最好的信息隐藏 / 揭示。
  • 时间处理：时间跳切 / 闪回 / 压缩膨胀的使用。
  • 沉默设计：全书最好的沉默时刻。

本剧对标映射

写故事/剧本时最直接的一张表——把原著技法逐项映射到手头作品的对应位置。四张对标表：

  • 结构对标：本书段落 | 技法 | → 本剧位置 | 可以怎么用
  • 对白对标：本书对白 | 技法 | → 本剧角色/场景 | 可以怎么用
  • 叙事技法对标：技法 | 本书怎么用的 | → 本剧怎么用
  • 场景类型对标：场景类型 | 本书范例 | → 本剧对应位置

四、特殊情况

理论类作品（如《千面英雄》）： 跳过对白与场景提取，改为——结构拆解写核心理论框架 + 引用的神话/故事原文；叙事技法写理论中的叙事原则；对标映射写理论框架与本剧的映射。

超长作品（超 15 万字）： 第一层骨架扫描仍覆盖全本；第二层精读控制在 10–15 段以内，优先精读对当前创作阶段最有用的段落。

多卷作品（如《基地》系列、《三体》三部曲）： 每卷单独消化、各出五类分析，最后再做一份跨卷汇总。

在 Nomi 创作区怎么用

  • 要改编一本原著时 — 先跑第一层骨架扫描，用「结构拆解」把全书的 Truby 骨架 + 关键转折摸清，作为改编大纲的地基；再对着「场景范例」挑最值得保留/放大的场景。
  • 手头故事卡在某处时 — 找一本同类型强作，只精读与你卡点对标的段落，用「本剧对标映射」把它的技法直接落到你的对应场景/角色上。
  • 想给对白提质时 — 精读原著对白范例，看 Mamet 动作链与 Kasdan 潜台词怎么运作，把语言指纹和策略升级的做法搬到自己角色身上（与 writer.dialogue 配合用）。
  • 想学叙事技法时 — 只读「叙事技法」维度，把物件叙事、信息控制、时间处理、沉默设计当成可复用的工具箱，写新场景时点着用。

First launch on macOS

The current macOS build is not Apple Developer ID signed or notarized. Only use download links on this site or in the official Nomi GitHub repository.

  1. Download the matching DMG and drag Nomi to Applications.
  2. In Finder, right-click Nomi in Applications, choose Open, then confirm Open.
  3. If it is still blocked, open System Settings → Privacy & Security, find Nomi, and click Open Anyway.

Only if macOS says Nomi is “damaged”: confirm the installer came from an official link above, then open Terminal and run:

xattr -dr com.apple.quarantine "/Applications/Nomi.app"

You do not need to disable Gatekeeper globally, and should not do so.
