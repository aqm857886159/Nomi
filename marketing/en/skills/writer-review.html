Nomi 创作区写完一份剧本后，回头用这套「导演视角」自审。审的是文字剧本本身——不是画面、不是视频提示词。

导演视角关注的不是「写了什么」，而是「观众会看到什么、感受到什么」。剧本是蓝图，这套方法审查这个蓝图能否被有效转化为视听体验：读起来通顺、但一旦要落到画面/舞台上就立不住、拍不出的地方，正是要揪出来的。

审的时候按下面六个维度逐条过；每个维度给了「怎么审」和「常见问题」。发现问题就带具体场景号记下来（见文末输出格式），供回改。

一、视觉叙事审查

审什么： 每个场景描述能否在脑海里形成清晰画面。

怎么审：

  • 有没有具体的视觉锚点——不是泛泛的「一个房间」，而是有细节的空间。
  • 关键时刻有没有视觉焦点——观众的目光被引向哪里。
  • 有没有用画面传递信息——而不是全靠对白解释。

分三层看画面是否成立：

层次 检查点 示例
前景 角色的动作和表情是否具体 「她把杯子转了半圈」 vs 「她很紧张」
中景 人物之间的空间关系是否有意义 两人之间放着一张桌子 = 距离感
背景 环境是否参与叙事 窗外的雨 ≠ 装饰，= 情绪底色

常见问题：

  • 场景描述只有对白，缺少视觉元素。
  • 关键情绪时刻没有视觉承载，全靠人物「说」出来。
  • 环境描写是装饰性的，不参与叙事。

二、节奏把控审查

审什么： 整份剧本有没有清晰的节奏变化——高张力之后有呼吸点让观众消化，再建立新的张力，推向高潮，而不是一条直线。

节奏要素逐个看：

要素 检查点
加速 短句、快速切换、动作密集——是否用在正确的位置？
减速 长描述、沉默、细节特写——是否给了观众呼吸空间？
停顿 关键信息后是否有停顿让观众消化？
对比 安静场景后是否跟高张力场景？反之亦然？

常见节奏病症：

  • 全程高压：没有呼吸点，观众疲劳。
  • 全程平淡：没有张力峰值，观众走神。
  • 错位高潮：高潮放在了错误的位置。
  • 拖沓收尾：高潮之后还堆了大量内容。

三、镜头语言审查

审什么： 剧本不该写导演说明，但好的剧本会暗示镜头语言——字里行间让人「看得到」该怎么拍。

好的写法暗示了镜头，对照看：

写法 暗示的镜头
「整个车间只有她一个人」 大全景 → 孤独感
「她的手指在桌面上敲了两下」 特写 → 紧张/等待
「他走过长长的走廊」 跟拍/推轨 → 压迫感
「两人隔着桌子对视」 正反打 → 对峙感
「窗外的城市灯火」 空镜 → 转场/情绪过渡

怎么审：

  • 关键情绪时刻是否有适合特写的细节描写。
  • 空间转换是否自然——不是突然跳到新场景。
  • 是否有可以作为空镜/转场的视觉元素。

四、空间调度审查

审什么： 人物在空间中的位置，反映的是权力关系和心理状态。审剧本里的走位/站位是否在替叙事说话。

空间元素怎么读：

空间元素 叙事含义
谁坐谁站 权力高低
谁先动 谁更急切/弱势
两人距离 关系远近
谁占据中心位置 谁主导场景
谁靠近出口 谁想逃离

怎么审：

  • 空间描述是否暗示了人物关系，而不是随手交代方位。
  • 人物的移动是否有目的——不是随意走动。
  • 空间变化是否反映情节发展。

五、情绪曲线审查

审什么： 好的剧本有清晰的情绪曲线——不是直线上升或直线下降，而是有起伏的波形：开场建立基调 → 中段有转折 → 高潮是情绪最强点 → 结尾留有余味。

怎么审：

  • 开场是否建立了情绪基调。
  • 是否有至少一次情绪转折——从正到负或从负到正。
  • 高潮时刻是否是全篇情绪最强的点。
  • 结尾是否留有余味——不是情绪归零。

常见情绪病症：

  • 情绪平线：全篇情绪没有变化。
  • 情绪断裂：相邻场景情绪跳跃过大，中间没有过渡。
  • 高潮提前：最强情绪出现在中段，后面无法超越。
  • 情绪泄漏：高潮后用对白把情绪解释了一遍，消解掉积累的力量。

六、视听语言武器库

审的时候用来对照：关键场景是否暗示了有效的视听手法？ 也可以在回改时从里面选。不是要求每种都用——用得对、用得克制才是好。

镜头语言类：

手法 效果 适合场景
一镜到底 真实感、沉浸感、时间不可逆 需要「在场感」的段落
固定机位时间流逝 变与不变的对比 时间跨度大的段落（一个空间的四季更替）
连续推轨/Dolly 空间的揭示，不断发现新信息 空间本身承载信息（从豪宅推到贫民窟）
第一人称 POV 极端代入感，限制信息 视角置换、「身临其境」的段落
微距/显微镜头 熟悉事物变陌生 尺度跳跃、质感特写

剪辑/时间类：

手法 效果 适合场景
跳切蒙太奇 时间压缩、重复的荒诞感 「日复一日」、快速推演后果
分屏 对比、并置、平行时间线 双线并置、对比两个空间
交叉剪辑 对比加速、张力累积 两条看似无关的线最终关联
倒放 熟悉动作变陌生、因果倒置 时间操作、循环结构
定格 强制注意、悬念标点 翻转瞬间、关键细节强调

画面构成类：

手法 效果 适合场景
对称构图 秩序感、仪式感、压迫感 制度化、规则化的场景
前景/背景双层叙事 同一画面内两层信息 不分屏但需要并置的段落
色彩限制 视觉「规则感」，颜色成为叙事元素 颜色与概念有直接关联时

声音类：

手法 效果 适合场景
画面与声音错位 两层信息碰撞、讽刺反差 画面平和+声音灾难，或反之
环境音放大 日常变得不安、异常 需要「日常中的恐怖感」的段落
静默 迫使注意力集中、真空感 高密度信息流后突然安静——沉默即高潮

界面/媒介类：

手法 效果 适合场景
屏幕录制 极致当代感、偷窥感 聊天记录、搜索、通知驱动的段落
伪纪录片 真实外壳包裹荒诞内核 需要「严肃」的壳来反衬的段落
数据可视化 冷静数字背后的巨大悲剧 用「客观感」制造反差

对照检查：

  • 关键场景是否暗示了适当的视听手法？
  • 视听手法是否与内容匹配——形式是否强化了内容？
  • 同一种手法是否过度使用（全篇同一种炫技就不再特别）？
  • 是否有至少一处视听手法的「递进」或「打破」（从固定变移动、从彩色变黑白）？

审查输出

自审完，按这个格式把发现落成可回改的备注，都带上具体场景号：

【导演视角自审】

视觉叙事：
- {场景号}：{评价 + 改进建议}

节奏把控：
- 整体节奏：{快/慢/有变化/单调}
- 问题位置：{场景号} — {问题描述}

镜头语言：
- {场景号}：{是否暗示了镜头 / 缺什么}

空间调度：
- {场景号}：{空间安排的叙事效果评价}

情绪曲线：
- 曲线走向：{描述}
- 问题位置：{场景号} — {情绪处理问题}

First launch on macOS

The current macOS build is not Apple Developer ID signed or notarized. Only use download links on this site or in the official Nomi GitHub repository.

  1. Download the matching DMG and drag Nomi to Applications.
  2. In Finder, right-click Nomi in Applications, choose Open, then confirm Open.
  3. If it is still blocked, open System Settings → Privacy & Security, find Nomi, and click Open Anyway.

Only if macOS says Nomi is “damaged”: confirm the installer came from an official link above, then open Terminal and run:

xattr -dr com.apple.quarantine "/Applications/Nomi.app"

You do not need to disable Gatekeeper globally, and should not do so.
