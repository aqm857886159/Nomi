Character-led writing

Build grounded drama from character relationships and everyday life.

以宋方金（《手机》《给青年编剧的信》）为方法论蓝本。他是中国编剧行业最系统的方法论输出者之一。在 Nomi 创作区写故事/写剧本时参考这套方法——尤其中式现实题材。

核心理念： 故事是人物的历险。情节是人物性格在特定情境下的自然产物，不是外部设计。编剧首先是手艺人。

写剧本时把下面这些当作创作底线：先立人、再生情节；每句台词有功能；场景有烟火气；关系是发动机。

一、十条创作铁律

写每一场、每一句对白前，都拿这十条对照一遍。

1. 人物先于情节

一切从人物出发。情节是人物性格的必然产物，不是外部强加的设计。

❌ 先想一个精彩的情节，再找角色来执行
✅ 先建立角色的性格和欲望，让情节从角色的选择中生长出来

2. 对白零废话

每句台词必须有功能——推进情节、揭示性格、制造冲突，三者至少占其一。

❌ "你好啊，最近怎么样？""还行吧，就那样。"
✅ 删掉。从有功能的第一句话开始。

3. 对白有辨识度

不同人物的说话方式必须可区分。摘掉名字也能知道是谁说的。

4. 潜台词优先

人物少说心里话，多用行动和侧面表达。说的和想的不一样——这才是戏。

5. 生活质感

场景要有烟火气，物件要有生活感。不写悬浮于现实之上的空中楼阁。

❌ "他吃了一口食物"
✅ "他把军用压缩营养块掰成四块，灰色粉末掉在金属桌面上"

6. 关系即戏剧

人物关系网络是故事的核心引擎。中国故事的核心不是个人英雄，是人与人之间的关系——家庭、师徒、战友、对手。

7. 每场有转变

角色在场景入口和出口的状态必须不同。进入时的关系、信息、情绪状态 ≠ 离开时。

8. 取神舍形

改编找精神内核，不做表面复制。用影视思维重新解构原著。

9. 立场鲜明

创作者对故事世界要有态度。回避立场的剧本是空洞的。

10. 反对悬浮

紧贴现实。即使是科幻，人物的情感逻辑和行为模式也必须来自真实的人性。

二、人物塑造法

人物要有"根"

每个人物要有其成长背景、核心创伤、行为逻辑的根源：

{角色名} 人物根源
成长背景：{具体的成长环境、家庭、教育}
核心创伤：{什么经历塑造了他现在的行为模式}
行为逻辑：{他为什么这样做而不是那样做}
信念来源：{他的核心信念从何而来}

人物要有矛盾

好人不全好，坏人不全坏。人物内部要有撕裂感：

{角色名} 内部矛盾
他相信的：{核心信念}
他做的：{实际行为，与信念有落差}
撕裂点：{信念和行为发生冲突的时刻}

反对"工具人"

每个出场人物都应该有自己的生活和欲望，不仅仅为主角服务：

检查：这个角色如果没有主角存在，他/她自己的生活是什么？
如果答不上来 → 这是个工具人 → 需要重新设计

三、"戏眼"概念

每场戏要有一个"戏眼" — 核心戏剧焦点。戏眼是这场戏存在的理由。围绕戏眼展开，不要分散注意力。

场景戏眼设计
戏眼：{一句话描述这场戏的核心焦点}
所有对白和动作是否围绕戏眼？{是/否}
如果有偏离戏眼的内容 → 删掉或移到其他场景

四、关系网络设计

宋方金强调人物关系本身就是故事的发动机。设计一个故事时，先把关系网络画清楚，再往里填情节。

关系网络

核心关系对：
1. {A} ↔ {B} — 关系性质：{师徒 / 战友 / 对手 / …}
   张力来源：{什么让这段关系有戏}
   变化轨迹：{从什么到什么}

2. {A} ↔ {C} — …

关系三角：
{A}-{B}-{C} 之间的三角关系是否存在？
→ {描述三方互动的张力来源}

检查：每对核心关系，从头到尾是否至少有一次不可逆的变化？

五、节奏的呼吸感

紧张与松弛必须交替。不能一味高潮。

✅ 紧张场景 → 呼吸场景 → 更紧张场景 → 呼吸场景 → 高潮
❌ 紧张 → 紧张 → 更紧张 → 更更紧张 → 观众疲劳

呼吸场景不是废场景 — 呼吸场景用来：

  • 展示人物的生活质感（吃什么、住哪里、怎么打发时间）
  • 巩固人物关系（不是推进冲突，是让观众喜欢这些人）
  • 埋伏笔（轻触即过的细节，后面有回响）

六、"桥段思维"警告

不要从精彩桥段出发倒推故事。 要从人物和主题出发生长故事。

❌ "我想到了一个超酷的反转！让我编一个故事来放这个反转。"
✅ "这个角色在这种压力下，他的性格决定了他会做出这个选择——而这个选择恰好是一个反转。"

用法小结

在 Nomi 创作区写故事/写剧本时：

  1. 先立人 — 用「人物塑造法」给主要角色建"根"和内部矛盾，反"工具人"。
  2. 画关系 — 关系网络先于情节；关系是发动机。
  3. 写场景 — 每场先定"戏眼"，守住"每场有转变"，注意节奏呼吸感。
  4. 抠对白 — 零废话、有辨识度、潜台词优先。
  5. 全程 — 十条铁律作为创作底线检查，反悬浮、反桥段思维。

First launch on macOS

The current macOS build is not Apple Developer ID signed or notarized. Only use download links on this site or in the official Nomi GitHub repository.

  1. Download the matching DMG and drag Nomi to Applications.
  2. In Finder, right-click Nomi in Applications, choose Open, then confirm Open.
  3. If it is still blocked, open System Settings → Privacy & Security, find Nomi, and click Open Anyway.

Only if macOS says Nomi is “damaged”: confirm the installer came from an official link above, then open Terminal and run:

xattr -dr com.apple.quarantine "/Applications/Nomi.app"
