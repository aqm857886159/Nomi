快速上手

从下载， 到第一个镜头。

四步。唯一要准备的是一个模型供应商的 Key——没有的话，第二步告诉你去哪拿。

  1. 下载安装

    下载对应你电脑的安装包

    安装包暂时没有做签名，第一次打开系统会拦一下，照下面做就行。

    v0.23.1

    macOS：在「应用程序」里右键 Nomi →「打开」。Windows：提示风险时点「更多信息 → 仍要运行」。

  2. 接模型

    接一个模型，贴一个 Key

    打开「设置 → 模型」，选 APIMart 或 Kie.ai，贴上在它们官网拿到的 Key，常用的图片、视频、对话模型就都能用了。也可以接你自己的中转站或本地 ComfyUI；不想自己弄，点「用 AI 帮我接入」交给 Claude Code 或 Codex。

  3. 跟 Agent 说

    说你想拍什么

    新建项目，在右边的 Agent 面板里用大白话说：拍什么、几个镜头、大概多长。建议先用默认的「自动改」档：它改文稿和时间轴不打扰你，要花钱生成时先让你确认。

  4. 挑片导出

    挑满意的版本，排好，导出

    不满意的镜头在分镜表里改提示词、换模型、再生成一版；角色要统一就锁一张参考卡。排好时间轴，导出 MP4。

卡住了看这里

接了模型，却生成不了

看模型框里这个模型有没有标「不可用」和原因：多半是 Key 没贴对，或者这一家还没给你开通这个模型。换一家能接的，或按提示去供应商后台开通。

每个镜头的脸都不一样

检查镜头有没有连上角色参考卡。没连，模型就不知道是谁；连上后重新生成那几个镜头。

Agent 做到一半停了

长任务中途它会停下来让你确认，尤其是要花钱的时候。看一眼它问的是什么，回一句「继续」就行。

常见问题

要花多少钱？

Nomi 本身免费。生成的费用按你接的那家供应商的价格，直接由你和它结算；接免费模型（比如魔搭社区的部分模型）或本地 ComfyUI 就不花钱。

没有独立显卡能用吗？

能。默认走云端 API，普通笔记本就够。本地 ComfyUI 是可选的，想省钱、有显卡再接。

我的素材会被上传吗？

项目都存在你自己的电脑上。只有在调用外部模型时，才把完成这一次生成必需的内容发给你配置的那家供应商。

Agent 能直接给我出成片吗？

它能从一句话做到人物、关键帧、视频，再排进时间轴；最后一步导出目前要你自己点一下。长任务中途它可能会停下来确认，回一句「继续」就行。

macOS 第一次打开

当前 macOS 安装包未使用 Apple Developer ID 签名，也未经过 Apple 公证。请只使用本页或 Nomi GitHub 官方仓库的下载链接。

  1. 下载对应的 DMG，把 Nomi 拖到“应用程序”。
  2. 在 Finder 的“应用程序”中右键 Nomi，选择“打开”，再确认“打开”。
  3. 如果仍被拦截，打开“系统设置” → “隐私与安全”，找到 Nomi 后点击“仍要打开”。

仅当 macOS 提示 Nomi“已损坏”时：先确认安装包来自上述官方链接，再打开“终端”运行：

xattr -dr com.apple.quarantine "/Applications/Nomi.app"

不需要、也不要全局关闭 Gatekeeper。
