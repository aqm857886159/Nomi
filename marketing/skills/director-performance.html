表演指导

非武打文戏的表演指导——微表情/肢体语言/视线设计/沉默表演/角色行为模式。AI 不会自己「演」，情绪必须在 prompt 里精确物理化成可拍的身体信号（眉/眼/嘴/手/肩/呼吸/停顿）。Nomi 写文戏 shot 的 prompt 时参考，让画面演得出「情绪」而不是只写情绪词。

  • 适用：文字
  • 许可证：AGPL-3.0-only

写文戏 shot 的 prompt 时用这套方法论。核心一句话：AI 不会「演戏」——你不能写「她很难过」然后指望 Seedance / 可灵生成一个悲伤的表演。你必须写可观察的物理动作：「她的嘴角向下压了一点，眼睛看着杯子但没聚焦，右手手指在桌面上无意识敲了两下」。

表演 = 可观察的物理动作。情绪是观众从动作里读出来的，不是写进 prompt 的。 这条和 director.shot.translation 的「污染词铁律」（抽象情绪词 = AI 演不出的污染）呼应；那边讲「哪些词不能写进 prompt」，这里讲表演本身怎么拆成可拍的身体信号。

铁律：不写情绪词，只写动作

情绪词（AI 演不出） 外化成 prompt 里的动作
她很紧张 她的拇指反复摩挲食指侧面
他很愤怒 他的下颌肌肉绷紧，太阳穴青筋微微跳动
她很悲伤 她低头，眼睛盯着桌面一个点，眨眼变慢
他很开心 他嘴角上扬，但只扬了一侧，眼睛微微眯起
她犹豫 她的手伸向门把手，停在半空，手指张了又合
他恐惧 他瞳孔扩大，肩膀微微收拢，后退半步但脚还没完全离地

写 prompt 时直接用右列这种外化描述。左列这类抽象词一个都别进 prompt 字段。

微表情 → 物理信号对照

微表情 = 持续不超过 0.5 秒的面部变化。观众可能没意识到看见了什么，但会「感觉到」。写 prompt 时从下表挑具体动作，别写「面露X色」。

面部区域 动作 传达
眉毛 内侧上扬 担忧、同情
眉毛 整体下压 愤怒、专注
眉毛 单侧挑起 怀疑、不屑
眼睛 瞳孔扩大 恐惧、惊讶、兴趣
眼睛 眯起 怀疑、开心、光线刺激
眼睛 视线下移 羞耻、回避、思考
眼睛 视线固定不动 震惊、决心、威胁
眼睛 眨眼加速 紧张、不安
眼睛 眨眼减慢 悲伤、疲惫、放空
嘴 嘴角下压 不满、悲伤
嘴 嘴唇抿紧 克制、忍耐
嘴 微微张开 惊讶、准备说话又没说
嘴 咬下唇 紧张、犹豫
下颌 绷紧 愤怒、决心
下颌 松弛 放松、放弃
鼻翼 微微扩张 愤怒、深呼吸

AI 生成里的微表情约束：当前 i2v 模型能生成明显表情（微笑、皱眉），但纯微表情（瞳孔变化、嘴角 1 毫米下压）可靠度低。所以：① 写微表情时配一个更明显的辅助动作（「她抿紧嘴唇，同时视线移开」）；② 微表情只在近景 / 特写才有效，中景远景里几乎无效——需要微表演的 shot，构图就往特写靠。

肢体语言

手部——最诚实的表演者

手很难被有意识地控制，是最细腻的情绪指标。

手部动作 传达
握拳 愤怒、紧张、克制
搓手 / 揉指 焦虑、不安
手指敲桌面 不耐烦、思考
双手交叉抱胸前 防御、封闭
手插口袋 隐藏、不参与
抚摸物件（杯子 / 手机） 寻求安慰、转移注意力
手掌向上摊开 坦诚、无奈
指向 攻击性、指控
手轻触嘴唇 犹豫要不要说
手指绞在一起 极度紧张

⚠️ 手部特写易生多指 / 畸形；非必要不给手部特写，需要时提示词里可加负面词排除「多余的手指」。

身体姿态——权力与安全感

姿态 传达
挺直坐 / 站 自信、警觉、正式
前倾 关注、进攻、兴趣
后仰 评估、放松、优越感
缩肩 不安全、防御、畏缩
扩肩 自信、威胁、占据空间
侧身 回避、不想正面面对
转身 拒绝、结束对话
靠墙 / 靠门框 旁观、不完全参与、随时准备离开

距离——关系的物理化

距离 关系含义
< 0.5 米 亲密或威胁
0.5–1 米 信任或对峙
1–2 米 社交距离
> 2 米 疏远或正式

距离变化 = 关系变化：角色走近 = 关系拉近（或压迫加大）；角色退开 = 关系疏远（或解除威胁）。多镜文戏里，两人间距在镜与镜之间的收放，本身就是叙事。

视线设计

视线 = 注意力方向 = 观众了解「角色在想什么」的最重要线索。写 prompt 时把「注视 / 望向 / 背对」翻成头部方向 + 眼睛焦点这种可拍的描述。

视线行为 含义
直视对方眼睛 自信、诚实、挑战、亲密
看对方但避开眼睛（看鼻 / 嘴 / 额） 不完全坦诚
视线偏移 / 移开 回避、说谎、羞耻、思考
视线下移 服从、悲伤、反思
视线上移 回忆、思考、不屑
视线固定在某物上 那个物件对角色有意义
视线穿过对方（看远方） 放空、失去连接、已做出决定
频繁转移视线 不安、寻找出路

视线与对话的配合：说话时看对方 = 传递信息；说话时不看对方 = 对自己说 / 回避；听时看对方 = 在接收；听时不看对方 = 在想自己的事。

沉默表演

沉默不是「什么都没发生」，是「所有事都在发生但没说出来」。一个没有台词的文戏 shot，prompt 里必须给足身体信号，否则 AI 会生成一张呆滞的静止脸。

沉默中该有什么（挑 1–2 个写进 prompt）：

  • 呼吸变化（加深 / 屏住 / 叹气，肩胸起伏）
  • 视线移动（看什么、不看什么）
  • 微动作（手指动、脚尖动、舔嘴唇）
  • 重心转移（从一只脚移到另一只脚）
  • 和环境的微互动（摸杯子、调整衣服、看手表）

沉默的长度（决定这一 shot 的 durationSec 与需要多少微表演支撑）：

长度 效果
0.5–1 秒 思考间隙，自然
2–3 秒 重量感——角色在做决定或消化信息
4–5 秒 极重——观众开始不适，张力拉满
5 秒以上 特意设计的「静止时刻」，必须靠微表情 + 微动作撑住，否则空

角色行为模式（同一角色的「身体签名」）

设计一段表演前，先在脑子里给角色勾一层行为底色，让同一角色在不同 shot 里的表演自然趋同。这只是你写 prompt 时的内部参考准绳，不写进任何字段、不逐镜校验。

维度 内容
习惯动作 不同状态下的标志性动作（思考摸下巴 / 紧张攥拳 / 放松翘脚）
空间习惯 房间里习惯待的位置（靠窗 / 靠门 / 中央 / 角落）
对话距离偏好 和人说话习惯保持多远
情绪泄漏点 最容易暴露真实情绪的部位（手 / 嘴唇 / 眼睛 / 肩膀）
防御姿态 感到威胁时的本能反应（抱臂 / 后退 / 沉默 / 反击）

角色的行为模式就是他的「身体签名」——想清楚它，多镜之间的表演才连得起来。

落进 shot 的 prompt 时

写文戏 shot 的 prompt 字段时：

  1. 先写动作（可观察的物理行为），用上面各表挑具体身体信号。
  2. 设计阶段如需记录表演目的，可在自己草稿里用括号补一句（如「他在犹豫是否要做这个决定」）——但落进 prompt 时删掉括号里的目的说明，只留动作。
  3. 补上这一 shot 的景别 / 运镜（视频镜头），需要微表演的往特写靠。
  4. 一条 prompt 里表演动作别超过 3–4 个——AI 处理不了太密集的表演指令，密了反而全糊。

示例（视频 shot 的 prompt）：

「近景。角色的手停在控制台上方，手指微微张开但没按下去。视线从控制台移向舷窗外的深空，停约两秒。然后闭眼，深吸一口气，肩膀起伏，手指合拢，按下去。」

macOS 第一次打开

当前 macOS 安装包未使用 Apple Developer ID 签名，也未经过 Apple 公证。请只使用本页或 Nomi GitHub 官方仓库的下载链接。

  1. 下载对应的 DMG，把 Nomi 拖到“应用程序”。
  2. 在 Finder 的“应用程序”中右键 Nomi，选择“打开”，再确认“打开”。
  3. 如果仍被拦截，打开“系统设置” → “隐私与安全”，找到 Nomi 后点击“仍要打开”。

仅当 macOS 提示 Nomi“已损坏”时：先确认安装包来自上述官方链接，再打开“终端”运行：

xattr -dr com.apple.quarantine "/Applications/Nomi.app"

不需要、也不要全局关闭 Gatekeeper。
