动作编排

非对抗性动作场景（跑酷/追逐/攀爬/特技/坠落）的动作编排知识——专业动作词汇、环境交互、动作节奏、FPV 追拍、身体力学约束、怎么把动作精确物理化地描述进视频提示词；Nomi 写动作戏 shot 时参考。

这是一份方法论知识库，供你在为 Nomi 的动作戏镜头写 shot.prompt（视频分镜）时参考。产出经应用内 Seedance / 可灵等视频模型生成——不是外部工具，不定义提示词框架（时长/运镜/结构以故事板规划的方法论为准，本文只补「动作本身怎么写清楚」）。

覆盖非对抗性动作序列：一个人跑、跳、翻、爬、坠落、被追。对抗性武打/格斗不在范围内（遇到就按物理动作直接描述）。

核心理念：AI 演不出抽象动作名

视频模型看不懂「帅气地翻过去」「敏捷地逃跑」这类抽象动作名——它只会给你一段软塌塌、没有身体力学的模糊运动。动作必须拆成可拍的物理动作序列：有名字、有出力方向、有身体部位、有落点。

三条纲领：

  1. 物理化描述——用具体身体力学替代笼统词（「跳过去」→「双脚起跳，脚趾扣住窗台边缘，膝盖深屈吸震」）；超出物理约束的设计必须交代成「超人/非人」或给剧情内解释，否则观众出戏。
  2. 流线连续——动量不断流：每个动作的出力喂入下一个动作的入力，暂停 = 断流；环境决定用什么动作，不是反过来。
  3. 节奏成波 + 升级——序列像海浪，蓄力-高潮-呼吸成弧，每一波峰值更高；危险/筹码/代价在时间轴上持续加码。

动作词汇表（把笼统词换成有身体力学的具体动作）

写 prompt 时不写「跳/跑/翻/爬」，而是从下表取一个具体动作 + 它的视觉特征，落成可拍的一句。

地面移动：跑酷步伐（连续跳跃式冲刺，每步瞄准落点）｜受身落地（前脚掌落地、膝髋深屈吸震、无声着地）｜肩滚翻（肩到对侧髋的对角线滚翻卸力）｜四足移动（手脚交替低姿爬行）｜猫式平衡（窄面上双臂展开缓慢精确移动）。

跳跃与精准着地：定点跳（双脚起跳、脚趾扣住边缘、膝盖吸震）｜跨越跳（全速飞越间隙、空中身体伸展、双腿前收准备着地）｜鹤立落地（单脚落窄点、另一腿后伸平衡）｜猫扑（跳向墙面、双脚先触墙、双手抓顶缘悬挂）｜踢墙跳（单脚蹬墙改变方向）。

翻越（Vault）：安全翻（一手撑同侧脚踩上跨过）｜速度翻（全速一手撑侧向飞过）｜懒人翻（侧向一手撑摆双腿横过）｜猴子翻（双手前撑、臀高抬、双腿从臂间穿过，蛙跳式）｜冲刺翻（脚先过、再双手撑推，脚先头后）｜弹跳翻（双脚踩顶、腿部弹射向上）。

墙面技术：垂直跑墙（冲刺后墙面跑 2-3 步、双手抓顶缘）｜水平跑墙（脚踩墙身体倾斜横向奔跑）｜攀上（从悬挂姿态拉身翻上墙顶）｜墙上后空翻（跑墙到峰值蹬离后空翻）｜爆发抓跳（从悬挂爆发向上抓更高把手）。

杆件/栏杆：摆荡释放（杆上摆荡、动量峰值释放飞向下一目标）｜穿杆（脚先/俯冲穿过横杆下间隙）｜引体翻上（引体过渡为撑体，一体动作从杆下升到杆上）｜栏杆定点（跳跃后精准落窄栏杆）｜栏杆滑行（沿栏杆表面滑行）。

空翻旋转（自由跑扩展）：后/前/侧空翻｜前冲后空翻（前向移动同时后翻的弧线轨迹）｜螺旋翻（后空翻 + 360° 扭转）｜蝴蝶踢（身体侧倾、双腿头顶水平扫过）。

环境交互：建筑元素 → 可用动作

先看这镜有什么障碍，再从对应动作里选——环境决定技术：

  • 低墙（腰到胸高）：速度翻/猴子翻/冲刺翻/懒人翻/安全翻/弹跳翻。
  • 高墙（>2m）：垂直跑墙上墙抓缘 → 攀上翻顶；或猫扑到悬挂 → 攀上；踢墙跳改向。
  • 楼间/平台间隙：跨越跳（全速飞跃）/定点跳（短距精准）/猫扑（远端太高够不到顶时抓缘）；大落差着地必接肩滚翻卸力。
  • 栏杆/横杆：摆荡释放/穿杆/引体翻上/栏杆定点/栏杆滑行。
  • 垂直墙面 / 窄巷：踢墙跳/双踢墙跳之字上升/墙上后空翻；窄巷可烟囱攀爬（背靠一墙、脚蹬对墙）。

常用流线（3-5 动作串成连贯段，写进一镜或跨几镜）：楼顶追逐 = 冲刺→跨越跳→肩滚翻→跑酷步伐→速度翻；巷道逃脱 = 冲刺→垂直跑墙→攀上→冲刺翻过女儿墙→下落→肩滚翻；伤痕挣扎 = 跨越跳（差点没够）→单臂抓缘→艰难攀上→跛行→勉强速度翻。自然接续：翻越落地（前向动量）接跑酷步伐；下落落地（下向动量）必接肩滚翻卸力；猫扑悬挂接攀上/踢墙跳离墙。

动作节奏（把动作组织成有张力的序列）

  • 变速（Speed Ramp）：冲击瞬间/决策点/峰值危险/技术展示处减速看清物理细节；过渡移动/重复动作/动量积累处加速制造推力。写进 prompt 就是描述这一拍是「加速三步蹬地」还是「慢动作起跳、身体脱离楼沿」。
  • 呼吸（Breath）：高速段之间插 0.5-2s 微暂停（反应特写/大冲击前的静止「尖叫前的吸气」/远景重建空间），让观众喘息、重新定位。
  • 升级（Escalation）：五条轴上持续加码——环境危险（地面→楼顶→真空跨越）/个人筹码（为任务→为生存）/身体代价（生龙活虎→负伤挣扎）/选项收窄（多条逃路→死角）/对手能力。常见错误是每拍同强度 = 没有方向感。
  • 三的法则：给角色三件事——第一次相对顺利（建立方法）、第二次出错（引入复杂度）、第三次要创造性即兴 + 最大筹码。
  • 值得慢放的瞬间：首次重大撞击/优势翻转那一击/致命一击/出乎意料的技巧/环境破坏。连击只慢放第一下、标准位移不慢放。

FPV 追拍（镜头与被追者的关系）

追拍是动作戏的常见镜头语言，写 prompt 时点明镜头与主体的位置关系：

  • 位置：背后追踪（你是追猎者，最常见）｜前方反向（你在被追，展示面部恐惧/决心/疲惫）｜侧面并行（强调奔跑姿态）｜上方俯瞰（揭示路线与前方障碍）｜不可能角度（穿间隙/从腿下/窗洞穿越，超现实沉浸）。
  • 距离定情绪：超近 0.5-1m = 恐慌无处可逃；近 1-3m = 标准动作追逐张力；中 3-8m = 语境与投入兼顾；远 8-15m = 渺小脆弱。
  • 速度关系：速度匹配（主体钉在画面、世界移动，持续张力）｜镜头追近（威胁升级、不可避免感）｜镜头落后（主体拉开距离、逃脱感）｜镜头飞过（超越主体、揭示前方）。
  • 第一人称 POV 描述法：在动作链里点明「胸前高度 POV、画面下沿可见角色背部局部（披风下摆/发尾/肩胛）」，把视角锚成第一人称追拍。
  • 一镜到底：视频模型生成不出真正的一镜到底——拆成多镜，每镜结尾安排自然遮挡物（楼角/披风/柱子/蒸汽）完全盖满画面，下一镜开头从遮挡后揭示新画面，靠首尾帧承接、后期在遮挡帧硬切，观众感知为连续运动。

身体力学约束（物理硬底线，超出必须交代）

违反这些观众会出戏；要突破就明确写成「超人/非人」或给剧情内解释。

  • 跳跃距离：跑酷定点跳普通人 1.0-1.5m、训练者 2.0-2.5m、极限约 2.76m；助跑跳远训练者 5-7m。最佳起跳角 20-30°（不是 45°），水平速度比角度更重要；从高处往低处跳能多出 2-4m 水平距离。
  • 跑墙：最大高度增益约 1.5 倍立定垂直跳，接触墙面 0.5-1.5s（2-3 步），接近角 30-60°；关键是先离地再触墙，水平动量靠向下蹬踏转成向上。
  • 着地：0.6-1.0m 前脚掌屈膝精准着地；1.8m 以上必须肩滚翻卸力；安全最大着地高度约 3m，更高只限专业练习者。落差大不写卸力 = 假。
  • 负重：每加 5kg 装备跳跃距离减 5-10%、冲击等比增加。叙事上重装角色用蛮力型移动（撞穿/翻越）、轻装角色用流畅型跑酷——这本身就是角色对比。
  • 速度：普通人冲刺约 6.3 m/s、运动员 8-10 m/s；含障碍的跑酷比平地慢 30-50%（每个障碍都要减速-技术-再加速）。
  • 体力四阶段衰减（按叙事节拍触发，不按时钟）：巅峰（流畅高效、路线最优）→ 裂痕（经历 2-3 障碍后落地略重、可闻喘息、微停顿变长）→ 退化（受伤后踉跄、选更简单路线、翻越从猴翻降级为安全翻、开始手滑踩偏）→ 意志力（最后一搏、放弃技术直接硬爬硬跳）。阶段转换本身就是戏剧时刻（第一次踉跄 = 观众意识到他快撑不住）；可肾上腺素短暂回升再跌更深；追赶者也要编排衰减，否则悬念失真。短追逐只走「巅峰→裂痕」，长追逐走完四阶段。

写给视频模型的额外注意（i2v 能力边界）

  • 表现好：走/跑/舞蹈/简单动作、慢到中速镜头运动、短片段、物理合理的单一运动。
  • 容易翻车：快速动作偶发伪影、复杂物理（跑+抓物+镜头跟随同时）、多元素交互、遮挡关系、长片段时间一致性、参考图没展示的表面（从正面照推背面）。命中这些就简化动作、拆片段、或用道具特写单独锁。
  • 每镜一个主要动作节拍——单次翻越/单次跳跃/单次镜头运动，别把一长串动作硬塞进一镜被压成糊。先用首帧图锁住角色姿态/光照/构图，视频只添加运动。
  • 动作中拼接最宽容（运动掩盖片段间的细微不一致）；在冲击瞬间、方向变化、遮挡时刻切镜。

macOS 第一次打开

当前 macOS 安装包未使用 Apple Developer ID 签名，也未经过 Apple 公证。请只使用本页或 Nomi GitHub 官方仓库的下载链接。

  1. 下载对应的 DMG，把 Nomi 拖到“应用程序”。
  2. 在 Finder 的“应用程序”中右键 Nomi，选择“打开”，再确认“打开”。
  3. 如果仍被拦截，打开“系统设置” → “隐私与安全”，找到 Nomi 后点击“仍要打开”。

仅当 macOS 提示 Nomi“已损坏”时：先确认安装包来自上述官方链接，再打开“终端”运行：

xattr -dr com.apple.quarantine "/Applications/Nomi.app"
